# 📥 _INBOX — 아무거나 던져넣는 곳

> 대표님이 파일을 어디 둘지 고민하지 마세요. **여기에 그냥 넣으면** 됩니다.
> 그러면 AI가 파일을 분석해서 알맞은 프로젝트·폴더로 자동 분류합니다.

## 쓰는 법

1. 분류할 파일·폴더를 이 `_INBOX/` 안에 **드래그해서 넣는다** (몇 개든).
2. 클로드에게 **"인박스 분류해줘"** 또는 **"파일 분류해줘"** 라고 한다.
   - (또는 정기 예약이 설정돼 있으면 알아서 돌아갑니다.)
3. AI가:
   - 각 파일을 열어 내용을 분석하고
   - **확신 있는 건 바로** 알맞은 위치로 이동
   - **애매한 건 모아서 한 번에 질문** ("이 파일은 입력자료예요, 산출물이에요?")
4. 끝나면 [`_분류로그.md`](_분류로그.md)에 "무엇을 어디로 옮겼는지" 다 기록됩니다. 되돌리기 가능.

## 규칙
- 분류 기준: [`../_core/VRIN_FILE_CLASSIFICATION.md`](../_core/VRIN_FILE_CLASSIFICATION.md)
- 폴더 표준: [`../_core/VRIN_PROJECT_STANDARD.md`](../_core/VRIN_PROJECT_STANDARD.md)
- 분류 못 한 파일은 [`_미분류/`](_미분류/)에 보관되고 질문 목록에 올라갑니다.
- **삭제는 절대 안 함** — 이동만. 충돌 나면 이름 뒤에 버전을 붙입니다.

## 폴더
- `_미분류/` — 어느 프로젝트인지 판단 못 한 파일이 잠시 머무는 곳
- `_분류로그.md` — 이동 내역 (자동 생성)
