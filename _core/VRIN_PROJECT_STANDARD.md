### 명명 규칙 (업그레이드 — 기존 `[N170]` 브랜드코드 폐기)

```
{연도}-{번호}_{고객사}_{사업명}
```

- 법인 구분 필요 시 `00_관리/_현황.md`에 메타(시앤피/대우)로 기록

### 2.1 세부 폴더 가이드 — 00~05 안을 어떻게 나누나 ⭐

**3대 원칙**
1. **최상위는 00~05 고정** — 새 번호폴더(`10_홈페이지` 등)나 프로젝트 루트에 작업파일을 흩뿌리지 **않는다**. (예: 홈페이지 시안은 `03_작업실/홈페이지_시안/`)
2. **세부 폴더는 한글 `번호_이름`** — 정렬과 의미를 동시에. 예) `01_제안`, `02_착수`, `03_수행`.
3. **깊이 2~3단계** — 과도한 중첩 금지. 정해진 틀을 강제하기보다, **프로젝트 상황에 맞게 담당자(스쿼드 리드·@CoS)가 한글로 체계 구성**.

**폴더별 권장 세부 (프로젝트에 맞게 가감)**
| 폴더 | 한글 세부 폴더 예시 |
|------|---------------------|
| 00_관리 | `_브리프.md` `_스쿼드.md` `_현황.md`(필수) · `보고및회의` `일정` `계약·행정` |
| 01_입력자료 | 출처·종류별 — `고객제공` `회의자료` `공고·RFP` |
| 02_지식리서치 | `참고자료` `조사분석` `작업위키` |
| 03_작업실 | 컨설팅·연구형: `01_제안` `02_착수` `03_수행` `04_보고`(또는 모듈별) · 개발형: 시안·기능별 폴더 |
| 04_산출물 | 납품 단위별 — `01_보고서` `02_매뉴얼` … + `.quality-log.md` |
| 05_보관 | `구버전` `폐기` `이전시안` |

**핵심 동선**: 작업 중 초안·시안 → **03_작업실** · 최종 납품본 → **04_산출물** · 구버전·폐기 → **05_보관**.
(개발형 유형B의 "소스코드 루트" 규칙은 §3 참조 — 프로젝트 전체가 코드일 때만. 복합 프로젝트의 홈페이지 등은 03/04 안에 둔다.)

**더 상세히** (분할 축·유형별 프리셋·Lazy 신설·자동분류 연계): [`VRIN_FOLDER_SUBSTRUCTURE.md`](VRIN_FOLDER_SUBSTRUCTURE.md).

### 2.2 기준이 바뀌면? (생애주기 · 기준선)
RFP·과업지시서·제안서는 **출발점이지 영원한 정답이 아니다.** 착수·중간·최종 보고를 거치며 합의로 바뀐다.
**현행 기준 = 최신 합의본**을 `00_관리/_기준선.md`로 추적(원본 보존). → [`VRIN_PROJECT_LIFECYCLE.md`](VRIN_PROJECT_LIFECYCLE.md).

## 3. 두 가지 프로젝트 유형 (같은 척추, 다른 살)

### 🟦 유형 A — 컨설팅·연구·사업형 (기본)
- 모든 작업 `03_작업실/`, 최종 `04_산출물/`
- **컨설팅 오버레이**(대표님 N170 흐름 — `03_작업실/` 내 단계 폴더 선택):
  `01_제안 → 02_보고회 → 03_실무진회의 → 04_수행준비 → 05_수행 → 06_성과공유 → 07_보고서작업`

### 🟩 유형 B — 개발형(소프트웨어)
- 소스코드는 **루트**(`app/ lib/ package.json`) — 빌드도구 요구
- 번호폴더는 비코드 자산만: `00_관리 / 01_입력자료 / 02_지식리서치 / 04_산출물`
- 예: 나라장터 웹앱, 홈페이지, SaaS, 진단도구

## 4. 스쿼드 — 프로젝트는 부서에서 차출한다

```
프로젝트 생성 → @CoS가 과업 분석 → 부서에서 팀원 차출 → .claude/agents/ 배치
            → 00_관리/_스쿼드.md 기록 → 7단계 수행 → 종료 시 해산(부서 복귀)
```
- 프로젝트 `.claude/agents/` = **그 프로젝트의 실제 스쿼드 명단**
- 필요 전문가 없으면 즉석 신설(계약직) → 검증되면 부서 정규직 승격 (↓5)

**승격 판정(@CLO 분기)**: 2개+ 프로젝트서 필요? @BAR 통과 3회+? 기존과 중복? → 글로벌 승격 or 로컬 유지 or 폐기.

**프로젝트 종료 의식**: ① 중간작업물 보존(지식자산) ② 04_산출물→루트 outputs 인덱스 ③ 재사용 지식→`_wiki/` 환원 ④ 폴더째 `projects/_완료/{연도}/` 이동.
