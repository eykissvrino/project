# Legal Consulting Skill

> 한국 법률 환경 기반 컨설팅 프로젝트의 법무 검토·문서화·리스크 진단 스킬
> 호출 에이전트: **Themis** (정의의 여신)

## 1. 적용 범위

### 시앤피컨설팅이 자주 마주치는 법적 이슈

| 영역 | 주요 법령 | 빈도 |
|------|----------|------|
| **계약 관리** | 민법, 상법, 하도급법, 공정거래법 | 매 프로젝트 |
| **근로·인사** | 근로기준법, 남녀고용평등법, 산업안전보건법 | HR 프로젝트 |

| **컨설팅 산출물** | 저작권법, 산업기술보호법 | 산출물 납품 |
| **공공 사업** | 국가계약법, 지방계약법, 입찰 관련 규정 | 정부·공공기관 용역 |

## 2. 핵심 작업 유형

### 2.1 계약서 검토 (Contract Review)

#### 표준 점검 항목 (12종)
1. **계약 당사자** — 법인격, 대표자, 권한 범위
2. **목적·범위** — 산출물·서비스 정의의 명확성
3. **대금·지급 조건** — 금액, 분할, 지연이자, 부가세
4. **납품·검수** — 일정, 검수 기준, 변경 절차
5. **저작권·소유권** — 산출물 권리귀속, 라이선스 범위
6. **비밀유지** — 범위, 기간, 위반 시 책임
7. **개인정보** — 수집·이용·제3자 제공·국외이전
8. **하자보수·A/S** — 기간, 범위, 비용 부담
9. **계약 변경·해지** — 사유, 절차, 위약금
10. **손해배상·면책** — 한도, 제외 사유, 보험
11. **분쟁 해결** — 준거법, 관할 법원, 중재 합의
12. **특수 조항** — 보증, 청렴, 갑·을 우월적 지위 남용 방지

#### 시앤피 컨설팅 계약 특이사항
- **공공 용역**: 국가계약법상 표준계약서 우선 사용. 특약 조항만 추가 검토.
- **민간 컨설팅**: 산출물 권리 귀속과 비밀유지가 핵심.
- **데이터 분석**: 개인정보보호법상 동의·익명화·파기 절차 명시 필수.

### 2.2 NDA / 비밀유지계약

#### NDA 핵심 5요소
1. **비밀정보 정의** — 무엇이 비밀인가? (구두·서면 포함 여부)
2. **사용 목적 제한** — 특정 프로젝트로만 한정
3. **유효기간** — 통상 3~5년, 영업비밀은 영구
4. **반환·파기** — 종료 시 자료 처리 절차
5. **위반 시 책임** — 위약금·손해배상·금지청구

#### 작성 시 유의
- 일방형 NDA (one-way) vs 상호형 NDA (mutual) 구분
- "관련 회사" 범위 명시 (자회사·계열사 포함 여부)
- 법적 강제 공개(법원·행정청 요구)는 예외 처리

### 2.3 근로·HR 법무

#### 자주 검토하는 이슈
| 사안 | 핵심 법령 | 시앤피 관점 |
|------|----------|------------|
| 근로계약서 작성 | 근로기준법 17조 | HR 컨설팅 산출물 핵심 |
| 취업규칙 변경 | 근로기준법 94조 | 불이익 변경 시 동의 필요 |
| 임금체계 개편 | 근기법, 통상임금 판례 | P2026-012 HRM 임금성과평가 |
| 직장 내 괴롭힘 | 근기법 76조의2 | HR 컨설팅 진단 항목 |
| 비정규직 활용 | 기간제법, 파견법 | 직무분석·조직설계 시 |
| 산업안전 | 산안법, 중대재해처벌법 | 안전관리 컨설팅 |

#### 2026년 주요 법 개정 사항 (확인 필요)
- 중대재해처벌법 50인 미만 사업장 확대 적용
- 근로기준법 4.5일제·연차 관련 동향
- 외국인 고용허가제 변경 사항

### 2.4 장애인 고용 (P2026-001 핵심)

#### 핵심 법령
- **장애인고용촉진 및 직업재활법** — 의무고용률 (2026년 민간 3.1%, 공공 3.6%)
- **장애인차별금지법** — 정당한 편의제공 의무
- **장애인복지법** — 장애인 정의·등급

#### B2B 사업 시 법적 체크포인트
1. **연계고용 부담금 감면** — 한국장애인고용공단 인증 필수
2. **표준사업장** — 인증 요건·세제 혜택
3. **직무재설계 컨설팅** — 정당한 편의제공 위반 방지
4. **장애인 개인정보** — 일반 개인정보보다 민감 (보호 강화 필요)

### 2.5 개인정보 보호

#### 컨설팅 프로젝트에서 자주 발생
- **설문조사** — 동의 양식, 수집 항목, 보유 기간
- **인사 데이터 분석** — 가명처리, 익명화 기준
- **HR 평가 시스템** — 자동화된 결정에 대한 권리(GDPR 22조 유사)
- **국외 이전** — 클라이언트 본사가 해외인 경우

#### 표준 동의서 7요소
1. 수집·이용 목적
2. 수집 항목
3. 보유·이용 기간
4. 동의 거부권 및 거부 시 불이익
5. 처리위탁 (외부 분석 시)
6. 제3자 제공
7. 정보주체 권리·행사 방법

## 4. 작업 프로세스

### 4.1 계약서 검토 표준 절차

```
1. 계약 목적·당사자 확인
   ↓
2. 12종 점검 항목 순차 검토
   ↓
3. 리스크 등급 부여 (상/중/하)
   ↓
4. 수정 권고안 작성 (Track Changes 또는 의견서)
   ↓
5. Ralph 루프 검증 (놓친 조항 없는지)
   ↓
6. 최종 보고
```

## 5. 한계 및 외부 자문 권고

### 이 스킬의 한계
- **법률 자문 자격 없음**: 본 스킬은 컨설턴트의 **사전 점검 도구**일 뿐, 정식 법률 자문이 아님
- **판례·해석 변화**: 최신 판례·행정해석은 외부 확인 필요
- **개별 사안 특수성**: 유사해 보여도 사실관계에 따라 결론 달라짐

### 외부 자문이 반드시 필요한 경우
- 분쟁 발생 또는 임박
- 거액(예: 5천만원 이상) 계약
- 중대재해·인명 관련 사안
- 새로운 법령·판례 적용이 모호한 경우
- 클라이언트가 법무법인 의견을 요구하는 경우

→ 시앤피컨설팅의 외부 법무 파트너에게 의뢰 (담당자에 따라 변경 가능)
