> B2B 컨설팅 업체의 브랜드 자산 구축·네이밍·마케팅 메시지 제작 스킬

## 1. 적용 범위

### 시앤피컨설팅의 브랜드 자산
- **시앤피컨설팅** — 모(母) 브랜드. HRM/HRD/OD 전문 컨설팅
- **이음** — 장애인 HR 솔루션 사업 브랜드 (P2026-001)
- **(신규)** — 직업능력컨설팅본부 (P2026-005)
- **(잠재)** — AX 진단도구, HR 데이터 분석 등 신규 사업 브랜드

### 브랜딩이 필요한 시점
| 상황 | 산출물 |
|------|--------|
| 신규 사업 런칭 | 브랜드명·로고·태그라인·키 메시지 |
| 제안서 작성 | 차별화 메시지·핵심 가치·고객 베네핏 |
| 홈페이지·랜딩 | 메인 카피·브랜드 스토리·CTA 문구 |
| 제휴·MOU | 협력 가치 제안·공동 메시지 |
| 클라이언트 미팅 | 1-pager·엘리베이터 피치 |

## 2. 핵심 작업 유형

### 2.1 브랜드 정체성 설계 (Brand Identity)

#### 5단 구조 — Why → What → How → Voice → Visual
1. **Why (브랜드 목적·미션)** — 왜 존재하는가
2. **What (제공 가치·약속)** — 무엇을 주는가
3. **How (차별화 요소)** — 어떻게 다른가
4. **Voice (브랜드 보이스·톤)** — 어떻게 말하는가
5. **Visual (비주얼 아이덴티티)** — 어떻게 보이는가

#### 시앤피컨설팅 브랜드 보이스 가이드
- **신뢰**: 전문성·근거 기반·검증된 프레임워크
- **공감**: 인간 중심·현장 이해·실용성
- **혁신**: 데이터·AI·미래 지향
- **금기**: 과장 표현, 자신감 결여, 모호한 단어, 영어 남발

### 2.2 네이밍 (Naming)

#### 컨설팅·HR 도메인 네이밍 원칙
1. **한국어 친화**: 한글 발음·의미가 직관적
2. **3음절 이하 권장**: 기억·발음 쉬움 (예: "이음", "온잡(OnJob)")
3. **도메인 가능**: .com / .co.kr 확보 가능 여부 사전 확인
4. **상표 검색**: 키프리스(kipris.or.kr) 사전 조회
5. **부정 연상 회피**: 동음이의어·외국어 부정 의미 확인
6. **스케일 여지**: 한 영역으로만 좁히지 않기 (예: HR 전체 vs 직무분석만)

#### 네이밍 5단계 프로세스
```
1. 키워드 발산 (50~100개)
   - 핵심 가치 → 한자·한글·영어·은유 분기
2. 결합·변형 (30~50개)
   - 합성어, 어근 변형, 운율
3. 1차 스크리닝 (10~15개)
   - 발음·기억·의미 직관성
4. 검증 (5~7개)
   - 상표 검색, 도메인, 부정 연상
5. 최종 선정 (1~2개)
   - 의사결정자 정성 평가
```

#### 카테고리별 네이밍 패턴
| 카테고리 | 패턴 | 예시 |
|----------|------|------|
| **HR 솔루션** | 사람·연결·성장 어휘 | 이음, 동행, 잇다 |
| **AI/디지털** | 영문 두음어, 알파벳 | AX-Lens, OnJob |
| **컨설팅·서비스** | 가치 단어 + 명사 | 핵심설계, 지혜로움 |
| **데이터·진단** | 측정·통찰·렌즈 | InsightHR, 가늠 |

### 2.3 태그라인·슬로건

#### 좋은 태그라인 4조건
1. **짧다** (5~12자 권장)
2. **고객 베네핏 명확** ("우리 잘남" → "당신 잘됨")
3. **차별점 함의**
4. **3년 이상 유효**

#### 예시 비교
- ❌ "최고의 HR 컨설팅 파트너" (자랑형, 차별점 없음)
- ✅ "사람에서 시작해 성과로 끝납니다" (가치 + 결과)
- ❌ "AI 기반 데이터 분석" (기능 나열)
- ✅ "데이터가 사람을 이해할 때" (감성 + 본질)

### 2.4 핵심 메시지 (Key Messages)

#### B2B 컨설팅 메시지 3층 구조
```
Layer 1: Headline (1줄)
   ↓ 무엇을 약속하는가
Layer 2: Body (3~5줄)
   ↓ 왜 우리에게 맡겨야 하는가 (근거 3개)
Layer 3: Proof (사례·수치·인증)
   ↓ 신뢰의 증거
```

#### 클라이언트 페르소나별 메시지 차별화
| 의사결정자 | 핵심 관심 | 메시지 톤 |
|-----------|----------|----------|
| **CEO/CHRO** | ROI, 전략적 가치 | 비전·임팩트 중심 |
| **인사팀장** | 실행 가능성, 리스크 | 프로세스·근거 중심 |
| **현업 부서장** | 업무 부담, 효과 | 실용·체감 중심 |
| **구매·재무팀** | 비용, 일정 | 명확성·약속 중심 |

### 2.5 마케팅 콘텐츠 제작

#### 컨설팅 B2B에서 효과적인 콘텐츠
| 유형 | 목적 | 빈도 |
|------|------|------|
| **인사이트 리포트** | 전문성 입증·리드 발굴 | 분기 1회 |
| **케이스 스터디** | 신뢰·구체성 | 프로젝트 완료 후 |
| **컬럼/기고** | 사고 리더십 | 월 1~2회 |
| **랜딩페이지** | 전환 (CTA) | 사업별 1개 |
| **1-pager 제안 요약** | 첫 미팅 도구 | 사업별 1개 |
| **카드뉴스/인포그래픽** | SNS·LinkedIn 확산 | 월 2~4회 |

#### 컨설팅 콘텐츠 7원칙
1. **데이터로 시작** — 통계·트렌드
2. **고객 문제 정의** — 공감
3. **프레임워크 제시** — 차별화
4. **사례 제시** — 신뢰
5. **실용 액션** — 가치
6. **CTA 명확** — 다음 단계
7. **브랜드 보이스 일관** — 일관성

## 3. 산출물 유형

| 산출물 | 형식 | 일반 분량 |
|--------|------|----------|
| 브랜드 정체성 문서 | docx, pdf | 10~20p |
| 네이밍 옵션 리스트 | docx, xlsx | 5~10개 후보 + 평가표 |
| 태그라인 후보 | docx | 5~10개 + 추천 1~2 |
| 핵심 메시지 가이드 | docx | 3~5p (페르소나별) |
| 1-pager 소개서 | pdf, pptx (1슬라이드) | 1p |
| 랜딩페이지 카피 | docx | 메인+세부 4~6 섹션 |
| 브랜드 보이스 가이드 | docx | 5~10p (Do/Don't) |
| 마케팅 콘텐츠 (블로그·컬럼) | md, docx | 800~2,000자 |
| 카드뉴스 시리즈 | png 또는 카드뉴스 스킬 호출 | 8~12장 |

## 4. 작업 프로세스

### 4.1 신규 브랜드 런칭 표준 절차

```
1. 디스커버리 (이해)
   - 사업 목적·타깃 고객·경쟁사 5종 분석
   ↓
2. 브랜드 정체성 (Why·What·How·Voice·Visual)
   ↓
3. 네이밍 (5단계 프로세스, 50→30→15→7→2)
   ↓
4. 메시지 시스템 (3층 구조 + 페르소나별 변주)
   ↓
5. 1-pager + 랜딩 카피 + 보이스 가이드 작성
   ↓
6. @BAR 품질검증 (보이스 일관성·차별화 점검)
   ↓
7. 최종 가이드 문서화
```

### 4.2 제안서 브랜딩 메시지 작성

```
1. 클라이언트 분석 (산업·규모·과제)
   ↓
2. 의사결정자 페르소나 정의 (CEO·CHRO·실무 등)
   ↓
3. 핵심 메시지 3층 (Headline·Body·Proof)
   ↓
4. 차별화 포지셔닝 (경쟁사 대비)
   ↓
5. 제안서 도입부·결론부 카피 작성
```

## 5. 시앤피컨설팅 브랜드 가드레일

### 사용 권장 단어
- 본질·핵심·근거·구조·체계·연결
- 사람·현장·성과·실용
- 함께·동행·이음·진단·설계

### 사용 회피
- "최고", "유일", "완벽" (검증 불가)
- "혁명적", "파괴적" (과장)
- 영어 남발 (필요 시 한글 우선, 영문 병기)
- 형식적 인사말 ("귀사의 무궁한 발전을 기원하며" 등)

### 시앤피 브랜드 톤 4축
| 축 | 비중 | 의미 |
|----|------|------|
| 전문성 | 40% | 검증된 프레임워크·데이터·근거 |
| 인간성 | 30% | 사람·현장·공감 |
| 혁신성 | 20% | AI·데이터·디지털 |
| 친근함 | 10% | 무게는 잡되 거리감 없음 |
