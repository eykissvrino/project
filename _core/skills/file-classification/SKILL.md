# 파일 자동분류 스킬 (File Classification)

> 던져진 파일을 분석 → 알맞은 위치로 분류 → 하위폴더 체계화. 두뇌: [`_core/VRIN_FILE_CLASSIFICATION.md`](../../VRIN_FILE_CLASSIFICATION.md)
> 운영원칙: **확신 자동 / 애매 질문 / 이동 전 로그 / 삭제 금지**

## 언제
- 대표님이 "인박스/파일 분류해줘", "정리해줘" 라고 할 때
- 정기 예약(routine)이 호출할 때
- 특정 폴더를 지정하면 그 폴더를 대상으로 ("03_작업실 정리해줘")

## 대상 (두 종류의 인박스)
- **루트 `_INBOX/`** — 어느 프로젝트인지 모를 때. STEP 1(프로젝트 판정)부터 전부 수행.
- **프로젝트별 `projects/<프로젝트>/_INBOX/`** — 이 프로젝트 확정. **STEP 1 생략**, 그 프로젝트 폴더(00~05) 안에서만 분류.
  - "여기 분류해줘"·"이 프로젝트 인박스" → 대화 맥락의 프로젝트 인박스를 대상으로.
- 공통 제외: `_미분류/`·`_분류로그.md`·`_질문대기.md`·`README.md`
- 지정 시: 사용자가 말한 폴더

## 실행 절차 (반드시 순서대로)

### STEP 0. 준비
1. 분류 기준서 [`_core/VRIN_FILE_CLASSIFICATION.md`](../../VRIN_FILE_CLASSIFICATION.md)를 읽는다.
2. **대상 인박스 종류 판별**:
   - 경로가 `projects/<프로젝트>/_INBOX/` 면 → 프로젝트 확정, **STEP 1 생략**. 분류 범위는 그 프로젝트 폴더 내부.
   - 루트 `_INBOX/` 면 → STEP 1부터. **프로젝트 목록 실시간 갱신**: `projects/` 스캔 + 신호 약하면
     후보 프로젝트의 `CLAUDE.md`/`README.md`를 읽어 키워드 보강(기준서 표는 스냅샷일 뿐).
3. 대상 폴더의 파일 목록을 만든다 (재귀 1단계). 빈 폴더면 "정리할 파일 없음" 보고 후 종료.

### STEP 1. 각 파일 분석
파일마다:
1. 확장자에 맞는 방법으로 **내용을 읽는다** (기준서 §6 표: hwp-mcp / pdf / docx / pptx / xlsx / Read).
   대용량·바이너리는 파일명+확장자만으로 판정.
2. **STEP 1(프로젝트) → STEP 2(폴더 00~05) → STEP 3(하위폴더)** 순으로 목적지를 정한다 (기준서 §2~4).
3. **확신도**를 매긴다 (기준서 §5): High / Mid / Low.
   - 유형 B(개발) 프로젝트의 소스코드는 루트행 (기준서 §3).

### STEP 2. 분류계획표 제시
이동 전에 반드시 표로 보여준다. 자동분과 질문분을 나눠서:

```
## 📂 분류 계획 (n개)

### ✅ 자동 이동 (확신) — m개
| 파일 | → 목적지 | 근거 |
|---|---|---|
| 상하수도협회_직무기술서_초안.hwp | projects/P2026-006.../03_작업실/ | 고객사명+'초안' |

### ❓ 확인 필요 — k개
| 파일 | 후보 | 무엇이 애매한가 |
|---|---|---|
| 보고서.docx | P2026-008 / 03 또는 04 | 초안인지 최종인지 불명확 |
```

- **자동 이동분이 있으면 바로 진행**한다(대표님이 "확신 건 자동"을 승인함). 단 표는 항상 먼저 보여준다.
- **질문분(❓)은 모아서 한 번에** 묻는다. AskUserQuestion 또는 표로. 파일마다 따로 묻지 않는다.

### STEP 3. 이동 실행
1. 목적지 폴더·하위폴더가 없으면 **생성**한다 (`mkdir -p`). 하위폴더 신설 규칙은 기준서 §4.
2. 파일을 **이동(mv)**한다. **복사 아님**(원본이 _INBOX에 남지 않게).
3. **이름 충돌 시 덮어쓰기 금지** → 대상에 같은 이름 있으면 `_v2`·`_YYYYMMDD` suffix.
4. **삭제 금지** — 폐기로 보이는 것도 지우지 말고 해당 프로젝트 `05_보관/`으로.

### STEP 4. 로그 + 보고
1. 이동한 모든 항목을 `_INBOX/_분류로그.md` 표에 1줄씩 추가
   (`날짜시각 | 원본 | 대상 | 확신 | 근거`). 날짜는 환경의 currentDate 사용.
2. 질문분은 답을 받은 뒤 처리하고 마찬가지로 로그.
3. 마무리 요약: 자동 n개 / 질문대기 k개 / 미분류 보류 j개, 생성한 하위폴더 목록.

## 안전 규칙 (절대 준수)
- **삭제·덮어쓰기 금지.** 이동만. 충돌은 suffix.
- **`01_입력자료`(고객 원본)는 변형 금지** — 위치만 정리.
- 어느 프로젝트인지 모르면 `_INBOX/_미분류/`에 두고 질문. 추측 이동 금지.
- 이동 전 분류계획표를 **항상** 먼저 출력. (자동분이라도 보여준 뒤 진행)
- 모든 이동은 로그에 남겨 **되돌리기 가능**하게.

## 되돌리기
"방금 분류 되돌려줘" → `_분류로그.md` 최신 항목들을 역순으로 `대상 → 원본` 이동, 로그에 취소 표시.
