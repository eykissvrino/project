# VRIN Cockpit — 실시간 현황 대시보드 (로컬 HTML)

> 전체 조직의 프로젝트·스쿼드·업무 현황을 한 화면에서 실시간으로 본다.
> **방식**: 로컬 HTML (`cockpit.html`) — 상태 파일에서 자동 생성·갱신.
> **상태**: v1.0 설계 · **작성**: 2026-06-15 · 상위: [`VRIN_ORG_SYSTEM.md`]

---

## 1. 데이터 흐름 (single source → 생성)

```
각 프로젝트 00_관리/_현황.md  (프론트매터 메타)
        ↓ @CoS 자동 집계
projects/_대시보드.md  (포트폴리오 통합)
        ↓ 렌더 스크립트 (scripts/build-cockpit)
cockpit.html  ← 브라우저로 열면 실시간 현황
```

### 프로젝트 현황 메타 표준 (`00_관리/_현황.md` 프론트매터)
```yaml
---
project: 2026-05_상하수도협회_직무분석
client: 한국상하수도협회
type: 컨설팅            # 컨설팅 | 연구 | 사업 | 개발
phase: 4               # 1~7 (Frame·Plan·Produce·Critique·Validate·Deliver·Learn)
status: green          # green 정상 | amber 주의 | red 지연
lead: "@HR"
squad: ["hr-job","res-web","del-report"]
progress: 55           # %
next: "중간보고회 자료"
due: 2026-06-22
updated: 2026-06-15
---
```

## 2. Cockpit 화면 구성

```
┌─ VRIN COCKPIT ──────────── 활성 6 · 🟢4 🟡1 🔴1 · 이번주 마감 2 ─┐
│                                                                    │
│ [KPI 바]  활성 프로젝트 · 단계분포 · 마감임박 · 위키 페이지수        │
│                                                                    │
│ [프로젝트 포트폴리오 표]                                            │
│  프로젝트         단계 게이지     스쿼드          상태   다음액션    │
│  상하수도_직무분석  ●●●●○○○ 4/7  @HR·res·del    🟢    중간보고     │
│  장애인_HR솔루션    ●●●○○○○ 3/7  @PT·hr·gtm+2   🟡    제품정의     │
│  ...                                                               │
│                                                                    │
│ [부서 가동률 바]  @HR 80% · @PT 70% · @RES 90% · @DEL 50% ...       │
│ [위키 건강]  페이지 N · 최근 Ingest · 미해결 모순 M · 고아 K        │
└────────────────────────────────────────────────────────────────────┘
```

### 구성 요소
1. **KPI 바** — 활성 수, 단계 분포, 마감 임박, 위키 페이지수
2. **포트폴리오 표** — 프로젝트별 7단계 게이지 · 스쿼드 칩 · RAG 상태 · 다음 액션 · 마감
3. **부서 가동률** — 어느 부서가 몇 개 프로젝트에 차출됐나 (과부하 감지)
4. **위키 건강** — `wiki_lint` 결과 (모순·고아·공백)

## 3. 기술 사양
- **단일 HTML 파일** (의존성 0, 더블클릭 실행) — flat 디자인, CSS 변수
- **갱신**: `_현황.md` 변경 시 또는 "현황 보여줘" → @CoS가 재생성
- **3-디바이스**: 데스크탑·노트북에서 cockpit.html. 폰은 Notion 미러(선택, Phase 4)
- **소스 = 상태 파일** — 대시보드는 항상 프로젝트 실제 상태를 반영 (수기 입력 X)
