# 🛰️ VRIN 에이전트 관제탑

> 대표님의 AI 회사(43명 에이전트)가 **지금 무엇을 하고 있는지** 실시간으로 보는 로컬 대시보드.
> 외부 설치 0개 · 인터넷 불필요 · 데이터는 이 PC에만 저장.

---

## 1. 켜는 법 (제일 중요)

**`START-대시보드.bat` 파일을 더블클릭**하세요.

- 검은 창이 하나 뜨고, 2초 뒤 브라우저에 대시보드가 자동으로 열립니다.
- 주소는 항상 **http://127.0.0.1:9777** (즐겨찾기 해두셔도 됩니다).
- **끄려면**: 그 검은 창을 닫으면 됩니다.
- 켜둔 채로 Claude Code에서 에이전트를 부리면, 활동이 실시간으로 화면에 흐릅니다.

> 처음 한 번 "한번 보고 싶다" 하실 땐, 켠 뒤 검은 창은 그대로 두고 브라우저만 보시면 됩니다.

## 2. 화면 구성 (3개 탭)

| 탭 | 내용 |
|----|------|
| ⚡ **실시간 활동** | 왼쪽: 활동 피드(누가·무엇을, 최신순). 오른쪽: "지금 일하는 중"(최근 90초 작동 에이전트) |
| 👥 **에이전트 갤러리** | 43명 전원을 부서별 카드로. 클릭하면 역할·모델·누적 활동 상세. 검색창으로 이름·역할·부서 검색 |
| 🗂️ **세션 히스토리** | 작업 단위(세션)별 기록 — 투입된 에이전트·사용 도구·활동 수·소요 시간 |

상단 KPI 바: 지금 작동 중 · 오늘 활동 수 · 세션 수 · 투입된 에이전트 · 전체 직원(43명).

---

## 3. 에이전트 캐릭터 이미지 넣기 (AI 일러스트)

지금은 각 에이전트가 **이모지 + 부서 색상**으로 표시됩니다. 진짜 캐릭터 일러스트를 넣으려면:

1. **[`character-prompts.md`](character-prompts.md)** 파일을 엽니다 — 43명 각각의 AI 이미지 생성 프롬프트가 들어있습니다(통일된 아트 스타일).
2. Midjourney / Google Antigravity / Gemini 등에 프롬프트를 넣어 이미지를 만듭니다.
3. 만든 이미지를 **`public/avatars/` 폴더**에 **에이전트 이름.png** 로 저장합니다.
   - 예: `public/avatars/hr-disability.png`, `public/avatars/cos.png`
4. 대시보드를 새로고침하면 이모지 대신 일러스트가 자동으로 표시됩니다. (png/jpg/webp/svg 지원)

> 43장을 한 번에 다 안 만들어도 됩니다. 만든 것부터 자동으로 바뀝니다.

## 4. 실시간 자동 포착은 어떻게 되나요?

Claude Code에는 **hook**(작업이 일어날 때 신호를 보내는 장치)이 있습니다.
설치 시 `.claude/settings.local.json`에 아래 신호를 잡도록 연결해 두었습니다:

- 💬 대표님이 지시를 보낼 때
- 🚀 에이전트(서브에이전트)가 호출될 때 / ✅ 끝날 때
- ⏹️ 응답이 완료될 때

이 신호들이 대시보드 서버로 전달돼 화면에 뜹니다.
**서버가 꺼져 있어도 Claude는 전혀 느려지거나 멈추지 않습니다** (신호는 0.4초 안에 조용히 통과).

### 더 자세히(파일 읽기·웹검색까지) 보고 싶다면
`.claude/settings.local.json`의 `hooks` → `PreToolUse`에서 `"matcher": "Task"` 를
`"matcher": ""` 로 바꾸면 모든 도구 사용이 잡힙니다. (단, 매 도구 호출마다 신호가 가서
아주 약간 느려질 수 있습니다. 기본값은 에이전트 단위만 잡는 가벼운 모드입니다.)

### 끄고 싶다면
같은 파일의 `"hooks"` 블록을 통째로 지우면 자동 포착이 멈춥니다(대시보드는 데모/수동으로 계속 사용 가능).

## 🤖 일 시키기 (cos 비서 — 대시보드에서 Claude에 업무 지시)

**🤖 일 시키기** 탭에서 cos 비서에게 직접 일을 시킵니다.
1. 입력창에 **한글로** 지시 (예: `장애인 직무발굴 워크숍 순서 초안 잡아줘`)
2. **담당** — 비워두면 cos 비서가 판단, 특정 전문가 지정 가능(예: `hr-disability`)
3. **권한** — `계획만(안전)`=답만 / `파일 작성 허용` / `제한 없음`=실제 작업. **처음엔 "계획만"** 권장.
4. ▶ 실행 → 30~50초 뒤 "작업 내역"에 결과. 진행 중엔 ⚡실시간 활동 탭에 흐름이 보임. 만든 파일은 📋프로젝트 탭에서 열기.

- 대표님 **Claude 구독을 그대로 사용** → 추가 API 비용 없음.
- ⚠️ claude를 **다른 Claude Code 세션 안에서** 띄우면 충돌로 멈춤 → 반드시 `START-대시보드.bat`(일반 터미널)로 켤 것. (서버 코드 `server/dispatch.js`가 부모 환경변수를 제거해 독립 실행시킴)

## 5. 한번 살아있는 모습 보기 (데모)

서버를 켠 상태에서, 별도 명령창에서:
```
node demo-seed.js
```
가짜 컨설팅 작업(장애인 직무발굴 시나리오)이 흘러가며 화면이 어떻게 살아 움직이는지 보여줍니다.

## 6. 앞으로 (2층 로드맵)

지금은 **1층 = 내 PC 로컬**입니다. 다음 단계로 확장 가능:

- **2층 — 클라우드 미러(Railway)**: 폰·외부에서도 현황 열람 (단, 이 PC가 켜져 있어야 데이터가 올라감)
- **2층 — 텔레그램 봇**: 에이전트 작동 알림을 텔레그램으로 받고, 텔레그램에서 에이전트를 원격 호출
- **프로젝트 포트폴리오 탭**: 기존 `cockpit.html`(16개 프로젝트 7단계 현황)을 이 대시보드 안으로 흡수

원하실 때 말씀해 주시면 2층을 올립니다.

## 폴더 구조 (참고)
```
agent-cockpit/
├── START-대시보드.bat      ← 더블클릭해서 켜기
├── server/                 ← 로컬 서버 (Node 내장, 의존성 0)
├── public/                 ← 대시보드 화면
│   └── avatars/            ← 여기에 캐릭터 일러스트 .png 저장
├── hooks/send-event.js     ← Claude 활동을 서버로 전달
├── character-prompts.md    ← 43명 AI 일러스트 생성 프롬프트
├── demo-seed.js            ← 데모 활동 재생
└── data/                   ← 실시간 이벤트 기록 (자동 생성, 이 PC 로컬)
```
