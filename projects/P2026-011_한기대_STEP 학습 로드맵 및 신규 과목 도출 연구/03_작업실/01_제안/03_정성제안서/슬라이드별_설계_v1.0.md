# 정성제안서 슬라이드별 설계 명세 v1.0

> **사용법**:
> 각 슬라이드 카드는 (1) 헤드라인 (2) 키 메시지 (3) 시각화 컨셉 (4) 도식 종류 (5) 출처/주석 5개 항목.
> 슬라이드 디자인 작업자는 본 명세를 기준으로 PPT 슬라이드를 제작한다.
>
> **표기**:
> - **★** = §9 핵심 차별화 슬라이드 12개 (디자인 투자 집중)
> - **[제도] [자동] [조사] [매뉴]** = 좌상단 RFP 4대 제언 기호
> - "도식: ◯◯" = 6종 패턴(매트릭스/흐름도/히트맵/비교카드/큰숫자/시간축) 중 적용
>
> **인덱스**:
> - 표지·요약·차례·약어 (s.1~4)
> - Ⅰ. 제안개요 (s.5~12)
> - Ⅱ-1 추진방향 (s.13~17)
> - Ⅱ-2 가·나·다·라·마·바 (s.18~39)
> - Ⅱ-3 일정 (s.40~46)
> - Ⅱ장 마무리 간지 (s.47)
> - Ⅲ 수행조직 (s.48~58) + 간지 (s.59)
> - Ⅳ 활용성 (s.60~62) + 간지 (s.63)
> - Ⅴ 제안업체 일반 (s.64~68)

## 표지·요약·차례·약어 (s.1~4)

### ★ s.1 — 표지
- **헤드라인**: "2026년도 STEP 학습 로드맵(SLR) 및 신규 과목 도출 연구 / 정성제안서"
- **키 메시지**: 마스터 슬로건 부제: **"한기대 STEP의 다년 파트너 — RFP 4대 제언 정직한 답, 27·28년 동행"**
- **시각화**: STEP SLR 도식 실루엣 (저채도 알파 15%) 배경, 슬로건 옐로우 박스
- **도식**: 표지 전용 (도식 패턴 미적용)
- **주석**: 우하단 작은 회사 로고, 제출일 자리(2026.__.__)

### ★ s.2 — 1쪽 요약 (마스터 메시지)
- **헤드라인**: "RFP §II-3 4대 제언에 정직한 답"
- **키 메시지**: 4대 Win Theme(WT1~4) 매트릭스, 중앙에 마스터 슬로건
- **시각화**: 4분면 매트릭스 + 융합 도출 핵심 박스 + 4대 약속 박스
- **도식**: 매트릭스 (4분면)
- **주석**: 본 페이지가 평가위원의 30초 인지를 결정. 디자인 투자 최우선.

### s.3 — 차례
- **헤드라인**: "차례"
- **키 메시지**: Ⅰ~Ⅴ 5장 + 별첨, 페이지 번호 우측 정렬
- **시각화**: 좌측 장 번호 큰 글씨 + 절·페이지 번호
- **도식**: 표 (간단)
- **주석**: ★ 표시는 신설/위치 재배치 항목. 시앤피 대비 차별 신호.

### s.4 — 약어·기호 정의
- **헤드라인**: "약어·기호 정의"
- **키 메시지**: NCS·SQF·SLR·AX·GX 등 + 본 제안서 표기 규칙(RFP 그대로) + RFP 4대 제언 기호 + 출처 표기 원칙
- **시각화**: 4단 표 (정부·STEP·산출물·AI/산업)
- **도식**: 표
- **주석**: TTR은 비교 맥락에서만 사용 명시.

## Ⅰ. 제안개요 — 8 슬라이드 (s.5~12)

### s.5 — Ⅰ장 간지
- **헤드라인**: "Ⅰ. 제안개요"
- **키 메시지**: "RFP 100% 충족 + 4대 약속 + 다년 동행 의사" 한 줄 요약
- **시각화**: 큰 "Ⅰ" 글씨 + 부제
- **도식**: 간지 전용
- **주석**: 평가항목 매핑 표시 ("이 장은 과업이해도 20점에 어필")

### s.6 — Ⅰ-1. 제안 목적·범위
- **헤드라인**: "RFP §II-1 과업목표 3종 + RFP §II-3 4대 제언에 100% 답합니다"
- **키 메시지**: 5개 범위표(SLR 고도화 / 400과목 / 보고서·매뉴얼 / 4대 제언 / 보고회 산출물)
- **시각화**: 좌측 RFP 출처 / 우측 우리 답안 매핑 표
- **도식**: 매트릭스 (5×3)
- **주석**: 출처 RFP §I-1 마, §II-1, §II-3

### s.7 — Ⅰ-2. 사업 배경 이해 (1/2)
- **헤드라인**: "RFP §I-2 4대 배경에 대한 우리의 이해 (1/2) — 가·나"
- **키 메시지**: 2개 배경 박스 (① STEP 단계별 직무 훈련 / ② 제도 연계 정합성)
- **시각화**: 2분면 (좌: RFP 인용, 우: 우리 이해 + 답안 위치)
- **도식**: 비교 카드 (2분면)
- **주석**: RFP 직접 인용 표기 ("RFP §I-2 가·나")

### s.8 — Ⅰ-2. 사업 배경 이해 (2/2)
- **헤드라인**: "RFP §I-2 4대 배경에 대한 우리의 이해 (2/2) — 다·라 + RFP §II-3 4대 제언"
- **키 메시지**: 2개 배경 (③ 27년 신규 과목 / ④ AI+X 융합) + RFP §II-3 4대 제언 표
- **시각화**: 2분면 + 하단 4대 제언 박스
- **도식**: 비교 카드 + 작은 매트릭스
- **주석**: AI+X 융합이 본 사업 가장 큰 변화임을 명시

### ★ s.9 — Ⅰ-3. 작년 vs 본 사업 5대 변화
- **헤드라인**: "작년 사업 토대 위에 본 사업이 새 단계로 진입하는 5가지 영역"
- **키 메시지**: 5개 영역(제도연계·자동화·조사체계·매뉴얼화·AI+X 도출)의 작년→올해 변화
- **시각화**: 5행 비교 표 (좌: 작년 시앤피 / 우: 본 사업 v0.2)
- **도식**: 비교 카드 (5행)
- **주석**: 시앤피 보고서 페이지 출처 표기. 작년 깎아내리지 않고 "RFP 새 명시 요구"로 포지셔닝.

### ★ s.10 — Ⅰ-4. 4대 Win Theme 매트릭스
- **헤드라인**: "본 제안의 4대 약속 — RFP §II-3 4대 제언과 1:1 정렬"
- **키 메시지**: WT1 제도연계 / WT2 자동화 / WT3 조사체계 / WT4 매뉴얼화 한 줄씩
- **시각화**: 4분면 매트릭스 + 각 분면에 RFP 인용·답안·산출물·다년 가치
- **도식**: 매트릭스 (4분면) ★ 슬라이드 2와 다른 디자인 (더 상세)
- **주석**: 표지·s.2와 함께 정성제안서의 3대 임팩트 페이지

### s.11 — Ⅰ-5. 사업 추진 5대 핵심 전제
- **헤드라인**: "본 사업은 5대 전제 위에서 수행됩니다"
- **키 메시지**: ① 종료일(11/20) 절대 준수 ② 발주처 협의 7건 ③ 보안·하도급 금지 ④ 출처 명기 100% ⑤ **다년 동행 의사**
- **시각화**: 5단 카드 (각 카드 아이콘 + 한 줄)
- **도식**: 카드형 (5개)
- **주석**: ⑤ 다년 동행은 오렌지 컬러 강조

### s.12 — Ⅰ-6. 제안서 구성 안내
- **헤드라인**: "평가위원이 점수 매기기 쉽도록 — 평가항목·RFP 제언 ↔ 페이지 매핑"
- **키 메시지**: 평가항목 4개와 본 제안서 페이지 매핑 + RFP 4대 제언과 본 제안서 페이지 매핑
- **시각화**: 2열 매핑 표 (좌: 평가항목 매핑, 우: RFP 제언 매핑)
- **도식**: 매트릭스 (2 × N)
- **주석**: 평가위원 편의성 어필
