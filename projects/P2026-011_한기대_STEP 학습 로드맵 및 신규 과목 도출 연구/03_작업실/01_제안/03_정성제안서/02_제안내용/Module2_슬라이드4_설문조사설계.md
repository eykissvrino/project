# 슬라이드 4 (PPTX p.18) — 세분류 단위 설문조사 내용 및 문항 설계

## 헤더
```
좌상단: Module 2. NCS 세분류 우선순위 도출
       Step 3. 정량·정성 Data 기반 NCS 세분류 수요분석
우상단: Ⅱ. 제안 내용 / 2. 과업 수행계획 및 방법
```

## 헤드 메시지 (Q.)
> **Q. 세분류 단위에서 학습자·기업·기관의 수요를 어떤 내용·문항으로 청취하여 응답 부담을 완화할 것인가?**

## 카피 메시지
> **응답자 1인당 평균 7개 세분류**를 사전 매칭하여 응답 부담을 완화하고, **학습자·기업·기관 3주체별 설문지**로 **신규 학습 수요·이러닝·가상훈련 개발 필요성**을 5점 척도로 청취. 약 **2,000명 표본** × 25%+ 응답률 목표

---

## 좌측: 설문조사 내용 (대상 · 표본 · 기간 · 방법)

### 대상

| 주체 | 구성 | 비중 |
|---|---|---|
| **학습자** | 2023~2024년 STEP 학습자 (직무 과정 분야별 2개 과정 이상 수강생) | **1,500명** (75%) |
| **기업 인사·교육 담당자** ★ 신설 | '22년 이후 STEP 훈련기관 협력 기업 + 관련 산업 인사·교육 담당자 | **300명** (15%) |
| **유관 기관** ★ 신설 | ISC · 산업인력공단 · 정부 출연 연구기관 | **200명** (10%) |
| **합계** |  | **약 2,000명** |

### 목표 표본 · 응답률
- 약 **2,000명** 발송 → **응답률 25%+ 목표**
- 실효 응답 **500명 이상** 확보 → 세분류 × 응답자 매트릭스에서 **세분류당 평균 14 응답** 보장

### 설문 기간
- 약 **2주(14일)** 본 조사
- 본 사업 종료 후 **분기 상시 사이클 운영 모델**로 인계 (27년 본격 운영)

### 조사 방법
- **온라인 설문 플랫폼** (모아폼 · 서베이몽키 활용)
- **3주체별 설문지 구분** (학습자 / 기업 / 기관)
- **응답자 사전 매칭** ★
  - 응답자가 본인 직무·관심 분야 NCS 세분류를 **5~10개 선택**
  - 응답자 1인당 평균 **7개 세분류** 응답 → 응답 피로 완화
- **5점 척도** 일관 적용 (1=매우 낮음 ~ 5=매우 높음)
- 대분류별 N개 집단 분배 (응답자 분산)

---

## 우측: 설문 문항 구성 (4섹션 · 5점 척도)

### A. 응답자 일반사항 (공통)

| 문항 | 내용 |
|---|---|
| A1 | 직무 분야 (NCS 대분류·중분류·소분류 사전 매칭) |
| A2 | 산업 분류 (제조 · 서비스 · IT · 교육 · 공공 등) |
| A3 | 경력 단계 (입문 · 중급 · 고급) |
| A4 | **관심 NCS 세분류 5~10개 선택** ★ (응답자별 응답 세분류 결정) |
| A5 | 소속 주체 (학습자 / 기업 / 기관) |

### B. 학습자 수요 청취 (B 섹션 — 학습자 응답자만, 5점 척도)

| 문항 | 내용 |
|---|---|
| B1 | 본 세분류의 **신규 학습 수요** (학습 의향 정도) |
| B2 | 본 세분류의 **이러닝 과정 개발 필요성** |
| B3 | 본 세분류의 **가상훈련 과정 개발 필요성** (필요 시) |
| B4 | 본 세분류 학습의 **시급성** (다른 분야 대비) |

### C. 기업 수요 청취 (C 섹션 — 기업·기관 응답자만, 5점 척도)

| 문항 | 내용 |
|---|---|
| C1 | 본 세분류 인재의 **현재 채용 수요** |
| C2 | 본 세분류 인재의 **향후 3년 채용 수요 전망** |
| C3 | 본 세분류 인재 양성을 위한 **STEP 신규 과정 필요성** |
| C4 | 본 세분류의 **기업 내 재교육 수요** |

### D. 정책·산업 수요 청취 (D 섹션 — 기관 응답자만, 5점 척도)

| 문항 | 내용 |
|---|---|
| D1 | 본 세분류의 **정책 우선순위** |
| D2 | 본 세분류의 **산업 동향·기술 변화 부합도** |
| D3 | 본 세분류 **ISC 직무 분류 변화 반영 필요성** |

> 본 문항 구성은 시앤피 2025 사업의 A·B·C 3섹션 구조를 유지하면서, **D 섹션(기관)** 을 신설하여 정책·산업 수요까지 통합 청취

### 응답자 분배 핵심 (요약)
```
2,000명 발송 × 25%+ 응답률 → 실효 응답 500+명
                ▼
응답자 1인당 평균 7개 세분류 응답 (사전 매칭)
                ▼
500명 × 7개 = 약 3,500개 세분류 응답 데이터
                ▼
세분류 약 240개 모집단 → 세분류당 평균 14 응답 보장
```

# 부록: 작업 메모

## 설문조사 설계 핵심 5종

1. **세분류 단위 설문** — 시나리오 B 재배치 기반
2. **응답자 사전 매칭** — 1인당 평균 7개 세분류 분배 → 응답 부담 완화
3. **3주체별 설문지** — 학습자(B) / 기업(C) / 기관(D) 구분
4. **5점 척도 일관 유지** — 시앤피 원본 척도 그대로
5. **표본 2,000명 × 25%+ 응답률** → 세분류당 평균 14 응답 보장

## 시앤피 2025 자료와의 연속성

| 항목 | 시앤피 2025 (원본) | 본 슬라이드 (확장) |
|---|---|---|
| 대상 | 학습자 중심 | 학습자 + **기업** + **기관** (3주체) |
| 표본 | 약 2,000명 | 약 2,000명 (학습자 1,500 + 기업 300 + 기관 200) |
| 척도 | 5점 척도 | 5점 척도 (유지) |
| 문항 | A. 일반 / B. 이러닝 / C. 가상훈련 | A. 일반 / B. 학습자 / C. 기업 / **D. 기관** (신설) |

| 응답자 분배 | 미설계 | **사전 매칭 1인당 7개 세분류** (응답 피로 완화) |
