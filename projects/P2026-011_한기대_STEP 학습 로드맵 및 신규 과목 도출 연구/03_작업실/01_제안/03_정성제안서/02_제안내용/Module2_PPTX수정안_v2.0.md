> 기존 "능력단위 선정 → 과목 도출 → 설문조사" 흐름에서는 설문이 후행 단계에 위치하여 응답률·반영도 한계가 있었음. 이를 **RFP §II-3 [조사체계 개선] 권고**에 따라 **세분류 단계에서 설문을 통합 진행하는 흐름(시나리오 B)** 으로 재배치하여 응답 부담을 줄이고 수요 청취 정합성을 확보하고자 함

### 기존 흐름 (~'25)
```
능력단위 선정  →  과목 도출  →  설문조사
```

### 기존 흐름의 이슈 및 문제점
- ① 응답률 약 9.5% — 설문 후행 배치로 응답 피로 누적
- ② 세분류 우선순위 산정 시 학습자·기업·기관 수요가 직접 반영되지 않음
- ③ 능력단위 단위 설문은 응답 부담이 크고 결과 활용도가 낮음
- ④ 분야별 균형 잡힌 수요 청취가 어려움

### 개선 흐름 ('26 — RFP §II-3 [조사체계 개선] 권고 반영)
```
세분류 우선순위 + 설문조사 (동시 진행)  →  능력단위 선정  →  과목 도출
```

### 트레이드오프 (단점과 기대효과)
- **단점**
  - 능력단위 단위 세부 수요 정보는 별도 수집 필요 → Module 3 정성 평가 3지표(수요·필요성·시급성)로 보완
  - 240개 세분류 × 응답자 → 표본 분산 가능성 → 응답자 가중치 모델(직무·산업·경력별)로 편향 보정
- **기대효과**
  - ① 응답 부담 감소로 응답률 25%+ 목표 (2.6배 향상)
  - ② 세분류 우선순위에 학습자·기업·기관 수요 직접 반영
  - ③ 후행 단계(능력단위·과목)의 신뢰성 향상
  - ④ RFP §II-3 [조사] 4대 제언에 정직한 답
  - ⑤ 27년 상시 운영 모델 확장 시 세분류 단위가 모집단 분포에 적합
