# 슬라이드 4 (PPTX p.18) — 세분류 단위 설문조사 내용 및 문항 설계

## 헤더
```
좌상단: Module 2. NCS 세분류 우선순위 도출
       Step 3. 정량·정성 Data 기반 NCS 세분류 수요분석
우상단: Ⅱ. 제안 내용 / 2. 과업 수행계획 및 방법
```

## 헤드 메시지 (평서문)
> **정량·정성 평가로 측정하기 어려운 세분류 단위 직접 수요 차원을 학습자·기업·기관 3주체별 설문조사로 청취하여, 종합 점수 200점의 신뢰성과 현장 정합성을 확보하고자 함**

---

## 좌측: 설문조사 내용 (대상 · 표본 · 기간 · 방법)

### 대상

| 주체 | 구성 | 표본 |
|---|---|---|
| **학습자** | 2023~2024년 STEP 학습자 (직무 과정 분야별 2개 과정 이상 수강생) | **1,500명** (75%) |
| **기업 인사·교육 담당자** | '22년 이후 STEP 훈련기관 협력 기업 + 관련 산업 기업 | **300명** (15%) |
| **유관 기관** | ISC · 산업인력공단 · 정부 출연 연구기관 | **200명** (10%) |
| **합계** |  | **약 2,000명** |

### 목표 표본 · 응답률
- 약 **2,000명** 발송 → **응답률 25%+ 목표**
- 실효 응답 **500명 이상** 확보 → 세분류당 평균 **14 응답** 보장

### 설문 기간
- 약 **2주(14일)** 본 조사
- 분기 상시 사이클 운영 모델 연계 (27년 본격 운영 인계)

### 조사 방법
- **온라인 설문 플랫폼** (모아폼 · 서베이몽키 활용)
- **3주체별 설문지 구분** (학습자 / 기업 / 기관)
- **응답자 사전 매칭** ★
  - 응답자가 본인 직무·관심 분야 NCS 세분류를 **5~10개 선택**
  - 응답자 1인당 평균 **7개 세분류** 응답 → 응답 피로 완화
- **5점 척도** 일관 적용 (1=매우 낮음 ~ 5=매우 높음)

---

## 우측: 설문 문항 구성 — 정량·정성과의 보완 관계

### 정량·정성·설문의 차원 보완 구조

```
정량 11지표 (70점) ────── 객관 통계 데이터로 측정 (HRD-Net·자격통계·STEP 실적)
정성 3지표 (30점) ─────── 전문가 평가로 측정 (수요 예상도·필요성·시급성)
                              ─────────────
설문조사 (100점)  ─────── 학습자·기업·기관의 직접 수요·의향
                          → 정량·정성으로 측정 불가능한 현장 차원 보완
```

### A. 응답자 일반사항 (공통)

| 문항 | 내용 |
|---|---|
| A1 | 응답자 직무 분야 (NCS 대분류·중분류·소분류 사전 매칭) |
| A2 | 산업 분류 (제조 · 서비스 · IT · 교육 · 공공 등) |
| A3 | 경력 단계 (입문 · 중급 · 고급) |
| A4 | **관심 NCS 세분류 5~10개 선택** ★ (응답 세분류 사전 결정) |
| A5 | 소속 주체 (학습자 / 기업 / 기관) |

### B. 학습자 직접 수요 (학습자 응답자 · 5점 척도)

| 문항 | 내용 | 보완 차원 |
|---|---|---|
| B1 | 본 세분류의 **본인 직무 부합성** | 개인 직무 관점 |
| B2 | 본 세분류의 **신규 학습 의향** | 학습 동기 |
| B3 | 본 세분류 **STEP 신규 과정 수강 의향** | 운영 측면 수요 |
| B4 | 본 세분류 **학습의 시급성** (개인 경력 관점) | 시급성 — 정성 지표 보완 |

### C. 기업 직접 수요 (기업 응답자 · 5점 척도)

| 문항 | 내용 | 보완 차원 |
|---|---|---|
| C1 | 본 세분류 인재의 **현재 채용 수요** | 현장 채용 — 정량 미반영 |
| C2 | 본 세분류 인재의 **향후 3년 채용 수요 전망** | 미래 수요 — 정성 보완 |
| C3 | 본 세분류의 **기업 내 재교육 수요** | 재직자 교육 — 정량 미반영 |
| C4 | 본 세분류 **STEP 신규 과정 활용 의향** | 운영 측면 수요 |

### D. 정책·기관 수요 (유관 기관 응답자 · 5점 척도)

| 문항 | 내용 | 보완 차원 |
|---|---|---|
| D1 | 본 세분류의 **정책 우선순위** | 정책 관점 |
| D2 | 본 세분류의 **산업 동향·기술 변화 부합도** | 산업 변화 — 정량 후행 |
| D3 | 본 세분류 **ISC 직무 분류 변화 반영 필요성** | NCS 갱신 관점 |

> ※ **과목 유형(이러닝·가상훈련·AI 융합 등) 질문은 본 세분류 단위 설문에 포함하지 않음** — 과목 유형 설정은 Module 3 능력단위 선정 단계의 결정 사항이며, 본 단계는 세분류 단위 수요·우선순위에 집중

## 하단: 응답자 사전 매칭 + 분배 방식

🔹 **HTML 도식 #6 (응답자 사전 매칭 · 분배 + 문항 매핑)** 삽입

### 응답자 분배 핵심 (요약)
```
2,000명 발송 × 25%+ 응답률 → 실효 응답 500+명
                ▼
응답자 1인당 평균 7개 세분류 응답 (사전 매칭)
                ▼
500명 × 7개 = 약 3,500개 세분류 응답 데이터
                ▼
세분류 모집단 → 세분류당 평균 14 응답 보장
```
