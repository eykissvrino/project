| 차원 | 시앤피 2025 한계 |
|---|---|
| **출발점** | "데이터·보안·윤리 3분야 자문회의" — NCS 표준 출발 부재 |

### 7점 척도 및 평가 결과 분류

| 점수 | 척도 | 의미 |
|---|---|---|
| 7점 | 매우 적합 | 해당 방식 최적, 다른 방식 대비 우수 |
| 6점 | 적합 | 무리 없이 진행 가능 |
| 5점 | 약간 적합 | 조건부 적합, 일부 보완 필요 |
| 4점 | 중립 | 적합·부적합 판단 어려움 |
| 3점 | 약간 부적합 | 제한적 활용 가능, 비효율 |
| 2점 | 부적합 | 큰 무리, 다른 방식 권장 |
| 1점 | 전혀 부적합 | 절대 불가 |

**그룹 분류 (지표별 평균 점수 기반)**:
- **핵심 개발군 (≥6.0)** — 즉시 개발 우선
- **우선 개발군 (5.0~5.9)** — 차순위 개발
- **개발 가능군 (4.0~4.9)** — 조건부 개발
- **개발 검토군 (<4.0)** — 재평가 또는 보류

```

**② Locus for Focus 4분면 분석**
```
                    개발 필요성 (높음)
                            ▲
                            │
                            │
              LH 분면         │      HH 분면 ★ 최우선 개발

   (낮음)                    │              (높음)
                            │
              LL 분면         │      HL 분면
        (수준 낮음 +         │    (수준 높음 +
