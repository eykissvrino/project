# Module 2. NCS 세분류 우선순위 도출

## 슬라이드 ① Module 2 도입 (1쪽)

### 헤더
> Q. **분야 구분 없이 NCS 세분류 전체를 어떻게 일관 평가하여 신규 개발 우선순위를 도출할 것인가?**

### 한 줄 메시지
**정량 11지표 + 정성 3지표 + 학습자·기업·기관 3주체 설문**을 분야 무관 전체 NCS 세분류 796개에 일관 적용하여, RFP 명시 가중치 **설문 50% + 정량 35% + 정성 15%** 로 세분류 우선순위 N₁_final을 확정한다.

### 핵심 차별점 3가지 (시앤피 2025 대비)

| 항목 | 시앤피 2025 한계 | 우리 2026 해법 |
|---|---|---|
| **종합 가중치** | 정량·정성 50% + 설문 50% (RFP 비율 이탈) | **RFP 명시 50/35/15 정확 적용** |
| **설문 응답률** | 9.5% (실효 표본 부족) | **25%+ 목표 + 응답자 가중치 모델** |
| **설문 배치** | 별도 트랙 (능력단위 단계 후) | **세분류 단위 통합 (시나리오 B 재배치)** |

### 본 모듈 추진 흐름

```
[Step 3] 정량·정성·설문 3축 수요분석 (분야 무관 796개 세분류 일관 평가)
   ↓
[Step 4] 외부 전문가 8인 패널 검토 → N₁_final 확정 (Module 3 모집단)
```

## 슬라이드 ② Step 3-1 (1쪽): 평가 준비 및 데이터 확보

### 헤더
> Q. **정량·정성·설문 평가를 위한 데이터를 어떻게 일관되게 확보·표준화할 것인가?**

### 수행 절차

**① 평가 대상 세분류 범위 확정**
- 2024.12.4 NCS 최신 고시 기준 세분류 **796개** 전수
- 신설 세분류(2024~2025 신규 고시분) 별도 표기 → 신설 세분류 평가 룰 적용
- 평생직업능력개발·디지털·첨단 분야 구분 없이 **분야 무관 일관 평가** (분야 분류는 Module 3 능력단위 단계로 이연)

**② 정량 11지표 데이터 확보**
- 훈련유형별 연평균 실시인원·개설과정 수·증가 수 (HRD-Net 운영현황, 3년치)
- 신청 훈련과정 수, 국가기술자격시험 응시자 수·증가율 (자격통계연보, 1년치)
- 향상·양성훈련수요 (RSC 지역인력 훈련수요·공급조사, 3년치)
- 취업자 수 연평균 성장률 전망 (중장기 인력수급전망, 1년치)
- STEP 과정별 연평균 수강생 수·증가 수 (STEP 실적, 1년치)

**③ 정성 3지표 평가 진행 (RFP §II-2 나 명시)**
- 미래 교육과정 수요 예상도 / 교육과정 개발 필요성 / 교육과정 개발 시급성
- 전문가 3인 패널 평가(분야별 ISC·교강사·산업전문가 각 1인)

**④ 신설 세분류 평가 룰**
- 정량평가: 해당 소분류 중앙값 대체 (결측 처리 매뉴얼 v0.1)
- 정성평가: 신설 당해 평가 후 3년 주기 동일 평가 진행

### 도식 위치 표시
🔹 우측: **3축 통합 평가 도식** (정량·정성·설문 → 50/35/15 가중 합산)

## 슬라이드 ③ Step 3-2 (1쪽): 설문조사 — 시나리오 B 재배치 ★

### 헤더
> Q. **설문 단계를 RFP 4대 제언 [조사] 권고대로 어떻게 재배치하고 응답률을 어떻게 끌어올릴 것인가?**

### 시나리오 B 채택 — 세분류 단위 통합 설문

**RFP §II-3 [조사체계 개선] 직접 답**

| 시나리오 | 설문 시점 | 대상 단위 | 권고 |
|---|---|---|---|
| A | 현재 RFP 순서 (능력단위 후) | 능력단위 | (선행 연구 답습) |
| **B ★** | **세분류 단계 통합** | **세분류 240개 → 능력단위 별도 검토** | **우리 권고** |
| C | 혼합 (세분류 + 능력단위) | 양쪽 | 부담↑ |

> 시나리오 B는 RFP §II-3에서 명시한 **"설문 단계 재배치 + 상시 수요조사 도입"** 요구에 정직하게 답한다.

### 응답률 25%+ 확보 4대 전략

```
① 표본 설계 정밀화        ② 응답 인센티브 + 사이트 협업
   - 학습자 1,500 (75%)       - STEP 홈페이지 공지·홍보
   - 기업 300 (15%)           - 1,000명 추첨 답례품
   - 기관 200 (10%)           - 발주처와 누적 응답 일일 공유
   합 2,000명, 응답률 25%+

③ 응답자 가중치 모델       ④ 상시 수요조사 사이클
   - 직무·산업·경력별 가중      - 분기 자동화 사이클
   - 표본 편향 자동 보정         - 27년 본격 운영 인계
```

### 종합 가중치 — RFP 50/35/15 정확 적용

```
세분류 종합 점수 = 설문(50%) + 정량(35%) + 정성(15%)
                                                       
  • 설문: 100점 (5점 척도 × 응답자 가중)              
  • 정량: 100점 (11지표 × 비중)                        
  • 정성: 100점 (3지표 × 비중)                         
                                                       
  ⇒ 총 100점으로 정규화 (시앤피 2025: 200점 만점 → 우리: 100점 표준화)
```

### 시앤피 2025 대비 차별점 (정량적 시그널)

| 지표 | 시앤피 2025 | 우리 2026 |
|---|---|---|
| 설문 가중치 | 50% (RFP 이탈) | **50% (RFP 정확)** |
| 정량/정성 비율 | 50:50 통합 | **35:15 정확 분리** |
| 응답률 | 9.5% | **25%+ (2.6배 향상)** |
| 응답자 가중치 | 미적용 | **직무·산업·경력별 모델** |
| 운영 사이클 | 단발성 | **분기 상시 사이클** |

## 슬라이드 ④ Step 3-3 (1쪽): 결측치·중복 처리 및 산출물 정리

### 헤더
> Q. **세분류 단위 평가 결과의 신뢰성을 어떻게 확보할 것인가?**

### 데이터 품질 확보 매뉴얼

**① 결측치 처리 룰 (매뉴얼화 [매뉴] 직접 답)**
- 정량 결측: 해당 소분류 중앙값 대체
- 정성 결측: 인접 분야 전문가 보완 평가 (3인 패널 중 2인 이상 응답 필수)
- 설문 결측: 무응답 항목은 평균값 대체 + 응답률 50% 미만 응답자 제외

**② 중복·이상치 자동 탐지**
- 동일 IP·기기에서 중복 응답 → 첫 응답만 채택
- 응답 시간 30초 이하 또는 모든 문항 동일 점수 → 이상치 제외
- 표본 응답률 25% 미달 시 추가 표본 보강

**③ 산출물 (Step 3 완료 시점)**

| 산출물 | 형식 | 분량 |
|---|---|---|
| 세분류 정량 수요분석 결과 | 표 | 796개 × 11지표 |
| 세분류 정성 수요분석 결과 | 표 | 796개 × 3지표 |
| 세분류 설문 분석 결과 | 표 + 가중 적용 | 796개 × 응답자 가중 |
| **세분류 종합 점수표** (50/35/15) | 표 | **796개 × 100점 정규화** |
| 상시 수요조사 운영 모델 v1.0 | 매뉴얼 | 분기 자동화 흐름도 + 운영 룰 |

### RFP 인용 표현
- "RFP §II-3 (조사체계 개선)에서 명시 요구한 **'설문 단계 재배치 + 상시 수요조사 도입'**에 대해 우리는 시나리오 B(세분류 단위 통합)로 답하며, RFP 명시 가중치(설문 50% + 정량 35% + 정성 15%)를 정확 적용한다."

## 슬라이드 ⑤ Step 4-1 (1쪽): N₁ 후보 도출 + 외부 검토 패널

### 헤더
> Q. **세분류 우선순위 후보를 어떻게 객관적·투명하게 검토·확정할 것인가?**

### 수행 절차

**① N₁_pre 1차 후보 도출**
- 796개 세분류 종합 점수 분포 분석
- 상위 30% (약 240개) → **N₁_pre 후보** (Module 3 능력단위 분석 모집단)

**② 외부 전문가 + 발주처 검토 패널 구성 (총 8인)**

```
┌─────────────────────────────────────────────────────────┐
│  외부 전문가 5인                  발주처 2인             │
│  ─────────────────                ──────────            │
│  • NCS 정책 전문가 1인 (KRIVET)   • 한기대 STEP 책임자    │
│  • 산업별 ISC 위원 2인            • 한기대 평생직능 책임자│
│   (디지털·첨단 / 평생)                                    │
│  • 산업전문가 1인 (제조·서비스)    우리 책임자 1인        │
│  • 훈련 운영 전문가 1인 (PHE)     ─────────             │
│                                    • 시앤피 책임연구원    │
│                                                          │
│  총 8인 합의 패널 (다수결 + 이견 시 책임자 조정 + 발주처 합의) │
└─────────────────────────────────────────────────────────┘
```

**③ 검토 룰**
- 후보 240개를 4개 그룹(산업·정책·운영·신설) 분배 → 그룹별 60개 정밀 검토
- 검토 기준: 산업·정책 동향 부합도 / 한기대 운영 적합성 / 시앤피 작년 시범 결과
- 다수결(찬성 ≥5인) + 이견 시 책임자 조정 + 발주처 최종 합의

### 시앤피 2025 차별점
- 시앤피: 검토 절차·근거 불투명 → 우리: **외부 8인 패널 + 다수결 + 발주처 합의 + 근거 데이터 공개**

### 근거 데이터 패키지 (산출물)

| 산출물 | 내용 | 인계 대상 |
|---|---|---|
| **세분류 우선순위표 N₁_final** | 240개 × 14열 (코드·명·점수·분야 등) | Module 3 입력 |
| 정량 지표별 점수 근거 표 | 11지표 × 세분류별 원시값 + 정규화 점수 | 발주처 검증용 |

| **상시 수요조사 운영 모델 v1.0** | 분기 사이클 흐름도 + 운영 룰 | 27년 본격 운영 인계 |

### RFP 인용 표현
- "RFP §II-2 나에서 명시한 'NCS 세분류 수요분석 결과'에 대해 우리는 정량 35% + 정성 15% + 설문 50%의 종합 점수와 외부 8인 패널 검토를 거쳐 240개 N₁_final로 정리하며, RFP §II-3 [조사체계 개선] 권고에 따라 분기 상시 운영 모델로 인계한다."

### Module 3 인계 메시지
> N₁_final 240개 세분류 → Module 3에서 **~2,850개 능력단위 풀** 추출 → **능력단위 스킬셋 도출** → **STEP-AX 매핑 매트릭스** → 과목 유형(E/V/EV/AX) 자동 분류
