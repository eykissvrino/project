# 2026 한기대 STEP SLR 사업 — 제안전략 마스터 v0.2

> **v0.1에서 v0.2로 바뀐 이유 (반드시 먼저 읽을 것)**
>
> v0.1의 마스터 메시지 "1년이 지나도 한기대가 직접 돌리는 자율 운영체계"는 **두 가지 치명적 오류**가 있었다.
>
> 1. **사업 본질 위배**: 발주처가 "다음에는 우리 도움 없이도 운영 가능"하게 만든다는 메시지는, 본 사업과 27·28년 후속사업의 우리 파트너십을 스스로 부정한다. 컨설팅·연구용역의 본질은 "함께 더 잘하기"이지 "발주처 자력 운영 인계"가 아니다.
>
> 2. **RFP 이탈**: v0.1은 "AI/LLM 자동화"·"학습로그 활용" 같은 자체 신기술을 메인 차별화로 잡았으나, RFP §II-3의 "자동화"는 명시적으로 **"신규 과목 도출 방식과 STEP 학습 로드맵 간 연계 효율화 및 시스템 연계 자동화"**를 의미한다. 우리 LLM 매핑·학습로그는 RFP가 요구하지 않은 부속 도구이다.
>
> **v0.2의 핵심 전환**:
> - 마스터 메시지: "자율 운영" → **"신뢰할 수 있는 다년 파트너 — 26년 완수 + 27·28년 동행"**
> - 4대 Win Theme: 자체 정의 트랙 → **RFP §II-3 4대 제언(제도연계·자동화·조사체계·매뉴얼화) 그대로 1:1 정렬**
> - 자체 신기술(LLM·학습로그): 메인 차별화에서 → **6대 절차 수행의 부속 도구**로 강등
> - 활용성: "발주처 자력 운영" → **"27년 신규과목 선정 + 28년 차기 SLR 고도화 연속 동행"**

## 2. 전략 수립의 근거 (Why this strategy)

### 2.1 RFP가 명시한 핵심 구조 — 우리는 이 구조를 그대로 따른다

#### A. 과업목표 3종 (RFP §II-1)
| # | 목표 | 산출물 |
|---|---|---|
| 가 | STEP 학습 로드맵(SLR) 고도화 | SLR 도식(PPT) 10대 분야 + Master DB(엑셀) 1식 |
| 나 | 신규 과목개요서 400과목 도출 | 평생 100 + 디지털·첨단 100 + 융합(AI+X) 200 |
| 다 | 연구보고서 + 관리매뉴얼 | 보고서 20부 + SLR 관리매뉴얼 1부 |

#### B. 연구절차 6단계 (RFP §II-2 가~바)
이 6단계가 본 사업의 척추. **자체 "Module" 재구조화 없이 RFP 표기 그대로 사용**.

| 단계 | 명칭 | 핵심 산출물 |
|---|---|---|
| 가 | STEP 학습 로드맵 최신화 | Master DB 1차 업데이트 |
| 나 | NCS 세분류 수요분석 | 세분류 순위 N₁ (정량 11지표 + 정성 3지표) |
| 다 | NCS 능력단위 수요분석 + 개발 적합성 평가 | 능력단위 순위 N₂ + 개발 적합성 평가 결과 |
| 라 | 설문조사 | 개발 우선순위 N₃ (설문 50% + 정량 35% + 정성 15%) |
| 마 | 과목개요서 제작 | 400과목 |
| 바 | 연구결과 정리 | SLR 도식 + Master DB 최종 + 보고서 + 매뉴얼 |

#### C. 4대 제언 영역 (RFP §II-3 가) — Win Theme의 모태
RFP가 "보고서에 포함되어야 할 사항"으로 명시 요구한 4개. **이것이 본 사업의 진짜 차별화 영역**.

> 작년 시앤피 사업이 운영되는 동안 발주처가 "이 4가지를 다음 사업에서 더 깊이 다뤄달라"고 RFP에 직접 적어 넣은 것.
> 우리는 이 4가지에 가장 충실히 답하는 회사가 된다.

| RFP 제언 | RFP 명시 요구 사항 |
|---|---|
| **제도연계** | 정책 활용 및 후속 사업 추진을 위한 관련 제도 연계 방안 제언 |
| **자동화** | 신규 과목 도출 방식과 STEP 학습 로드맵 간 연계 효율화 및 시스템 연계 자동화 제언 |
| **조사체계 개선** | (a) 설문 단계 재배치 타당성 검증 (b) 분야 분류 지표 명확화 (c) 상시 수요조사 도입 |
| **매뉴얼화** | (a) 산출물 관리 (b) Master DB 데이터관리 (c) 미활용 과목개요서 후속조치 (d) 결측치 처리 규정 |

### 2.2 평가 가중치를 따라간 자원 배분
RFP §IV-3 동점자 우선순위 = ①수행계획(25) → ②인력조직(25) → ③과업이해도(20) → ④활용성(10).

| 평가 항목 | 배점 | 정성제안서 분량 비중 | 발표 시간 |
|---|---|---|---|
| 과업이해도 | 20 | 18% (≈12쪽) | 3분 |
| **수행계획적합성** | **25** | **35% (≈24쪽)** | **8분** |
| **인력조직관리** | **25** | **22% (≈15쪽)** | **5분** |
| 활용성 | 10 | 12% (≈8쪽) | 2분 |
| 표지·개요·요약 | — | 8% | 2분 |
| 합계 | 80 | 100% (≈68쪽 본문) | 20분 |

### 2.3 작년 시앤피의 약점은 "도구"가 아니라 "RFP 충실도"
v0.1은 작년 시앤피의 약점을 "AI 활용 부족"으로 잡았다. 그러나 더 본질적 약점은:
- **RFP 4대 제언을 충분히 답하지 않음** — 직무능력은행제 1쪽, 매뉴얼화 단편 등
- **차별화 메시지(슬로건) 부재** — 표지·요약에 임팩트 메시지 없음
- **한기대 다년 누적 관계만 어필** — 이번 사업의 "무엇을 다르게 할지"가 약함

→ 우리는 이 3가지를 정조준한다. AI/데이터 도구는 답을 만드는 보조 수단이지 메시지가 아니다.

## 3. 4대 Win Theme — RFP §II-3 제언과 1:1 정렬

각 Win Theme은 (1) RFP 명시 요구 (2) 핵심 답안 (3) 산출물 (4) 27·28년 동행 가치를 갖는다.
**자체 정의 트랙(자동화/데이터/도메인/매뉴얼) 같은 인위적 구조는 사용하지 않는다.**

### WT1. 제도연계 — "27년·28년 후속사업의 출발점을 본 사업에서 함께 설계"

| 항목 | 내용 |
|---|---|
| **RFP 명시 요구** | "정책 활용 및 후속 사업 추진을 위한 관련 제도 연계 방안 제언" (RFP §II-3) |
| **핵심 답안** | ① **직무능력은행제 시범 매핑**: 1개 분야(예: 정보통신)부터 NCS 능력단위→학점·학습성과 변환 매트릭스 시범<br>② **SQF 직접 발표본 적극 활용**: 작년 SQF 매칭률 한계의 근본 원인(NCS 사이트 SQF만 참조) 보완. ISC 발표본 동시 활용<br>③ **27년 후속사업 연속성 명분**: 본 사업 산출물이 27년 신규 과목 선정·28년 SLR 차기 고도화로 어떻게 이어지는지 로드맵 명시<br>④ **과정평가형 자격 등 관련 제도와의 연계 모델** 제안 (작년 시앤피가 "추가 검토 필요"로 미완성으로 남긴 부분) |
| **산출물** | • 「제도 연계 제언서」 (보고서 별책 1부)<br>• 직무능력은행제 시범 매핑 사례 1건<br>• SLR–SQF–직능은행제 연계 다이어그램 |
| **다년 동행 가치** | 본 사업이 27년·28년 후속사업의 명분과 출발점을 함께 만든다. 발주처가 후속사업 RFP를 기획할 때 본 사업 산출물이 그 근거가 된다. |
| **시앤피 대비** | 작년: 직능은행제 1쪽 + "협의체 구성 협의" 약속만 → **우리: 시범 매핑 + 후속사업 로드맵 + SQF 직접본 활용** |

### WT2. 자동화 — "신규과목 도출 ↔ SLR 시스템 자동 연계 (RFP가 명시한 그 자동화)"

| 항목 | 내용 |
|---|---|
| **RFP 명시 요구** | "신규 과목 도출 방식과 STEP 학습 로드맵 간 연계 효율화 및 시스템 연계 자동화 제언" (RFP §II-3) |
| **핵심 답안** | ① **신규 과목개요서 → SLR 도식 자동 반영 워크플로우** 설계 (Master DB → SLR 도식 자동 갱신 모델)<br>② **Master DB 데이터 관리 자동화**: 수기 엑셀의 무결성 자동 검증·중복 제거·결측치 알림 (RFP §II-3 매뉴얼화 항목과 연계)<br>③ **미활용 과목개요서 자동 만료 알림**: 1년/2년 룰을 시스템적으로 운영<br>④ **NCS 개정 시 매핑 자동 갱신** 모델: 산업인력공단·ISC 데이터 정기 동기화 |
| **산출물** | • 「시스템 연계 자동화 제언서」 (보고서 본문 별도 장)<br>• Master DB 자동 검증 스크립트<br>• 신규과목→SLR 연계 API 명세서 (발주처 IT 부서와 협의 가능 형태) |
| **다년 동행 가치** | 본 사업이 시스템 연계 모델을 제언하면, 27년·28년에 발주처-우리가 함께 실제 시스템 구축을 추진할 명분이 생긴다. |
| **시앤피 대비** | 작년: 시스템 연계·자동화 언급 없음 → **우리: RFP 명시 항목에 직접 답하는 첫 사업** |

> **주의**: WT2의 "자동화"는 v0.1에서 강조한 "LLM 매핑 자동화"가 아니다.
> RFP가 말하는 자동화는 **신규과목 도출 결과가 SLR 시스템(STEP 사이트)에 반영되는 워크플로우의 자동화**이다.
> LLM·NLP 같은 도구는 본 사업 수행 효율을 위한 보조 수단으로 §3의 6대 절차 수행 방법에 포함하되, 슬로건이나 Win Theme의 메인 메시지로 쓰지 않는다.

### WT3. 조사체계 개선 — "RFP가 명시한 3가지 모두에 답한다"

| 항목 | 내용 |
|---|---|
| **RFP 명시 요구** | (a) 설문 단계 재배치 방안 + 타당성 검증<br>(b) 개발 분야(평생·디지털·첨단·융합) 추출·분류 지표 및 명확한 기준<br>(c) 상시 수요조사 도입 (실시방법·가중치·결과 반영 비율 포함) |
| **핵심 답안** | ① **설문 단계 재배치 시나리오 A/B/C 비교 매트릭스** + 권고안 + **발주처와 합의해 채택**<br>② **융합(AI+X) 분류 정성 3지표 정의서** (RFP가 "AI 적용적합성 등 3개 지표"라고만 표기한 부분을 우리가 구체 정의)<br>③ **상시 수요조사 운영 모델**: 분기별 수요조사 사이클 + STEP 학습이력 데이터 정기 분석 + 27년 후속사업이 그대로 이어받을 수 있는 운영 매뉴얼<br>④ **응답대상별 가중치 모델 + 50%/35%/15% 비율 검증** 제안 (RFP 명시 요구 항목) |

## 4. 6대 절차의 수행 접근 — RFP §II-2 그대로 따르되 차별화 답을 심는다

> **이 절은 정성제안서 §Ⅱ-2 "수행계획 및 방법"의 척추이다.**
> 자체 "Module/Track" 재구조화 없이 RFP 표기 가·나·다·라·마·바 그대로 사용.

### 가. STEP 학습 로드맵 최신화 (RFP §II-2 가)
- **데이터 확보**: 산업인력공단 + ISC 직접 발표본 동시 활용 (작년 SQF 매칭 한계 보완) → **WT1 답변에 활용**
- **데이터 매핑**: 기개발 2,586개(이러닝 2,397 + 가상 189) 100% 매핑, 미활용 능력단위·과목개요서 도출
- **미활용 사후조치 매뉴얼화** → **WT4 답변에 활용**
- **Master DB 1차 업데이트** + **데이터 관리 자동화 모델 제안** → **WT2 답변에 활용**

### 나. NCS 세분류 수요분석 (RFP §II-2 나)
- **정량평가 11지표** (RFP 예시 3개 + 추가 8개 발주처 협의)
  - 11개 지표별 출처·산출식·결측치 처리 방법 표준화 → **WT4 결측치 규정**
  - 가중치 산정 모델 제안 (발주처 합의)
- **정성평가 3지표**: ISC 위원·교강사·산업전문가 패널 구성 (자문위원 명단·동의서 첨부)
- **N₁ 도출**: 정량·정성 합산 비율 제안 (발주처 합의)
- (보조) STEP 학습 로그·검색어 데이터를 정량지표 보조 자료로 참고 → **단, 메인 메시지가 아닌 수행 방법의 일부**

### 다. NCS 능력단위 수요분석 + 개발 적합성 평가 (RFP §II-2 다)
- **개발 분야 추출·분류** (평생·디지털·융합)
- **융합(AI+X) 분류 정성 3지표 정의** → **WT3 답변 핵심**
- **능력단위 정성평가** → **N₂ 도출**
- **개발 적합성 평가 6지표** (이러닝 3 + 가상훈련 3): 정의·타당성 검토 + 평가 척도 보완 방안 (RFP 명시 요구)

### 라. 설문조사 (RFP §II-2 라)
- **설문조사 범위 설정**: N₂ 기반 과목명·과목정보 도출
- **설문 단계 재배치 시나리오 A/B/C** + 권고안 → **WT3 답변 핵심**
- **설문 실시 방법 제안 + 응답대상별 가중치 + 50/35/15% 검증** (RFP 3중 명시 요구)
- **상시 수요조사 운영 모델** → **WT3 답변 핵심**
- **결과 종합**: N₃ 도출 (설문 50% + 정량 35% + 정성 15%)

### 마. 과목개요서 제작 (RFP §II-2 마)
- **신규 과목 범위 확정**: 외부 전문가 + 발주처 검토
- **400과목 도출**:
  - 평생직업능력개발 100과목 (10대 NCS 대분류)
  - 디지털·첨단 100과목 (21대 직종)
  - 융합(AI+X) 200과목 (안전(로봇) 포함, AX·GX 포함)
- **가상훈련(V) + E·V 연계 30개 이상** (평생·디지털 합산, RFP 명시)
- **이러닝과 가상훈련 연계 권장 과목(E,V)**: 연계 근거·요소·방안 별도 작성 (RFP 명시)
- **회차 단위 학습 내용 + NCS 능력단위요소 제시** (RFP 명시)

### 바. 연구결과 정리 (RFP §II-2 바)
- **SLR 도식 10대 분야** + Master DB 최종 업데이트
- **신규 과목 → SLR 자동 반영 모델** → **WT2 답변 핵심**
- **연구보고서 20부** + **SLR 관리매뉴얼 1부**
- **연구절차별 개선사항** (RFP §II-1 다 명시) → **WT4와 직결**
