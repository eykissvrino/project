# 정성제안서 목차 — v0.2 (총 68쪽 ± 본문)

> **v0.1에서 v0.2로 바뀐 핵심**
> 1. 자체 정의 "6대 절차 × 4트랙 매트릭스" **폐기**.
> 2. RFP 표기 가·나·다·라·마·바를 **그대로 본문 절 제목으로 사용**.
> 3. 모든 페이지 좌상단의 "WT 번호" 표시는 RFP 4대 제언(제도연계·자동화·조사체계·매뉴얼화) 기호로 변경: **[제도] [자동] [조사] [매뉴]**
> 4. 활용성 1쪽이 아닌 **별도 챕터 Ⅴ (4쪽)**로 신설하여 "27·28년 동행 로드맵" 어필.
> 5. v0.1의 "AI/LLM 자동화" 강조 페이지들 → **6대 절차 수행 효율 보조 도구** 위치로 재배치.

## 8. 작성 가이드 (모든 작성자 공통)

### 8.1 페이지 구성 규칙
1. **모든 페이지 좌상단**에 RFP 4대 제언 기호 표시: **[제도] [자동] [조사] [매뉴]** (해당 시).
2. **모든 헤드라인은 "RFP 인용 + 우리 답"** 형식.
   - 예: "RFP §II-3 (자동화) 신규 과목 도출 ↔ SLR 시스템 연계 자동화에 대한 우리 답"
3. **출처 표기 필수** (RFP p.X, 시앤피 2025 보고서 p.Y, 정책자료명).
4. **장 시작 페이지마다 마스터 메시지 푸터 1줄** (브랜딩 효과).

### 8.2 표현 금지·권장
- **금지** (RFP §V 명시): "가능하다 / 동의한다 / 할 수도 있다 / 고려하고 있다"
- **금지** (v0.2 신설): "발주처 자력 운영 / 한기대가 직접 운영 / 인계 후 종료"
- **금지** (v0.2 신설): "자체 Framework / Module 1~7" — RFP 표기 그대로
- **권장**:
  - "RFP §II-3에서 명시 요구한 ~에 대해 우리는 …"
  - "발주처와 협의하여 …"
  - "본 사업이 27·28년 후속사업의 …"

### 8.3 도식·시각화 (작년 시앤피와 차별)
- 시앤피의 박스+텍스트형 → 우리는 **시각적 메타포**
- 단, **"AI 신기술 과시"형 비주얼 자제** (v0.1 LLM 다이어그램 등은 6대 절차 본문 내 보조 위치로)
