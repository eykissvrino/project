# 우리만의 연구 절차·방법론 v0.2

> **v0.1에서 v0.2로 바뀐 핵심 (반드시 먼저 읽을 것)**
>
> v0.1은 **분야 분류(평생/디지털·첨단/융합) 단계를 잘못 배치**했다.
> v0.1: 다-2 단계에서 "세분류 우선순위 확정 (평생 + 디지털 + 융합 분야별)" — **잘못**
> v0.2: 세분류 단계는 분야 무관 우선순위 확정. **분야 분류는 라. 능력단위 단계에서 수행.**
>
> 또한 v0.1은 **융합(AI+X) 도출 방법**을 추상적인 "STEP-AX 스킬셋 분류체계 + AS-IS/TO-BE"로만 다뤘다.
> v0.2는 **NCS 능력단위 안에 이미 정의된 능력단위요소별 스킬을 출발점**으로 하는 구체 방법론으로 재정의:
>
> 1. **능력단위 스킬셋 도출** — NCS 능력단위 안의 능력단위요소별 스킬을 중복제거·핵심화하여 추출
> 2. **AI 스킬셋과 융합** — 우리 STEP-AX 스킬셋과의 매핑 매트릭스로 융합 가능 페어 식별
> 3. **융합(AI+X) 과목 생성** — 능력단위 단위로 도메인 특화 융합 과목 도출
> 4. **STEP SLR 통합** — 도출된 융합 과목이 기존 SLR 직무별 학습 로드맵에 자연스럽게 추가
>
> **이 방법은 시앤피 작년 "AI 리터러시 26개" 한계의 본질적 해결**:
> 시앤피 = AI 리터러시를 별도 만듦 + NCS 매핑 부재
> 우리 = NCS 능력단위에서 출발 → 모든 융합 과목이 자동으로 NCS·SLR 매핑

## 2. Q3. 능력단위 단계 — 라-1·2·3·4·5 상세

### 2.1 라-1. 능력단위 풀 추출 (모든 분야 공통)

- 선정된 세분류(상위 30% 약 240개) 내 모든 능력단위 추출
- 9,497개 × 30% ≈ **2,850개 능력단위 풀** (시앤피 4,018개 대비 약 70% 수준)
- 미활용 능력단위 우선 검토 (RFP §II-1 가 명시 요구)
- 중복 능력단위(여러 세분류에서 공유) 정리

### 2.2 라-2. 능력단위 스킬셋 도출 ★ 모든 능력단위 공통 (v0.2 핵심 신규)

> **이 단계가 본 사업의 가장 큰 차별화 자산.**
> NCS 능력단위는 이미 능력단위요소별 KSA(Knowledge·**Skill**·Attitude)가 표준화되어 있다.
> 이를 능력단위 단위로 추출·정리하여 **능력단위 핵심 스킬셋**을 만든다.

#### 2.2.1 NCS 능력단위 표준 구조 활용

```
NCS 대분류 → 중분류 → 소분류 → 세분류 → 능력단위 → 능력단위요소
                                          (Unit of      (Element of
                                           Competency)   Competency)
                                              │
                                              └─ 각 능력단위요소별
                                                 K (Knowledge): 지식
                                                 S (Skill): 기술 ★ 우리 추출 대상
                                                 A (Attitude): 태도
```

#### 2.2.2 능력단위 스킬셋 추출 4단계 워크플로우

```
[Step 1] 능력단위요소별 스킬(S) 항목 파싱
   - NCS 표준에서 각 능력단위 안의 N개 능력단위요소 식별
   - 각 능력단위요소의 [기술(S)] 섹션 추출
   - 한 능력단위 평균 4~6개 능력단위요소 × 3~5개 스킬 = 12~30개 원시 스킬

[Step 2] 중복 제거 + 의미 정규화
   - 동일·유사 표현 통합 (예: "데이터 입력" + "정보 입력" → "데이터 입력")
   - LLM 보조 1차 정규화 + 분야 전문가 검증
   - 분야별 표준 용어집 적용

[Step 3] 핵심 스킬 선별
   - 출현 빈도 + 능력단위요소 가중치 + 분야 전문가 평가
   - 능력단위당 5~10개 핵심 스킬셋 도출

[Step 4] 능력단위별 핵심 스킬셋 DB 구축
   - 매핑 양식: 능력단위 코드 / 능력단위명 / 스킬 ID / 스킬명 / 출처 능력단위요소 / 가중치
   - **이 DB가 본 사업의 다년 자산** (27·28년 후속사업·매뉴얼 v2·v3 갱신에 활용)
```

#### 2.2.3 예시: "교환전송설비공사" 직무 (사용자 화면 캡처 참조)

| 능력단위 (예시) | 능력단위요소별 스킬 (NCS 표준) | 중복제거 후 핵심 스킬셋 |
|---|---|---|
| 라우팅 관리 | • 경로 상태 확인하기<br>• 라우팅 프로토콜 설정하기<br>• 트래픽 분석하기<br>• ... | ① 라우팅 프로토콜 설정<br>② 트래픽 모니터링·분석<br>③ 네트워크 경로 최적화<br>④ 장애 진단·복구 |
| L2·L3 스위치 구축 | • 스위치 설치하기<br>• VLAN 구성하기<br>• ... | ① 스위치 하드웨어 설치<br>② VLAN/STP 구성<br>③ QoS 설정<br>④ 보안 정책 적용 |

→ 이 핵심 스킬셋이 다음 단계(라-3 분야 분류·라-5 융합)의 입력이 된다.

### 2.3 라-3. 분야 분류 (RFP §II-2 다 분류 기준 적용)

RFP §II-2 다 표를 그대로 적용:

| 개발 분야 | 분류 기준 (RFP 명시) | 우리 적용 방법 |
|---|---|---|
| **디지털·첨단** | 디지털·첨단 21종 직종 키워드에 해당하는 능력단위 | 21직종 키워드 사전 매칭 (자동) + 분야 전문가 검증 |
| **융합(AI+X)** | 3개 지표(AI 적용적합성 등) 정성 평가를 통해 융합 분야로 판단된 능력단위 | **라-2 능력단위 스킬셋 + AI 스킬셋 매핑 가능성**으로 판단 (라-5 참조) |
| **평생직업능력개발** | 위 두 가지에 해당하지 않는 능력단위 | 잔여 자동 분류 |

**중요**: RFP §II-2 다는 융합(AI+X) 분류를 "정성 평가"로만 명시한다.
우리는 이 정성 평가를 **능력단위 스킬셋 × AI 스킬셋 매핑 매트릭스**로 객관화한다.

### 2.4 라-4. 평생 + 디지털·첨단 트랙 처리 (200과목 도출)

#### 2.4.1 평가 (정성 3지표 + 적합성 6지표)

| 평가 축 | 지표 수 | 척도 | 평가자 |
|---|---|---|---|
| **정성평가** (RFP 명시 3개) | 3개 (수요예상도·개발필요성·시급성) | 5점 | 분야별 전문가 3인 패널 |
| **개발 적합성** (RFP 명시 6개) | 이러닝 3 + 가상훈련 3 | 7점 | 1차 AI 자동 + 2차 전문가 검토 (시앤피 방식 준용) |

#### 2.4.2 우선순위 도출 (Borich + Locus for Focus 4분면)

KTR 도구 차용. HH 분면 = 신규 개발 우선.

#### 2.4.3 능력단위 → 과목 매핑 룰 (3룰)

| 룰 | 조건 | 결과 |
|---|---|---|
| 1:1 매핑 | NCS 수준 3+, 학습량 ≥15h | 능력단위 1개 = 신규 과목 1개 |
| N:1 통합 | 동일 세분류 선·후행 능력단위 묶음 | 능력단위 N개 = 통합 과목 1개 |
| 1:N 분할 | 학습량 ≥60h 또는 난이도 격차 큼 | 능력단위 1개 = 입문·심화 2개 |

#### 2.4.4 결과
- 평생 100과목 + 디지털·첨단 100과목 = **200과목**

### 2.5 라-5. 융합(AI+X) 트랙 처리 (200과목 도출) ★ STEP-AX 융합 모델

## 3. Q4. 융합(AI+X) 200과목 도출 — STEP-AX 융합 모델 (5단계)

### 3.1 전체 흐름

```
[INPUT]
   • 능력단위 스킬셋 (라-2 결과, 모든 능력단위)
   • STEP-AX 스킬셋 (별도 구축, 우리 자산)
       ↓
[Step 1] STEP-AX 스킬셋 분류체계 구축 (사전 작업)
       ↓
[Step 2] 능력단위 스킬셋 × AI 스킬셋 매핑 매트릭스
       ↓
[Step 3] 융합 가능 페어 식별 + 융합 효과 평가 (AS-IS/TO-BE)
       ↓
[Step 4] 융합 분류 정성 3지표 평가 (RFP 명시)
       ↓
[Step 5] 융합 과목 생성 + 분야 분배 + STEP SLR 통합
```

### 3.2 Step 1. STEP-AX 스킬셋 분류체계 구축 ★ 우리만의 자산

```
   D-3. GX·안전(로봇)

L3. 세부 스킬 (40~50개 내외, 분야별 차등)
   예: A-1 아래 "ChatGPT 업무 활용", "Copilot 문서 자동화"
       D-1 아래 "AI 활용 화학 분광 분석", "AI 기반 공정 이상 탐지"
```

### 3.3 Step 2. 능력단위 스킬셋 × AI 스킬셋 매핑 매트릭스

#### 3.3.1 매핑 매트릭스 구조

```
                    AI 스킬셋 (L2 12개)
                ┌──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┐
                │A1│A2│A3│B1│B2│B3│C1│C2│C3│D1│D2│D3│
   ┌────────────┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┤
능 │라우팅 관리 │  │○ │  │● │  │  │  │○ │  │○ │  │  │
력 ├────────────┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┤
단 │L2·L3 스위치│  │  │  │○ │  │  │  │● │  │○ │  │  │
위 ├────────────┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┤
스 │트래픽 분석 │  │● │  │● │○ │  │  │  │  │○ │  │  │
킬 ├────────────┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┤
셋 │장애 진단   │○ │● │  │○ │  │  │  │  │  │○ │  │  │
   └────────────┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┘

   범례: ● 핵심 융합 (필수 학습) / ○ 보조 융합 / 빈칸 = 미융합
```

#### 3.3.2 매핑 워크플로우

```
[1차] LLM 자동 매핑
   - 입력: 능력단위 스킬셋 + L2 12개 AI 스킬셋 정의
   - LLM이 능력단위 스킬마다 융합 가능 AI 스킬셋(●/○/빈칸) 판정
   - 시앤피도 시작년도 적합성 평가에 ChatGPT/Gemini 등 사용 (보고서 p.50)
   - 우리는 동일 도구 + 검증 메커니즘 강화

[2차] 분야별 전문가 패널 검증
   - 분야별 AI 전문가 + NCS 전문가 5인 1조
   - LLM 1차 결과 검토 → 수정·승인
   - 합의 룰: 다수결 + 이견 시 책임자 조정

[3차] 매핑 매트릭스 v1.0 확정
   - 능력단위 단위로 핵심 융합 ● 페어 N개, 보조 융합 ○ 페어 M개 도출
   - DB 구축 (다년 자산)
```

### 3.4 Step 3. 융합 가능 페어 → AS-IS/TO-BE 워크플로우 (KTR 도구 차용)

각 융합 페어(능력단위 스킬 × AI 스킬)에 대해:

| 항목 | 내용 |
|---|---|
| **AS-IS** | AI 도입 전 직무 흐름 (현재 업무 방식) |
| **TO-BE** | AI 도입 후 변화 (시간 절감·정확도 향상·자동화 비율) |
| **AI 적용 임팩트** | 변혁(★★★) / 보조(★★) / 한정(★) 3등급 |
| **학습자 핵심 스킬** | 학습자가 익혀야 할 구체 스킬 (L3 세부 스킬에 매핑) |

#### 예시: "라우팅 관리" × "A-2 AI 워크플로우 자동화"

| 항목 | AS-IS | TO-BE |
|---|---|---|
| 트래픽 모니터링 | 운영자가 대시보드 실시간 감시 | AI 에이전트가 이상 트래픽 자동 탐지·알림 |
| 경로 최적화 | 수동 라우팅 테이블 조정 | AI 추천 + 자동 적용 (확인 후 승인) |
| 장애 복구 | 운영자가 로그 분석 후 조치 | AI가 장애 패턴 학습·자동 진단·1차 복구 시도 |

→ AI 적용 임팩트: **변혁(★★★)** → 융합 과목 우선 개발 대상

### 3.5 Step 4. 융합 분류 정성 3지표 평가 (RFP 명시)

RFP는 "AI 적용적합성 등 3개 지표"라고만 명시. 우리는 다음 3지표를 구체 정의:

| 지표 | 정의 | 척도 | 평가자 |
|---|---|---|---|
| **AI 적용적합성** | AI를 적용했을 때 직무 효율·품질 개선 효과 | 5점 | AI 전문가 + 산업 SME |
| **확장성** | 학습 후 다른 직무·산업으로 응용 가능성 | 5점 | 산업 SME + 교육공학 전문가 |
| **미래성** | 향후 3~5년 직무 변화에 부합하는 정도 | 5점 | AI 전문가 + 산업 정책 전문가 |

→ 라-3 융합 분야 분류의 객관적 근거가 됨 (RFP §II-2 다 정성 평가 요구사항).

### 3.6 Step 5. 융합 과목 생성 + 분야 분배 + STEP SLR 통합

#### 3.6.1 융합 과목 생성 룰

```
한 능력단위의 매핑 매트릭스 결과:
   • 핵심 융합 ● 페어 N개
   • 보조 융합 ○ 페어 M개

→ 융합 과목 생성 옵션:
   [옵션 1] 능력단위 1개 = 융합 과목 1개 (대표 페어 1개 중심)
   [옵션 2] 능력단위 1개 = 융합 과목 N개 (페어별 분리)
   [옵션 3] N개 능력단위 = 융합 과목 1개 (스킬셋 유사 능력단위 묶음)

판단 기준:
   - 학습량 (15시간 단위)
   - 학습자 인지부하
   - 직무 흐름 일관성
```

#### 3.6.2 분야 분배 (200과목, 발주처 협의 후 확정)

| 영역 | 과목 수 | 도출 방식 |
|---|---|---|
| **AX 공통** (전 산업 공통) | 20 | L2 A·B·C 영역 중심, 능력단위 무관 보편 과목 (예: 생성형 AI 활용·프롬프트 엔지니어링·AI 윤리) |
| **산업별 AI 활용** (10대 NCS) | 150 | 능력단위 스킬셋 × L2 D-1·D-2 매핑 결과 (대분류별 평균 15과목) |
| **GX (Green Transformation)** | 20 | L2 D-3 GX + 환경·에너지·안전 분야 능력단위 매핑 |
| **안전(로봇)** | 10 | RFP 명시. L2 D-3 + 로봇 분야 능력단위 매핑 |
| **합계** | **200** | — |

#### 3.6.3 STEP SLR 통합 ★ 사용자 화면 캡처 직접 반영

**중요한 인사이트**: 사용자가 보여준 STEP SLR 화면(직무별 학습 로드맵 — 인공지능서비스기획·교환전송설비공사 등)에서 확인됨:
- SLR은 직무별 × NCS 수준(1~8) 매트릭스 형태
- 각 셀에 과목들이 배치 (이러닝 E / 가상훈련 V 표시)
- "디지털 + 첨단 직종" 별도 표시
- 작년 시앤피 AI 리터러시 26개는 "사무직의 AI 리터러시 향상", "마케팅 직군의 AI 리터러시 향상" 같은 일반 과목으로 모든 직무에 동일하게 추가됨 → **도메인 특화 X**

**우리 융합 과목의 SLR 통합 방식**:

```
기존 STEP SLR (예: 교환전송설비공사 직무)
                    수준 3·4·5·6에 통신 관련 과목들
                    + (작년) 일반 AI 리터러시 6개 과목

   ↓ 우리 융합 과목 추가

  새 STEP SLR (예: 교환전송설비공사 직무)
                    수준 3·4·5·6에 통신 관련 과목들 (유지)
                    + (신규) AI 활용 네트워크 트래픽 자동 분석 (수준 5)
                    + (신규) AI 기반 라우팅 최적화 실무 (수준 6)
                    + (신규) AI 활용 장애 자동 진단·복구 (수준 6)
                    + (신규) 통신 인프라 AX 거버넌스 (수준 7)
                    ※ 시앤피 작년 일반 AI 리터러시는 별도 트랙으로 유지 가능
```

**결과**:
- 모든 융합 과목이 **NCS 능력단위 + 직무 + NCS 수준에 자동 매핑**
- SLR 화면에서 직무별로 자연스러운 학습 흐름
- **직능은행제·과정평가형 자격 연계 가능** (NCS 매핑이 출발점이므로)

## 5. 우리 방법론의 4대 강점 (제안서·발표자료 어필 포인트)

### 강점 1. **NCS 표준에서 출발 = 출처·근거의 강력함**
- 능력단위요소별 스킬은 NCS가 이미 표준화·고시한 자료
- 우리는 새로 만들지 않고 **이미 있는 자료를 정밀 활용**
- 발주처·평가위원 누구도 "근거 없음"을 제기할 수 없음
- RFP §III-1 "정부 및 공공기관의 공식통계와 신뢰할 수 있는 연구기관의 보고서와 조사 결과만을 사용하고 반드시 출처를 명기" 요구에 자연스럽게 부합

### 강점 2. **모든 융합 과목이 NCS·직무·SLR에 자동 매핑 = 시앤피 약점 본질적 해결**
- 시앤피 작년 AI 리터러시 7개는 NCS 매핑 부재로 직능은행제·자격 연계 불가
- 우리 200개는 능력단위에서 출발 → 매핑·연계 자동
- RFP §II-3 "제도연계" 직접 답

### 강점 3. **도메인 특화 융합 과목 = AX 본질에 부합**
- 과기정통부 AX 정의: "특정 분야 한정 AI 활용을 넘어 산업·공공·사회 전반의 AI 대전환"
- 시앤피 일반 AI 리터러시(사무직·마케팅) → AX 정의에 부합 X
- 우리 도메인 특화 융합 → AX 정의에 정확히 부합

### 강점 4. **다년 자산화 = 한기대-우리 다년 동행의 근거**
- 능력단위 스킬셋 DB + 매핑 매트릭스 = 27·28년 후속사업이 그대로 가져갈 수 있는 자산
- 매년 NCS 개정 시 매트릭스만 부분 갱신 (대대적 재구축 불요)
- 본 사업이 **지속 가능한 인프라**를 함께 만든다 (메모리 톤 부합)
