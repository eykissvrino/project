## 1. 전략 수립의 근거 (Why this strategy)

### 1.1 RFP가 명시한 4대 "제언" 영역 (RFP §II-3 가)
RFP가 본 사업에서 **반드시 답을 요구한** 4개 영역.
이 4개에 차별화 답이 있으면 25점 "수행계획적합성" 만점에 가까워진다.

| RFP 제언 영역 | 우리의 답 (요약) |
|---|---|
| **제도연계** | 직무능력은행제 시범 매핑 + 27년 후속사업 로드맵 |
| **자동화** | LLM 기반 NCS 매핑 + Master DB Python 파이프라인 + SLR 시스템 연계 |
| **조사체계 개선** | 설문 단계 재배치 시나리오 검증 + STEP 학습로그 활용 + 상시 수요조사 운영체계 |
| **매뉴얼화** | 산출물·DB·미활용·결측치 4종 매뉴얼 + 자동 만료 시스템 |

### 1.2 작년 시앤피 약점 = 우리 차별화 기회
2025년 정성제안서 분석에서 확인된 5가지 부족점.
**이 5개를 정조준하면 25점 "수행계획" + 10점 "활용성" 35점에 직접 영향**한다.

| 작년 부족점 | 우리의 차별화 |
|---|---|
| Win Theme/슬로건 부재 | 표지·1쪽·요약페이지 모두에 "AI·데이터로 진화하는 SLR" 통일 메시지 |
| AI/데이터 활용 한 줄도 없음 | 자동화 트랙(M1·M6 자동화·매핑·DB) 신설 + AX 도메인 200과목 |
| 수요조사 재래식 (모아폼+답례품) | STEP 학습 로그·검색어·중도이탈 활용 + 응답률 제고 4종 정책 |
| 직무능력은행제(M6) 빈약 (1쪽) | "제도 연계"를 별도 챕터로 5쪽 이상 + 시범 매핑 사례 1건 제시 |
| 외부 IT/데이터 전문가 없음 | NCS·이러닝 + AI/데이터 + AX 도메인 3축 컨소시엄 |

### 1.3 평가 가중치를 따라간 자원 배분 원칙
RFP §IV-3 동점자 우선순위 = ①수행계획(25) → ②인력조직(25) → ③과업이해도(20) → ④활용성(10).
**제안서 분량·발표 시간도 이 순서를 그대로 따른다.**

| 평가 항목 | 배점 | 정성제안서 분량 비중 | 발표 시간 |
|---|---|---|---|
| 과업이해도 | 20 | 18% (≈12쪽) | 3분 |
| **수행계획적합성** | **25** | **35% (≈24쪽)** | **8분** |
| **인력조직관리** | **25** | **22% (≈15쪽)** | **5분** |
| 활용성 | 10 | 12% (≈8쪽) | 2분 |
| 표지·개요·요약 | — | 8% | 2분 |
| 합계 | 80 | 100% (≈68쪽 본문) | 20분 |

## 2. 마스터 메시지 (Win Theme)

### 2.1 한 줄 슬로건
> ## **"AI·데이터로 진화하는 SLR — 1년이 지나도 한기대가 직접 돌리는 자율 운영체계"**

이 한 줄은 표지·요약페이지·발표 1쪽·발표 마지막 1쪽에 모두 등장한다.

### 2.2 슬로건 풀이 (3-Layer Story)

```
[Layer 1] AI·데이터로 진화하는 SLR
   → "수기·자문·서베이"의 시앤피식 방법론을 넘어
     LLM·학습로그·자동화 파이프라인을 결합한 차세대 방법론

[Layer 2] 1년이 지나도 한기대가 직접 돌리는
   → 단발성 컨설팅이 아닌, 발주처가 다음 해부터 자력 운영 가능한
     코드·매뉴얼·교육 패키지 함께 납품 (RFP "매뉴얼화" 직접 응답)

[Layer 3] 자율 운영체계
   → 신규 과목 도출 ↔ SLR 시스템 자동 연계
     상시 수요조사 운영 모델
     27년 후속사업의 부담을 작년의 1/3로 줄이는 구조
```

## 3. 4대 Win Theme (RFP 4대 제언 영역과 1:1 정렬)

각 Win Theme은 (1) 핵심 메시지 (2) 입증 근거 (3) 산출물 (4) RFP 매핑을 갖는다.

### WT1. AI 기반 SLR 자동화 엔진 — "수기를 코드로"

| 항목 | 내용 |
|---|---|
| **핵심 메시지** | LLM·NLP·Python으로 작년 매핑·DB 작업의 70%를 자동화. 재현 가능한 코드 자산을 함께 납품한다. |
| **입증 근거** | ① LLM 기반 NCS 능력단위-과목 매핑 정확도 95%+ 사전 검증<br>② Master DB → CSV → Pandas 파이프라인 시연 가능<br>③ 미활용 과목개요서 자동 만료 알림 시스템 프로토타입 |
| **산출물** | • Master DB Python 처리 코드 (GitHub 사내 저장)<br>• NCS 매핑 자동검증 스크립트<br>• 신규과목 ↔ SLR 시스템 연계 API 명세서 |
| **RFP 매핑** | §II-3 가 (자동화) / §II-2 가·바 (M1·M6) |
| **시앤피 대비** | 시앤피 작년 제안서: AI/데이터 활용 0건 → **우리: 4개 자동화 산출물** |

### WT2. 실증 데이터 기반 수요조사 재설계 — "응답자가 아닌 학습자에게 묻는다"

| 항목 | 내용 |
|---|---|
| **핵심 메시지** | 모아폼 설문 1,000명에 의존하는 작년 방식을 넘어, STEP 학습로그·검색어·중도이탈 데이터를 1차 신호로 사용한다. 설문은 가설 검증용으로 재정의한다. |
| **입증 근거** | ① 설문 단계 재배치 시나리오 A(현행)/B(설문선행)/C(혼합) 비교 매트릭스<br>② STEP 188만 학습자 행동데이터 활용 분석 설계서<br>③ 응답률 제고 4종 정책 (마이페이지 알림·강사 협조·인센티브·시점 분산)<br>④ 응답대상별 가중치 정량 모델 (학습자 0.4 / 기업 0.4 / ISC 0.2 등 RFP 협의안) |
| **산출물** | • 설문조사 설계 매뉴얼 (시나리오 비교 포함)<br>• 학습로그 분석 보고서 (M2·M4 단계)<br>• 상시 수요조사 운영체계 제안서 |
| **RFP 매핑** | §II-3 가 (조사체계 개선) / §II-2 라 (M4) |
| **시앤피 대비** | 시앤피 작년: "온라인 설문 + 답례품 추첨" 1줄 → **우리: 4개 메커니즘 + 학습로그 결합** |

### WT3. AX·GX·안전 통합 융합 200과목 설계 — "AI 리터러시 26개에서 AX 200개로"

| 항목 | 내용 |
|---|---|
| **핵심 메시지** | 작년 사업의 "AI 리터러시 26개" 한계를 정조준. 과기정통부 AX 정의(국가 전반의 AI 대전환)에 부합하는 10대 NCS 대분류 × AI 적용 매트릭스로 200과목을 체계적으로 도출한다. |
| **입증 근거** | ① 10대 NCS 대분류 × AX 적용 영역 매트릭스 (사전 작성 완료)<br>② AX 공통 20과목 + 분야별 150과목 + GX 20과목 + 안전(로봇) 10과목 사전 후보군<br>③ 18종 정책·산업 보고서 인용 (KIAT·삼정KPMG·딜로이트·과기정통부 등)<br>④ AI+X 자문위원 3인 (사전 자문 동의서 첨부 예정) |

| **RFP 매핑** | §II-2 마 (M5) / §I-2 라 (배경 - AI+X 융합 확대) |
| **시앤피 대비** | 작년 26개 → **올해 7.7배 확대 + 도메인 매트릭스 사전 제시** (시앤피는 AI 리터러시 정의도 협소했음) |

### WT4. 지속가능 매뉴얼화·제도연계 — "27년 후속사업의 부담을 작년의 1/3로"

| 항목 | 내용 |
|---|---|
| **핵심 메시지** | 본 사업이 끝난 12월부터 한기대 담당자 1인이 운영 가능한 형태로 산출물을 정리한다. 직무능력은행제 시범 연계로 27년 후속 사업의 명분도 함께 만든다. |

## 4. 메시지 위계 (Message Hierarchy)

평가위원 한 명이 30초만 본다고 가정한 **3-Layer 메시지 트리**.

```
[Layer 0 / 1줄] AI·데이터로 진화하는 SLR — 한기대가 직접 돌리는 자율 운영체계

  [Layer 1 / 4개 Win Theme]
   1. AI 자동화 엔진 (수기를 코드로)
   2. 실증 데이터 수요조사 (응답자가 아닌 학습자에게 묻는다)
   3. AX·GX 200과목 (26 → 200, 7.7배)
   4. 매뉴얼화·제도연계 (27년 부담 1/3)

    [Layer 2 / 각 Win Theme별 3개 입증]
     - 메시지 + 숫자 + 산출물
     - (모든 페이지 좌상단 헤더에 해당 Win Theme 번호 표시)
```

### 표현 규칙 (작년 시앤피와 차별)
- 모든 헤드라인은 "**숫자 + 결과형 동사**"로 작성
  - ✅ "Master DB 수기 작업 70% 감축"
  - ✅ "AX 26과목 → 200과목 (7.7배)"
  - ❌ "데이터 관리방안을 마련함" (작년 어조)
- RFP 금지어 절대 사용 금지: "가능하다 / 동의한다 / 할 수도 있다 / 고려하고 있다"
- 모든 숫자는 출처 표기 (예: "RFP p.7", "STEP 내부 통계")

## 5. 인력조직 차별화 전략 (배점 25점, 동점자 2순위)

### 5.1 컨소시엄 3축 구조 (시앤피의 단일축과 차별)

```
┌───────────────────────────────────────────────────────┐
│  Axis 1. NCS·이러닝 본진 (작년 시앤피와 동일 영역)            │
│   - 책임자(박사·교수) + ID 전문가 + NCS 분석가             │
├───────────────────────────────────────────────────────┤
│  Axis 2. AI·데이터 트랙 ★ 신설 (시앤피 약점 정조준)          │
│   - 데이터 엔지니어 + LLM 활용 가능 NLP 엔지니어              │
├───────────────────────────────────────────────────────┤
│  Axis 3. AX·GX·안전 도메인 자문단 ★                        │
│   - 제조 AX, 공공 AX, ESG·GX, 로봇·안전 분야 자문위원         │
└───────────────────────────────────────────────────────┘
```

### 5.2 책임자 자격 (RFP §IV-1)
- 대학 조교수 이상 / 박사 또는 기술사 + 3년 이상 / 학사 + 10년 이상 중 하나
- 책임자 후보 확정 → 이력서·자격증명서·재직증명서 사전 확보 (착수계 10일 내 제출 필요)

### 5.3 자문위원 구성 (제안서 명시 필수)
- ISC 위원 또는 NCS 전문가 (M1·M2 자문) — 작년 매칭률 38% 한계 보완
- 분야별 SME (M3·M5) — 10대 NCS 대분류별 1인
- AI 전문가 (M5 AX) — AX 200과목 도출의 신뢰성 담보
- 교육공학 전문가 (M5 양식·품질) — 과목개요서 표준화

→ **자문 동의서 사전 확보**, 제안서에 명단·소속·약력·동의 표시.

## 6. 발표(20분 + Q&A 10분) 차별화 전략

### 6.1 발표 슬라이드 1쪽 = Win Theme
시앤피처럼 환경분석부터 시작하지 않는다. **표지 직후 Win Theme 슬로건 + 4대 차별화 매트릭스 1쪽**으로 평가위원의 30초를 잡는다.

### 6.2 시각화 컨셉 (작년 시앤피와 차별)
- 작년 시앤피: 표/박스/번호 중심의 "텍스트 슬라이드"
- 우리: **시각적 메타포 + 수치 강조**
  - 자동화: "수기 → 코드" 변환 다이어그램
  - 학습로그: STEP 188만 학습자의 발자취를 점·선으로 시각화
  - AX 200과목: "26 vs 200" 큰 숫자 + 매트릭스 히트맵
