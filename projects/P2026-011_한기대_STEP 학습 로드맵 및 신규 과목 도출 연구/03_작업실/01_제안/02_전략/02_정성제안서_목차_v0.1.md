# 정성제안서 목차 — v0.1 (총 68쪽 ± 본문)

> **설계 원칙**
> 1. RFP §V "정성제안서 작성지침" 4대 항목(Ⅰ 제안개요·Ⅱ 제안내용·Ⅲ 수행조직·Ⅳ 제안업체)을 그대로 사용.
> 2. 분량은 평가 배점에 비례 (수행계획 35% > 인력조직 22% > 과업이해 18% > 활용성 12%).
> 3. 모든 페이지 좌상단에 해당하는 **Win Theme 번호(WT1~4)** 표시 → 평가위원이 어디를 보든 차별화 메시지가 노출.
> 4. 작년 시앤피의 **6 Module Framework**과 차별: 우리는 RFP 6대 절차(가~바)를 그대로 따르되 "트랙(자동화/데이터/도메인/매뉴얼)"이라는 직교축을 추가.

## 6. 활용성 (별도 챕터 신설 여부 검토)

> RFP 작성지침에는 "활용성"이 별도 항목으로 명시되어 있지 않다.
> 그러나 평가배점 10점이 있으므로, **Ⅱ장 후반 또는 Ⅴ장 별첨**으로 1~2쪽 추가 검토.
>
> **제안: Ⅱ-3 추진일정계획 직후 "Ⅱ-4 결과물의 활용성" 1~2쪽 추가**
> - 한기대가 12월부터 자력 운영 가능한 형태
> - 27년 후속사업 직접 연계
> - 직무능력은행제·SQF 시범 매핑 결과 활용
> - 다른 공공·민간 평생교육 기관 벤치마크 가능성

→ v0.2에서 결정. 우선 본 목차에는 미반영.

## 8. 작성 가이드 (모든 작성자 공통)

1. **모든 페이지 좌상단에 Win Theme 번호 표시** (WT1~4 또는 "기반").
2. **모든 헤드라인은 "숫자 + 결과형 동사"**.
3. **출처 표기 필수** (RFP p.X / 시앤피 2025 보고서 p.Y / 정책자료명).
4. **금지어**: "가능하다 / 동의한다 / 할 수도 있다 / 고려하고 있다 / Framework / TTR / Updating".
5. **숫자 통일**: 11지표·3지표·6지표·400과목·N₁N₂N₃·50%/35%/15% 등 RFP 그대로.
6. **이미지·도식**: 시앤피의 박스+텍스트형이 아닌 **시각적 메타포 + 큰 숫자**.
7. **장 시작 페이지마다 Layer 0 슬로건 푸터 1줄** (브랜딩 효과).
8. **PDF 변환 시 폰트 임베드** (나라장터 미리보기에서 깨짐 방지).
