# /weekly-report

## 트리거
- 매주 금요일 (또는 발주처 협의 요일)
- 수시협의 발생 시 추가

## 단계

1. 지난 주 진행 모듈(M1~M6) 별 진척률 집계
2. 산출물 목록 (이번 주 완료된 것)
3. 다음 주 계획
4. 리스크·이슈 (있을 시)
5. 발주처 협의·확인 필요 사항
6. `_AI_체계/templates/주차보고_template.md` 기반 자동 채움
7. `04_보고및회의/02_주차보고/[YYMMDD]_주차보고_v[N].hwp` 저장
8. 발주처 발송 + 회의록 별도 보관

## 양식 (요약)

```
[2026-MM-DD] 주차보고
1. 지난주 진행 사항 (모듈별)
2. 산출물 (링크)
3. 다음 주 계획
4. 리스크·이슈
5. 발주처 확인 요청 사항
```
