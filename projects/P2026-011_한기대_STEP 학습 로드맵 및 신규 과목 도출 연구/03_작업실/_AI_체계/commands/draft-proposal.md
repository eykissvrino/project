# /draft-proposal

## 사전 조건
- `01_제안/01_분석/` 4개 파일 모두 작성됨
- `01_제안/02_전략/` 윈테마 확정됨
- 참여 인력 정보 확보 (학력·경력·연구실적)

## 실행 단계

1. **proposal-writer 에이전트 호출**
2. **섹션별 초안 작성** (CLAUDE.md §5의 정성제안서 골격 따름)
   - 각 섹션을 `01_제안/03_정성제안서/{번호}_{섹션명}.md`로 저장
3. **시각 자료 플레이스홀더** 표시 (`[FIG: 6대 연구절차 흐름도]`)
4. **qa-reviewer 호출** → 초안 검수
5. **2차 작성** → 검수 반영 → 재검수
6. **최종 머지** → 단일 .docx/.pptx
7. **PDF 변환** → `01_제안/06_제출본/`

## 출력 후 사용자 액션

1. 시각 자료 (도식·표·그림) 디자이너에게 의뢰
2. 참여 인력 학력·경력 사실 확인
3. 신용평가서·증빙서류 첨부
4. 발표자 선정 → `prep-presentation` 커맨드 실행
