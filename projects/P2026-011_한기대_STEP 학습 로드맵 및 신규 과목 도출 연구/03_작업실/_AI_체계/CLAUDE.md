## 1. 우리의 미션 (Two-Phase Mission)

본 프로젝트는 두 단계 미션을 가진다. **AI 체계는 두 단계 모두를 지원해야 한다.**

### Phase A — 수주 (제안서 작성·발표·낙찰)
- 산출물: 정량제안서 / 정성제안서 / 발표자료 / 제안요약서 (모두 PDF, 합계 300MB 이내)
- 평가: 외부 5인 포함 8인 평가위원, 발표 20분 + Q&A 10분
- 결승선: **수주 (협상순위 1순위 선정)**

### Phase B — 수행 (낙찰 후 사업 수행 및 납품)
- 6대 연구절차 수행 → 6개 모듈 산출물 생성 → 11/20 납품
- 결승선: **무사 완료 + 발주처 만족도 + 후속 사업 수주 기반 마련**

→ **제안서에 쓴 모든 약속(Promise)은 Phase B에서 실제로 이행 가능해야 한다.**
→ 제안서 작성 시 Claude는 "이 문구를 우리가 11/20까지 실제로 만들 수 있는가?"를 항상 자문한다.

## 2. 과업 핵심 (3대 최종산출물 + 6대 연구절차)

### 2.1 3대 최종산출물
1. **SLR 고도화**: 10대 분야 도식(PPT) + Master DB(엑셀) 1식
2. **신규 과목개요서 400과목**
   - 평생직업능력개발 100과목 (10대 NCS 대분류 중심)
   - 디지털·첨단 100과목 (21대 직종 중심)
   - 융합(AI+X) 200과목 (AX + GX + 안전(로봇) 포함)
   - 가상훈련(V) 및 E·V 연계 최소 30개 이상 포함
3. **연구보고서 20부 + SLR 관리매뉴얼 1부**

### 2.2 6대 연구절차 (RFP §II-2)
| 단계 | 명칭 | 핵심 산출물 | 폴더 |
|---|---|---|---|
| 가 | STEP 학습 로드맵 최신화 | Master DB 1차 업데이트 | `03_수행/M1_SLR최신화/` |
| 나 | NCS 세분류 수요분석 | **세분류 순위 N₁** (정량 11지표 + 정성 3지표) | `03_수행/M2_세분류수요분석/` |
| 다 | NCS 능력단위 수요분석 + 개발 적합성 평가 | **능력단위 순위 N₂** (정성 + 6지표) | `03_수행/M3_능력단위적합성/` |
| 라 | 설문조사 | **개발 우선순위 N₃** (설문 50% + 정량 35% + 정성 15%) | `03_수행/M4_설문조사/` |

### 2.3 RFP가 우리에게 명시적으로 "제언"을 요구한 4대 영역 (= 윈 테마 후보)
> 이 4가지는 제안서에서 반드시 차별화 답을 제시해야 한다 (RFP §II-3 가).

1. **제도연계** — 정책 활용 및 후속 사업 추진을 위한 관련 제도 연계 방안
2. **자동화** — 신규 과목 도출 ↔ SLR 시스템 연계 자동화
3. **조사체계 개선** — 설문조사 단계 재배치 타당성 검증, 개발분야 분류 지표 명확화, 상시 수요조사 도입
4. **매뉴얼화** — 산출물 관리, Master DB 데이터관리, 미활용 과목개요서 후속조치, 결측치 처리 규정화

## 6. Claude 행동 원칙 (Project-Specific)

1. **한글로 답한다.** 단, NCS/SQF/STEP/SLR/AX/GX 같은 약어는 그대로.
2. **RFP 용어를 임의 변경하지 않는다.** 작년 명칭(TTR)은 비교 맥락에서만 사용.
3. **모든 수치·정의는 RFP 페이지를 인용한다.** (예: "RFP p.7")
4. **숫자는 항상 출처를 단다.** 2,586개 과목, 9,497개 능력단위, 400과목, N₁/N₂/N₃ 등.
5. **불확실하면 발주처에 확인할 사항으로 따로 기록한다** → `99_프로젝트관리/DECISION_LOG.md`
6. **제안서 작성 시 "가능하다 / 동의한다 / 할 수도 있다"는 금지어** (RFP p.22 명시).
7. **모든 데이터 처리는 출처를 명기**한다 (RFP p.12 §III-1).
8. **하도급 금지** — 외부 자문위원/협력사는 자문/검토 형태만 가능.
9. **보안각서** — 외부에 자료 유출 절대 금지. AI에게 제공한 자료도 본 디렉토리 외부로 복사 금지.
10. **버전 관리** — Master DB는 `master_db_versions/`에 날짜+버전(v0.1, v0.2...)으로 저장.

## 7. 핵심 용어집 (요약 — 상세는 `memory/glossary.md`)

- **STEP**: Smart Training Education Platform (한기대 온라인평생교육원 플랫폼)

- **미활용 능력단위**: NCS에서 삭제·통합·신설로 활용되지 않은 능력단위 (미활용 과목개요서 포함)

## 8. 발주처가 싫어하는 것 (작년 사업 회고 기반)

작년 시앤피컨설팅 산출물 분석 결과 발주처가 추가 요청·논의한 사항들:

- 설문조사 문항 수가 방대해 응답 신뢰도 낮음 → **단계 재배치 타당성 검증 요청** (RFP §II-3)
- 미활용 과목개요서가 누적되는 문제 → **사후처리 기준 마련 요청**
- Master DB 수기 관리 → **데이터 관리 방안 요청**
- AI 리터러시는 협소 → **AX(AI+X) 융합으로 확대 + GX 신규 포함**
- SQF 매칭률 38%에 그침 → **ISC 최신 자료 직접 반영 필요**

→ 이 5가지는 우리 제안서에서 **반드시** 차별화 답을 제시한다.
