# 작년 사업 교훈 (2025 → 2026)

## 작년 수행사
- **시앤피컨설팅(주)** (2025 TTR 사업 수행)
- 보고서 200쪽, 중간보고 34쪽, AI 추가 협의자료 6쪽
- 제안서 68쪽

## 작년에 좋았던 점 (우리도 따라가야 할 수준)
1. **Framework 7개 Module 재구조화** — RFP를 단순 따라가지 않고 자체 구조 제시
2. **AI 리터러시 26개 과목** 별도 트랙 신규 개발
3. **NCS 매핑률 99.3%** (2,624개 중 2,606개)
4. **오픈마켓 콘텐츠 NCS 매핑 97.8%** (2,909개 중 2,845개)
5. **전문가 검토 + 온평원 최종 검토** 2중 검수

## 작년에 부족했던 점 (= 우리 차별화 기회)
1. **SQF 매칭률 38%** — NCS 사이트 SQF만 참조한 한계
   → **우리 해결책**: ISC 직접 발표본 동시 활용
2. **설문 문항 방대 + 응답 신뢰도 낮음** (RFP가 명시 요청)
   → **우리 해결책**: 설문 단계 재배치 (시나리오 A/B/C 비교)
3. **미활용 과목개요서 누적**
   → **우리 해결책**: 1년/2년 정책 + 자동 만료 시스템
4. **Master DB 수기 관리**
   → **우리 해결책**: Python 자동화 파이프라인
5. **AI 리터러시 → 협소** (발주처 11/13 회의에서 명시)
   → **우리 해결책**: AX(200개) + GX + 안전(로봇) 통합 설계

## 발주처가 추가 요청한 사항 (11/13 회의자료)
1. AI 리터러시 공통 3개(데이터·보안·윤리)는 유지, 기초·활용은 AX로 재개발
2. AX 영역 = 기존 TTR 10대 대분류 범위
3. AX 정의: 특정 분야 한정 AI 활용을 넘는 국가 전반 AI 대전환 (과기정통부)
4. AX 개발 절차 1안/2안 제시 받음 → 발주처 선호 방향 확인 필요
5. 평생 vs 디지털 비중: 동일 50:50 or 세분류 규모 81:19 → 발주처 결정 사항
6. TTR 직무체계 최신화 = NCS 12/4 고시 기준 능력단위 적용
7. SQF 최신 자료는 NCS 사이트 + ISC 발표본 모두 참조

→ 이 7가지가 올해 RFP에 모두 반영됨. **우리는 이 7가지 답을 사전 준비**한다.
