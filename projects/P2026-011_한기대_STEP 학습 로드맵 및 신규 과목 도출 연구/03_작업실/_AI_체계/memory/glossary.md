# 용어집

## 정부·제도
| 약어 | 풀이 | 설명 |
|---|---|---|
| NCS | National Competency Standards | 국가직무능력표준. 산업현장 직무 수행에 요구되는 지식·기술·태도를 표준화 |
| SQF | Sectoral Qualifications Framework | 산업별 자격체계. NCS와 자격을 연계 |
| ISC | Industry Sector Council | 산업별 인적자원개발위원회. SQF 직무체계 직접 발표 |
| 직무능력은행제 | Job Skill Bank System | 학습·자격·경력을 통합 인정하는 제도 |

## STEP·SLR
| 약어 | 풀이 | 설명 |
|---|---|---|
| STEP | Smart Training Education Platform | 한기대 온평원의 통합 학습 플랫폼 |
| SLR | STEP Learning Roadmap | STEP 학습 로드맵 (2026 신규 명칭) |
| TTR | Technical Training Roadmap | (구) 기술교육로드맵 — 2025까지 명칭. 본 사업에서 사용 금지 |
| 온평원 | 온라인평생교육원 | 한기대 산하 부서 (발주처) |
| 이러닝(E) | e-Learning | 온라인 비대면 학습 |
| 가상훈련(V) | Virtual Training | VR/AR/메타버스 기반 가상 실습 |
| 연계(E·V) | E·V 연계 | 이러닝과 가상훈련 결합 |
