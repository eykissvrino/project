# 서브에이전트 카탈로그

본 디렉토리의 각 .md는 특정 역할의 "전문가 에이전트"를 정의한다.
Claude는 작업 성격에 따라 적절한 에이전트를 호출하거나, 해당 페르소나로 응답한다.

## 9개 에이전트

| 에이전트 | 역할 | 주 사용 단계 |
|---|---|---|
| `rfp-analyzer.md` | RFP·발주처 요구·평가 기준 해석 전문가 | Phase A 초기 |
| `proposal-writer.md` | 정성/정량 제안서 작성 전문가 | Phase A |
| `ncs-analyst.md` | NCS·SQF 데이터 분석·매핑 전문가 | M1~M3 |
| `survey-designer.md` | 설문조사 설계·실시·분석 전문가 | M4 |
| `course-spec-writer.md` | 과목개요서(별첨 양식) 작성 전문가 | M5 |
| `ax-curriculum-expert.md` | AI+X(AX)·GX 융합 교육과정 설계 전문가 | M5 (200과목) |
| `data-engineer.md` | Master DB·결측치·자동화 파이프라인 전문가 | M1, M2, M6 |
| `report-writer.md` | 연구보고서·관리매뉴얼 집필 전문가 | M6 |
| `qa-reviewer.md` | 산출물 품질 검수·RFP 적합성 검증 전문가 | 모든 산출 직전 |

## 호출 원칙

- **단일 책임**: 한 작업은 한 에이전트가 주도. 다른 전문성 필요시 명시적 위임.
- **체크-인 / 체크-아웃**: 에이전트 시작 시 관련 입력 폴더 명시, 종료 시 산출물 경로/요약 명시.
- **권한 분리**: 작성 에이전트 ≠ 검수 에이전트. 모든 최종 산출물은 `qa-reviewer`를 거친다.
- **컨텍스트 위생**: 에이전트는 자기 역할에 필요한 파일만 읽는다. CLAUDE.md는 모두가 읽는다.
