# Proposal Formatting

## 정성제안서 (메인)

### 형식 권장
- 형태: PPT 또는 HWP → PDF 변환
- 페이지: 30~50p (RFP에 별도 제한 없으나 가독성 우선)
- 폰트: 본문 11~12pt, 제목 16~20pt, 한글 폰트(맑은고딕/HY견고딕)
- 색상: 한기대 BI 컬러 (확인 필요) + 무채색 보조

### 페이지 구성
- 표지 1 (서식 3, RFP p.30)
- 제출문 / 목차 / 머리말 1~3
- Ⅰ 제안개요 3~5
- Ⅱ 제안내용 (가장 두꺼움) 20~30
  - 추진방향 2~3
  - 수행계획 15~20 (M1~M6 + 윈테마)
  - 일정 2~3
- Ⅲ 수행조직 5~8
- Ⅳ 제안업체 일반 3~5
- 부록 (참고)

### 시각화 원칙
- 1쪽당 시각 자료 1개 이상 (도식·표·타임라인)
- "벽돌 텍스트" 금지
- 색·아이콘으로 시선 유도
- 모든 그림에 캡션

## 발표자료 (제안요약서)

### 형식 (RFP p.18, 20분 발표)
- 17~19 슬라이드
- 1슬라이드 = 1메시지
- 발표 시 1슬라이드 약 1분 페이스

### 권장 흐름
| 슬라이드 | 내용 |
|---|---|
| 1 | 표지 |
| 2 | 목차 |
| 3 | "우리가 약속하는 3가지" — 윈 테마 헤드라인 |
| 4-5 | 과업 이해 (RFP 재정의 + 작년 대비 변화) |
| 6-12 | 수행 방안 (M1~M6 + 윈테마 핵심 1~2장씩) |
| 13-14 | 조직·인력 |
| 15 | 일정 |
| 16-17 | 차별화·활용성 |
| 18 | 마무리 — 우리가 약속하는 것 |
| 19 | 감사 |

## 파일 명명 (제안서 산출물)

```
01_제안/06_제출본/
├── [YYMMDD]_정량제안서_v[N].pdf
├── [YYMMDD]_정성제안서_v[N].pdf
├── [YYMMDD]_발표자료_제안요약서_v[N].pdf
└── [YYMMDD]_기타서류_v[N].pdf  (신용평가, 책임자 자격, 상생협력 증빙)
```

## PDF 용량 관리 (RFP: 합계 300MB 이내)

- 이미지: 300dpi 이내, JPG 압축
- 폰트: Subset 임베드
- 워드/PPT → PDF 시 "최소 크기" 옵션
- 최종 합계 250MB 이내 권장 (여유 50MB)

## 제출 직전 체크 (RFP p.20~21 준수)

- [ ] 나라장터에 정상 송신 확인
- [ ] PDF 형식 (다른 형식 불가)
- [ ] 합계 300MB 이내
- [ ] 제안 담당자 (성명·전화) 정확 입력
- [ ] 사인·날인 필요 서식 모두 처리
- [ ] 정량/정성/발표자료/기타 4종 모두 포함
- [ ] 우선협상대상자 선정 시 USB 또는 인쇄물 추가 제출 대비
