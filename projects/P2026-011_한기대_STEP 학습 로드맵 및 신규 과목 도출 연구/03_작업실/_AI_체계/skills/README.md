# 스킬 카탈로그

각 디렉토리는 반복적으로 수행되는 도메인 작업의 SOP(Standard Operating Procedure)다.

| 스킬 | 용도 |
|---|---|
| `ncs-sqf-handling/` | NCS·SQF 데이터 수집·매핑·검증 |
| `master-db-management/` | Master DB 스키마·버전·자동 검증 |
| `course-outline-generation/` | 과목개요서 400과목 일관 생성 |
| `slr-diagram-creation/` | SLR 10대 분야 도식 자동 생성 |
| `proposal-formatting/` | 제안서 표지/페이지/스타일 |
| `koreatech-style-guide/` | 한기대(KOREATECH) 발주처 톤·용어 |

각 스킬 디렉토리의 `SKILL.md`를 참조하여 사용한다.
