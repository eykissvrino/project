# NCS·SQF Handling

## 데이터 출처 (우선순위)

1. **NCS 최신 고시본** — https://ncs.go.kr (능력단위 + 학습모듈 + 채용가이드)
2. **SQF (NCS 게시)** — NCS 사이트 내 SQF 메뉴
3. **SQF (ISC 직접 발표)** — 산업별 인적자원개발위원회 (작년 매칭률 38% 한계 극복용)
4. **국가기술자격 정보** — Q-Net
5. **TTR/SLR 직무체계** — 발주처 제공 + STEP 사이트

## 표준 작업 절차

### Step 1: 데이터 수집
```
- NCS 사이트에서 최신 고시본 다운로드 (분기 1회)
- 능력단위 변경 이력(삭제·통합·신설) 별도 시트 추출
- ISC 사이트에서 분야별 직무체계 직접 수집 (작년 한계 극복)
- 출처·수집일자 메타데이터 필수 기록
```

### Step 2: 정제·표준화
```
- 능력단위 코드 규격화: XXXX_YYV[숫자] (NCS 표준)
- 분류번호 분리: 대(2)-중(2)-소(2)-세(2)
- 한글명 트림·중복공백 제거
- 영문명 보존
```

### Step 3: 매핑 (기개발 과목 ↔ 최신 능력단위)

**3중 검증** 원칙:
1. **코드 매칭** (1차) — 동일/유사 코드
2. **이름 유사도** (2차) — 능력단위명 + 능력단위요소 명 비교
3. **내용 검토** (3차) — 학습목표·학습내용 키워드 비교

매핑 신뢰도 점수화:
- 1.0 = 코드 동일 + 이름 동일
- 0.8 = 코드 다름 but 이름·내용 동일 (통합 케이스)
- 0.5 = 부분 일치 (인간 검수 필요)
- 0.0 = 매칭 불가 → 미활용

### Step 4: 검증
```python
# 의사코드
assert no_orphan_codes()      # 사용된 코드가 모두 NCS에 존재
assert no_duplicates()         # 동일 능력단위에 복수 과목 매핑 시 의도된 것
assert all_courses_mapped()    # 2,586개 모두 매핑 시도됨
assert mapping_confidence >= 0.5 or flagged_for_review
```

### Step 5: 산출
- `master_db_versions/[YYMMDD]_v[N]_매핑.xlsx`
- `_공통데이터/ncs_raw/[YYMMDD]_변경분.xlsx`
- 검증 리포트 `.md`

## 자주 발생하는 이슈

- **버전 충돌**: 같은 능력단위에 22v3·22v4 공존 → **22v4 우선** + 22v3 매핑 변경 이력 추적
- **분류 이동**: 능력단위가 다른 세분류로 이동 → 양쪽 모두 기록 + 신 분류 우선
- **명칭만 변경**: 코드 동일 + 이름 변경 → 신명칭 사용 + 구명칭 별칭으로 기록
- **SQF 불일치**: NCS 사이트 SQF와 ISC SQF 다름 → **ISC 우선** + 차이 별도 시트

## 한국 NCS 특수 사항

- NCS는 매년 12월 고시 (분기별 패치도 있음)
- 산업안전·환경 등은 법령 변경에 따라 비정기 개정
- "수준 1~8" 체계 — 본 사업 대상은 주로 3~5수준
- 능력단위요소 표기: `[능력단위코드].[순번]` (예: 1901070108_22v3.1)
