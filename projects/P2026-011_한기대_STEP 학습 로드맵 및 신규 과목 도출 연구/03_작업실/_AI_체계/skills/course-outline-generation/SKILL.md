# Course Outline Generation

## 입력
- N₃ 우선순위 결과 (400개 과목 후보)
- NCS 능력단위 상세 (능력단위요소·학습목표·평가준거)
- 발주처 승인 분야 비율 (평생:100 / 디지털:100 / AIX:200)

## 절차

### 1. 과목 메타 확정 (10과목 단위 배치)
- 과목명 (국문 정확 + 영문 선택)
- NCS 분류번호 (대-중-소-세분류)
- 능력단위 코드 + 명 + 수준
- 분야 구분 + 적합성 평가 결과 (E/V/E·V)
- 자격연계 가능 여부

### 2. 과목 소개 작성
- 과목 개요: 능력단위 정의를 풀어쓴 1~2문장
- 과목 특징: 이 과목만의 차별적 가치
- 과목 필요성: 누가, 왜 듣는지 — 학습 대상 명시

### 3. 학습목표·구성
- 학습목표 3~5개 (모두 행동 동사형)
- 학습 대상·난이도·도구·키워드 5개
- 참고자료 3개 (최근 2년)

### 4. 회차별 구성 (가장 큰 작업)
- 회차 수 결정 (능력단위 표준 12회차, 가변)
- 회차마다:
  - 회차명
  - 학습목표 2개
  - 학습내용 2개
  - 능력단위요소 (분류번호)
  - 이론/실습/사례 6칸 체크

### 5. 부가정보
- 선수·후수 과목 (Master DB 참조)
- 개발 필요성 매트릭스
- 메타버스 활용성
- 수요기관·활용처

## 일관성 보장 도구

### 공통 어휘 사전 (`_AI_체계/templates/과목개요서_사전.md`)
| 잘못된 표현 | 권장 표현 |
|---|---|
| "~를 알 수 있다" | "~를 설명할 수 있다" |
| "~의 이해" | "~의 원리 이해 및 적용" |
| "할 줄 안다" | "수행할 수 있다" |
| "기본적인 ~" | "기초 수준의 ~" (NCS 수준 일치) |

### 분야별 베이스 템플릿
- `_AI_체계/templates/과목개요서_평생.md`
- `_AI_체계/templates/과목개요서_디지털.md`
- `_AI_체계/templates/과목개요서_AIX.md`

## 자동화 + 인간 검수 워크플로우

```
[1] N₃ 결과 → 과목 후보 리스트 자동 생성
[2] AI (course-spec-writer) → 초안 100개 배치
[3] 도메인 SME (전문가 자문위원) → 10개 샘플 검수
[4] AI 보정 → 검수 피드백 반영하여 90개 정제
[5] qa-reviewer → 100개 전수 양식 검수
[6] 발주처 중간 보고 → 분야별 샘플 5~10개 확인
[7] 최종 100개 확정
```

## 산출 형식

- **개별 파일**: `[분야약자]_[NCS세분류]_[과목명].docx`
  - 분야약자: `LL` (평생), `DG` (디지털·첨단), `AX` (AI+X), `GX` (Green), `RB` (안전 로봇)
- **메타 일괄**: `[YYMMDD]_과목개요서_400_메타.xlsx` (모든 헤더 정보)
- **인덱스**: `[YYMMDD]_과목개요서_400_색인.md` (제출용 목록)

## 가상훈련(V) 30개 보장 전략

평생 + 디지털 200과목 중 V·E·V 최소 30개 확보:
- 우선 후보: 산업안전 / 위험 실습 / 고비용 장비 / 정밀 조작
- 메타버스 친화: 협업·시뮬레이션·디지털 트윈 가능 분야

## QA 자동 체크

각 생성 직후:
- [ ] 양식 누락 항목 없음
- [ ] NCS 분류번호 유효 (Master DB와 일치)
- [ ] 학습목표가 평가 가능한 행동 동사
- [ ] 참고자료 2024년 이후
- [ ] 회차당 능력단위요소 명시
- [ ] 이론/실습 체크 1개 이상
