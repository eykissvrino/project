# KOREATECH Style Guide

## 기관 명칭

- 정식: 한국기술교육대학교 (영문: KOREATECH)
- 약칭: 한기대 (구어용. 공식 문서에서는 정식 명칭 권장)
- 본 사업 발주 부서: **온라인평생교육원** (약칭 "온평원" 사용 가능)
- 부서 내: **이러닝파트**
- 결제·회계: 회계팀 (041-560-2550)

> 작년 시앤피 자료에서 "온평원"이 빈번히 사용됨 → 발주처 친숙 용어로 인정.

## STEP 플랫폼

- 정식: **STEP** (Smart Training Education Platform)
- 약칭으로 "STEP"만 단독 사용 가능
- 도메인: step.or.kr

## 핵심 약어 (반드시 정확하게)

| 약어 | 풀이 | 비고 |
|---|---|---|
| SLR | STEP Learning Roadmap | 본 사업의 핵심 산출물 명 (2026 신규) |
| TTR | Technical Training Roadmap | **작년까지의 명칭**. 본 사업에서 사용 금지 (비교 맥락 제외) |
| NCS | National Competency Standards | 국가직무능력표준 |
| SQF | Sectoral Qualifications Framework | 산업별 자격체계 |
| ISC | Industry Sector Council | 산업별 인적자원개발위원회 |
| AX | AI Transformation | 인공지능 대전환 (=AI+X) |
| GX | Green Transformation | 탄소중립/녹색전환 |
| E / V | 이러닝 / 가상훈련 | 과목 유형 |

## 표기 일관성

- "STEP 학습 로드맵(SLR)" — 처음 등장 시 풀어쓰기, 이후 SLR
- "신규 과목개요서 400과목" — "400개" 아님, **400과목**
- "이러닝(E)·가상훈련(V)" — 가운데점 사용
- "융합(AI+X)분야" — 띄어쓰기 없음

## 톤

- **공식·중립**: 사적 의견·감정 표현 배제
- **데이터·증거 기반**: "~로 보인다" 대신 "~로 나타났다 (출처)"
- **약속·확신**: "가능하다" 대신 "수행한다" / "제출한다"
- **존중·협업**: 발주처를 "귀 기관" 또는 "한국기술교육대학교 온라인평생교육원"으로 호칭

## 금지 표현 (RFP p.22 명시)

- 가능하다 / 동의한다 / 가능하다고 본다 / 할 수도 있다 / 고려하고 있다
- → 모두 **확정 동사**로 대체

## 작년 자료의 표현 — 주의

작년 시앤피 보고서·제안서에서 발견된 표현:
- "Framework" → 한글 "체계" 권장
- "Updating" → "최신화" / "갱신"
- "List" → "목록"
- "Pool" → "풀" 또는 "후보군"
- "DB" → "DB" 유지 (보편적)
- "TTR Master DB" → "**SLR Master DB**" (명칭 변경 반영)

## 문서 헤더 표준

```
사업명: 2026년도 STEP 학습 로드맵(SLR) 및 신규 과목 도출 연구
발주: 한국기술교육대학교 온라인평생교육원
수행: [당사명]
작성일: YYYY.MM.DD
버전: v[N.N]
```
