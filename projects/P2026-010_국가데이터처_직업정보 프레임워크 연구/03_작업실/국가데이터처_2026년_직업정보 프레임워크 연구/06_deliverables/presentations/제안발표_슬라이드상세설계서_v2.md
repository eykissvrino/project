# S03. 연구 배경 및 필요성 (1/2)

> **헤드메시지**: ISCO-28 전면 개정에 대비하여, 직업분류 편제 기준인 직능유형 프레임워크의 구축이 시급함.

**좌측 — 연구 배경 (글머리기호)**

■ 직업분류 체계의 정책적 중요성
  - 국가 차원의 직업분류체계는 노동시장 통계 생산뿐만 아니라 직업정보 제공, 인력수급 분석, 교육·훈련 정책 설계 등 다양한 정책 영역에서 활용되는 핵심 기반 인프라임
  - 우리나라의 한국표준직업분류(KSCO) 역시 국제표준직업분류(ISCO-08)를 기반으로 구축되어 국가 통계 및 행정자료 생산의 표준 기준으로 활용되고 있음

■ ISCO-28 개정 동향
  - 국제노동기구(ILO)는 ISCO-28 개정 논의 과정에서 직능수준체계를 교육(Education), 책임성(Responsibility), 경험(Experience), 업무기반학습(Work-based learning) 등 다양한 요소를 반영하는 방향으로 확대하고 있음
  - 이에 따라 한국표준직업분류의 대분류 등 전면 개정이 예상되며, 이를 뒷받침할 직능유형 프레임워크가 필요함

■ 노동시장 환경의 급격한 변화
  - 기술혁신, 디지털 전환, 새로운 산업의 등장 등으로 인해 직업 구조가 빠르게 변화하고 있으며, 기존 직업분류체계만으로는 직업 간 유사성, 직무 특성, 요구 역량 등을 체계적으로 설명하는 데 한계가 제기되고 있음

**우측 — 해외 vs 국내 직업정보 격차 (비교 도식)**

```
┌── 해외 (O*NET 등) ──┐     ┌── 국내 (KSCO) ────┐
│ ✓ 업무활동(Work Act.)│     │ ✓ 직업명, 코드     │
│ ✓ 기술/도구          │     │ ✓ 직무 정의       │
│ ✓ 역량/능력/지식     │     │ ✓ 주요 업무(서술형)│
│ ✓ 학력/자격 요건     │     │ ✗ 구조화된 정보    │
│ ✓ 업무환경/맥락      │     │ ✗ 역량/기술/도구   │
│ ✓ 임금/고용전망      │     │ ✗ 업무환경/자격    │
│                     │     │                   │
│ → 다차원 구조화 DB   │     │ → 서술형 텍스트    │
└─────────────────────┘     └───────────────────┘
           ◀────── GAP ──────▶
```

# S04. 연구 배경 및 필요성 (2/2)

> **헤드메시지**: 현행 한국표준직업분류는 직업정보가 서술형·비구조화 형태로, 직업 간 체계적 비교·분석 및 정책 활용에 한계가 있음.

**상단 — KSCO 직업정보의 3대 한계 (넘버 카드)**

```
┌──── ❶ 서술형 문장 형태 ────┐  ┌──── ❷ 표준화된 분류 부재 ──┐  ┌──── ❸ 데이터 구조 미구축 ──┐
│                           │  │                          │  │                          │
│ 직업의 수행 활동이 서술형   │  │ 동일한 업무활동이 서로 다른 │  │ 직업정보가 데이터 구조     │
│ 문장 형태로 제시되어 있음.  │  │ 표현으로 기술되는 경우가   │  │ 형태로 구축되어 있지 않음. │
│ KSCO에서는 각 직업의 주요  │  │ 많아 직업 간 업무활동의    │  │ 현재의 직업 설명은 문장    │
│ 업무를 문장 형태로 설명하고 │  │ 유사성을 체계적으로       │  │ 형태로 제시되어 있어       │
│ 있으나, 이러한 설명은      │  │ 분석하기 어려움           │  │ 직업정보 데이터베이스      │
│ 직무활동 단위로 구조화되어  │  │                          │  │ 구축이나 직업 분석 연구에  │
│ 있지 않아 직업 간 비교     │  │                          │  │ 활용하기에 제한적임        │
│ 분석에 활용하기에 한계가 있음│  │                          │  │                          │
└───────────────────────────┘  └──────────────────────────┘  └──────────────────────────┘
```

**하단 — 직업정보 프레임워크 개선과 직업분류 개정의 관계 (흐름도)**

```
  직업정보 프레임워크         직업 간 업무활동            직업분류 체계
       구축          ───→    유사성·차이 분석   ───→     고도화·개정
                                   │
                     ┌─────────────┴──────────────┐
                     │ • 직업 간 업무활동 유사성 분석  │
                     │ • 신규 직업의 기능적 위치 파악  │
                     │ • 직업군 재구성 가능성 검토    │
                     │ • 직업 경계 조정              │
                     └────────────────────────────┘
```

- 따라서 향후 한국표준직업분류의 고도화를 위해서는 단순한 직업 분류체계를 넘어 직무 내용과 직능 특성을 구조적으로 설명할 수 있는 **직업정보 프레임워크** 구축이 필요함
- 본 연구는 이러한 문제의식을 바탕으로 한국표준직업분류를 기반으로 한 직업정보 프레임워크를 구축하고 직무요소를 구조화함으로써 직업분류체계의 활용성과 정책적 활용 기반을 강화하는 것을 목적으로 함

# S05. 연구 목적 및 범위

> **헤드메시지**: 본 연구의 목적은 KSCO 직업정보의 DB를 구축하고, 직업분류 고도화의 기반을 마련하는 것임.

**상단 — 연구 목적 (강조 박스)**

```
┌────────────────────────────────────────────────────────────────┐
│  ISCO-28 개정안에 따른 대분류 등 전면 개정을 위해                    │
│  직업분류 편제 기준인 직능유형 프레임워크를 구축하고,                  │
│  일정한 기준에 따라 직업별 특성과 요구조건 등을 구분할 수 있는          │
│  직업정보 DB 구축 기반을 마련함                                     │
└────────────────────────────────────────────────────────────────┘
```

세부 연구목표:
  - KSCO 내 직업별 직무기술 정의서를 체계적으로 작성하여, 직업별 직무요소를 표준화된 구조로 정리하여 직업 간 비교 가능성 확보
  - 국내외 주요 직업정보 시스템 분석을 통해 직능유형 구성요소 도출
  - 한국표준직업분류 기반 직업정보 프레임워크 구축
  - 일부 직업군 대상 시뮬레이션 적용 및 전문가 검증

**하단 — 4대 연구영역 플로우 (RFP 사업범위 1:1 대응)**

```
  [영역1]                [영역2]               [영역3]               [영역4]
┌────────────┐      ┌────────────┐       ┌────────────┐       ┌────────────┐
│ 직무기술    │      │ 국내·외     │       │ 구조적 틀   │       │ 시뮬레이션  │
│ 정의서 작성 │ ───→ │ 사례 분석   │ ───→  │ 마련       │ ───→  │ 검증       │
├────────────┤      ├────────────┤       ├────────────┤       ├────────────┤
│ M+2~5      │      │ M+1~3      │       │ M+3~6      │       │ M+5~7      │
├────────────┤      ├────────────┤       ├────────────┤       ├────────────┤
│ • 세분류    │      │ • O*NET    │       │ • 6대 차원  │       │ • 중분류   │
│   직업 대상 │      │   ESCO 등  │       │   (안) 설계 │       │   2~3개    │
│ • AI 텍스트 │      │   해외 분석 │       │ • 구성요소  │       │   시범 적용 │
│   분석으로  │      │ • KSCO 등  │       │   선정·     │       │ • 전문가   │
│   직무활동  │      │   국내 분석 │       │   구조화    │       │   검토·조정│
│   추출·    │      │ • 구성요소  │       │ • 정책적    │       │ • 최종안   │
│   표준화   │      │   비교·검토 │       │   활용 방안 │       │   확정     │
└────────────┘      └────────────┘       └────────────┘       └────────────┘
  산출: 직무기술       산출: 구성요소         산출: 프레임워크        산출: 시뮬레이션
  정의서              비교분석표             설계서                결과보고서
```

# S07. 핵심 차별점 — AI(NLP) 기반 방법론 ★

> **헤드메시지**: 본 연구는 AI 기반 텍스트 분석과 O*NET 참조 프레임워크를 결합하여, 직무활동을 체계적으로 추출·구조화하는 차별화된 방법론을 적용함.

**상단 — 기존 방법론 vs 제안 방법론 (2컬럼 비교)**

```
┌──── 기존 방법론 ─────────────┐     ┌──── 제안 방법론 (본 연구) ──────┐
│                             │     │                               │
│ • 전문가가 수작업으로 직무내용│     │ • AI/NLP 기반 텍스트 분석으로   │
│   을 판단·분류               │     │   직무활동을 자동 추출          │
│ • 개별 직업마다 독립적으로   │     │ • 표준화된 직무요소(work       │
│   직무기술서 작성            │     │   elements) 형태로 구조화       │
│ • 직업 설명이 서술형 문장    │     │ • O*NET 업무활동 분류체계를     │
│   중심으로 구성              │     │   참고하여 분류 기준 설계       │
│ • 직업 간 비교를 위한        │     │ • 직업 간 체계적 비교·분석이   │
│   공통 기준 부재            │     │   가능한 구조적 산출물 도출     │
│                             │     │ • 전문가 검증을 통한 품질 확보  │
└─────────────────────────────┘     └───────────────────────────────┘
```

**하단 — AI 텍스트 분석 4단계 파이프라인 (핵심 도식)**

```
  ① 텍스트 수집·정제       ② NLP 구조 분석         ③ 행동 동사 추출        ④ 유사 활동 군집화
┌────────────────┐    ┌────────────────┐    ┌────────────────┐    ┌────────────────┐
│ KSCO 직업 설명  │    │ 자연어 처리(NLP)│    │ 직무 수행과     │    │ 의미적으로      │
│ 텍스트를 수집   │ →  │ 를 활용한 문장  │ →  │ 관련된 행동     │ →  │ 유사한 직무     │
│ 하고 분석 가능한│    │ 구조 분석 수행  │    │ 중심 동사 및    │    │ 활동의 군집화   │

                                                                        │
                                                                        ▼
                                                         ┌─────────────────────────┐
                                                         │ O*NET Work Activities    │
                                                         │ 분류체계를 참고하여       │
                                                         │ 표준화된 직무요소(work    │

```

- 이러한 접근은 직무활동을 직업별로 독립적으로 정의하는 방식이 아니라, 국제적으로 검증된 직무활동 체계를 참고하여 직무요소를 표준화한다는 점에서 **직업 간 비교 가능성을 높이는 장점**을 가짐
- AI 분석 결과는 반드시 **전문가 검토 절차**를 거쳐 최종 확정함

# S09. [영역1] 직무기술 정의서 — AI 기반 방법론 상세

> **헤드메시지**: AI 기반 텍스트 분석을 통해 직무활동을 추출하고, O*NET 업무활동 분류체계를 참고하여 표준화된 직무요소로 구조화함.

**상단 — 방법론 설명 (글머리기호)**

■ AI 기반 직무활동 추출 방법
  - 본 연구의 분석 대상 자료는 한국표준직업분류(KSCO)에 제시된 직업 설명 텍스트임
  - KSCO는 각 직업에 대해 수행되는 주요 업무내용을 서술형 문장으로 제시하고 있으며, 이러한 직업 설명에는 직무 수행 과정에서 이루어지는 다양한 과업(task)과 업무 활동이 포함되어 있음
  - 그러나 이러한 직업 설명은 ①직무활동이 문장 형태로 제시되어 있고, ②동일한 직무활동이 다양한 표현으로 기술되어 있으며, ③직무활동 간 구조적 관계가 명확하게 제시되어 있지 않음
  - 따라서 본 연구에서는 KSCO 직업 설명 텍스트를 대상으로 AI 기반 텍스트 분석을 수행하여 직무활동(activity)을 추출하고 이를 구조화하는 분석 방법을 적용함

■ O*NET 방법론 활용 방안
  - 추출된 직무활동을 체계적으로 구조화하기 위해 미국 O*NET의 업무활동(work activities) 체계를 참고함
  - O*NET은 직무활동을 GWA → IWA → DWA → Tasks의 계층 구조로 체계화하고 있음

**하단 — O*NET 업무활동 계층구조 (도식)**

```
┌──────────────────────────────────────────────────────────────┐
│  GWA (일반화된 업무활동)  ← 41개 항목, 4개 대범주               │
│   정보 입력(Information Input) / 정신적 과정(Mental Processes)  │
│   업무 산출(Work Output) / 타인과의 상호작용(Interacting)       │
│    │                                                         │
│    ▼                                                         │
│  IWA (중간 수준 업무활동)  ← 각 GWA의 구체적인 수준             │
│   예) '정보 분석'은 IWA에서 '통계 데이터 분석', '재무 정보 검토' │
│    │                                                         │
│    ▼                                                         │
│  DWA (세부 업무활동)      ← 약 2,000여 개, 직업별 구체적 활동   │
│    │                                                         │
│    ▼                                                         │
│  Tasks (과업)            ← 직업별 수십 개, 가장 구체적 수준     │
└──────────────────────────────────────────────────────────────┘
```

- 본 연구에서는 이러한 O*NET의 업무활동 구조를 참고하여 한국표준직업분류 직무활동의 분류 기준을 설계함
- 특히 GWA의 4개 대범주를 참고하여 직무활동을 **정보 수집 및 정보 분석 활동 / 문제 해결 및 의사결정 활동 / 대인 서비스 및 의사소통 활동 / 조직 관리 및 조정 활동 / 기술 및 장비 활용 활동** 등의 유형으로 구분함

# S10. [영역1] 직무기술 정의서 — 표준화 직무요소 구조화 예시

> **헤드메시지**: 직업명이나 직무 표현이 다르더라도, 공통된 직무요소를 기준으로 직업 간 유사성과 차이를 체계적으로 비교할 수 있음.

**상단 — 직무요소 표준화 기준 3가지**

  - **직업 간 공통적으로 나타나는 활동 중심 통합**: 여러 직업에서 공통적으로 나타나는 업무활동을 중심으로 직무요소를 통합함
  - **의미적으로 유사한 직무활동의 군집화**: 표현은 다르지만 의미적으로 유사한 직무활동을 하나의 직무요소로 군집화함
  - **직무 수행 목적 중심의 활동 재구성**: 직무활동을 수행 목적에 따라 재구성하여 구조화함

**중단 — 표준화 직무요소 구조화 예시 (표)**

```
┌──────┬─────────┬──────────────────────────────┬──────────────────────┐
│ 구분 │  직업   │        업무내용                │   표준화 직무요소      │
├──────┼─────────┼──────────────────────────────┼──────────────────────┤
│      │  교사   │ 학생들에게 교과서 등 적절한     │                      │
│ 동일 │        │ 방법을 적용하여 교육과정의      │ 지식전달, 의사소통,    │
│ 직무 │        │ 학습내용을 가르치고 평가하며     │ 학습자 이해, 수업 설계 │
│ 요소 │        │ 생활지도 업무를 수행            │                      │
│      ├─────────┼──────────────────────────────┼──────────────────────┤
│      │  강사   │ 수강생들에게 관련 과목의 학습   │ 지식전달, 의사소통,    │
│      │        │ 내용이나 이론, 기술 등을        │ 학습자 이해, 수업 설계 │
│      │        │ 가르치고 실기나 기능을 평가      │                      │
├──────┼─────────┼──────────────────────────────┼──────────────────────┤
│      │ 데이터  │ 데이터를 가공·분석하여          │ 분석, 데이터 해석,    │
│ 유사 │ 분석가  │ 의사결정에 필요한 정보를 제공   │ 의사결정 지원         │
│ 직무 ├─────────┼──────────────────────────────┼──────────────────────┤
│ 요소 │ 마케팅  │ 시장 및 소비자 정보를 분석하여  │ 분석, 데이터 해석,    │
│      │ 전문가  │ 전략을 수립                    │ 전략 수립            │
└──────┴─────────┴──────────────────────────────┴──────────────────────┘
```

**하단 — 시사점 박스**

  - 교사와 강사: 교육 대상과 환경이 다르나 직무요소 수준에서는 **동일한 구조**를 공유함
  - 데이터 분석가와 마케팅 전문가: 분석 대상이 상이하나 **'분석'과 '데이터 해석'**이라는 핵심 직무요소를 공통적으로 포함함
  - 이러한 방식으로 직업별 직무를 표준화된 직무요소 형태로 구조화함으로써, 향후 직업 간 비교 분석, 직능유형 구성요소와의 연계, 정책적 활용을 위한 **기초 데이터로서의 역할**을 수행할 수 있도록 함

# S12. [영역2] 국내·외 사례 분석 — 국내 체계 + 비교표

> **헤드메시지**: 국내 6개 직업정보 체계를 해외 체계와 비교 분석한 결과, O*NET은 거의 모든 구성요소를 포괄하는 반면 KSCO는 기본 정보 중심으로 부가정보가 부족함.

**상단 — 국내 체계 요약 (글머리기호)**

■ 적용방안 ① — 주요 업무(Tasks)의 최신화 및 보강
  - ISCO의 주요 직무(Tasks)와 O*NET의 tasks 목록(18,796개), 한국직업사전(6,000여 개) 등을 활용
  - 특히 NCS의 능력단위(또는 능력단위 요소)를 활용한다면 한국적 직무 표준을 충실히 구축할 수 있을 것으로 판단
  → **업무(Work Activities) 차원의 근거**

■ 적용방안 ② — 부가정보의 보강
  - 임금직업포털의 풍부한 직업정보와 KNOW의 직업 숙련도·중요도 데이터를 KSCO 직무기술서와 연계하여 활용
  → **지식·기술·능력·도구·환경 차원의 근거**

■ 적용방안 ③ — KQF/SQF 연계
  - KQF 및 산업별 역량체계(SQF)의 수준별 정의 구조를 참고하여, 직능유형 구성요소가 역량 수준(Level)과 연계 가능한 형태로 설계될 수 있는지를 검토
  → **역량 수준(Level) 연계 가능성 확보**

이러한 분석 결과는 본 연구에서 제안하는 **한국형 직능유형 6대 차원(업무, 지식, 기술, 능력, 도구, 환경)**의 설계 근거로 직접 활용되며, 각 차원별 구성요소를 어떤 기존 체계의 정보로부터 도출·연계할 수 있는지에 대한 실증적 기반을 제공함

# S15. [영역3] 구성요소 설계 기준 및 정책적 활용 방안

> **헤드메시지**: 직능유형 구성요소는 직업 간 비교 가능하고 행정 데이터와 연계 가능한 구조로 설계하며, 향후 직업정보가 지속적으로 축적·갱신될 수 있는 프레임워크로서의 기능을 고려하여 설계함.

**좌측 — 구성요소 설계 기준 3가지 (카드)**

■ ① 직업 간 기능적 비교가 가능한 구조
  - 한국표준직업분류의 직업 설명 자료를 분석하여 직업 수행 활동을 중심으로 직능유형 요소를 도출하고, 각 차원별로 측정 가능한 직능유형 구성요소를 선정함
  - 이 과정에서 직업 수행 활동의 공통성을 고려하여 직업 간 비교가 가능한 표준화된 직무활동 단위를 설정하고, 이를 직능유형 차원별로 구조화함

■ ② 행정 데이터(고용보험, 국가자격 등)와 연계 가능한 구조
  - 선정된 구성요소는 행정·정책 현장에서 해석 및 활용 가능하도록 구체적인 적용방안과 함께 제시함

■ ③ 직업분류 체계와 연계 가능한 정보 구조
  - 도출된 직능유형 구성요소는 차원별로 체계화하여 한국표준직업분류와 연계 가능한 직업정보 구조로 제시함
  - 또한 각 구성요소에 대한 개념 정의와 적용 기준을 함께 제시함으로써 향후 직업정보 구축 및 직업분류 개정 과정에서 활용할 수 있는 기초 틀을 마련함

# S21. 품질·보안 관리

> **헤드메시지**: 전문가 검증 기반의 품질관리 체계와 엄격한 보안·연구윤리 관리를 통해 연구의 신뢰성을 확보함.

**좌측 — 품질관리 체계 (3원칙)**

■ ① 전문가 검토 필수
  - 모든 AI 분석 결과는 반드시 해당 분야 전문가(직업분류, 직무분석, 노동시장 연구 등) 검토를 거쳐 확정함
  - AI가 도출한 직무활동과 표준화 직무요소에 대해 전문가가 적절성·타당성을 판단함

■ ② 샘플 사전 검증
  - 전체 직업에 대한 배치 처리(batch processing) 전에, 반드시 샘플 직업 10~20개를 대상으로 분석 결과의 품질을 사전 확인함
  - 샘플 검증을 통해 분석 방법의 적합성을 검증한 후 전체 분석을 실시함

■ ③ 이중 검증
  - 시뮬레이션 결과는 정량적 분석(변별력, 일관성 등)과 전문가 정성 평가를 병행하여 이중으로 검증함
  - 특히 직능유형 구성요소의 타당성에 대해 관련 분야 전문가를 대상으로 검토를 실시함

**우측 — 보안 관리 및 연구 윤리**

■ 보안 관리
  - 연구용역 기간 동안 발생하는 모든 사안에 대해서 용역기관의 용역수행 관계자를 제외하고는 대외비로 취급함
  - 연구용역 수행과 관련하여 주관기관에 기 제출된 모든 문서와 주관기관이 제공한 자료 및 정보에 대해서는 외부기관에 공개할 수 없음
  - 용역 결과물을 발주기관의 사전 승인 없이 독자적으로 발표하거나 타인에게 양도 또는 대여할 수 없음

■ 연구 윤리
  - 연구진 윤리 교육 이수 및 연구윤리 준수 서약
  - 표절 방지 검사 실시
  - AI 분석 방법의 투명성 확보 — 보고서에 AI가 어떤 방법으로 분석했는지를 명시적으로 기술함
