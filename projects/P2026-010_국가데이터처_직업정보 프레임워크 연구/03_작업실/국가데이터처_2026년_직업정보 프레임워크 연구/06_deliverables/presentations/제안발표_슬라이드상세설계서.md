# S09. [영역1] 직무기술 정의서 — 방법론 상세

> **헤드메시지**: AI 기반 텍스트 분석을 통해 직무활동을 추출하고, O*NET 업무활동 분류체계를 참고하여 표준화된 직무요소로 구조화함.

**본문 구성**:

상단 — O*NET 업무활동 계층구조 도식

```
┌──────────────────────────────────────────────────┐
│           O*NET 직무활동 계층 구조                   │
│                                                    │
│  GWA (일반화된 업무활동)  ← 41개, 4개 대범주         │
│    │  정보 입력 / 정신적 과정 / 업무 산출 / 타인 상호작용│
│    ▼                                                │
│  IWA (중간 수준 업무활동)  ← 보다 구체적인 수준       │
│    ▼                                                │
│  DWA (세부 업무활동)      ← 약 2,000여 개            │
│    ▼                                                │
│  Tasks (과업)            ← 직업별 수십 개            │
└──────────────────────────────────────────────────┘
```

하단 — 직무활동 도출 예시 (표)

```

├─────────┼────────────────────────┼────────────────────┤
│  교사   │ 학생들에게 교육과정의    │ 지식 전달,          │
│         │ 내용을 가르치고 학습     │ 학습 평가           │
│         │ 결과를 평가한다         │                    │
├─────────┼────────────────────────┼────────────────────┤
│ 데이터  │ 데이터를 분석하여       │ 데이터 분석,         │
```
