## 슬라이드 구성 (23장)

### PART 0: 오프닝 (1장, ~30초)

#### 슬라이드 #1 — 표지
- **내용**: 과제명, 수행기관명, 발표일자, 연구책임자명
- **레이아웃**: 다크 네이비 배경, 중앙 정렬, 기관 로고
- **비주얼**: 직업분류 체계를 상징하는 추상적 네트워크 그래픽
- **시간**: 30초 (인사 및 도입)

### PART 1: 과제 이해 (3장, ~3분) → 평가: 과제 이해도 10점

#### 슬라이드 #2 — 연구의 배경과 필요성
- **핵심 메시지**: "ISCO-28 전면 개정 대비, 직업분류 고도화의 기반이 필요하다"
- **내용**:
  - ISCO-28 개정 동향 (교육·책임성·경험·업무기반학습 등 직능수준 확대)
  - 현행 KSCO 직업정보의 한계 3가지 (서술형, 비표준화, 비구조화)
  - 해외(O*NET, ESCO) vs 국내 직업정보 격차
- **레이아웃**: 좌측 텍스트 + 우측 비교 다이어그램 (해외 vs 국내 격차)
- **비주얼**: Before(현행 KSCO 서술형) → After(구조화된 프레임워크) 대비 그래픽

#### 슬라이드 #3 — 과제 목적과 범위
- **핵심 메시지**: "KSCO 직업정보 DB 구축 + 직업분류 고도화 기반 마련"
- **내용**:
  - 연구 목적: 직능유형 프레임워크 구축 + 직업정보 DB 기반 마련
  - 4대 연구영역 개요 (직무기술 정의서 / 사례분석 / 구조적 틀 / 시뮬레이션)
  - RFP 사업범위와 제안 범위의 1:1 대응 명시
- **레이아웃**: RFP p.5 연구영역 다이어그램을 재해석한 4-블록 구성
- **비주얼**: 4개 영역 아이콘 + 화살표 흐름도

#### 슬라이드 #4 — 과제 수행 관련 기술보유 수준
- **핵심 메시지**: "직업·자격 전문 학회 + AI/NLP 분석 역량의 결합"
- **내용**:
  - 한국직업자격학회 14년 전문성 (2012~2026)
  - 직업분류·직무분석 관련 핵심 수행실적 하이라이트 (37건 중 핵심 5~6건)
  - AI/NLP 텍스트 분석 기술 보유 현황
- **레이아웃**: 좌측 학회 연혁 타임라인 + 우측 핵심 실적 카드 3~4개
- **비주얼**: 타임라인 + 실적 카드(발주기관·과제명·금액)

### PART 2: 연구 해결방향 (2장, ~2분) → 평가: 과제 해결방향 적정성 5점

#### 슬라이드 #5 — 연구 해결 전략 총괄
- **핵심 메시지**: "AI 텍스트 분석 × O*NET 참조 프레임워크 = 한국형 직업정보 구조화"
- **내용**:
  - 전체 연구 전략: "데이터 기반 귀납적 접근 + 국제 검증된 체계 참조"
  - 3단계 전략: ①데이터 수집·분석 → ②프레임워크 설계 → ③시뮬레이션 검증
  - 각 단계별 핵심 방법론 요약
- **레이아웃**: 3-스텝 프로세스 플로우 (좌→우 화살표)
- **비주얼**: 큰 프로세스 다이어그램 + 단계별 아이콘

#### 슬라이드 #6 — 차별화 포인트: AI 기반 방법론 ★
- **핵심 메시지**: "기존 수작업 직무분석을 넘어, AI가 직무활동을 구조화한다"
- **내용**:
  - 기존 방법론(수작업 전문가 판단) vs 제안 방법론(AI NLP + 전문가 검증)
  - AI 텍스트 분석 4단계: 텍스트 수집 → NLP 문장 구조 분석 → 행동 동사 추출 → 유사 직무활동 군집화
  - O*NET Work Activities 계층구조(GWA→IWA→DWA→Tasks) 참조 프레임워크 결합
  - "국제적으로 검증된 분류체계를 참고하여 한국 데이터에서 직접 도출" — 장점
- **레이아웃**: 좌측 방법론 비교(Before/After) + 우측 4단계 프로세스
- **비주얼**: AI NLP 파이프라인 다이어그램 (★ 발표의 하이라이트 슬라이드)

### PART 3: 연구내용 (8장, ~10분) → 평가: 연구내용 30점 (최대 배점)

#### 슬라이드 #7 — [영역1] 직무기술 정의서 작성 — 개요
- **핵심 메시지**: "세분류 직업 대상, 표준화된 직무기술 정의서를 체계적으로 작성"
- **내용**:
  - 대상: KSCO 세분류 수준 전체 직업
  - 직무기술 정의서 구조: ①직업개요 ②주요업무내용 ③핵심직무활동 ④표준화직무요소
  - 작성 절차: 현행 업무내용 기술 검토 → AI 텍스트 분석 → 직무요소 표준화
- **레이아웃**: 정의서 구조를 4-블록 카드로 시각화
- **비주얼**: 직무기술 정의서 샘플 미리보기 (교사/데이터분석가 예시)

#### 슬라이드 #8 — [영역1] 직무기술 정의서 — 방법론 상세
- **핵심 메시지**: "AI 텍스트 분석 → O*NET 참조 분류 → 표준화 직무요소 도출"
- **내용**:
  - AI 기반 직무활동 추출 절차 상세
  - O*NET 업무활동 계층구조 참고 방안 (GWA 41개 → 4개 대범주)
  - 직무요소 표준화 기준: 공통 활동 통합 / 유사 활동 군집화 / 목적 중심 재구성
  - <표> 직무활동 도출 예시 (교사·데이터분석가·마케팅전문가)
- **레이아웃**: 상단 프로세스 흐름 + 하단 예시 표
- **비주얼**: NLP 분석 파이프라인 + 직무활동 도출 예시 테이블

#### 슬라이드 #9 — [영역2] 국내외 사례분석 — 해외 체계
- **핵심 메시지**: "O*NET·ISCO·ESCO·NOC 등 주요 선진국 직업정보 체계 비교분석"
- **내용**:
  - O*NET 콘텐츠 모델 (6개 영역, 직업-근로자 중심 관점)
  - ISCO-08 직무기술서 구조
  - 해외 체계의 핵심 시사점: "다차원적 직업정보 구조화"
- **레이아웃**: O*NET 콘텐츠 모델 다이어그램 중심 + 주변 해외 체계 비교
- **비주얼**: O*NET 6개 영역 원형 다이어그램

#### 슬라이드 #10 — [영역2] 국내외 사례분석 — 국내 체계 + 비교표
- **핵심 메시지**: "국내 8개 체계 분석 → 공통요소와 차별요소 구분"
- **내용**:
  - 국내 체계: KSCO, KECO, 워크피디아, 한국직업사전, NCS, KQF/SQF
  - 국내외 8개 체계 직무기술서 구성 항목 비교표 (제안서 p.48~49)
  - 핵심 발견: "KSCO는 기본 정보만, O*NET은 거의 모든 구성요소 포함"
- **레이아웃**: 비교표 중심 (제안서 p.48 표 재활용, 시각적으로 재디자인)
- **비주얼**: 국내외 비교 매트릭스 (O/X/△ 컬러 코딩)

#### 슬라이드 #11 — [영역2→3] 국내 적용방안 검토 결과
- **핵심 메시지**: "국내외 분석 결과를 바탕으로 한국형 6대 차원 도출"
- **내용**:
  - 미국 SOC↔O*NET 통합 구조 vs 한국 KSCO↔KECO 분리 구조의 차이
  - 적용방안 3가지: ①주요 업무 최신화·보강 ②부가정보 보강 ③KQF/SQF 연계
  - → 한국형 직능유형 6대 차원(안) 도출 근거
- **레이아웃**: 좌측 비교(미국 vs 한국) + 우측 적용방안 3가지
- **비주얼**: 대비 다이어그램 + 화살표로 "제안" 연결

#### 슬라이드 #12 — [영역3] 한국형 직능유형 6대 차원 프레임워크 ★★
- **핵심 메시지**: "업무·지식·기술·능력·도구·환경 — 6대 차원으로 직업정보 구조화"
- **내용**:
  - 6대 차원 표 (차원명 + 정의): 업무(Work Activities), 지식(Knowledge), 기술(Skills), 능력(Abilities), 도구(Tools & Technology), 환경(Work Context)
  - 구성요소 설계 기준: 직업 간 비교 가능 / 행정 데이터 연계 / 직업분류 체계 연계
  - 정책적 활용 방안 5가지
- **레이아웃**: 중앙에 6각형 프레임워크 다이어그램, 주변에 각 차원 설명
- **비주얼**: 한국형 프레임워크 구조도 (★★ 발표의 핵심 슬라이드)

#### 슬라이드 #13 — [영역3] 프레임워크 활용 비전
- **핵심 메시지**: "일회성 분석 도구가 아니라, 지속적으로 갱신되는 프레임워크"
- **내용**:
  - 정책적 활용: 직업군 재구조화 / 신규 직업 분류 / 직업 간 전환 가능성 분석
  - 직업분류 개정 시 직무활동 데이터 기반 체계적 분석 기반 제공
  - 향후 직업정보 DB 확충을 위한 실질적 토대
- **레이아웃**: 현재(이번 연구) → 미래(향후 활용) 타임라인
- **비주얼**: 로드맵형 다이어그램

#### 슬라이드 #14 — [영역4] 시뮬레이션 검증 계획
- **핵심 메시지**: "중분류 2~3개에 시범 적용 → 전문가 검증 → 구성요소 최종 확정"
- **내용**:
  - 시뮬레이션 대상 선정 기준: 서로 다른 산업 영역 대표, 지식/기술 기반 혼합
  - 분석 절차: ①직업 설명 분석 → ②활동 추출 → ③차원별 재구성 → ④변별력 검토
  - 전문가 검토 항목: 차원 구분 적절성, 구성요소 타당성, KSCO 정합성, 정책 활용성
  - 전문가 검토 → 최종 조정안 도출
- **레이아웃**: 좌측 시뮬레이션 절차 4스텝 + 우측 전문가 검토 체크리스트
- **비주얼**: 프로세스 + 검증 다이어그램

### PART 4: 수행체계 (4장, ~4분) → 평가: 연구인력/일정관리 25점

#### 슬라이드 #15 — 기대 성과와 산출물
- **핵심 메시지**: "4대 영역별 구체적 산출물로 최종목표 달성"
- **내용**:
  - 영역1: 직업별 직무기술 정의서 (세분류 전체)
  - 영역2: 직능유형 구성요소 비교분석표
  - 영역3: 직업정보 프레임워크 설계서
  - 영역4: 시뮬레이션 결과 보고서 + 최종 조정안
  - + 최종보고서, 데이터셋, 원시자료
- **레이아웃**: 4개 영역별 산출물 카드 (아이콘 + 산출물명 + 간단 설명)
- **비주얼**: 4-카드 그리드

#### 슬라이드 #16 — 품질관리 및 최종목표 달성 방안
- **핵심 메시지**: "전문가 검증 + 다중 보고회를 통한 체계적 품질관리"
- **내용**:
