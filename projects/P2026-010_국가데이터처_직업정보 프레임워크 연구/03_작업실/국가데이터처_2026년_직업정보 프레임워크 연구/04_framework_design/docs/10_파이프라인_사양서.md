### 0.2 본 연구의 핵심 차별화 (반드시 인지)

1. **6대 차원 중 3차원에 집중** — 업무(Work Activities) + 도구(Tools&Tech) + 환경(Work Context). 지식·기술·능력은 본 연구 범위 외(O*NET 매핑 슬롯만 제공).

5. **DuckDB 단일파일** — 모든 중간·최종 데이터 `pipeline.duckdb` 한 파일에 통합. 재현·이관·백업 단순화.

### 1.2 LLM 프롬프트 — TASK 추출 (시스템)

```text
당신은 한국표준직업분류(KSCO) 8차 직업설명을 분석하여, 그 직업의 직무활동(Tasks)·사용 도구(Tools)·작업 환경(Work Context)을 동시에 추출하는 NLP 전문가다.

본 추출은 다음 기준을 엄격히 따른다.

[추출 단위 — Task]
- Task는 "동사 + 목적어 (+ 수단/맥락)" 구조의 단일 행동 진술이다.
- ONET task statement 규약 차용: 하나의 task에는 하나의 주된 동사만 둔다.
- 예: "도면을 검토하여 제관할 형태를 확인한다" → verb="검토하다", object="도면", full_statement="도면을 검토하여 제관할 형태를 확인한다"
- 복합 행동(예: "설계하고 시공한다")은 2개 task로 분할한다.
- 너무 일반적인 진술(예: "업무를 수행한다", "관련 일을 한다")은 제외한다.
- 직업 예시 나열(예: "·신용 관련 추심원 ·채권 사후 관리원")은 task가 아니므로 제외한다.

[추출 단위 — Tools & Tech]
- 입력 텍스트에 명시된 장비·기계·SW·시스템·도구 명사구를 추출한다.
- 구체성 수준: "컴퓨터" 같은 일반어는 제외. "CAD 소프트웨어", "절단기·벤딩기·프레스", "전산회계시스템" 처럼 직업 특정성이 드러나는 수준 채택.
- 동일 문장에 여러 도구가 "·" 또는 "또는"으로 나열된 경우 각각 별도 항목으로 분리.

[추출 단위 — Work Context]
- 작업 장소(실내·실외·고소·지하·이동), 위험 요소(고전압·화학물질·생물 위험·중량물), 사회적 맥락(고객 응대·팀 작업·독립 작업), 신체적 부담 신호(반복·정밀·체력) 등을 추출한다.
- 입력 텍스트에 명시적 단서가 있을 때만 추출 (추측 금지).
- 각 항목은 카테고리 + 구체 단서 텍스트.

[Layer 메타]
- 입력 텍스트가 KSCO 해설서이면 source="KSCO_HS", source_subject=null
- 한국직업사전이면 source="KJD_GROUP", source_subject=<원 직업명>
- NCS이면 source="NCS", source_subject=<능력단위명>

[출력 JSON 스키마 — 반드시 이 형태로]
{
  "ksco_code": "<입력 받은 코드>",
  "tasks": [
    {
      "verb": "<단일 동사>",
      "object": "<목적어 명사구>",
      "full_statement": "<원문에 충실한 1문장>",
      "source_sentence": "<원문 그대로>",
      "confidence": <0.0~1.0>
    }
  ],
  "tools": [
    {
      "name": "<도구/시스템/장비명>",
      "category": "<HW/SW/도구/장비/시스템>",
      "evidence_span": "<원문 발췌>"
    }
  ],
  "work_context": [
    {
      "category": "<장소/위험/사회적/신체적>",
      "value": "<구체 단서>",
      "evidence_span": "<원문 발췌>"
    }
  ]
}

[금지]
- JSON 외 어떤 문자도 출력하지 않는다.
- 입력에 없는 사실을 추측·창작하지 않는다.
- 영문 번역하지 않는다 (원문 한국어 보존).
- task가 추출되지 않으면 tasks 배열을 빈 리스트로 둔다 (오류 X).
```

### 1.3 LLM 프롬프트 — TASK 추출 (사용자, 세세분류 1건)

> **v1.1 패치 사유(2026-05-29, doc 12 D0)**: 도출 단위가 세세분류로 변경됨. 세세분류는 주요업무가 없으므로(0/1,270) **부모 세분류 주요업무·정의를 상속 골격(Pass 1)으로 주입**하고, 세세분류 정의·예시로 **특화(Pass 2)**한다. 시스템 프롬프트(§1.2)는 불변.

```text
[세세분류 코드] {ksco_code}        # 5자리
[세세분류 명칭] {name}
[부모 세분류] {parent_code} {parent_name}
[Layer] {layer}
[source] {source}
[source_subject] {source_subject_or_null}

[부모 세분류 정의]
{parent_definition_text}

[부모 세분류 주요 업무]   ← 활동 골격 (Pass 1: 상속)
{parent_main_tasks_text}

[세세분류 정의]   ← 특화 신호 (Pass 2)
{definition_text}

[세세분류 직업 예시]
{examples_text}

위 정보를 분석하되, 부모 세분류 주요 업무를 활동 골격으로 삼고 세세분류 정의·예시로 특화하여 시스템 규약대로 JSON을 출력하라. 해당 세세분류와 무관한 상속 활동은 제외한다. (세세분류 정의가 이름·영문만 있어 특화 신호가 약하면, 상속 골격을 보존하고 confidence를 낮춰 출력한다.)
```

### 1.4 Self-Consistency 알고리즘 (2회 독립 실행)

```python
def extract_with_consistency(ksco_code, prompt_user, llm_model="opus-4"):
    out1 = call_llm(model=llm_model, system=SYSTEM_TASK_EXTRACT, user=prompt_user, temperature=0, seed=0)
    out2 = call_llm(model=llm_model, system=SYSTEM_TASK_EXTRACT, user=prompt_user, temperature=0, seed=1)

    set1 = {(t['verb'], t['object']) for t in out1['tasks']}
    set2 = {(t['verb'], t['object']) for t in out2['tasks']}

    if not set1 and not set2:
        jaccard = 1.0  # 양쪽 모두 비었을 경우
    else:
        jaccard = len(set1 & set2) / max(1, len(set1 | set2))

    if jaccard >= 0.85:
        # 교집합만 채택, confidence 0.95
        accepted = [t for t in out1['tasks'] if (t['verb'], t['object']) in set1 & set2]
        return accepted, jaccard, "auto_accept"
    else:
        # GPT-5 cross-check (모델 다양성)
        out3 = call_llm(model="gpt-5", system=SYSTEM_TASK_EXTRACT, user=prompt_user, temperature=0, seed=0)
        set3 = {(t['verb'], t['object']) for t in out3['tasks']}
        # 3-set 다수결: 2개 이상에 나타난 task만 채택
        all_tasks = set1 | set2 | set3
        majority = [k for k in all_tasks if (k in set1) + (k in set2) + (k in set3) >= 2]
        # confidence 0.75 + 검토 큐 flag
        return majority, jaccard, "review_required"
```

### 2.2 ONET 41 GWA 참조 데이터 — 사전 적재 필요

### 2.5 Self-Consistency + Cross-Model

```python
def assign_gwa(task, seed_pairs=[(0,1)], gpt_fallback=True):
    out1 = call_llm("opus-4", SYS_GWA, fmt_user(task), seed=0)
    out2 = call_llm("opus-4", SYS_GWA, fmt_user(task), seed=1)
    if out1['primary_gwa_id'] == out2['primary_gwa_id']:
        return out1['primary_gwa_id'], (out1['confidence']+out2['confidence'])/2, "consistent"
    if gpt_fallback:
        out3 = call_llm("gpt-5", SYS_GWA, fmt_user(task), seed=0)
        votes = Counter([out1['primary_gwa_id'], out2['primary_gwa_id'], out3['primary_gwa_id']])
        winner, count = votes.most_common(1)[0]
        return winner, count/3.0, "cross_model_vote"
    return out1['primary_gwa_id'], out1['confidence'], "single"
```

### 3.2 임베딩·군집 코드 사양

```python
# 03_NLP_analysis/scripts/utils/clustering.py 신규
from sentence_transformers import SentenceTransformer
import hdbscan
import numpy as np

def embed_tasks(task_statements: list[str]) -> np.ndarray:
    model = SentenceTransformer("BAAI/bge-m3")
    emb = model.encode(task_statements, normalize_embeddings=True, batch_size=32)
    return emb  # (N, 1024)

def cluster_in_gwa(task_ids, statements, min_cluster_size=4, min_samples=2):
    emb = embed_tasks(statements)
    clusterer = hdbscan.HDBSCAN(
        min_cluster_size=min_cluster_size,
        min_samples=min_samples,
        metric='euclidean',  # bge-m3 정규화된 벡터에 사용
        cluster_selection_method='eom'
    )
    labels = clusterer.fit_predict(emb)
    return labels  # -1 = noise
```

### 3.5 자동 8조항 검증 (LLM 출력 → 코드 후처리)

```python
def validate_dwa_rules(dwa_label: str) -> list[str]:
    violations = []
    # 1. 단일 동사 — 동사 형태소 2개 이상이면 위반
    # 2. 현재형 어미 — 끝이 "한다/수행한다" 패턴
    if not re.search(r"(한다|수행한다|관리한다|작성한다|분석한다|운영한다|제공한다|개발한다|점검한다|판단한다)\.?$", dwa_label):
        violations.append("rule_2_tense")
    # 3·4. 명사 수, 일반화 수준 — heuristic
    nouns = extract_nouns_mecab(dwa_label)
    if len(nouns) > 5:
        violations.append("rule_3_too_many_nouns")
    if any(n in BANNED_TOO_GENERIC for n in nouns):
        violations.append("rule_4_too_generic")
    # 6. 예시구
    if "예:" in dwa_label or "포함하여" in dwa_label:
        violations.append("rule_6_examples")
    # 7. 목적절
    if "위해" in dwa_label or "위하여" in dwa_label:
        violations.append("rule_7_purpose_clause")
    # 8. 가독성 — 단순 글자수
    if len(dwa_label) > 80:
        violations.append("rule_8_too_long")
    return violations

def label_dwa_with_retry(cluster_tasks, gwa_label, max_retries=3):
    for attempt in range(max_retries):
        out = call_llm("opus-4", SYS_DWA_WRITE, fmt_user(cluster_tasks, gwa_label), seed=attempt)
        v_llm = out.get('violated_rules', [])
        v_code = validate_dwa_rules(out['dwa_label'])
        if not v_llm and not v_code:
            return out['dwa_label'], 1.0, attempt+1
        # 위반 알려서 재시도
        retry_user = fmt_user(cluster_tasks, gwa_label) + f"\n\n[이전 시도 {attempt+1} 위반]: {v_llm + v_code}\n위반을 수정하여 다시 출력하라."
    # 3회 모두 실패 → flagged
    return out['dwa_label'], 0.5, max_retries
```

## §4. DWA QC (Step 3d) — Round-Robin 2회 + 4기준

### 4.1 QC 4기준

| # | 기준 | 자동 평가 가능 | LLM 평가 |

| 4 | DWA 유일성 (Uniqueness) | 다른 DWA와 코사인 < 0.75 | 개념적 중복 없는지 |

```python
    # Round 1: Opus 4
    r1 = call_llm("opus-4", SYS_QC, fmt_qc(dwa_label, cluster_tasks, neighbor_dwas), seed=0)
```

```python
def score_responsibility(ksco_code, definition, tasks):
    out1 = call_llm("opus-4", SYS_RESP, fmt_resp(ksco_code, definition, tasks), seed=0)
    out2 = call_llm("opus-4", SYS_RESP, fmt_resp(ksco_code, definition, tasks), seed=1)

    # 3축 점수차의 합
    diff = abs(out1['mgmt_score']-out2['mgmt_score']) + abs(out1['supervisory_score']-out2['supervisory_score']) + abs(out1['safety_score']-out2['safety_score'])

    if diff == 0:
        return out1, 1.0, "consistent"
    elif diff <= 2:

        avg['total_score'] = sum(avg.values())
        # 근거는 두 출력 모두 보존
        avg['evidence_spans'] = {
            'mgmt': out1['mgmt_evidence'] + out2['mgmt_evidence'],
            'supervisory': out1['supervisory_evidence'] + out2['supervisory_evidence'],

        }

    else:

        out3 = call_llm("gpt-5", SYS_RESP, fmt_resp(ksco_code, definition, tasks), seed=0)
        # 3-set 중앙값
```

### 6.5 변별력 자동 분석 (치킨집 사례 자동 감지)

```python
def detect_responsibility_branching():
    """
    같은 KSCO 코드 내에서 source_subject 별로 R점수 격차가 큰 경우
    → 세세분류 분기 후보로 자동 플래그
    """
    sql = """
    WITH per_subject AS (
        SELECT t.ksco_code, t.source_subject,
               AVG(r.mgmt_score + r.supervisory_score + r.safety_score) AS r_total
        FROM task t
        JOIN responsibility r ON t.ksco_code = r.ksco_code
        WHERE t.source = 'KJD_GROUP'
        GROUP BY t.ksco_code, t.source_subject
    )
    SELECT ksco_code,
           MAX(r_total) - MIN(r_total) AS r_gap,
           COUNT(*) AS subject_count
    FROM per_subject
    GROUP BY ksco_code
    HAVING r_gap >= 4 AND subject_count >= 2
    ORDER BY r_gap DESC
    """
    return con.execute(sql).fetchdf()
```

→ 본 결과가 본 연구 시뮬레이션 단계(영역 4)의 "분류체계 변별력 검증" 핵심 산출.

```python
def normalize_tools():
    # 1. 모든 추출 도구 텍스트 수집
    raw = con.execute("SELECT name, category, ksco_code FROM tool_inventory").fetchdf()
    # 2. 임베딩으로 동일·유사 도구 군집화
    emb = embed_tasks(raw['name'].tolist())
    labels = hdbscan.HDBSCAN(min_cluster_size=3).fit_predict(emb)
    # 3. 군집별 대표명 LLM 결정 (canonical_name)
    for cid in set(labels):
        if cid == -1: continue
        names = raw[labels==cid]['name'].tolist()
        canonical = call_llm("opus-4", SYS_TOOL_NORM, fmt_names(names))
        # 4. lexicon 테이블에 저장
        for n in names:
            con.execute(f"INSERT INTO lexicon VALUES ('{n}','{canonical}','tool_norm',NULL)")
```

### 7.3 환경 카테고리 표준화

5개 표준 카테고리로 매핑:
1. **물리적 장소** (실내·실외·고소·지하·이동·차량 내·수중)

4. **신체적 부담** (반복 작업·정밀 작업·체력 요구·정적 자세)
5. **시간적 패턴** (교대 근무·야간·연속 근무·계절성)
