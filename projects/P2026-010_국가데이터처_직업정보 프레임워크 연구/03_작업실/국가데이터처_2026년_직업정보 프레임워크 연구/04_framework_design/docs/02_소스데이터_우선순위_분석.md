# TASK 추출용 소스 데이터 우선순위 분석

> 작성: 이석주 · 2026-05-29
> 위치: `04_framework_design/docs/02_소스데이터_우선순위_분석.md`
> 모태 질문: **"TASK 도출 시 KSCO 직업설명만으로 충분한가? 보강이 필요하면 어디까지 어떤 기준으로?"**

---

## 0. 핵심 결론 (3줄)

1. **KSCO 8차 해설서**는 직업당 평균 5~10개 task statement(주요 업무 글머리표)를 추출 가능한 **자체 정합적·법적 권위 자료**다. **PRIMARY 소스로 채택**.
2. 한국직업사전·KECO·NCS는 KSCO 세분류와 **1:1이 아니라 N:1 (세분류 1개에 직업사전 직업 평균 10~30개+ 매핑)** 이므로, 합집합 입력 시 **입자도 불균형**과 **이질 직업의 task 혼입**이 발생한다.
3. 따라서 **KSCO 단독 → 부족 직업만 한국직업사전 그룹으로 보강 → 그래도 부족하면 NCS** 의 3-Layer 우선순위 룰을 채택한다. 보강 트리거는 정량 임계로 자동화.

---

## 1. 실측 데이터로 본 KSCO 해설서의 충분성

### 1.1 KSCO 해설서 (제8차) 분량 측정

| 지표 | 값 |
|---|---|
| 페이지 수 | 1,036 |
| 총 글자수 | **828,246자** |
| 세분류(4자리) 수 | 495 |
| 세세분류(5자리) 수 | 1,270 |
| "주요 업무" 섹션 등장 횟수 | **461** (= 495 중 34개 누락 추정) |
| 글머리표(·) 총 수 | 11,859 (주요 업무 + 직업 예시) |
| 세분류당 글머리표 평균 | 약 24개 (주요 업무 5~10개 + 직업 예시 14~19개) |

→ **KSCO 해설서만으로 직업당 5~10개의 task statement 추출 가능** (HumRRO 권장 15~25개에는 부족하나 1차 입력으로는 충분).

### 1.2 구조 예시 — KSCO 1340 "문화·예술 관련 관리자" (해설서 p.151)

```
세분류 정의 (1~2문장):
  신문사, 방송사, 영화사, 연극단체, 도서관, 기록보관소, 박물관, 화랑 등
  문화, 예술, 디자인, 영상관련 분야 기관의 운영을 기획, 관리 및 조정한다.

▍주요 업무 (글머리표 6개) ← task statement 원형
  · 공연하는 기관이나 미술관·박물관 등 기관의 경영방침을 수립하고 실행한다.
  · 신문사·출판사·영화사 등의 경영방침을 수립하고 실행한다.
  · 정책, 홍보 및 선전 프로그램을 개발하고 촉진시키며 시행한다.
  · 전문가, 기술직 및 사무직의 채용·배치·교육·훈련을 관리한다.
  · 작가, 작곡가, 제작자 및 감독들과 연락을 취한다.
  · 도서관, 기록보관소 내의 활동을 계획, 조직하고 지시하며 관리한다.

세세분류 3개 (각각 정의 + 직업 예시 5~15개):
  13401 공연·시각 예술 관련 관리자
  13402 디자인 관련 관리자
  13403 방송·출판 및 영상 관련 관리자
```

→ "주요 업무" 글머리표는 거의 **ONET task statement 형식(동사+목적어+맥락)** 그대로다. **NLP 추출이 매우 용이**.

## 2. 매핑 카디널리티 — KSCO ↔ KECO ↔ 직업사전 ↔ NCS

### 2.1 KSCO ↔ KECO (4자리 세분류)

통계청·고용정보원 공식 연계표 실측 결과:

| 항목 | 값 |
|---|---|
| 연계 라인 수 | 495 |
| KECO 세분류 수 | 495 |
| KSCO 세분류 수 | 495 |
| 카디널리티 | **1:1** (KECO 1개 ↔ KSCO 1개) |

→ 세분류 수준에서 KECO·KSCO는 깔끔하게 1:1. **그러나 이것은 행정적 매핑일 뿐**이고 실제 직업 내용에서 변동성은 그 아래 층(직업사전)에서 발생한다.

### 2.2 KSCO ↔ 한국직업사전 (N:1)

ISCO-08 개정안 평가연구 부록4(p.136~) 연계표 실측 샘플:

| KSCO 코드 | KSCO 명 | 매핑된 직업사전 직업 수 | 직업사전 예시 (일부) |
|---|---|---|---|
| 2121 | 인문과학 연구원 | **13** | 심리학연구원·교육학연구원·언어학연구원·역사학연구원·고전번역가·유적발굴원·게이미피케이션전문가·문학연구원·생명윤리연구원 … |
| 2122 | 사회과학 연구원 | **30+** | 법학연구원·연금재정추계분석원·미래학자·국방정책연구원·풍수지리학자·노동연구원·금융연구원·경제분석가 … |
| 2364 | 산업 안전 및 위험 관리원 | **25+** | 정밀화학안전환경보건위생관리자·석유화학안전점검원·승강기검사원·해양플랜트안전관리자·원자력안전관리원·항공안전관리원 … |
| 3126 | 운송 사무원 | **80+** | 열차운행관리원·수출입화물검수사·항공화물물류센터운송사무원·도선상황실운영원·복합운송주선인 … |

→ **KSCO 세분류 1개 안에 직업사전 직업이 평균 10~30개**, 많게는 80개 이상 매핑. 이질성이 매우 크다.

### 2.3 시사점 — 직업사전의 "양날의 검"

| 측면 | KSCO 해설서 | 한국직업사전 합집합 |
|---|---|---|
| 입자도 | 추상적 (KSCO 세분류 수준) | 미시적 (개별 직업명 수준) |
| 직업당 task 수 | 5~10개 | 50~300개 (혼합) |
| 출처 권위 | 통계청 고시 | 고용정보원 조사 |
| 일관성 | 형식 통일 ("…한다") | 직업별 서술 편차 |
| **이질성 위험** | **낮음** | **높음** (같은 KSCO 안에 풍수지리학자·미래학자 공존) |
| 책무성 단서 | 추상적 | 구체적 (감독·예산 단위 키워드 풍부) |

→ 한국직업사전 합집합 사용 시 **TASK 추출 입력에 동일 직업 그룹 내 이질적 직업의 task가 섞여 들어가** DWA 클러스터링이 KSCO 표준 직무가 아니라 직업사전 직업명 단위로 쪼개질 위험.

**역설적으로 이 "이질성"은 본 연구의 변별력 분석에 활용 가능** — 같은 KSCO 안에서 어떤 직업사전 직업이 다른 R점수·다른 DWA 분포를 갖는지가 곧 **세세분류 분기 또는 책무성 태그 도입의 정량적 근거**가 된다.

## 3. 채택 룰 — 3-Layer Priority

### 3.1 Layer 정의

```
┌──────────────────────────────────────────────────────────────┐
│ Layer 0: PRIMARY  (가중치 1.0, 출처 KSCO_HS)                  │
│   KSCO 8차 해설서                                              │
│   - 세분류 정의 + 주요 업무 + 세세분류 정의 + 직업 예시         │
│   - 모든 직업에 무조건 적용 (495/495)                          │
└──────────────────────────────────────────────────────────────┘
                            ▼
        [Trigger 검사]  KSCO L0 단독으로 충분한가?
                            ▼
┌──────────────────────────────────────────────────────────────┐
│ Layer 1: SECONDARY  (가중치 0.7, 출처 KJD_GROUP)              │
│   한국직업사전 (2020 통합본 5판) — KSCO 세분류에 매핑된         │
│   모든 직업의 직무내용 합집합. ISCO 평가연구 부록4 연계표 사용. │
│   - 조건부 적용 (Trigger 통과 시만)                            │
│   - 모든 task statement에 원천 직업명을 메타로 보존            │
└──────────────────────────────────────────────────────────────┘
                            ▼
        [Trigger 검사 2]  L0+L1 도 부족한가?
                            ▼
┌──────────────────────────────────────────────────────────────┐
│ Layer 2: TERTIARY  (가중치 0.5, 출처 NCS)                     │
│   국가직무능력표준 능력단위                                     │
│   - 특수직·신규직 등 극단적 부족 경우만                         │
└──────────────────────────────────────────────────────────────┘

[참조용, task 추출 비대상]
  KECO 해설서, 워크피디아·KNOW — 외부 검증·교차 확인용
```

### 3.2 Layer 승급 트리거 (정량 임계)

KSCO L0 처리 후 다음 중 하나라도 해당하면 L1 보강:

| 트리거 | 임계 | 검사 시점 |
|---|---|---|
| 추출 task 수 부족 | 직업당 task < **8개** | ② TASK 추출 직후 |
| "주요 업무" 섹션 누락 | KSCO 해설서에 "주요 업무" 없음 (34개 추정) | ① 전처리 직후 |
| 정의 분량 부족 | 세분류 정의 < 80자 | ① 전처리 직후 |
| 책무성 점수 모호 | LLM 2회 R점수 자기일치 < 0.7 | ⑤ Resp 점수화 후 |
| DWA 군집 미배치 | 추출 task 중 ≥30%가 어느 DWA에도 군집화 실패 | ③ DWA 군집 직후 |

L1 보강 후 동일 트리거가 다시 발생하면 L2(NCS) 적용 (예상 발생률 < 5%).

### 3.3 N:1 매핑 처리 룰 (한국직업사전 → KSCO)

| 항목 | 처리 |
|---|---|
| 입력 단위 | 한국직업사전 직업명 1건 = 1개 record. 각 record에 KSCO 코드 + 원 직업명 메타 부여 |
| 합산 시점 | KSCO 세분류 단위로 task statement 풀에 누적 |
| 메타 보존 | `task.source_subject = 직업사전 원 직업명` 필드로 저장 (DuckDB) |
| DWA 군집 후 분석 | 군집 내 source_subject 분포 검사 → 특정 직업명만 출현하는 DWA = "직업사전 특수 DWA"로 식별 |
| 책무성 분석 활용 | 같은 KSCO 안에서 직업명별 R점수 분포 → **세세분류 분기 후보 자동 추출** |

→ 즉 N:1 매핑이 노이즈가 아니라 **본 연구가 증명해야 할 "분류체계 변별력" 분석의 직접 데이터**가 된다.

## 4. 처리 파이프라인 의사코드

```python
def extract_tasks_for_ksco(ksco_code):
    # Layer 0
    text_l0 = ksco_handbook[ksco_code]  # 정의 + 주요 업무 + 세세분류
    tasks_l0 = llm_extract_tasks(text_l0, weight=1.0, source="KSCO_HS")

    # Trigger 1
    if (len(tasks_l0) < 8
        or not has_section(text_l0, "주요 업무")
        or len(definition(text_l0)) < 80):

        # Layer 1
        kjd_jobs = mapping_table_to_kjd[ksco_code]  # 부록4 기반
        tasks_l1 = []
        for job_name in kjd_jobs:
            kjd_text = korean_job_dict[job_name]
            t = llm_extract_tasks(kjd_text, weight=0.7,
                                   source="KJD_GROUP",
                                   source_subject=job_name)
            tasks_l1.extend(t)

        # 중복 통합 (L0 우선)
        tasks = dedupe(tasks_l0 + tasks_l1, prefer="KSCO_HS")
    else:
        tasks = tasks_l0

    return tasks
```

## 5. 옵션 비교 — 사용자 의사결정용

| 옵션 | 입력 | 장점 | 단점 | 예상 활용 |
|---|---|---|---|---|
| **A. KSCO 단독** | L0만 | 가장 보수적·재현 가능, 작업량 최소, 통계청 고시 권위 100% | 직업당 task 부족, 한국 노동시장의 미시 다양성 미반영 | 시범적용 1단계만 |
| **B. KSCO 우선 + 조건부 보강 (권장)** | L0 → 트리거 시 L1/L2 | KSCO 권위 유지 + 부족 직업만 보강, 작업량·품질 균형 | 트리거 룰 설계·검증 필요 (본 분석서로 해결) | **본 연구 기본** |
| C. 동시 통합 | L0 + L1 항상 합집합 | 최대 정보량 | 입자도 불균형, 이질성 노이즈, 책무성 분석 모호화 | 비권장 |

→ **권장: B**. 다음 §6에 트리거 검증 계획.

## 6. 검증 계획 (M+2 파일럿 적용)

1. 파일럿 3개 중분류 60 세분류에 대해 **옵션 A·B 동시 실행**
2. 비교 지표:
   - 직업당 task 수 분포
   - DWA 군집 응집도 (코사인)
   - 책무성 3축 점수 분산 — **변별력 차이가 옵션 B에서 더 크게 나오는지**
   - 전문가 채택율
3. 결과에 따라 v1.3에서 트리거 임계 미세조정 (8 → 6 또는 10)
