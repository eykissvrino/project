## 0. 종합 판정 (3줄)

1. **방법론 기둥은 견고하다** — ONET 정합·소스 우선순위·CBM 정합·LLM 최상위 등 v1.0→v1.3에서 4번의 보강을 거치며 **연구 방법론 신뢰도는 학회·통계청 방어에 충분한 수준**에 도달했다.
2. **그러나 본 연구 산출물의 "스코프 폭"이 v1.3에 다 들어와 있지 않다** — 한국형 **6대 차원** 중 우리는 사실상 "업무(Work Activities)" 차원만 상세 설계했고, 나머지 5차원(지식·기술·능력·도구·환경)의 도출 절차가 누락되었다. 이는 가장 큰 갭이다.
3. **추가로 9개의 누락·약점·정합성 오류**가 발견되었다. 모두 해결 가능한 수준이며 일부는 v1.4 패치로, 일부는 별도 산출물 또는 의사결정으로 해결한다. **착수 전에 이 체크리스트의 §4 액션 7개는 반드시 정리하고 시작**해야 한다.

## 2. 핵심 갭 (착수 전 보완 필수)

### G1. ★★★ "6대 차원 중 5차원이 누락" — 본 연구 최대 갭

**Charter A2-3 / KICKOFF 체크리스트 / 04_framework_design/README** 모두에서 본 연구는 **6대 차원** 프레임워크를 설계하기로 명시:

| 차원 | 정의 | 본 v1.3 처리 |
|---|---|---|
| **업무 (Work Activities)** | 수행되는 주요 업무활동 | ✔ 4계층(Task→DWA→IWA→GWA) 상세 |
| **지식 (Knowledge)** | 이론적·전문적 지식 | ✗ 누락 |
| **기술 (Skills)** | 실무적 기술 | ✗ 누락 |
| **능력 (Abilities)** | 인지·신체적 능력 | ✗ 누락 |
| **도구 (Tools & Tech)** | 장비·기술·SW | ✗ 누락 |
| **환경 (Work Context)** | 물리·사회적 환경 | ✗ 누락 |

**시사점**: v1.3 은 사실상 "업무 차원만 상세화한 설계"이고, 나머지 5차원은 도출 절차·임계·산출물 양식 모두 미정. 보고서 Ⅳ장은 "6차원 프레임워크"인데 Ⅴ장(직무활동 표준화)에서 1차원만 다루면 분량·완결성 문제.

**해결안 (v1.4)**:
- 동일 NLP 파이프라인을 5차원에도 확장 적용 (LLM이 직업설명에서 "사용 지식·기술·능력·도구·환경"을 동시 추출)
- 차원별 표준 척도 (BARS) — Charter A2-3에 명시된 항목 별도 산출물로 작성
- 또는 5차원을 외부 데이터(O\*NET Knowledge·Skills·Abilities + 한국직업사전 도구·환경 항목) 매핑으로 처리하고 본 연구 NLP는 업무 차원에 집중 — 둘 중 사용자 결정 필요

### G2. ★★★ HumRRO 임계치를 어떻게 "측정"할지 불명확

**Charter A2-1·A4-3**: relevance 60% / importance 3.0+ / F-test p<.05 명시. 그러나 이 측정은 본래 **incumbent survey** (직무 종사자 5~15인 설문) 결과로 나옴. 우리는 8개월 내 incumbent survey 못 함.

**v1.3 §6.2**: 평가지표 9종 모두 internal metrics (LLM 일치율·코사인·전문가 채택율). incumbent survey 기반 지표 없음.

**해결안**:
- **전문가 검토위원회(5인)를 incumbent surrogate로 운영** — Charter A5-1과 정합
- 각 위원이 자신의 전문 영역에서 task의 relevance / importance를 5점 척도로 평정
- 5인 평균이 HumRRO 임계 (relevance 60% / importance 3.0+) 충족 시 채택
- 이걸 `40_평가지표_측정프로토콜.md` 에 명시

### G3. ★★ KSCO 중분류 코드 정합성 오류 — Charter·v1.3 양쪽 모두

KSCO 8차 분류항목표 실측 결과:

| 중분류 | 정확한 명칭 |
|---|---|
| **22** | 정보 통신 전문가 및 기술직 |
| 23 | 공학 전문가 및 기술직 |
| **24** | 보건 전문가 및 관련직 |
| 25 | 사회복지·종교 전문가 및 관련직 |
| 26 | 교육 전문가 및 관련직 |
| **28** | 경영·금융 전문가 및 관련직 |

**Charter KICKOFF 체크리스트 A4-1**:
- "후보 A — **중분류 26** 정보통신" → 실제 26은 **교육 전문가**. ✗ 오류
- "후보 B — **중분류 73** 전기·전자 정비" → 실제 73은 **목재·가구·악기·간판**. ✗ 오류
- "후보 C — **중분류 14** 보건" → 실제 14는 **건설·전기 생산 관리직**. ✗ 오류

**v1.3 §6.1**:
- "경영 및 행정·금융 전문가 23(일부)·25" → 23은 공학, 25는 사회복지. ✗ 오류 (28이 맞음)
- "정보통신 22" → ✓ 정확
- "보건·사회복지 24·25" → 24만 보건, 25는 사회복지. △ 모호

**해결안 (v1.4)** — 파일럿 3개 중분류 코드 확정:

| 중분류 | KSCO 정확한 명칭 | 선정 이유 |
|---|---|---|
| **28** | 경영·금융 전문가 및 관련직 | 관리책무성 변별 (치킨집 ↔ 프랜차이즈 본사 직접 사례) |
| **22** | 정보 통신 전문가 및 기술직 | 신생직업·고숙련·KECO 2025 53개 신설 직업 포함 |
| **24** | 보건 전문가 및 관련직 | 안전책무성·감독책무성 농도 차이 + 8차 분리 신설 |

### G4. ★★ RFP 산출물 #5 "참고자료 번역본·해설서" 누락

KICKOFF 체크리스트 A6-1: **계약만료 후 2주 이내 책자 20부 (번역본·해설서 각각)** 제출 명시.

대상 자료는 명시되어 있지 않으나 정황상 **ISCO-28 SLF 영문 자료** 또는 **ONET WA Technical Report**가 유력. 분량 큰 작업(번역 100~200p + 한국어 해설).

**해결안**: 산출물 #5의 정확한 자료 범위를 발주기관에 확인 → 본 연구 시작 전 명문화. 11월 초까지 완료해야 하므로 9월부터 병행 필요.

### G5. ★★ 데이터 보안 — LLM API 호출의 폐쇄망 문제

**v1.3 §5.2**: Claude Opus 4 + GPT-5 채택. 모두 **외부 클라우드 API** 호출 필요.

**현실 점검**:
- 본 연구 입력 데이터는 모두 **공개 자료** (KSCO 해설서·KECO·한국직업사전·NCS·O\*NET) — 기밀 누출 위험 낮음
- 단, 국가데이터처/통계청 폐쇄망 환경에서는 외부 API 호출 자체가 정책상 차단 가능
- 또한 LLM 제공사의 **학습 데이터 미사용 (Zero Data Retention)** 약관 가입 필수

**해결안**:
- 본 연구는 사용자(이석주) 개인 환경 또는 한국직업자격학회 환경에서 외부 LLM 호출 → 결과를 발주기관에 납품. 발주기관 폐쇄망 내 실행이 강제되는지 사전 확인
- Anthropic·OpenAI 모두 "API 입력은 학습에 미사용" 옵션 존재 (Enterprise 약관)
- 사용 LLM·약관 가입 사실을 보고서·발표 자료에 명시 (Q&A 방어)

### G6. ★★ BARS·측정 척도 설계 미반영

**목차안 Ⅳ-2**: "BARS 행동 앵커 및 측정 척도(수준·중요도) 설계" 명시.
**Charter A2-3**: "차원별 구성요소 + 측정 척도 + 활용 시나리오" 명시.

**v1.3**: BARS 자체 언급 없음. 측정 척도는 R 3축의 0-3점 외에 6대 차원에 대한 척도 없음.

**해결안**: 별도 산출물 `41_차원별_측정척도_BARS_설계.md` 신설. 각 차원에 대해 (a) 측정 척도 (예: 5점 척도·이진·비율 등), (b) BARS 행동 앵커 3~5개, (c) 평가자 가이드라인 정의. M+3까지 완료.

### G7. ★ 전문가 검토위원회 위촉 — 결정 잔여 (Charter A5-1 강조 항목)

Charter A5-1: **착수보고 시점에 5인 명단(직책)·동의서 제출** 명시 — RFP 평가 가점 직접 항목.

**v1.3 §8**: "검토 위원 수·구성 3·5·7명 결정 필요" — 즉 위촉 안 됨.

**해결안**: 5인 = 학계 2 + 한국고용정보원 1 + 통계청 1 + 산업계 1 구성으로 확정 → 본 연구 착수 전 위촉 완료.

### G8. ★ NLP 4단계 vs 5단계 명명 충돌

### G9. ★ DWA 채택 임계치 — Charter 한국화 vs v1.3 ONET 원본

## 3. 위험 시나리오 stress test

| # | 위험 | 발생 확률 | 영향도 | Fallback |
|---|---|---|---|---|
| R1 | LLM 출력이 너무 일반적이라 한국 KSCO 변별 안 됨 | 中 | 高 | 프롬프트에 KSCO 직업명·예시·기존 NCS 능력단위를 reference로 제공 (in-context learning). 그래도 안 되면 한국직업사전 보강(L1) 강제 |
| R2 | 5인 전문가 의견 분열 | 中 | 中 | 의사결정 룰 사전 명시: ① 5인 중 4인 이상 동의 → 채택, ② 3인 동의 → PI 최종 판단 + 회의록 기록, ③ 2인 이하 → 보류·재분석 |
| R3 | 발주기관이 분류 개편 권고 거부 | 中 | 中 | 본 연구는 "정량 근거 제시"이고 최종 결정은 통계청. 보고서 명시. 권고의 통계청 행정 적용 절차(차기 KSCO 9차 시 활용)를 별도 트랙으로 제안 |
| R4 | LLM 제공사 가용성·정책 변동 | 低 | 高 | 모델 2종(Anthropic·OpenAI) 병행 사용으로 일부 위험 분산. 비상시 로컬 모델(Qwen-2.5/Llama-3.1)로 전환 — 품질 하락 인정 후 추가 검증 강화 |
| R5 | KSCO 해설서 34개 누락 직업 (주요 업무 섹션 없음) | 確認필요 | 中 | L1 한국직업사전 보강 강제 적용. 그래도 부족 시 NCS L2. 그래도 부족 시 직업명 인터넷 검색 기반 LLM 추론 (전문가 검증 강화) |
| R6 | HumRRO 임계 (relevance 60%) 미달 직업이 다수 | 中 | 中 | 임계 미달 직업을 "보완 검토 대상"으로 분류하고 보고서에 명시. 전수 적용 전에 임계 조정(60% → 50%) 시뮬레이션 |
| R7 | 8개월 일정 압박 | 高 | 高 | M+4 시점에 진행률 < 50% 면 전수 → 80% 표본으로 축소. 보고서에 표본 한계 명시. 시뮬레이션 우선 완성 |
