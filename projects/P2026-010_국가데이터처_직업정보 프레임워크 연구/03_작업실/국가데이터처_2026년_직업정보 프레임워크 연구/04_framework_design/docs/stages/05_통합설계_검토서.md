# 통합 설계 검토서 — Stage 0~4 (KSCO → TASK→DWA→IWA→GWA)

> v1.0 · 2026-06-08 · 6개 단계 문서를 교차 점검한 마스터 검토서. **돌리기 전 최종 정합성 확인.**
> 대상: `00_전체구조` + `Stage0~4`. 결론: **설계 정합·구현 착수 가능(Go)**, 단 아래 보류·리스크 인지.

---

## 1. 종합 판정
- ✅ **단계 간 모순 없음.** 옛 결정(무제한·1차1:1·GPT cross·잠정라벨·HDBSCAN·GWA top-down 버킷)은 모두 폐기·갱신 확인.
- ✅ **연구 목적과 정합**: KSCO 직업설명 → TASK→DWA→IWA→GWA(상향식) + ONET 하이브리드/비교.
- ✅ **방어 가능**: 결정론 군집·dendrogram·ONET 절차 차용·구성타당도.
- ⚠️ **보류(범위 밖, 의도적)**: 직업 프로파일링·GWA 중요도·Responsibility 3축·변별력 분석(축2, Stage 5~7).

## 2. End-to-End 파이프라인 (확정본)
```
[Stage0] KSCO 정의·주요업무  ──정제·세세분류단위·부모상속──▶ 추출가능 입력
[Stage1] ──Opus 심층추출(전수1,270, 8~30개, 3차원동시, ~다필터)──▶ TASK
[Stage2] ──bge-m3 임베딩 → 계층응집군집(자연∩ONET band) ──▶ DWA  (+Opus 8조항 명명)
          └ TASK→DWA Multiple Linkage ≤3 (평균~1.3, ONET 1.26) = 네트워크 형성
[Stage3] ──같은 트리 상위절단(strict nesting)──▶ IWA  (+Opus 동사구 명명)
[Stage4] ──(주)ONET41 한국어 채택+IWA매핑 / (탐색)순수상향식+ONET비교──▶ GWA  (+한국신규 격리, 4영역)
= 직업↔TASK↔DWA↔IWA↔GWA 네트워크 (Sankey·dendrogram 시각화)
```

## 3. 핵심 결정 레지스트리 (전 단계 한눈)
| 항목 | 확정 | 출처 |
|---|---|---|
| 도출 단위 | 세세분류(5자리) + 부모 세분류 주요업무 상속 | S0/S1 |
| 주요업무 없는 직업 | 자기 정의로만 + `remarks` 비고(L1 보강 안 함) | S0 |

| TASK 3차원 | 업무+도구+환경 동시(명시단서·근거스팬·빈값허용) | S1 |
| 행동진술 필터 | "~다 종결 + 동사 형태소"(직업명 제외) | S1 |
| 군집 방법 | **계층적 응집군집**(평균/Ward·코사인), 스케일시 2단계 | 00/S2 |

| 한국 신규 GWA | 허용(cos<0.55 격리, `is_kr_unique`) | S4 |
| GWA 명명형 | 명사형(ONET형) + 4대 영역 표기 | S4 |

## 4. 데이터 모델 (얽힌 네트워크)
| 관계 | 카디널리티 | 구조 |
|---|---|---|
| 직업 → TASK | 1:N | — |
| TASK → DWA | **N:M (≤3)** | Multiple Linkage = 얽힘 |
| DWA → IWA → GWA | N:1, N:1 | strict tree |
| 직업 → GWA | N:M | 프로파일(축2, 후속) |
> 백본은 트리, TASK 다중연결 + 직업 다중GWA로 **전체는 네트워크**.
