# Stage 5 설계 — 직업별 GWA 측정(Level·Importance) + Responsibility + 프레임워크 범위

> 단계별 설계 시리즈 #5 (축2 · 시범 2개 중분류) · **v0.1 초안 (2026-06-10)**
> 입력: Stage 4까지의 직무활동체계(GWA·IWA·DWA·TASK) + 시범 2개 중분류 직업
> 출력: 직업별 GWA Level·Importance + Responsibility + 직업정보 프레임워크(시범)
>
> 🔴 **본 문서의 모든 ★ 항목은 "고려 방향(방안)"이며 최종 확정이 아니다. 실제 가동 전 반드시 의사결정이 필요하다.**
> ※ 축1(직무활동체계, Stage 0~4)은 **전수**. 본 축2(직업별 측정)는 **시범 2개 중분류만** — 프레임워크 검증·분류개편 근거 마련용. 전 직업 확대는 후속 사업.

---

## ① 목표·정의

- **목표**: 전수 구축된 직무활동체계(GWA/IWA/DWA/TASK) 위에서, **시범 2개 중분류 직업별로** 각 GWA를 *얼마나 중요하게(Importance)·어느 수준으로(Level)* 수행하는지 측정하고, **Responsibility(책무성)**를 부여하여 직업정보 프레임워크를 완성·검증한다.
- **위치**: 축1(어휘체계 도출, 전수) → **축2(직업 프로파일링, 시범)** → 검증 → KSCO 개편 근거(ISCO 반영).
- **측정 주체**: ONET의 재직자(incumbent) 설문을 **도메인 전문가 평정(incumbent surrogate)**으로 대체.

---

## ② ONET 실제 측정 방식 (벤치마크)

> 출처: [O*NET OnLine — Scales, Ratings, and Standardized Scores](https://www.onetonline.org/help/online/scales), [O*NET Analyst Procedures](https://www.onetcenter.org/dl_files/AnalystProc.pdf), [O*NET 22.0 Data Dictionary](https://www.onetcenter.org/dictionary/22.0/excel/appendix_incumbent.html)

| 항목 | ONET 방식 |
|---|---|
| 측정 대상 | **41개 GWA 전부** (직업별 선별 없음) |
| 척도 1 — **Importance(중요도)** | **1~5점** (1=Not Important ~ 5=Extremely Important) |
| 척도 2 — **Level(수준)** | **0~7점** (행동기준 닻점 Level Scale Anchors로 측정 — "얼마나 높은 수준/복잡도로 수행") |
| 표준화 | Importance·Level 모두 **0~100 표준점수**로 변환 제시 (척도 간 해석 일관성) |
| 수집 | 재직자(incumbent) 설문 + 훈련된 직업분석가 |
| 제시·억제 | ① 정밀도(precision) 미달 항목은 **"not available"로 억제** ② 분류·요약 활용 시 **평균 Importance ≥ 3.0인 GWA만 나열**(반올림) |

> **핵심 시사**: ONET의 실제 운영은 **"41개 전부 측정 + 낮은 값은 사실상 거름(≥3.0만 의미있게 제시)"**의 절충이다. "전부 측정"과 "상위만 제시"는 배타적 선택이 아니라 ONET 안에서 결합돼 있다.

## ③ ★ A. 직업별 GWA 선별 방식 — **의사결정 필요**

> "직업별로 41개 GWA 중 어떤 것을, 어떻게 골라 제시할 것인가."

| 방안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A-1. 전부 측정·전부 제시** | ONET DB식. 41개 모두 Importance·Level 부여, 낮은 값도 0~100으로 표기 | ONET 완전 호환·직업간 비교 완벽·빈칸 없음 | 전문가 부담 큼(직업당 41개)·낮은 값 다수 노이즈 |
| **A-2. 전부 측정·임계 이상만 제시** | ONET 분류활용식. 41개 평정하되 **Importance ≥ 3.0(또는 표준점수 기준)만 보고** | ONET 정석·완전성+간결성 | 여전히 41개 평정 부담 |
| **A-3. 상위 N개만 측정·제시** | 직업당 핵심 GWA 상위 N개(예 8~12)만 | 전문가 부담↓·핵심 집중 | 직업간 비교 시 빈칸·N 자의성·ONET 비호환 |
| **A-4. 2단계 스크리닝(절충·권장 후보)** | ① TASK→GWA 비중 **텍스트 프록시로 41개 1차 자동 추정** → ② 전문가는 상위 후보·경계 GWA만 **정밀 평정·조정** | 전문가 부담↓ + 41개 완전성 유지 + 전문가 검증 | 프록시 품질 의존·2단계 운영 복잡 |

- **잠정 권고**: **A-4(2단계 스크리닝)** 또는 **A-2**. 시범이 2개 중분류로 한정되므로 A-2(전부 전문가 평정)도 현실적. A-4는 후속 전수 확대 시 부담을 크게 줄임.
- 🔴 **의사결정 필요**: 전문가 가용 시간·산출물 활용 목적(완전 비교 vs 핵심 요약)에 따라 발주기관·연구진 협의로 확정.

## ④ ★ B. Level·Importance 측정 방법 — **의사결정 필요**

| 항목 | 고려 방향 |
|---|---|
| 척도 | ONET 차용: **Importance 1~5 · Level 0~7**, 0~100 표준화 병기 (국내 사용자 친화 위해 척도 라벨 한국어화) |
| 측정 주체 | **중분류 단위 도메인 전문가 평정**(재직자 설문 대체). 복수 전문가 평정 → 합의/평균 |
| 보조 입력 | TASK 빈도·비중 기반 **프록시 사전 추정치** 제공 → 평정 효율·일관성↑ (선택) |
| 신뢰도 | 전문가 간 일치도(ICC 등) 측정·보고. 불일치 GWA는 토론 조정 |
| Level 닻점 | ONET Level Scale Anchors의 한국어판 행동기준 예시 필요(★작성 과제) |

- 🔴 **의사결정 필요**: ① Importance만 vs Importance+Level 둘 다 측정할지 ② 프록시 사전추정 사용 여부 ③ 전문가 수·평정 방식(개별→합의 vs 패널).

## ⑤ ★ Responsibility(책무성) 반영 방안 — **의사결정 필요**

> ISCO 국제표준직업분류 개정 논의에서 직능수준(skill level)을 보완하는 **책무성·자율성** 차원이 강조됨. 본 연구는 시범 직업에 이를 부여.

| 후보 축(기존 설계 "R 3축" 참고) | 의미 |
|---|---|
| 관리·감독 책임 | 인력·조직 관리, 의사결정 권한 범위 |
| 자원·예산 책임 | 예산·자산·자원 운용 책임 규모 |
| 안전·위험 책임 | 안전·생명·법적 책임의 중대성 |

- 측정: 도메인 전문가 평정(척도 미정) 또는 직무기술 기반 규칙.
- 🔴 **의사결정 필요**: ① 축 구성(3축 유지 vs ISCO 개정안 정의 정렬) ② 척도 ③ GWA와의 관계(독립 차원 vs GWA Level 보정).
- ※ ISCO 개정안의 책무성 정의는 [03_ISCO08_Companion_Guide 심층분석](../../07_references/심층분석/03_ISCO08_Companion_Guide_심층분석.md) 재확인 후 정렬 필요.

## ⑥ ★ 프레임워크 범위(담을 직업정보) — **의사결정 필요**

> 한국형 직업정보 프레임워크에 직업별로 **무엇을** 담을지. 3개 안.

| 안 | 포함 차원 | 데이터 출처 | 비고 |
|---|---|---|---|
| **1안 (최소)** | TASK · GWA | 본 연구 자체 도출 | 직무활동 중심·경량. 빠른 검증 |
| **2안 (중간·권장 후보)** | TASK · GWA · **Responsibility** · 작업환경 · 도구 | 본 연구(작업환경·도구는 Stage 1서 이미 추출) | 본 연구 집중 범위와 정합. ISCO 책무성 반영 |
| **3안 (확장)** | 2안 + **지식 · 기술 · 임금정보 등** | NCS·임금정보포털·한국직업사전 등 국내 데이터 연계 | 풍부하나 외부 데이터 정합·작업량↑. 후속 확장 여지 |

- **현재 연구 집중 선언**: GWA · TASK · Responsibility (CLAUDE/설계 합의).
- 🔴 **의사결정 필요**: 2안 확정 vs 3안 일부 채택(예: 지식·기술 "자리만 마련"). 작업환경·도구는 Stage 1서 이미 전수 추출되어 **2안은 추가비용 적음**.
