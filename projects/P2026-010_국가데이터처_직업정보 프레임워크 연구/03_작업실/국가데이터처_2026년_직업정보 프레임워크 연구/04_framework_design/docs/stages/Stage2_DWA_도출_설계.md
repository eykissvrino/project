# Stage 2 설계 — DWA 도출 (TASK → 군집 → DWA + 명명)

> 단계별 설계 시리즈 #2 · **v1.0 확정(2026-06-01)**
> ※ DWA(상향식 군집)는 **하이브리드·순수상향식 두 트랙 공통**. GWA 채택 방식 차이는 Stage 4에서만 갈림.
> 입력: Stage 1의 TASK(전수) / 출력: DWA(상세 작업활동) + TASK↔DWA 연결
> 원칙(앞 단계 합의): **순수 상향식**(GWA 선버킷 없음) · **목표 없는 자연 절단점** + **ONET 비율 broad 참고** · **Opus 단독 명명(8조항)** · GPT 없음

---

## ① 목표·정의
- **목표**: 전수 TASK를 의미 유사도로 **상향식 군집**하여 **DWA(Detailed Work Activity, 상세 작업활동)**를 도출하고, 각 DWA에 **정식 이름(8조항)**을 붙인다.
- **DWA 정의**: 여러 직업·여러 TASK가 공유하는 **중간 추상 수준의 작업활동 진술**. 예: "재무 기록을 조사하여 재무제표를 작성한다" (회계사·세무사·신용분석가의 유사 TASK를 묶음).
- **핵심 가치**: 같은 DWA에 *다른 직업*의 TASK가 묶이면 = 직업 간 공통활동(Cross-Job) → 직업전환·변별력 분석 기초(목적 #3).

## ② 도출 이론 (왜)
- **ONET WA Project DWA 절차 차용**: GWA 내에서 task를 의미 유사성으로 군집 → DWA. 단 본 연구는 **GWA 선버킷 없이 전체 TASK를 상향식 군집**(연구진 방법: 아래에서 위로 도출 후 GWA는 최상위에서).
- **분포가설 + 계층적 군집**: 의미 유사 TASK는 임베딩 공간에서 근접 → 응집 군집으로 묶임. 단일 dendrogram → 상위 계층(IWA·GWA)과 nesting 보장.
- **자연 절단 + ONET 비율 참고**: 목표값을 강제하지 않되(순환 회피), ONET 비율(TASK:DWA≈9:1)을 **broad 참고 범위**로 사용해 적정 추상수준 선택(Stage 1 TASK 범위 결정과 동일 철학).
- **8조항 Writing Standards**: DWA 진술은 단일동사·현재서술형·중간일반화 등 8조항 준수(ONET 규약 한국어판). **→ 8개 조항 본문은 §⑨에 권위 명문화.**
- **채택 임계(★확정 = 한국형 3/2, 2026-06-10)**: 최소 **3 task 또는 2 직업**에서 출현해야 DWA로 인정. ONET은 4/3이나, 전수 실측상 한국은 직업당 TASK가 적어(중앙값 12 vs ONET 20) 3/2로 완화 확정 — 직업 수는 오히려 많아(1,270 vs 923) "여러 직업 공유" 조건은 쉽게 충족. 잡음은 응집도(≥0.70)·검수로 통제. (시범서 4/3 대조 측정 병행=참고)

## ③ 입력 → 출력 스키마
**입력**: Stage 1 `task`(전수) + 임베딩.
**출력**
```
dwa: {dwa_id, label(8조항 정식명), definition, cluster_size, n_jobs(소속 직업수),
      mean_cosine(응집도), eight_rules_passed(bool), is_cross_family(bool)}
task_to_dwa: {task_id, dwa_id, link_order(1~3)}   # Multiple Linkage
```

## ④ 도출 방법 (절차)
1. **임베딩**: 전수 TASK `full_statement` → bge-m3(1024d, L2정규화).
2. **상향식 계층군집**: 전체 TASK에 평균연결·코사인 `linkage` 1회 → dendrogram(상위 계층과 공유).
3. **DWA 수준 절단(자연 + ONET band)**:
   - 절단높이별 군집수 곡선·안정구간(plateau) 산출.
   - **ONET 비율 broad band** = (전수 TASK수 ÷ 12) ~ (÷ 6) 범위. 이 band 안에서 가장 안정적인 절단점 채택.
   - band 내 뚜렷한 plateau 없으면 band 중앙으로 절단하고 "선택된 추상수준"으로 명시(정직).
4. **채택 임계(한국형 3/2 확정)**: 군집크기 < 3 task **또는** 소속 직업 < 2 → DWA 미인정(소형군집은 인접 DWA 병합 또는 검토큐). (ONET 4/3 대비 완화 — 한국 직업당 TASK 적음 반영, 2026-06-10)
5. **Multiple Linkage(핵심·ONET 준거)**: 각 TASK를 1차 DWA(자기 군집) + **유사도 임계 초과 인접 DWA centroid에 최대 3개** 연결(link_order∈{1,2,3}). 목표 평균 ~1.3(ONET 실측 1.26). ★ **이 다중연결이 strict-tree 백본(DWA-IWA-GWA)에 TASK를 엮어 "얽힌 네트워크"를 만든다**(직업→여러 GWA 프로파일의 원천).
6. **DWA 명명(★ Opus 정식 라벨)**: 각 DWA 군집의 대표 TASK 5건을 Opus에 입력 → **8조항 준수 DWA 라벨 작성**(대표문장 잠정 ❌). 군집 다수 → 서브에이전트 배치.
7. **8조항 자동검증**: 어미·명사수·금지일반어·예시구·목적절·길이 규칙 검사 → 위반 시 Opus 재작성(최대 3회).
8. **적재**: dwa / task_to_dwa(트랜잭션) + cross-family 플래그(다른 직업군 묶임).

## ⑤ 사용 모델
- **임베딩**: BAAI/bge-m3 (다국어·1024d).
- **군집**: scipy 계층군집(평균연결·코사인) — 단일 트리로 IWA/GWA와 nesting.
- **명명·재작성**: **Opus 4.8 단독**(구독, 서브에이전트 배치, API/GPT 없음).
- **8조항 검증**: 규칙(형태소/정규식).

## ⑧ 핵심 설계 결정 (확정)
1. **군집 방법 = 계층적 응집군집**(평균/Ward·코사인) — **★단일트리 확정(2026-06-10)**. 전수 실측 16,168 TASK → 거리행렬 ~1.05GB(피크 2~3GB)로 단일 응집트리 직접 가능, 2단계 하이브리드 불필요. nesting(DWA⊂IWA⊂GWA) 보장이 가장 단순.
2. **DWA 수준 절단 = 자연 plateau ∩ ONET band(TASK÷6~12)**. band 내 plateau 없으면 band 중앙(선택된 추상수준으로 명시).
3. **채택 임계 = 3 task or 2 직업 (한국형 3/2 확정, 2026-06-10)**. ONET 4/3 대비 완화 — 한국은 직업 수 많고(1,270) 직업당 TASK 적음(중앙값 12). 시범서 4/3 대조 측정은 참고로 병행.
4. **임베딩 = bge-m3**(다국어, ONET 교차비교 가능) 채택. 한국어 특화 모델(KoSimCSE 등)은 *옵션 벤치*.
5. **Multiple Linkage = ≤3 (ONET 준거·핵심, 부활)**: TASK→DWA를 1:1 아닌 **최대 3 연결**(평균~1.3, ONET 1.26). 백본(DWA-IWA-GWA)은 strict tree, **TASK 다중연결로 네트워크 형성**. `task_to_dwa.link_order`. ※ 이전 "1차 1:1" 결정 폐기.
6. **DWA 명명 = Opus 8조항 정식 라벨**(서브에이전트 배치). 대표문장 잠정 폐기.

## ⑨ DWA Writing Standards — 8조항 (권위 명문화) ★

> **출처**: O\*NET Work Activities Project 보고서 p.24 / Appendix B "DWA Writing Standards" (8 rules).
> **성격**: 영어 원문 8조항을 **한국어 DWA 진술 작성 규칙으로 변환·확정**한 본 연구의 공식 기준.
> **연계**: `prompts/dwa_write_system.md`(Opus 라이팅 프롬프트)와 `utils/dwa_rules.py`(자동검증)는 **본 절과 1:1 대응**하여 작성한다(§④-6·7, §⑥).
> **한국어 변환 2대 원칙**: ① 영어의 "동사로 시작"은 한국어 어순상 **"서술어로 종결"**로 등가 변환. ② 영어 SMOG 8학년 가독성은 한국어 가독성 지표로 대체(조항 8, 시범 28 실측으로 확정).

| # | O\*NET 원문 규칙 | 한국어 적용 규칙 (확정) | 자동검증 (`dwa_rules.py`) |
|---|---|---|---|
| **1** | DWA당 주요 활동동사 1개, **동사로 시작** | **단일 핵심 서술어**: DWA 1건 = 주요 활동 1개. "~한다"형 단일 서술어로 종결. 복합서술('~하고 ~한다')은 활동이 본질적으로 결합된 경우만 허용 | 종결 서술어 1개 확인; 연결어미('-고','-며','-거나') 2개↑ 시 경고 |
| **2** | 동사형식 **3인칭·현재·복수** (Inspect, not Inspects/Inspecting) | **현재 평서형 종결 '~한다'**: 명사형('조사'), 명사화('~하기'), 과거형('~하였다'), 높임('~합니다') **금지** | 어미 정규식 `~다$` 확인; '함/하기/했다/합니다' 검출 시 위반 |
| **3** | 명사 최소화·구체성 유지, 다중객체는 **'or'** | **목적어 명사 절제 + 다중객체 '및/또는'**: 불필요 수식 제거, 병렬 객체는 '및/또는'으로 묶음 | 목적어구 토큰수 상한; 쉼표 나열 3개↑ 경고 |
| **4** | **JobFamily 적합 명사** (중간 일반화) | **중간 추상도 명사**: 광의 일반어("장비/자료/업무/기타")✕, 협의 고유명("○○사 전용 장비")✕, 직업군 통용 중간어("의료처치장비")○ | 금지일반어 블랙리스트 사전 대조 |
| **5** | 명료성을 위해 **형용사 사용** | **변별 한정수식 허용**: 의미 구분에 필요한 수식어는 사용(과잉 수식은 지양) | 정성 기준 — 자동검증 제외, QC 육안 |
| **6** | **예시절 회피** ("such as", "including") | **예시·열거구 금지**: '~등', '~와 같은', '예를 들어', '가령' 회피. 꼭 필요 시 최소 | 금지표현 정규식 검출 |
| **7** | **목적절("to …") 최소** | **목적·결과절 최소화**: '~하기 위하여/위해', '~함으로써', '~하도록' 남용 금지. 단 **목적 상이 시 KSAO가 달라져 변별 의미** 있으면 유지 | 목적절 패턴 카운트; 1개 초과 경고 |
| **8** | **8학년 가독성** (SMOG index) | **일반사용자 가독성**: 구직자·교사·인사담당자가 1독 이해 가능. 과도한 한자어·전문용어·중첩수식 금지 | 문장 어절수 상한 + 음절/난이도 휴리스틱 (한국어 지표는 아래 註) |

**부속 규정**
- **길이 가이드(권고)**: DWA 라벨 = **1문장**. 어절 상한은 시범 28 실측 분포로 확정(잠정: 과도한 길이 지양). ONET DWA 평균 길이 참고.
- **준수율 기준**: 자동검증 통과율(`eight_rules_passed = true`) **≥ 0.90** (§⑦ 품질기준과 연계).
- **위반 처리**: 자동검증 실패 시 Opus 재작성(최대 3회, §④-7). 3회 후에도 미달이면 검토큐 회부.

**한국어 가독성 지표 (조항 8) — 확정 과제**
- 영어 SMOG(8학년)의 한국어 등가 지표 후보: **KOR-DALE, KU-readability** 등.
- 시범 28 단계에서 후보 지표로 실제 DWA 라벨을 측정 → 임계값(목표 학년/난이도) 확정 후 `dwa_rules.py`에 반영.
- 확정 전까지는 **어절수 상한 + 전문용어 휴리스틱**으로 잠정 운용.
