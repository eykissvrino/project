# 방법론의 이론적·논리적 타당성 — KSCO 직무활동 4계층 도출

> 작성: 2026-06-01 · v1.0
> 목적: 본 연구가 KSCO 텍스트에서 TASK→DWA→IWA→GWA를 도출하는 **각 단계의 이론적 근거·절차·사용 모델·논리적 타당성**을 명시하고, 실증 결과로 드러난 **타당성 위협과 보완책**을 정직하게 기록한다. 학회·통계청 심의 방어 및 연구진 내부 검토용.
> 관련: `12_도출방법론_설계서.md` · `13_실행과정_검토용.md` · `03_CBM_설명가능AI_정합성_분석.md`

## 0. 전체 논리 구조

**연구 가설(H)**: KSCO 직업설명에서 직무활동을 *상향식(bottom-up)*으로 군집·추상화하면, ONET의 4계층 작업활동 체계(GWA 41 / IWA 332 / DWA 2,087)와 **구조적으로 정합**하는 한국형 체계가 도출될 것이다.

```
KSCO 직업설명(정의·주요업무)
   │  ① 추출 (텍스트 → 행동진술)
   ▼
 TASK ── ② 임베딩 ── ③ 계층군집 ──┬── ④ 추상화(절단) ── DWA → IWA → GWA (한국형)
                                   │
                                   └── ⑤ ONET 비교 (구성타당도 검증)  ← ONET은 입력 아님, 검증 기준
```

**방법론 정체성**: ONET Work Activities Project(2014)의 *절차*(군집→추상화)는 차용하되, ONET의 41 GWA를 *입력 버킷으로 강제하지 않고*, 한국 데이터에서 계층을 **자생적으로 도출**한 뒤 ONET을 **수렴타당도(convergent validity) 기준**으로 비교한다.

## 1. 단계별 이론·절차·모델·타당성

### ① TASK 추출 — 텍스트에서 행동진술 단위 도출
| 구분 | 내용 |
|---|---|
| **이론** | 직무분석(Job Analysis)의 *task inventory* 전통(McCormick 1979); ONET task statement 규약(동사+목적어, 단일 주동사) |
| **절차** | 세세분류 정의 + 부모 세분류 주요업무(상속) → 행동진술만 추출(직업명·소제목·"~다" 미종결 제외) |
| **모델/방법** | (시범) LLM(Claude Opus) 직업별 특화 / (전수) 규칙추출(글머리 분해 + 행동진술 필터) |
| **논리적 타당성** | KSCO는 통계청 고시(권위 100%)이며 주요업무가 "동사+목적어" 형태로 기술 → task 단위 추출에 적합. 단 **규칙추출은 직무특화가 약함**(아래 §4 위협 1) |

### ② 의미 임베딩 — TASK를 벡터 공간에 사상
| 구분 | 내용 |
|---|---|
| **이론** | **분포가설**(Distributional Hypothesis, Harris 1954; Firth 1957 "유사 맥락의 단어는 유사 의미"); 문장 임베딩(Transformer 기반) |
| **모델** | `BAAI/bge-m3`(Chen et al. 2024) — 다국어·1024차원, L2 정규화 → **코사인 유사도 = 의미 근접도** |
| **절차** | TASK 진술 → 임베딩, 정규화. 동일 입력 동일 벡터(재현성) |
| **논리적 타당성** | 의미가 유사한 직무활동은 벡터 공간에서 가깝다는 것이 분포가설의 직접 함의. 다국어 모델이라 한국어 TASK ↔ 영어 ONET 라벨 교차비교 가능(단 §4 위협 2: 교차언어 손실) |

### ③ 계층 군집 — 유사 TASK를 상향식으로 병합
| 구분 | 내용 |
|---|---|
| **이론** | 계층적 응집 군집(Hierarchical Agglomerative Clustering); ONET WA Project의 GWA 내 군집화 절차 차용 |
| **모델/방법** | 평균연결(average linkage) + 코사인 거리, `scipy.linkage` 1회 → 단일 트리(dendrogram). 평균연결은 군집 간 평균 거리 기준이라 사슬효과(single linkage)·구형가정(Ward) 편향을 완화 |
| **절차** | 전체 TASK 임베딩으로 트리 1회 생성 → 여러 높이에서 절단하여 다층 추출(트리가 같아 **계층 nesting 보장**: DWA ⊂ IWA ⊂ GWA) |
| **논리적 타당성** | 단일 트리에서의 절단은 "같은 DWA는 반드시 같은 IWA·GWA에 속한다"는 위계 일관성을 수학적으로 보장 → CBM concept hierarchy(Koh 2020)와 정합 |

### ④ 추상화 수준 결정 — 자연 절단점(목표값 없음)
| 구분 | 내용 |
|---|---|
| **이론** | 군집 수 결정·군집 타당도(Milligan & Cooper 1985); **안정성 기반 모델선택**(Ben-Hur et al. 2002) — 넓은 절단높이 구간에서 군집 수가 유지될수록(plateau 넓을수록) 자연스러운 분할 |
| **절차** | 절단높이별 군집수 곡선 산출 → 안정구간(plateau) 폭 측정 → 폭이 넓은(=안정적인) 3개 수준을 DWA/IWA/GWA로 채택. **사전 목표 군집수 없음** |
| **논리적 타당성** | 목표값을 넣지 않으므로 ONET 41에 맞추는 *순환논증 회피*. 데이터 자체의 구조만으로 granularity 결정 |
| **★ 실증 결과(정직)** | 본 KSCO 데이터에서 **안정구간 폭이 모두 매우 좁음(≤0.017)** → 뚜렷한 자연 경계 없음(계층이 연속적). 가장 안정적 분할 = GWA 5 / IWA 28 / DWA 54. **즉 "자연 granularity"는 약하게만 정의됨** → §4 위협 4 |

### ⑤ ONET 비교 — 구성타당도(수렴타당도) 검증
| 구분 | 내용 |
|---|---|
| **이론** | 구성타당도(Cronbach & Meehl 1955) — 새 측정체계가 기존 확립된 체계와 수렴하면 타당성 지지. ONET = 국제 표준 작업활동 체계 |
| **절차** | 한국형 GWA 군집 중심벡터 ↔ ONET 41 GWA 라벨 임베딩 최근접 매칭 → 매칭 수·평균 유사도 |
| **논리적 타당성** | 한국형 체계가 ONET에 수렴하면 H 지지, 발산하면 "한국 직업구조 고유성" 또는 "방법 한계"로 해석 → 어느 쪽이든 연구적 정보 |
| **★ 실증 결과(정직)** | 자연절단(GWA 5) 기준 ONET 매칭 4/41·유사도 0.58, 41-근접 절단 기준 18/41·0.62. **수렴 약함** → §4 위협 2·3 |

## 2. 본 방법이 연구 목적에 타당한 이유 (종합 논리)

1. **재현가능성**: 임베딩·군집·절단이 결정론적(seed·파라미터 고정) → 통계청 "같은 입력 같은 결과" 요건 충족.
2. **설명가능성(CBM)**: TASK→DWA→IWA→GWA는 concept bottleneck 계층으로, 각 직업의 GWA 판정을 하위 TASK까지 역추적 가능 → "왜 이 분류인가"에 답함.
3. **국제정합성**: ONET 절차 차용 + ONET 비교로 ISCO-28 SLF 연계 근거 확보.
4. **변별력(목적 #1)**: 같은 KSCO 코드 내 직업이 다른 DWA·R점수로 갈리면 세세분류 분기 근거 → 단, R3축은 본 실행 미구현(다음 단계).

## 3. 타당성 위협과 보완책 (정직한 한계)

| # | 타당성 위협 | 근거(실증) | 보완책 |
|---|---|---|---|
| 1 | **추출 일반성** — 규칙추출 TASK가 "분석한다/작성한다/관리한다"류로 일반적 → 직무 변별 약화 | 전수 규칙추출 | **LLM 추출로 직업별 특화**(시범 28에서 검증; 전수는 API 배치) |
| 2 | **교차언어 비교 손실** — 한국어 TASK ↔ 영어 ONET 라벨 | ONET 유사도 0.58~0.62 | ONET 41 GWA 라벨·정의 **한국어 번역** 후 비교 |
| 3 | **수렴 약함** — 한국형 GWA가 ONET에 부분만 매칭(4~18/41) | 실증 | LLM 추출·한국어 비교 후 재측정; 발산 시 "한국 고유성"으로 해석 |
| 4 | **자연 granularity 부재** — 안정구간 폭 ≤0.017, 자연 GWA≈5(41 아님) | 자연절단 분석 | granularity를 **자연 사실이 아닌 "선택된 추상수준"**으로 정의하고 ONET으로 *검증*; 또는 전문가 검토로 수준 확정 |
| 5 | **라벨 미완** — DWA/IWA/GWA 이름이 대표문장 잠정 | 실행 | LLM 8조항 정식 라벨링 |
| 6 | **노이즈/미배치** — (HDBSCAN 버전) 일부 TASK 미배치 | 이전 실행 | 계층군집(전배정)으로 해소 완료 |

### ★ 가설에 대한 정직한 현재 결론
- 가설 "ONET 41이 **자연 emergent**" → **현 방법으론 미지지**(자연 granularity는 ~5, 약하게 정의).
- 더 방어 가능한 재정식화: **"KSCO 활동을 ONET 절차로 다층화할 수 있고, ONET 41 수준에서 자르면 한국형 GWA가 ONET과 부분 수렴(0.62)한다. 수렴도는 LLM 추출·한국어 비교로 향상 가능하다."**
