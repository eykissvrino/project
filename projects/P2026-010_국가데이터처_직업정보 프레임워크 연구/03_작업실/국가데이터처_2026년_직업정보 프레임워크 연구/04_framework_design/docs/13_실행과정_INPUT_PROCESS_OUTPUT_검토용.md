## 0. 한눈에 — 두 가지 실행 트랙

지금까지 **목적이 다른 두 트랙**을 돌렸다. 혼동 방지를 위해 명확히 구분한다.

| | **트랙 A — 시범(고품질)** | **트랙 B — 전수(스케일·절차 검증)** |
|---|---|---|
| 범위 | 중분류 28(경영·금융) 50 직업 | **전체 KSCO 389 세분류 / 56 중분류** |
| 추출 방법 | **LLM(Opus 4.8=Claude Code) 직업별 특화** | **규칙추출**(주요업무 글머리 분해) |
| TASK | 206 (직업별 특화, 고유 199) | **1,945** (고유) |
| DWA→IWA→GWA | 13 → (시범) → 26버킷 | **155 → 113 → 39** |
| 비용 | 0원(구독) | 0원(규칙) |
| 용도 | "직업별 특화가 된다"는 품질 증명 | "절차가 전체 스케일에서 올바른 위계를 만든다"는 검증 |
| 한계 | 50직업만 | 직업별 특화 없음(형제 동일), 라벨 잠정 |

> **왜 둘로 나뉘나**: 전체 1,270 직업을 LLM 품질로 손추출하는 건 불가능 → 전수는 규칙추출. 직업별 LLM 특화 전수는 **API 배치**(소액)가 정답. 두 트랙은 상호보완.

## 1. INPUT — 무엇을 입력으로 쓰는가

### 1.1 원천 데이터 (DuckDB `pipeline.duckdb`)
| 자원 | 내용 | 규모 | 사용 트랙 |
|---|---|---|---|
| `ksco_occupation` 세분류(4자리) | 코드·명 + **정의** + **주요업무** + 예시 | 495 (주요업무 보유 389) | A·B |
| `ksco_occupation` 세세분류(5자리) | 코드·명 + 정의 + 예시 (**주요업무 없음**) | 1,270 | A |
| `external_ref.onet_gwa/iwa/dwa` | ONET 29.3 위계 기준 | 41 / 332 / 2,087 | A·B(GWA 할당 기준) |

### 1.2 도출 단위 (설계 D0)
- TASK 도출 단위 = **세세분류(5자리)**. 단 주요업무는 세분류(4자리)에만 존재 → **부모 세분류 주요업무를 자식에게 상속**.
- 트랙 A: 세세분류별로 부모 주요업무를 상속받아 LLM이 직업별 특화.
- 트랙 B: 세분류 주요업무 글머리를 그대로 TASK로(규칙), 자식은 상속.

### 1.3 [검토 포인트] 입력의 적절성
- ✅ KSCO 통계청 고시 = 권위 100%. 정의 채움 98.5%.
- ⚠️ 주요업무 미보유 세분류 ~106개(군인·단순노무 등) → 해당 직업 TASK 부족 → **한국직업사전(L1) 보강 필요**(후순위).
- ⚠️ 정의에 페이지헤더 노이즈("대분류 2", "378┃한국표준직업분류") 섞임 → 전처리에서 제거.

## 2. PROCESS — 기준·절차·방법 (단계별)

```mermaid
flowchart LR
  K[KSCO DB<br/>정의·주요업무] --> E[① TASK 추출]
  E --> EM[② 임베딩 bge-m3]
  EM --> G[③ GWA 할당<br/>ONET 41]
  G --> D[④ DWA 군집<br/>HDBSCAN leaf]
  D --> I[⑤ IWA 군집<br/>DWA 재군집]
  I --> M[⑥ GWA 매핑]
  M --> O[위계 GWA⊃IWA⊃DWA⊃TASK]
```

### ① TASK 추출
| 항목 | 트랙 A(LLM) | 트랙 B(규칙) |
|---|---|---|
| **기준** | ONET task 규약: 동사+목적어, 단일 주동사, 일반진술·예시 제외 (사양서 §1.2) | 주요업무 글머리(·) 1개 = 1 TASK |
| **절차** | 세세분류별: 부모 주요업무 상속 → 자기 정의로 특화 → 2회 self-consistency | 세분류 주요업무 split → 노이즈 제거 → 중복 제거 |
| **방법** | Claude Opus 4.8가 직접 추출(=LLM), `extract_one`→`persist` | 정규식 split (`utils/clustering` 외 `parse_bullets`) |
| **산출** | task 테이블 206행 | 고유 TASK 1,945 |
| **[검토]** | 직업별 특화 O, 재현성 O(캐시·로그) / 50직업 한정 | 전수 O / **특화 X(형제 동일), 동사·목적어 미분리** |

> ★ 설계(사양서 §1.2)는 **LLM 2회 self-consistency**가 표준. 트랙 B는 스케일 위해 규칙으로 대체 — **이게 가장 큰 설계-실행 차이**. 전수 품질이 필요하면 API LLM 배치로 전환.

### ② 임베딩
- **기준/방법**: `BAAI/bge-m3`(1024차원, 다국어), L2 정규화 → 코사인=내적. (사양서 §3.2)
- **[검토]** ✅ 설계 그대로. 다국어라 한국어 TASK ↔ 영어 GWA 라벨 교차 비교 가능.

### ③ GWA 할당 (TASK → ONET 41 GWA 버킷)
| 항목 | 내용 |
|---|---|
| **기준** | 각 TASK를 ONET 41 GWA 중 가장 가까운 1개에 배정 |
| **방법(실행)** | **임베딩 최근접**(TASK 임베딩 ↔ 41 GWA 라벨 임베딩, 코사인 argmax) |
| **산출** | 39/41 GWA 사용 |
| **[검토]** | ⚠️ **설계(사양서 §2.3)는 LLM zero-shot 2회**인데, 실행은 **임베딩 최근접으로 대체**(스케일·무료). 빠르지만 LLM보다 거칠 수 있음. 또 GWA 라벨이 영어라 한↔영 교차 매칭 — 검증 필요. |

### ④ DWA 군집 (GWA 버킷 내 TASK 군집)
| 항목 | 내용 |
|---|---|
| **기준** | 같은 GWA 버킷 내 의미 유사 TASK를 묶음 (사양서 §3) |
| **방법** | **HDBSCAN** (sklearn 내장), `min_cluster_size=3`, `cluster_selection_method='leaf'`(세밀) |
| **산출** | DWA 155개, 배치 742/1945(38%), 평균 응집도(트랙B) |
| **[검토]** | ✅ GWA 버킷 단위 실행(설계 일치). `leaf`로 세분화(eom은 55개로 과대뭉침 → 155개로 개선). ⚠️ **배치율 38%**(62%는 단발 TASK라 노이즈) — 규칙추출 진술이 길고 거칠어 군집이 느슨. LLM 추출·전수 확대 시 개선. ⚠️ DWA 라벨 = **군집 대표문장 잠정**(8조항 정식 라벨 아님). |

### ⑤ IWA 군집 (DWA → IWA, 중간 계층)
| 항목 | 내용 |
|---|---|
| **기준** | DWA들을 한 단계 일반화하여 IWA로 묶음 (GWA ⊃ IWA ⊃ DWA) |
| **방법(실행)** | 같은 GWA 내 **DWA 대표벡터(medoid) 재군집**(HDBSCAN eom, min 2) |
| **산출** | IWA 113개 |
| **[검토]** | ⚠️ **설계(사양서 §4c)는 "한국 DWA 재클러스터링 → 한국 IWA"** — 실행은 그 취지를 DWA medoid 재군집으로 구현(합리적이나 설계 원문과 방법 차이). 한국 IWA↔ONET IWA332 비교(코사인<0.55 신규격리)는 **미구현**. |

### ⑥ GWA 매핑
- IWA를 그 구성 DWA의 GWA로 매핑(이미 ③에서 GWA 결정). ONET 41 + 한국신규(미구현).
- **[검토]** ⚠️ 설계의 "한국 IWA→ONET GWA 비교 매핑"은 단순화됨.

### (미실행 — 설계엔 있으나 이번 실행에 없음)
- **Responsibility 3축 점수화**(⑤단계, 본 연구 핵심 차별화) — 미실행.
- **Cross-Family DWA 통합**, **Multiple Linkage(≤3)**, **DWA QC(Round-Robin)**, **8조항 자동검증** — 미실행.
- **세세분류 R격차 변별력 분석**(목적 #1) — 미실행.

## 5. 결론
- **절차(INPUT→TASK→DWA→IWA→GWA)는 전체 KSCO 스케일에서 끝까지 작동**하고, 위계 비율이 정상화됨을 확인.
- 단, **추출·GWA할당·라벨링을 LLM 품질로 올리는 것**, 그리고 **R3축 변별력**이 본 연구 목적 달성을 위한 핵심 남은 과제.
- 본 실행은 "**파이프라인이 돈다**"의 검증이며, "**산출물이 학회·통계청 수준 품질이다**"는 위 4.2~4.3 보강 후 도달.
