### B2. Q&A 예상 질문 대비 카드 (20분)

#### Q1. AI(NLP) 산출물의 신뢰도는 어떻게 보장하는가?
**A**: HumRRO(2010)의 3대 기준을 한국화하여 적용 — 전문가 5인 평가, 관련성 60%, 중요도 3.0 이상. 모든 NLP 산출물은 전문가 검증 후 확정.

#### Q2. 6대 차원이 O*NET 6도메인을 단순 번역한 것 아닌가?
**A**: 한국 데이터 가용성과 RFP 행정 데이터 연계 요구를 반영한 압축·통합. Worker Characteristics를 능력 1차원으로, Workforce Characteristics를 외부 연계로 분리. 단순 번역이 아닌 한국화 설계.

#### Q3. 시뮬레이션 대상 중분류가 충분한가?
**A**: 지식·기술·대인서비스 3대 영역에서 각 1개씩 전략적 선정. 8차 개정 분리 영역(보건 전문가) 우선 포함. 변별력 검증으로 6차원의 일반화 가능성 입증.

#### Q4. KECO와의 관계는?
**A**: KSCO 8차 ↔ KECO 2025 세분류 1:1 연계 활용. 본 연구 산출물은 두 체계 모두에 적용 가능. 신생 직업(데이터·플랫폼·반려동물 53개)은 KECO 2025 분류로 NLP 우선 적용.

#### Q5. ISCO-28 개정과의 정합성은?
**A**: ISCO-28 직능수준 4축 확대(Education·Responsibility·Experience·Work-based learning)를 본 연구 6차원이 선제 수용. 월 1회 ILO 동향 모니터링 + 보고서 즉시 반영.

#### Q6. 8개월에 KSCO 세분류 495개 전체 가능한가?
**A**: AI 기반 NLP 자동화로 1차 처리 → 전문가 검증의 효율 모드 운영. 영역1을 M+2~M+7 6개월간 분산 + 시뮬레이션은 3개 중분류로 한정 → 전체 모집단 대비 검증 표본 적정성 확보.

#### Q7. 행정 데이터 연계는 어떻게 구현하는가?
**A**: 본 연구는 6차원 외부에 *행정 데이터 연계 영역* 별도 설계. 고용보험·국가자격·NCS 등과 연계 가능한 구조 + 차원별 측정 척도가 행정 데이터 항목에 매핑되도록 설계.

#### Q8. 전문가 검토위원 5인 명단은?
**A**: (착수보고 시점에 학계 2인·KEIS 1인·통계청 OB 1인·산업계 1인 위촉 완료 명단 제시). 4회 자문회의로 단계별 검증.
