## 자료 성격 구분

| 폴더 | 성격 | 변경 가능성 |
|---|---|---|
| `00_external_references/` | 외부에서 받은 1차 자료 (학술 논문, 분류 자료) | 변경 금지 (원본 보존) |
| `01_proposal/` | 발주기관에 제출된 공식 문서 (RFP, 제안서) | 변경 금지 (원본 보존) |
| `raw/` `processed/` `reference/` | 본 연구 NLP 작업 산출물 | 작업 중 자유 변경 |
