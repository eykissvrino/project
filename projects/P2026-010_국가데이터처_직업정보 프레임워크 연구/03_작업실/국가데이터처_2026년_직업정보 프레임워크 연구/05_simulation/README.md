# 05_simulation — 시뮬레이션 검증 + 전문가 검토 (RFP 영역4)

> KSCO 8차 중분류 2~3개에 한국형 6대 차원 시범 적용 → 변별력 검증.

## 폴더 구조

| 폴더 | 용도 |
|---|---|
| `target_jobs/` | 시뮬레이션 대상 KSCO 중분류 직업군 정보 |
| `results/` | 단계별 시뮬레이션 결과 (직업 설명 분석·활동 추출·차원별 재구성·변별력 검토) |
| `expert_review/` | 전문가 검토 의견서 (4회 자문회의 누적) |

## 시뮬레이션 대상 후보 (KSCO 8차 기준)

| 우선순위 | KSCO 중분류 | 명칭 | 세분류 수 | 선정 근거 |
|---|---|---|---|---|
| 지식 기반 | 22·26 | 행정·경영 / 교육 전문가 | 15·18 | KECO 2025 데이터/AI 신설 영역 |
| 기술·도구 | 78 | 정보통신·방송기기 기능원 | 19 | 도구·환경 차원 변별력 |
| 대인서비스 | 29 | 법률·사회복지·종교·문화 등 | 36 | 8차 분리신설 영향 |

> ※ 정확한 코드는 KSCO 8차 분류항목표 정밀 확인 후 착수보고 시 확정

## 시뮬레이션 4단계 절차 (제안서)

| 단계 | 활동 | 산출 |
|---|---|---|
| ① 직업 설명 분석 | 선정 중분류 내 세분류 직업 설명·주요업무 종합 | 직업별 정제 텍스트 |
| ② 활동 추출·정리 | AI 기반 직무 수행 활동 추출 (행동 중심) | 후보 활동 풀 |
| ③ 차원별 재구성 | 6대 차원에 따라 분류, 직능유형 요소로 재구성 | 차원별 매핑표 |
| ④ 변별력 검토 | 직업 간 구조 비교 → 각 차원 구성요소 유의미성 확인 | 변별력 보고서 |

## 변별력 평가 5대 지표 (HumRRO 2010 한국화)

- 작업 진술 명료성: 전문가 "이해 가능" 응답률 ≥ 80%
- 직업 관련성: 전문가 관련성 응답률 ≥ 60%
- 핵심 작업 적합성: 평균 중요도 ≥ 3.0/5점
- 직업 간 변별력: 차원별 점수의 직업 간 분산 F검정 p < .05
- 다중연결 비율: 1 DWA 적용 직업 수 2.5~5.0

## 전문가 검토 5항목

| 항목 | 검토 내용 |
|---|---|
| ① | 직능유형 차원 구분의 적절성 |
| ② | 차원별 구성요소 타당성·변별력 |
| ③ | KSCO 체계와의 정합성 |
| ④ | 정책 현장 적용 가능성 |
| ⑤ | ISCO-28 개정 시 활용 가능성 |
