## 1순위 자료 (Peterson 1999 도서 대체)

### A. Peterson et al. (2001) Personnel Psychology 논문 — **최우선**
- **제목**: Understanding Work Using the Occupational Information Network (O*NET): Implications for Practice and Research
- **저자**: Peterson, Mumford, Borman, Jeanneret, Fleishman, Levin, Campion, Mayfield, Morgeson, Pearlman, Gowing, Lancaster, Silver, Dye
- **출처**: *Personnel Psychology*, 54(2), 451-492 (2001)
- **성격**: 1999년 APA 도서의 핵심 결과를 학술지에 압축한 공식 후속 논문. **사실상 도서의 요약본**.
- **다운로드 URL (택1)**:
  - https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1744-6570.2001.tb00100.x (Wiley, 기관 구독 필요)
  - https://digitalcommons.usf.edu/psy_facpub/1075/ (USF 무료 PDF) ← **권장**
  - http://www.morgeson.com/downloads/peterson_et_al_2001.pdf (Morgeson 개인 사이트 무료 PDF)
- **저장 파일명 권장**: `Peterson_2001_Understanding_Work_ONET.pdf`

### B. O*NET Content Model — Detailed Description
- **출처**: O*NET Resource Center 공식 문서
- **성격**: 현재 운영 중인 O*NET Content Model 6대 영역(Worker Characteristics / Worker Requirements / Experience Requirements / Occupational Requirements / Workforce Characteristics / Occupation-Specific Information) 상세 정의서. 1999년 도서에서 제시된 프로토타입의 현행 버전.
- **다운로드 URL**: https://www.onetcenter.org/dl_files/ContentModel_DetailedDesc.pdf
- **저장 파일명 권장**: `ONET_ContentModel_DetailedDesc.pdf`

### C. O*NET Data Collection Program 기술 보고서 (최신본)
- **출처**: https://www.onetcenter.org/reports.html
- **성격**: 데이터 수집 방법론, 표본설계, 가중치, 측정척도. 직업정보 프레임워크 운영 단계 설계에 직접 참고.
- **권장 보고서 (3종)**:
  1. *O*NET Data Collection Program: Overview* — `https://www.onetcenter.org/dl_files/omb2024/Overview.pdf`
  2. *Job Analyst Procedures Manual* — onetcenter.org/reports.html 에서 최신본 검색
  3. *Analyst Database Procedures* — onetcenter.org/reports.html 에서 최신본 검색

## 2순위 자료 (이론·맥락 보강)

### D. NRC (2010) *A Database for a Changing Economy: Review of the O*NET*
- **출처**: National Academies Press, 무료 PDF
- **URL**: https://nap.nationalacademies.org/catalog/12814
- **성격**: O*NET 시스템에 대한 미국 NRC의 공식 평가·개선권고 보고서. 1999 도서 이후 10년의 운영 경험을 종합 평가.
