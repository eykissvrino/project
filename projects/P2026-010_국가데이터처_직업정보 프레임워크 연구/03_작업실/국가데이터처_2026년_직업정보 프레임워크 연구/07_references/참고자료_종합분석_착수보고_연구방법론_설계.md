## 1. 해외 참고자료 분석 (착수보고/방법론 관점)

### 1.1 O*NET 1995 프로토타입 보고서 — 콘텐츠 모델의 원형

#### 핵심 메시지
DOT(Dictionary of Occupational Titles)의 4가지 한계 — ① 과업 중심 기술의 일반화 불가, ② 사람 속성 정보 부재, ③ 과다한 갱신 비용, ④ 타 DB와의 연결성 부족 — 을 해결하기 위해 **다목적·공통어·확장 가능한 데이터베이스형 직업정보 시스템**을 설계한 최초 문서.

#### 본 연구에 직접 적용할 4가지 설계 원리
1. **사람 속성(Worker) vs. 직무 속성(Occupation)** 분리
2. **교차직업(cross-occupation) vs. 직업특수(occupation-specific)** 분리 ← KSCO 직업단위와 별개의 cross-cutting 분류 축 도입의 학술적 근거
3. **가변적 요건 vs. 비가변적 특성** 분리
4. **위계적(hierarchical) 조직** — 사용자가 분석 목적에 따라 거시·미시 수준 선택

#### 활용 시사점 (착수보고)
- 본 연구의 **6대 차원(업무·지식·기술·능력·도구·환경)**은 위 4원리 중 ②·③의 한국화 적용임을 착수보고서에 명시
- "DOT → O\*NET 전환"을 한국 맥락에 맞춰 "**KSCO 서술형 → 구조화 DB 전환**" 서사로 재구성 → 발주기관 정책 설득력 강화

### 1.2 O*NET 콘텐츠 모델 — Understanding Work Using O*NET

#### 6대 도메인 (현행 O*NET, 본 연구 6대 차원의 직접 모태)

| O*NET 도메인 | 하위 디스크립터 | 본 연구 6대 차원 매핑 |
|---|---|---|
| Worker Characteristics (근로자 특성) | Abilities 52 / Work Styles 17 / Values·Interests | **능력(Abilities)** 차원 |
| Worker Requirements (근로자 요구) | Skills 25 / Knowledge 33 / Education | **지식(Knowledge)** + **기술(Skills)** 차원 |
| Experience Requirements | Training / Licensure / Experience | (보강 검토 영역) |
| Occupational Requirements | **GWA 41 / Work Context** | **업무(Work Activities)** + **환경(Work Context)** 차원 |
| Occupation-Specific | Tasks 18,796 / Technology Skills / Tools | **도구(Tools & Tech)** 차원 |
| Workforce Characteristics | Wages / Outlook / Labor Market | (별도 행정 데이터 연계) |

#### 3대 설계 원칙
- **Multiple Windows** (다중 관점) — 동일 직업을 여러 측면에서 동시 기술
- **Common Language** (공통 언어) — 직업 간 비교 가능성 확보
- **Hierarchical Taxonomies** (위계적 분류) — 거시·미시 동시 수용

#### O*NET-SOC 분류 위계 (참고)
대분류 23 → 소분류 98 → 광범위직업 459 → 세부직업 867 → O\*NET 1,016

#### 활용 시사점 (방법론 설계)
- 본 연구 6대 차원이 O\*NET 5개 도메인을 **압축·통합**한 형태임을 명확히 정의해야 함 (특히 Worker Characteristics가 능력 차원으로 단일화된 이유 설명 필요)
- Workforce Characteristics(임금·전망)는 **고용보험·국가자격 등 행정 데이터 연계** 영역으로 분리하여 본 프레임워크 외부에 두는 것이 RFP 요구사항(연계 가능 구조)과 정합

### 1.3 O*NET Work Activities Project Technical Report — DWA 방법론

#### 핵심 구조: 4단계 직무활동 계층

| 계층 | 수 | 정의 | 본 연구 활용 |
|---|---|---|---|
| **GWA** (Generalized Work Activities) | 41~42개 | 모든 직업 횡단 일반 활동 (예: "정보 수집") | 한국형 GWA 1차안 도출의 직접 비교 대상 |
| **IWA** (Intermediate Work Activities) | 332개 | GWA를 직무 영역별로 구체화 | 한국 산업 맥락에 맞춘 IWA 후보군 설계 참고 |
| **DWA** (Detailed Work Activities) | 2,069개 | 다수 직업이 공유하는 상세 활동 | **AI 군집화 산출물의 검증 기준** — 다중연결(multi-link) 가능 |
| Tasks | 18,796~19,450개 | 직업특수 과업 진술 | KSCO 세분류 426개 직업 설명 텍스트가 이에 해당 |

#### 핵심 방법론 (본 연구 NLP 파이프라인의 검증 기준)
- O\*NET 18.0의 19,450개 Tasks를 **정성 분석 + 군집화**로 DWA 도출
- DWA 채택 기준: **최소 4개 작업 또는 3개 직업에서 언급**
- 다중연결(multi-link) 식별 → **직업 간 전환 가능성** 분석에 활용 (RFP 정책활용 항목과 정합)

#### 활용 시사점 (방법론 설계)
- 본 연구 NLP 4단계 파이프라인(수집·정제 → 구문분석 → 동사 추출 → 군집화)의 ④단계 출력이 한국형 DWA에 해당함을 명시
- DWA 채택 임계치를 한국형 데이터 규모에 맞춰 조정 (예: 한국직업사전 6,000여 직무기술서 + KSCO 426 세분류 → 임계치 "최소 3개 작업 또는 2개 직업"으로 완화 검토)
- **다중연결 분석**은 시뮬레이션 4단계 변별력 검토 단계에 포함

### 1.4 ISCO-08 Companion Guide (ILO) — 국가분류 개발의 표준 절차

#### ISCO-08 4단계 위계
주요군 10 → 세부주요군 43 → 소군 130 → 단위군 436

#### 분류 기초 (KSCO도 동일 채택)
- **기술수준(Skill Level, 1~4)** — 직무 복잡도
- **기술전문성(Skill Specialization, 4차원)** — 지식분야 / 도구·기계 / 대상 / 산출물

#### 국가분류 개발 7개 모듈 (착수보고 시 본 연구 단계 정렬)

| 모듈 | 내용 | 본 연구 매핑 |
|---|---|---|
| 1. 개요(Overview) | 분류 목적·범위 정의 | 착수보고서 1장 |
| 2. 경계 설정(Scope) | 직업의 정의·포함기준 | KSCO 세분류 426개 채택의 근거 |
| 3. 거버넌스(Governance) | 의사결정 체계 | 발주기관·전문가 검토위원회 구성 |
| 4. 구조 개발(Structure) | 분류 체계 설계 | **한국형 6대 차원 프레임워크 설계 (영역 3)** |
| 5. 코딩(Coding) | 분류 코드 부여 | 시뮬레이션 단계 차원별 코드 부여 |
| 6. 매핑(Mapping) | 타 분류와의 연계 | KECO·NCS·KQF 매핑 검토 |
| 7. 배포(Implementation) | 적용·관리 | 정책 활용방안 제시 |

#### 핵심 원칙
- **상호배타성(Mutual Exclusivity)** — 한 직무활동이 둘 이상의 차원에 동시 분류되지 않을 것
- **완전성(Exhaustiveness)** — 모든 직업이 분류 가능
- **일관성(Consistency)** — 동일 기준 적용

#### 활용 시사점 (착수보고)
- ISCO-28 개정 동향(직능수준을 Education/Responsibility/Experience/Work-based learning으로 확대)을 인용하여 **본 연구가 ISCO-28 대응 선행 작업임**을 강조 → RFP 1장 사업목적과 일치
- 7개 모듈을 추진일정과 매핑한 표를 착수보고서에 포함 → ILO 표준 준수 입증

### 1.5 HumRRO — A Preliminary Analysis of Occupational Task Statements

#### 핵심 발견 (작업기술 품질관리)
- 작성된 task statements 중 **65.4%만 실제 작업으로 판정**, 56%가 고유한 작업
- 평가 기준: **최소 15명 평가, 50% 이상 관련성, 평균 중요도 3.0 이상**
- **작업 수가 적을수록 관련성·중요도·빈도 평가가 높음** (상관 -0.64) — 즉 직업당 task 수를 너무 늘리면 품질 저하

#### 활용 시사점 (방법론 설계)
- 본 연구 AI 추출 산출물의 **품질 검증 임계치** 설계 시 HumRRO 기준 차용
  - 한국형 임계치 안: "전문가 패널 5인 이상, 60% 이상 관련성 동의, 중요도 평균 3.0 이상"
- **직업당 적정 활동 수 가이드라인** 도출 — 1직업당 DWA 후보를 무한정 추출하지 않고 상위 N개로 제한
- 시뮬레이션 4단계 변별력 검토에 task 품질 지표 포함

## 2. 국내 참고자료 분석 (착수보고/방법론 관점)

### 2.1 한국표준직업분류 8차 개정 (KSCO 2024)

#### 개정 개요
- 통계청 고시 제2024-328호 (2024.7)
- ISCO-08 기반, **직능수준(Skill Level) + 직능유형(Skill Specialization)**을 분류 기준으로 채택
- 본 연구의 **법적 분석 대상** — 본 연구 산출물은 이 분류체계 위에 직능유형 정보를 부착하는 형태

#### 본 연구 활용 포인트
- KSCO 세분류 426개 + 세세분류 1,206개가 직무기술 정의서 대상 모집단
- 8차 개정 총설(원칙·기준)을 본 연구의 **상위 규범**으로 인용
- ISCO-28 개정에 대비한 한국형 직능유형 프레임워크 구축이 사업 목적

### 2.2 한국고용직업분류 2025 개정 (KECO 2025)

#### 개정 개요
- KSCO 8차 개정의 후속 (2025.1, 한국고용정보원)
- 대분류 10·중분류 35 유지 / 소분류 140·세분류 495 (4개 증가)
- 주요 신설: **반려동물 서비스, AI/빅데이터 직업, 플랫폼 노동 관련**
- KSCO 8차 ↔ KECO 2025 연계표(xlsx) 제공 — 매핑 작업 시 직접 활용

#### KSCO vs KECO 핵심 차이 (방법론적 함의)
- **KSCO**: 직능수준(Skill Level) **우선** → 통계 표준
- **KECO**: 직무유형(Job Type) **우선** → 고용서비스 실무
- 본 연구 6대 차원은 KSCO의 직능수준 위계를 **유지하면서** KECO의 직무유형 관점을 **흡수**하는 구조 (= 양 체계 통합 활용 가능)

#### 활용 시사점 (착수보고)
- KECO 2025 신설 분야(AI·플랫폼 노동)는 본 연구의 **AI 텍스트 분석 적용 우선순위**로 검토 — 신생 직업의 직무요소 도출은 서술형 수작업으로 한계
- KSCO ↔ KECO 연계표를 시뮬레이션 단계 직업군 선정에 활용 (서로 다른 직능유형이 어떻게 연계되는지 검증)

## 3. 제안서·RFP 자료 분석 (약속이행 항목 추출)

### 3.1 RFP 핵심 요구사항 정리

#### 사업 목적·범위 (RFP 1장)
- **목적**: ISCO-28 개정안 대응 → 직능유형 프레임워크 구축 + 직업정보 DB 구축 기반 마련
- **범위(4개 영역)**:
  ① 한국표준직업분류 각 직업 직무기술 정의서 작성
  ② 국내·외 사례 분석 — 직능유형 구성요소 검토
  ③ 한국표준직업분류 기반 차원별 구성요소 도입 구조적 틀 마련
  ④ 중분류 일부 시뮬레이션 검증 + 전문가 검토·조정

#### 제출 산출물 (RFP 4쪽 표)

| 구분 | 시기 | 형식 |
|---|---|---|
| 과제수행계획서 | 계약 후 1주 이내 | e-mail |
| 착수 보고서 | 계약 후 1개월 이내 | e-mail |
| 중간 보고서 | 계약 후 4개월 이내 | e-mail + 책자 20부 |
| 최종 보고서 | 계약만료 1개월 전 | e-mail + 책자 20부 |

- 직무 수행 방식이 비교적 명확하게 구분
- 예시: **전문서비스 영역 + 생산 영역 + 기술 영역** 중 2~3개

### 4.2 한국형 6대 차원의 학술적 정당화 (착수보고 핵심 메시지)

> 본 연구의 6대 차원은 **임의 설계가 아닌 O*NET 콘텐츠 모델의 한국 맥락 압축·통합**임을 다음과 같이 입증:

1. **압축 근거**: O\*NET 6대 도메인 중 *Workforce Characteristics*(임금·전망)는 RFP가 요구하는 "행정 데이터 연계 가능 구조"에 따라 **외부 연계 영역**으로 분리
2. **통합 근거**: O\*NET *Worker Characteristics* + *Worker Requirements*는 한국 데이터 가용성을 고려해 **능력·지식·기술** 3차원으로 단순화 (가치·흥미·업무스타일은 워크피디아·KNOW에서 보강)
3. **확장 근거**: O\*NET *Occupation-Specific*의 Tools·Technology를 **도구(Tools & Tech)** 단일 차원으로 정규화 → 신기술 직업(AI·플랫폼)에 즉시 대응
4. **유지 근거**: *Occupational Requirements*의 Work Activities, Work Context는 본 연구 **업무·환경** 차원으로 1대1 대응 → 국제 비교 가능성 확보

## 부록 B. 약어 정리

- **KSCO**: Korean Standard Classification of Occupations (한국표준직업분류, 통계청)
- **KECO**: Korean Employment Classification of Occupations (한국고용직업분류, 한국고용정보원)
- **ISCO**: International Standard Classification of Occupations (ILO 국제표준직업분류)
- **O*NET**: Occupational Information Network (미국 노동부 직업정보 네트워크)
- **ESCO**: European Skills, Competences, Qualifications and Occupations
- **NOC**: National Occupational Classification (캐나다)
- **NCS**: National Competency Standards (한국 국가직무능력표준)
- **KQF/SQF**: Korean / Sectoral Qualifications Framework (국가/산업 역량체계)
- **KNOW**: Korea Network for Occupations and Workers (한국직업정보시스템)
- **GWA / IWA / DWA**: Generalized / Intermediate / Detailed Work Activities (O\*NET 직무활동 3계층)
- **NLP**: Natural Language Processing (자연어처리)
- **HumRRO**: Human Resources Research Organization (미국 인적자원연구기관)
- **RFP**: Request For Proposal (제안요청서)
