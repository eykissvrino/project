# [심층분석 04] HumRRO — A Preliminary Analysis of Occupational Task Statements (작업기술 품질관리)

## 1. 자료 메타정보

| 항목 | 내용 |
|---|---|
| 원제 | A Preliminary Analysis of Occupational Task Statements |
| 발간 | Human Resources Research Organization (HumRRO), 2010, 미국 노동부 위탁 |
| 분량 | 약 60페이지 (한글본 3,804행) |
| 위상 | O\*NET 데이터베이스의 **Task statements 품질관리 방법론** 제시 — 8개 사전 테스트 직업의 87개 Task + 1,088개 응답자 자유기술(write-in) 분석 결과 |
| 본 연구에서의 위치 | **NLP 자동 추출 산출물의 품질 임계치 설계 + 전문가 검증 패널 운영 가이드라인의 직접적 모태** |

## 2. 핵심 메시지 5줄 요약

1. 응답자 자유기술 1,088건 중 **712건(65.4%)만이 실제 작업으로 판정** — 나머지는 이해 불가, 너무 광범위, 또는 기존 작업과 동일.
2. 작업 유지를 위한 **3대 기준**: ① 최소 15명 평가, ② 50% 이상이 직업과 관련 있다고 응답, ③ 평균 중요도 3.0 이상.
3. 작업 수와 평가 점수는 **음의 상관(-0.64)** — 직업당 작업 수가 적을수록 관련성·중요도·빈도 평가가 높음 → **직업당 적정 작업 수 가이드라인** 제공.
4. 빈도(frequency)는 핵심 작업 판정 기준으로 부적합 — 드물지만 매우 중요한 작업이 존재.
5. 중요도와 빈도의 상관(.38~.76, 평균 .53)은 직업·작업별로 큰 변동 → **두 척도를 별도 측정**해야 함.

## 3. 핵심 개념·구조 정밀 정리

### 3.1 연구 설계

#### 데이터 구성
- **사전 테스트 직업 8개**의 현행 작업 목록 87개 진술
- 같은 직업 + 추가 9번째 직업의 응답자 **자유기술(write-in) 1,088건**
- 응답자는 작업 진술이 현재 직업의 작업 목록에 누락되어 있다고 판단할 때 자유기술 가능

#### 평가자 패널
- 직업당 평균 67.14명의 재직자
- 작업당 평가 항목: **관련성 / 중요도 / 빈도** 3차원

### 3.2 자유기술(Write-in) 진술 판정 결과

| 판정 | 건수 | 비율 |
|---|---|---|
| 실제 작업으로 판정 | **712** | **65.4%** |
| 이해 불가능 / 너무 광범위 / 작업이 아닌 활동 | 376 | 34.6% |
| **합계** | 1,088 | 100% |

#### 작업 판정된 712건의 세부 분류

| 유형 | 비율 |
|---|---|
| 기존 목록과 완전 고유(unique) | **56%** |
| 부분 중복(partially redundant) | 25% |
| 완전 중복(completely redundant) | 19% |

#### 추가 자료
- 1,088건 중 **17건의 신규 작업**이 향후 데이터 수집 대상으로 선별됨

### 3.3 작업 유지 3대 기준 (Recommended Criteria for Retaining Tasks)

#### 기준 ① — 최소 평가자 수
- **최소 15명의 재직자**가 해당 작업의 관련성·중요도·빈도 중 하나 이상을 평가해야 함
- 근거: 7점 척도에서 평균 중요도를 95% 신뢰구간 ±1~1.5점 범위로 추정하려면 약 15명 필요 (이전 KSAOs 연구)

#### 기준 ② — 관련성 (50% 이상)
- 평가 응답자의 **50% 이상이 해당 작업이 직업과 관련 있다고 응답**해야 함
- 계산식:
  ```
  관련성 점수 = (중요도/빈도 평가 응답자 수)
                ÷ (중요도/빈도 평가 응답자 수 + 비관련 응답자 수)
  ```
- 비관련(not relevant) 응답을 별도 항목으로 분리 — 무응답자는 계산 제외

#### 기준 ③ — 평균 중요도 (3.0 이상)
- 5점 척도에서 평균 **3.0 이상**이어야 직업 핵심 작업으로 판정
- 5점 척도 앵커: 1=관련 없음, 2=다소 중요, 3=중요, 4=매우 중요, 5=극도로 중요
- ※ 평균 중요도 계산 시 **관련성 점수는 포함하지 않음** — 오직 중요도 점수만 사용

#### 기준 부적합 — 빈도(Frequency)
- 빈도는 핵심 작업 판정 기준으로 권장되지 않음
- 이유: **드물게 수행되지만 매우 중요한 작업** 존재 (예: 의사의 응급 수술, 비행사의 비상 착륙)

### 3.4 핵심 발견 (Key Findings)

#### 발견 1: 직업당 작업 수와 평가 점수의 음의 상관

| 평가 차원 | 직업당 작업 수와의 상관 |
|---|---|
| 관련성 | 음의 상관 |
| **중요도** | **-0.64** (강한 음의 상관) |
| 빈도 | 음의 상관 |

**해석**: 직업당 작업 수가 많을수록 평균 평가 점수가 낮아짐 → 작업 목록을 무한정 늘리면 직업 핵심을 흐리는 결과 초래

#### 발견 2: 평가 점수 분포 (8개 사전 테스트 직업, 87개 작업)

| 척도값 | 빈도 N | 빈도 % | 중요도 N | 중요도 % |
|---|---|---|---|---|
| 1 | 185 | 4.1% | 56 | 1.3% |
| 2 | 452 | 10.1% | 245 | 5.5% |
| 3 | 645 | 14.4% | 790 | 17.8% |
| 4 | 626 | 13.9% | 1,156 | 26.0% |
| 5 | 1,003 | 22.3% | 2,192 | 49.4% |
| 6 | 733 | 16.3% | — | — |
| 7 | 851 | 18.9% | — | — |

**해석**:
- 평균 중요도 4.08 / 평균 빈도 4.38 / 관련성 평균 84.03%
- 작업 목록의 **대다수가 기준 ②③을 충족** → 사전 테스트 직업의 현행 작업 목록은 양호

#### 발견 3: 중요도-빈도 상관의 직업·작업별 변동
- 직업별 상관: **.38 ~ .76** (평균 .53)
- 개별 작업별 상관: **.12 ~ .82**
- 결론: 두 척도는 **별도로 측정 필요** — 단일 척도로 환원 불가

## 4. 본 연구에의 적용 매핑

### 4.1 한국형 품질관리 임계치 (HumRRO 기준 차용)

| 기준 | HumRRO (미국) | 본 연구 한국형 (제안) | 근거 |
|---|---|---|---|
| **최소 평가자 수** | **15명 (재직자)** | **5명 (전문가)** | 본 연구는 재직자 패널 미운영 → 전문가 검증 패널 5인 활용 |
| **관련성 임계** | **50% 이상** | **60% 이상** | 전문가 평가의 신뢰도가 재직자보다 높음 → 임계치 상향 |
| **중요도 임계** | **평균 3.0 이상 (5점)** | **평균 3.0 이상 (5점)** | 동일 |
| **척도 통일** | Importance 5점 / Frequency 7점 | Importance 5점 / Frequency 5점 | 한국 척도 관행 |
| **빈도 활용** | 보조 정보 (판정 기준 X) | 보조 정보 (판정 기준 X) | 동일 |

### 4.2 NLP 자동 추출 → 전문가 검증 워크플로우

```
[1] NLP 자동 추출 (KSCO 426 + 한국직업사전 + NCS)
    ↓ (직업당 평균 25개 후보 직무활동)
[2] 자동 중복 제거 (의미 유사도 임베딩)
    ↓ (직업당 평균 15개로 압축)
[3] 전문가 5인 패널 평가
    - 관련성 (관련/비관련)
    - 중요도 (1~5점)
    ↓
[4] 임계치 적용
    - 관련성 60% 미만 → 제외
    - 중요도 평균 3.0 미만 → 제외
    ↓
[5] 직업당 핵심 직무활동 8~12개 확정 (목표치)
    ↓
[6] DWA 군집화 → 한국형 직무활동 계층 구축
```

### 4.3 직업당 적정 작업 수 가이드라인

HumRRO 발견 1(작업 수와 평가 점수의 음의 상관)을 본 연구에 적용:

| 분류 수준 | 권장 작업/활동 수 |
|---|---|
| KSCO 세분류 직업 (직업당) | **8~12개 핵심 직무활동** (HumRRO 사전 테스트 평균 10.88 참조) |
| 한국형 DWA (전체) | 1,500~2,000개 (O\*NET 2,069개 ±25%) |
| 한국형 IWA (전체) | 250~330개 (O\*NET 332개 참조) |
| 한국형 GWA (전체) | 35~45개 (O\*NET 41개 참조) |

### 4.4 시뮬레이션 ④단계 변별력 검토 지표

본 연구 시뮬레이션 ④단계에 HumRRO 기준 적용:

| 지표 | 측정 방식 | 합격 기준 |
|---|---|---|
| 작업 진술 명료성 | 전문가 5인의 "이해 가능" 응답률 | ≥ 80% |
| 직업 관련성 | 전문가 5인의 관련성 응답률 | ≥ 60% |
| 핵심 작업 적합성 | 평균 중요도 (5점) | ≥ 3.0 |
| 직업 간 변별력 | 차원별 점수의 직업 간 분산(F검정) | p < .05 |
| 다중연결 비율 | 1 DWA가 적용되는 평균 직업 수 | 2.5~5.0 (적정 범위) |

## 5. 착수보고서 인용 가능 표현

> 본 연구의 NLP 자동 추출 산출물 품질관리는 **HumRRO(2010)가 O\*NET Task statements에 적용한 3대 기준**을 한국 맥락에 맞게 조정하여 적용한다. 구체적으로 ① 전문가 5인 이상 평가, ② 관련성 60% 이상, ③ 평균 중요도 3.0 이상을 충족하는 직무활동만을 한국형 DWA 후보로 채택한다.

> HumRRO의 핵심 발견인 "**직업당 작업 수와 평가 점수의 음의 상관(-0.64)**" 에 따라, 본 연구는 KSCO 세분류 직업당 핵심 직무활동을 **8~12개로 제한**하여 직업 핵심을 명료히 한다.

> 빈도(Frequency)는 보조 정보로 수집하되 핵심 작업 판정 기준으로는 사용하지 않는다 — 드물게 수행되지만 매우 중요한 직무활동이 존재하기 때문이다(HumRRO, 2010).

## 6. 한계·주의점

| 항목 | 내용 | 본 연구 대응 |
|---|---|---|
| **재직자 응답 기준** | HumRRO 15명 기준은 재직자 응답 기반 → 본 연구는 전문가 평가 | 평가자 수를 5인으로 축소하되 임계치 상향 (관련성 60%) |
| **사전 테스트 8개 직업** | 일반화에 한계 — 8개 직업의 현행 작업 목록은 이미 양호한 수준 | 본 연구는 KSCO 426개 전체 적용 → 한국형 데이터로 임계치 재검증 필요 |
| **빈도 5점 vs 7점 척도** | HumRRO는 빈도 7점 척도 사용 → 본 연구 5점 통일 시 비교 가능성 저하 | 본 연구 산출물은 5점 척도로 표준화하되, 7점 환산 부록 제공 |
| **불일치 작업 처리** | HumRRO는 기준 미달 작업 즉시 제거 → 본 연구는 보존·검토 풀로 분리 | "기준 미달 → 보류 → 차기 개정 검토" 3단계 처리 |

## 7. 추가 인용·심화 검토 권고

- **사전 테스트 8개 직업**의 현행 작업 목록 → 본 연구 시뮬레이션 대상 중분류 선정 시 비교 사례
- **17건의 신규 작업**이 차기 데이터 수집 대상으로 선별된 절차 → 본 연구 차기 개정 검토 풀 운영 모델
- **빈도 7점 척도 분포** (1=4.1%, 7=18.9%) → 본 연구 5점 환산 시 가중치 설계
- **중요도-빈도 상관 변동 (.12~.82)** — 본 연구 시뮬레이션 단계에서 차원 간 상관 분석 시 참조
- 후속 연구: HumRRO 본 보고서는 "Preliminary" — 후속 작업 (Tsacoumis 외 2014, 2017) 추가 인용 권고
