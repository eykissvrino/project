# Part 5. 도출 기준 설정 — 정량 임계와 품질 기준

## 학습 목표

1. **TASK 채택 임계**(Relevance·Importance·표본수)의 미국 기준과 한국 보정 권고를 회상할 수 있다.
2. **DWA·IWA 클러스터 5대 품질 기준**과 검증 방법을 적용할 수 있다.
3. **분석가 간 합의도**(Cohen's Kappa) 임계와 모니터링 절차를 설계할 수 있다.
4. **자동분류 정확도 임계**(인간-AI Kappa, F1, 정확도)와 합격 조건을 정의할 수 있다.

---

## 5.1 본 Part가 다루는 4개 임계 영역

```
1. TASK 채택 임계      (개별 task 채택/폐기 결정)
2. DWA·IWA 품질 임계  (군집 결과의 채택/재작업 결정)

```

각 영역은 독립적이지만, 최종적으로는 한 직업의 직무기술 정의서가 출시 가능한지를 종합 판단하는 데 사용됩니다.

## 5.2 TASK 채택 임계 — HumRRO 기준의 한국 보정

### 5.2.1 미국 원본 기준 (HumRRO 2003)

| 임계 | 값 | 적용 |
|------|---|-----|
| 최소 응답자 수 (per task) | 15명 | 통계적 안정성 (SEM ≤ 0.50) |
| Core Tasks Relevance | > 67% | 핵심 task 인정 |
| Core Tasks Importance | > 3.0 (5점 척도) | 핵심 task 인정 |
| Non-relevant Threshold | < 10% | 폐기 |
| Supplementary Type A | Relevance > 67%, Importance < 3.0 | 보존 |
| Supplementary Type B | Relevance 10~66% | 보존 |

### 5.2.2 한국 보정 권고

| 임계 | 미국 (HumRRO) | 한국 보정 권고 | 근거 |
|------|------------|------------|------|
| 최소 응답자/task | 15명 | **자체 SEM 시뮬레이션 후 결정** | 한국 직업 응답자 다양성이 미국과 다를 수 있음 |
| Core Relevance | > 67% | **분포 검토 후 결정** (잠정 60~67%) | 한국 직업의 incumbent 다양성이 미국보다 작을 가능성 |
| Core Importance | > 3.0 (5점) | 그대로 가능 | 5점 척도 표준 |
| Non-relevant | < 10% | 그대로 가능 | 보수적 폐기 기준 유지 |

### 5.2.3 SEM 시뮬레이션 절차

본 연구가 사업 1개월차에 수행해야 할 자체 검증입니다.

```
1. 한국 KECO·KNOW에서 응답자 수가 풍부한 직업 5개 선택
   (예: 간호사·회계사·소프트웨어개발자·교사·미용사)
2. 각 직업의 모든 응답을 모집단으로 가정
3. 표본 크기 N = 5, 10, 15, 20, 30 시뮬레이션
   - 각 N에서 무작위 표본 추출 1,000회
   - 평균 중요도의 표준오차(SEM) 계산
4. 한국 데이터의 SEM ≤ 0.50을 만족하는 최소 N 도출
5. 결정: N ≥ 추정값 (예: 12명, 15명, 또는 20명)
```

> **발표 방어 카드**: "한국 데이터로 자체 검증한 결과, 최소 응답자 수는 ○○명이 적정하며, 이는 미국 15명과 비교하여 ±△명의 차이를 보입니다."

### 5.2.4 표본수가 부족할 때

본 연구는 새로운 설문조사 없이 기존 데이터(KECO·NCS·KNOW·직업사전)를 활용하므로, 일부 직업은 임계 응답자 수를 충족하지 못할 수 있습니다. 이때의 대응:

| 상황 | 대응 |
|------|------|
| 응답자 N < 임계 | "잠정 분류" 라벨 부여, 추가 데이터 수집 시 재검토 |
| 응답자 N = 0 | KSCO 분류항목표 텍스트와 KNOW 직업 설명 기반 LLM 추출 (전문가 검증 필수) |
| 신생 직업 | 직업 전문가(SME) 인터뷰로 보완, "신생직업 잠정 분류" 라벨 |

## 5.3 DWA·IWA 5대 클러스터 품질 기준

Part 2에서 소개한 5대 기준의 정량 측정 방법을 정리합니다.

### 5.3.1 Cluster Homogeneity (동질성)

#### 정의
군집 내 task들이 동일 활동 테마를 강하게 공유하는 정도.

#### 측정 방법
```
1. 군집 내 모든 task 쌍의 cosine similarity 평균 계산
   → Intra-cluster similarity
2. 임계: ≥ 0.70 (강한 동질성), 0.60~0.70 (적정), < 0.60 (재검토)
```

#### LLM 기반 보조 측정
LLM에게 군집 내 task 목록을 보여주고 "이 task들이 공통 활동을 공유하는가?"를 1~5점으로 평가하도록 요청.

### 5.3.2 Task-Cluster Fit (적합성)

#### 정의
개별 task가 클러스터 테마에 잘 맞는 정도. outlier 식별이 목적.

#### 측정 방법
```
1. 각 task와 군집 중심(centroid)의 cosine similarity 계산
2. 평균 ± 2 표준편차를 벗어나는 task = outlier
3. Outlier rate ≤ 5%가 권장
```

### 5.3.3 Cluster Uniqueness (유일성)

#### 정의
같은 job family 내 다른 클러스터와 개념적으로 구별되는 정도.

#### 측정 방법
```
1. 군집 i의 중심 vec_i, 군집 j의 중심 vec_j 계산 (모든 i, j 쌍)
2. cosine(vec_i, vec_j) ≤ 0.50 권장 (충분히 구별)
3. cosine > 0.70인 군집 쌍 = 통합 검토 대상
```

### 5.3.4 Cluster Specificity (구체성)

#### 정의
task보다 일반적, GWA보다 구체적인 적정 추상도.

#### 측정 방법
정량 측정이 어려운 정성 기준. LLM 평가로 보조.

```
LLM Prompt:
이 DWA 진술의 추상도가 적절한가?
[ ] 너무 구체적 (task와 같은 수준) — 직업특수 표현 포함
[ ] 적절 (DWA 수준) — 같은 직무군 내 여러 직업에 적용 가능
[ ] 너무 일반적 (GWA와 같은 수준) — 전 직업에 적용
```

### 5.3.5 Cluster Size (규모)

#### 정의
DWA가 최소 4개 task / 3개 직업에서 나타나야 함.

#### 측정 방법
```
1. DWA에 연결된 task 수 ≥ 4
2. DWA에 연결된 직업 수 ≥ 3
3. 한국 보정 권고: task ≥ 3, 직업 ≥ 2 (한국 데이터 규모 고려)
```

### 5.3.6 5대 기준 종합 점수표

| 기준 | 측정 | 합격선 | 자동·인간 분담 |
|------|------|-------|-------------|
| Homogeneity | 임베딩 유사도 평균 | ≥ 0.70 | 자동 |
| Fit | outlier rate | ≤ 5% | 자동 |
| Uniqueness | 군집간 유사도 | ≤ 0.50 | 자동 |
| Specificity | LLM/인간 평가 | "적절" | LLM 1차, 인간 2차 |
| Size | task/직업 수 | task≥4, occ≥3 | 자동 |

## 5.4 DWA·IWA 작성 규칙 자동 검증

### 5.4.1 DWA 8대 작성 규칙

Part 2에서 다룬 8대 규칙의 자동 검증 방법:

| # | 규칙 | 자동 검증 |
|---|------|---------|
| 1 | 동사로 시작 | 형태소 분석 후 첫 어절이 동사인지 확인 |
| 2 | 3인칭·현재·복수 | 한국어는 동사 형식 유연하므로 "한다"로 끝나는지 확인 (또는 명사형으로 종결) |
| 3 | 명사 최소화 | 형태소 분석 후 명사 수 / 전체 어절 수 비율 ≤ 0.5 |
| 4 | 직무군 적합 명사 | 군집 내 task의 명사 분포에서 vocab 일치 검증 |
| 5 | 형용사 적정 | 형용사 수 ≤ 2 |
| 6 | 예시절 회피 | "예", "이를테면", "such as", "including" 단어 검색 |
| 7 | 목적절 최소 | "위해", "위하여", "to ..." 빈도 ≤ 1 |
| 8 | 가독성 | KOR-DALE 또는 KU-readability 8학년 수준 |

### 5.4.2 한국어 가독성 측정

영문 SMOG index에 대응하는 한국어 지표:

| 지표 | 특성 |
|------|-----|
| **KOR-DALE** | Dale-Chall Korean adaptation. 어려운 단어 비율 + 문장 길이 |
| **KU-readability** | 한국교원대 개발. 어휘·구문·담화 종합 |
| **음절 수/단어 수 비율** | 단순 지표 (영문 SMOG 유사) |

본 연구는 **KOR-DALE 8학년 수준**을 권장 기준으로 설정하되, 표준 직업분류라는 행정 특성을 감안하여 약간 더 형식적 어휘 허용.

### 5.4.3 모호 동사 회피 사전

본 연구가 회피해야 할 한국어 모호 동사 리스트:

| 모호 동사 | 권고 대체 |
|---------|---------|
| 사용한다 | 조작한다 / 활용한다 (맥락에 따라) |
| 수행한다 | 처리한다 / 진행한다 / 실시한다 |
| 한다 | (구체 동사로 대체) |
| 처리한다 (일반) | 분석한다 / 검토한다 / 조치한다 |
| 관리한다 | 점검한다 / 통제한다 / 운영한다 |
| 다룬다 | (구체 동사로 대체) |

권장 동사 코퍼스 (행동 동사 우선):
- **수집·확인 계열**: 조사한다, 측정한다, 인터뷰한다, 청취한다, 기록한다
- **분석·판단 계열**: 분석한다, 검토한다, 평가한다, 진단한다, 비교한다
- **결정·계획 계열**: 결정한다, 계획한다, 설계한다, 수립한다, 책정한다
- **실행·생산 계열**: 조립한다, 설치한다, 가공한다, 제작한다, 운영한다
- **소통·서비스 계열**: 안내한다, 상담한다, 협상한다, 교육한다, 처방한다

## 5.5 분석가 간 합의 임계 — Cohen's Kappa

### 5.5.1 Kappa 임계의 의미

Landis & Koch(1977)의 표준 해석:

| Kappa | 해석 | 본 연구 기준 |
|-------|------|----------|
| < 0.00 | 일치도 없음 | 절차 재설계 |
| 0.00–0.20 | 약한 일치 | 절차 재설계 |
| 0.21–0.40 | 보통 일치 | 절차 재설계 |
| 0.41–0.60 | 적정 일치 | 훈련 강화 |
| 0.61–0.80 | 상당한 일치 | **최소 합격선** |
| **0.81–1.00** | **거의 완전한 일치** | **목표 (HumRRO 0.88 벤치마크)** |

### 5.5.2 Kappa 모니터링 절차

본 연구의 권고 절차:

```
1. 분석가 훈련 (1주차)
   - 2-3개 직업을 paired 분석
   - 첫 평정 후 Kappa 측정
   - Kappa < 0.7이면 토론 → 재교육

2. 본 분석 (2~6주차)
   - 매 20개 직업마다 2명이 동일 직업을 평정
   - Kappa 계산 및 기록
   - Kappa가 0.7 미만으로 떨어지면 즉시 미팅 소집

3. 불일치 사례 활용
   - 불일치 task를 별도 코퍼스로 보존
   - LLM 자동분류 fine-tuning 자료로 활용
   - 분석가 회의에서 합의 사례 만들기

4. 최종 보고
   - 전체 Kappa 평균, 직업군별 Kappa 분포
   - 목표: 평균 ≥ 0.80, 모든 직업군 ≥ 0.70
```

### 5.5.3 한국 적용 가능성

HumRRO는 박사급 2명 페어로 Kappa 0.88을 달성했습니다. 한국에서는:

- **인적 자원**: 본 연구진 6명 중 책임·공동연구자 4명이 페어 가능
- **목표**: 평균 Kappa ≥ 0.80 (HumRRO 벤치마크 -8%)
- **현실 위험**: 분석가 시간 제약으로 paired 평정 표본이 적을 수 있음 → 매 20개 직업당 1회 표본 평정으로 효율 확보

## 5.6 AI 자동분류 정확도 임계

### 5.6.1 인간-AI Kappa

본 연구의 AI 자동분류가 인간 분석가와 어느 정도 일치해야 채택할 수 있는가?

| Human-AI Kappa | 채택 결정 | 인간 검수율 |
|--------------|---------|----------|
| ≥ 0.85 | 자동 채택, 인간 검수 5% | 매우 신뢰 |
| 0.70~0.85 | 자동 채택, 인간 검수 20% | 표준 신뢰 |
| 0.55~0.70 | 자동 + 인간 50% | 부분 신뢰 |
| < 0.55 | 자동 불채택, 인간 100% | 불신 |

### 5.6.2 F1, Precision, Recall

분류 과제는 다음 3개 지표로 측정.

| 지표 | 정의 | 본 연구 임계 |
|------|------|----------|
| Precision | TP / (TP + FP) | ≥ 0.85 |
| Recall | TP / (TP + FN) | ≥ 0.80 |
| F1 | 2 × P × R / (P + R) | ≥ 0.82 |

### 5.6.3 군집화 정확도

군집화 결과 평가:

| 지표 | 의미 | 본 연구 임계 |
|------|------|----------|
| Silhouette Score | 군집 내 응집도 + 군집 간 분리도 | ≥ 0.30 |
| Davies-Bouldin Index | 군집 분리도 (낮을수록 좋음) | ≤ 1.0 |
| 인간 검토 동의율 | 군집 결과를 인간이 "타당"으로 판단 | ≥ 80% |

### 5.6.4 hallucination 검출

LLM이 생성한 DWA·TASK가 hallucination이 아닌지 검증:

| 검증 항목 | 방법 |
|---------|------|
| TASK source 검증 | 생성된 task가 원천 텍스트(KSCO·KNOW·NCS)에 실제로 근거가 있는가? — Retrieval-based check |
| DWA writing rule 검증 | 8대 규칙 자동 검증기 통과 |
| 의미적 일관성 검증 | DWA가 군집 내 task와 의미적으로 일치 (cosine similarity ≥ 0.65 with task centroid) |

## 5.8 임계 결정 의사결정 트리

직무기술 정의서 1건이 출시 가능한지 판단하는 종합 의사결정:

```
[직업 1개의 도출 완료]
        ↓
[질문 1] TASK 응답자 N ≥ 임계?
   ├── Yes → 진행
   └── No  → "잠정" 라벨, 추가 데이터 검토
        ↓
[질문 2] Core TASK 수 ≥ 8개?
   ├── Yes → 진행
   └── No  → 추가 TASK 발굴 또는 추가 데이터
        ↓
[질문 3] DWA 군집의 5대 품질 기준 통과?
   ├── 전부 통과 → 진행
   └── 일부 실패 → 군집 재작업
        ↓
[질문 4] DWA Writing 8대 규칙 통과?
   ├── 전부 통과 → 진행
   └── 일부 실패 → 진술 재작성
```
