# Part 7. 추가 필요 자료 및 학습 로드맵

## 학습 목표

1. 본 연구에 현재 확보된 자료의 **갭(gap)**을 식별하고, 추가로 필요한 자료의 우선순위를 매길 수 있다.
2. 자료 종류별 **확보 경로**(공개 데이터셋, 정부 자료, 학술 논문, 외부 전문가 패널 등)를 설계할 수 있다.
3. **학습 로드맵**(연구진의 단계별 학습 계획)을 수립할 수 있다.

| 항목 | 내용 |

#### (4) KNOW 워크넷 직업정보 API

| 항목 | 내용 |

| 형식 | OpenAPI / LOD |
| 활용 | 직업의 능력·지식·직업가치 등 메타 정보 |

#### (5) O*NET 최신 데이터베이스 (30.x)

## 7.3 데이터 통합 ETL 아키텍처

위의 자료를 본 연구 데이터베이스로 통합하는 ETL 흐름:

```
[원천 데이터]
KSCO HWPX        한국직업사전 PDF/XML       NCS HWP/PDF       KNOW API         O*NET TXT/MDB
   │                  │                       │                │                │
   ▼                  ▼                       ▼                ▼                ▼
[Extract]
HWPX 파서          PDF→TXT 변환            HWP→TXT 변환     API 호출         CSV 변환
   │                  │                       │                │                │
   ▼                  ▼                       ▼                ▼                ▼
[Transform]
정형 JSON          정형 JSON              정형 JSON         정형 JSON       정형 JSON
   │                  │                       │                │                │
   └────────┬─────────┴───────────┬───────────┴────────┬───────┘                │
            │                     │                     │                        │
            ▼                     ▼                     ▼                        ▼
       [KSCO 세분류 매핑]    [임베딩 매칭]         [인간 검증]                  [영문 비교용]
            │                     │                     │
            └─────────────────────┴─────────────────────┘
                                  │
                                  ▼
            ┌──────────────────────────────────────────┐
            │      [통합 직업 코퍼스 DB]                  │
            │   - 직업당 단일 통합 텍스트                  │
            │   - 출처 메타데이터 포함                     │
            │   - 임베딩 벡터 사전 계산                    │
            └──────────────────────────────────────────┘
                                  │
                                  ▼
                      [Layer 3~10 분석 파이프라인]
```
