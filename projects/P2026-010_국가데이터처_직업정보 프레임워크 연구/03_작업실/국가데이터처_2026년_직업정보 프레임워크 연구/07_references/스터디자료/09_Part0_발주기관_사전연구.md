## 0.1 핵심 메시지 (먼저 보세요)

본 Part는 4개의 핵심 메시지로 요약됩니다.

1. **발주처는 단순 통계청이 아니다**. 2025년 10월 1일 통계청이 **국가데이터처**(National Data Agency, MODS)로 격상되었고, 본 사업은 격상 후 9개월차에 발주된 **새로운 위상에서의 첫 직업분류 정책연구**다.
2. **본 사업은 격리된 신규 연구가 아니다**. 본 사업 연구책임자(조세형 박사)가 **2025년 12월 국가데이터처에 제출한 ISCO-28 SLF 연구**와 **통계청에 제출한 직업문항 연구**가 직계 사전연구다. 본 사업 RFP의 행간은 이 두 연구의 후속 실행이다.
3. **본 사업의 실제 구조는 3개 차원의 결합이다**: (i) **직무활동** 4계층(O*NET GWA·IWA·DWA·TASK) + (ii) **직능수준** 4차원(K-SLF: 교육·책임성·경험·WBL) + (iii) **직업문항** 개선(직능유형·직능수준·산업의 3-tier 측정). 본 스터디 자료가 (i)에 집중되어 있었으나, (ii)와 (iii) 없이는 본 사업이 완성되지 않는다.
4. **KRIVET 사전연구 2건**(1차 2021, 2차 2023)이 KSCO 8차 개정의 학술 근거이며, 본 사업은 그 8차 분류 코드는 그대로 두고 그 위에 **정보 층**을 부착하는 작업이다.

## 0.2 발주처: 국가데이터처(MODS, Ministry of Data Strategy)

| 영문 약칭 | MODS (Ministry of Data Strategy) |

### 0.2.2 격상의 의미 — 단순 명칭 변경이 아니다

| 차원 | 통계청 (~2025.9) | 국가데이터처 (2025.10~) |
|---|---|---|
| 위상 | 기획재정부 외청 | 국무총리 직속 처 |
| 역할 | 국가통계 작성·관리 | **범정부 데이터 총괄·조정 + 활용 정책** |
| 책임 범위 | 통계 (1,363종) | 통계 + 정부 데이터 정책 + 활용 |
| 핵심 자산 | KOSIS, MDIS | KOSIS, MDIS, SDC, **나라통계 2.0(k-stat.go.kr)** |
| 대외 위치 | 국제 통계 비교(ISCO·SNA 등) | 좌동 + **데이터 거버넌스 컨트롤타워** |

### 0.2.3 본 사업과의 직접 연관

본 사업이 발주된 시점(2026년)은 국가데이터처 출범 후 약 6~9개월차다. 이 시점에서 발주된 직업분류 연구의 정책 의도는 다음 4가지로 읽을 수 있다.

1. **격상에 걸맞은 직업분류 고도화**: 통계청 시절에는 KSCO를 "통계 작성용 분류"로만 운영했으나, 국가데이터처 격상 후에는 **범정부 데이터 활용을 위한 직업정보 프레임워크**로 확장해야 함
2. **ISCO-28 대응 압력**: ILO가 ISCO-28 개정을 진행 중이고, 국제 비교가능성 유지를 위해 한국이 선제 대응 필요
3. **AI 시대의 노동시장 분석 인프라**: 단순 직업명 분류로는 AI 자동화·직업 전환 분석이 불가능 → 직무활동 수준의 정보가 필요
4. **타 부처 직업정보 통합 컨트롤타워 역할**: 고용노동부(KECO·NCS·KNOW), 한국고용정보원, 산업인력공단, 통계청 등에 산재된 직업정보를 표준화하는 책임

> **발표 Q&A 핵심 카드**: "본 사업은 국가데이터처 출범 후 첫 직업분류 정책연구이며, 단순 통계 분류 작업이 아니라 범정부 데이터 거버넌스 차원의 직업정보 프레임워크 구축입니다. 격상된 위상에 부합하는 산출물의 야망과 표준화 수준이 요구됩니다."

## 0.3 직계 사전연구 ① — ISCO-28 SLF 국내도입 적정성 평가

### 0.3.1 메타 정보

| 항목 | 내용 |
|---|---|
| 정식 명칭 | 국제표준직업분류 개정안 국내도입 적정성 평가 연구 |
| 영문 | The Study on the Appropriateness of Adopting the Revised ISCO in KOREA |
| 발주처 | **국가데이터처장** |
| 연구기관 | **(사)한국직업자격학회** (본 사업과 동일) |
| 연구책임자 | **조세형** (본 사업과 동일 인물) |
| 공동연구원 | 정동열, 나태희, 용석현 |
| 제출일 | **2025년 12월 8일** |

> **결정적 관계**: 본 사업 RFP가 2026년에 발주되었고, 제안기관·연구책임자가 동일하며, 사전연구 제출은 그보다 약 5~6개월 전이다. 본 사업은 사실상 이 사전연구의 **실행 단계 후속과제**다.

### 0.3.2 ISCO-08의 한계 (사전연구가 짚은 문제)

ILO가 ISCO-28 개정을 추진하는 이유는 ISCO-08의 다음 한계 때문이다.

1. **직능수준 2의 범위가 과도하게 넓음**: KSCO 대분류 3~8(사무·서비스·판매·농림어업·기능원·장치조작)이 모두 직능수준 2로 묶임 → 변별력 부족
2. **직능수준 2와 3의 경계 불명확**
3. **형식교육수준만으로 직능수준 측정**: 비형식학습, 경험, 업무기반학습, 책임 등이 반영되지 않음
4. **기술변화에 따라 직업군 배치 오류**: AI·디지털 직무의 적정 직능수준 판정이 어려움

### 0.3.3 ISCO-28 SLF (Skill Level Framework) 4차원

ISCO-28은 ISCO-08과 동일한 2차원 구조(직능수준 × 직능유형)를 유지하되, **직능수준을 4차원으로 다차원화**한 SLF를 적용한다.

```
ISCO-28 SLF (Skill Level Framework)
   │
   ├── 차원 1. 교육 (Education)
   │      - ISCED-11 기준
   │      - 중요 변경: ISCED 4수준(중등 후 비학위과정)을 ISCO 직능수준 2 → 3으로 상향
   │
   ├── 차원 2. 책임성 (Responsibility)
   │      - 관리 책임성 (Managerial): 사람·프로세스·운영 관리
   │      - 감독 책임성 (Supervisory): 다른 사람의 활동 감독
   │      - 안전 책임성 (Safety): 자신·타인·환경의 안전 보장
   │
   ├── 차원 3. 경험 (Experience)
   │      - 핵심 과업을 독립 수행하기 위해 필요한 실무 숙련 기간
   │      - 정규직·파트타임·임시직·인턴십·자원봉사 등 포함
   │      - 경험의 기간 + 질 + 관련성 3차 평가
   │
   └── 차원 4. 업무기반학습 (Work-Based Learning, WBL)
          - 실제 업무환경에서의 모든 학습
          - 수습/도제, 직장 내 교육(OJT), 인턴십, 연수 등
          - 형식·비형식·무형식 학습 형태 모두 포함
```

### 0.3.4 SLF 우선순위와 최적합 원칙

ISCO-28은 위 4차원을 다음 **5단계 우선순위**로 적용한다.

```
① 직무 내용 (task content) → ② 공식 자격요건 (qualification) →
③ 교육수준 (education) → ④ 책임 (responsibility) → ⑤ 경험 및 WBL
```

그리고 4차원이 모두 일치하지 않더라도 **최적합 원칙(best fit)**을 적용하여 직무 수행을 가장 잘 설명하는 핵심요소 중심으로 종합 판단한다.

### 0.3.5 K-SLF — 한국형 4단계 적용 절차

조세형 사전연구가 제안한 한국형 적용 절차:

| 단계 | 주요 내용 |
|---|---|
| **1단계** | SLF 4차원의 국내 대응요소 정의 및 연계기준 설정 |
| **2단계** | 포함기준(Inclusion Criteria) 설정 및 한국형 직능수준프레임워크(K-SLF) 마련 |
| **3단계** | 직업세분류별 직업정보 매핑 및 직능수준 1차 평가 |
| **4단계** | 전문가 검증 및 확정 |

### 0.3.6 K-SLF 4차원의 국내 대응 자료

| SLF 차원 | 국내 대응 자료 (사전연구 제안) |
|---|---|
| 교육 | 경제활동인구조사·임금직업포털 직업정보 / 과정평가형 국가기술자격 훈련과정 / 국가기간·전략산업직종 훈련과정 |
| 책임성 | KSCO·한국직업사전에서 책임성 관련 과업 및 역할정보 추출 (500개 세분류 전수 직무분석은 비현실적 → 기존 텍스트 우선 활용 + 의사결정 부족분만 선택적 직무분석) |
| 경험 | 한국직업사전의 **숙련기간** 항목 / 채용공고(Job Posting) 보조 활용 / 전문가 합의 |
| 업무기반학습 | **일학습병행 자격제도**를 대표 모델로 우선 적용 |

## 0.4 직계 사전연구 ② — 직업문항 측정방법 평가 및 개선

### 0.4.1 메타 정보

| 항목 | 내용 |
|---|---|
| 정식 명칭 | 직업문항 측정방법 평가 및 개선 연구 |
| 발주처 | **통계청장** (격상 이전, 시점상 2024~2025) |
| 연구기관 | (사)한국직업자격학회 |
| 연구책임자 | (조세형 추정 — 표지 빈칸이나 제목과 학회 동일) |
| 핵심 산출 | 개선된 직업문항 + 파일럿 테스트(500명) + AI 활용 사례 분석 |

### 0.4.2 직업문항이란

**직업문항**(Occupation Question Items)은 통계조사에서 응답자의 직업을 묻기 위한 설문 문항이다.

기존 한국 직업문항(통계청 주요 조사):
- 하는 일 (자유응답)
- 직위/직책
- 산업

문제점: 직업코딩(KSCO 4자리 코드 부여) 시 응답이 모호하여 정확도가 낮음.

### 0.4.3 개선 방향 — 3개 영역 측정

사전연구가 제안한 개선 직업문항 구조:

| 영역 | 측정 내용 | 문항 예시 |
|---|---|---|
| **직능유형** | 수행업무 + 사용 도구·장비 | "수행하는 업무 3가지 이상을 기술하세요" / "사용하는 주요 장비·도구는?" |
| **직능수준** | 학력 + 자격 + 경력 + 책임 | "최소학력은?" / "보유 자격은?" / "관리·감독 역할 비중은?" |
| **산업** | 산업분야 + 산출물 + 근무환경 | "생산하거나 제공하는 제품/서비스는?" / "근무 장소는?" |

### 0.4.4 파일럿 테스트 결과 (결정적 수치)

- 표본: 500명 (KSCO 소분류 균등할당)
- 조사방식: 온라인 50% + 면접 50%
- 설문 유형: 응답안내 미포함 vs 포함 각 50%

| 지표 | 기존 문항 | 개선 문항 |
|---|---|---|
| 1차 매칭률 | - | **80.2%** |
| 2차 매칭률 | - | **97.8%** |
| 문항 수 | 3개 | 11개 (증가) |

**결정적 발견**:
- 매칭률 17.6%p 향상 (80.2% → 97.8%)
- 단, 응답 부담 증가 (문항 3→11)
- 직능수준 문항은 응답자 이해 부족으로 효과 제한적
- 산업/산출물 문항은 KSCO 대분류 8(조립·제작·조작) 직업군에 특히 유효

### 0.4.6 사전연구의 제언 — 본 사업이 계승할 사항

1. 직업문항 수 최적화 (기여도 낮은 문항 간소화)
2. 직능수준 문항에 **명확한 예시와 가이드** 제공
3. 산출물·근무장소 문항 활용 강화 (특히 KSCO 8 직업군)
4. 응답안내·예시 포함 설문지 유형 확대
5. 다양한 직업군·연령층 추가 파일럿
6. 직업별 최소학력·경력·자격 기준 정립

> **본 사업 시사점**: 본 사업이 만들 한국형 AutoCoder의 입력은 **개선된 11개 직업문항 응답**이어야 하며, 출력은 **KSCO 코드 + 직무활동 매핑 + K-SLF 직능수준 4차원**이어야 한다. 사전연구 ②의 직업문항이 입력, 사전연구 ①의 SLF가 출력 차원, 본 스터디 자료가 다룬 4계층이 매칭 엔진이다.

### 발표 Q&A 핵심 답변 카드 (사전연구 활용)

**Q: 본 사업이 다른 정책연구와 어떻게 다른가요?**

A: 본 사업은 우리 연구진이 작성한 두 직계 사전연구 ── 2025년 12월 국가데이터처에 제출한 ISCO-28 SLF 도입 평가 연구와 통계청 직업문항 측정방법 연구 ── 의 후속 실행 단계입니다. 사전연구가 도입 적정성 평가와 측정도구 개선이었다면, 본 사업은 그 결과를 KSCO 495개 세분류에 실제로 적용하는 단계입니다.

**Q: 직업분류 "고도화"란 정확히 무엇입니까?**

A: 두 가지를 의미합니다. 첫째, KSCO 8차의 분류 코드는 그대로 두고 그 위에 **3차원 정보 층**을 부착하는 것(직무활동·K-SLF·개선 직업문항). 둘째, 그 정보 층을 AI 자동 코딩이 가능한 형태로 표준화하는 것입니다. 미국 O*NET-SOC AutoCoder가 시간당 10만 건·정확도 85%를 달성한 것처럼, 한국형 AutoCoder의 기반을 마련하는 것이 본 사업의 장기 산출입니다.

**Q: 국가데이터처 격상 후 첫 직업분류 사업으로서의 의의는?**

A: 통계청 시절 KSCO는 통계 작성 도구였지만, 국가데이터처 출범 후에는 범정부 데이터 거버넌스의 일부가 됩니다. 본 사업은 고용노동부·산업인력공단·한국고용정보원 등에 산재된 직업정보를 통계청 KSCO 코드 단위로 통합하는 첫 시도로, 국가데이터처의 컨트롤타워 역할에 부합하는 작업입니다.

## 0.7 본 Part 요약 카드

- **국가데이터처(MODS)**는 2025.10.1 통계청에서 격상된 국무총리 직속 처. 본 사업은 격상 후 첫 직업분류 정책연구
- 본 사업 연구책임자 **조세형 박사가 직접 작성한 두 사전연구**(2025.12 ISCO-28 SLF, 통계청 직업문항)가 본 사업의 직계 선행과제
- 본 사업의 실제 구조는 **직무활동(O*NET 4계층) + 직능수준(K-SLF 4차원) + 직업문항 개선(3영역)** 세 영역 통합
- **K-SLF 4차원**: 교육(ISCED-11)·책임성(관리·감독·안전)·경험(숙련기간)·업무기반학습(일학습병행)
- 개선 직업문항 파일럿: 1차 80.2% → 2차 **97.8% 매칭률**
- **AutoCoder 3대 사례**: O*NET-SOC(NLP+ML, 시간당 10만건 85%↑) / NIOCCS(SOC 2018, ML) / G-Code(FastText+XGBoost)
- **KRIVET 사전연구**(2021·2023)는 KSCO 8차 코드 개정의 학술 근거
