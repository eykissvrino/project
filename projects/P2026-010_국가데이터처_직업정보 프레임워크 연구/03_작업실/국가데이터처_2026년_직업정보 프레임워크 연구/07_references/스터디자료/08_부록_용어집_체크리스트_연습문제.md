# 부록 — 용어집 · 체크리스트 · 연습문제

## A. 용어집 (가나다·알파벳 순)

본 스터디 자료에 등장하는 주요 용어를 가나다 또는 영문 알파벳 순서로 정리합니다.

### 한글 용어

| 용어 | 정의 |
|------|------|
| **공통 좌표** | 모든 직업을 동일한 척도로 측정하기 위한 표준화된 기준. O*NET의 GWA 41개가 대표 사례 |
| **귀납적 추상화** | 구체 진술(task)에서 출발하여 점차 일반화된 표현(DWA → IWA → GWA)으로 추상화해 가는 방법 |
| **다중연결(multi-link)** | 하나의 task가 최대 3개 DWA에 연결되는 N:M 관계. 직업 간 전환 분석의 기초 |
| **다활동 task** | 여러 활동(예: 측정+절단+설치)을 한 진술에 포함하는 task. 분해 처리 필요 |
| **데이터 무결성** | child가 항상 immediate parent를 갖도록 하는 위계 분류 표준 |
| **모드 붕괴 (mode collapse)** | LLM이 다양한 입력에도 유사한 답만 반복 생성하는 현상 |
| **모호 동사** | "사용한다", "수행한다", "처리한다" 등 구체적 의미가 약한 동사. DWA 작성에서 회피 |
| **반복가능성 (reproducibility)** | 같은 입력에 같은 출력을 보장하는 성질. LLM 분석에서 중요한 품질 기준 |
| **세분류** | KSCO 4단계 분류 (1,000명 이상 종사 기준). 본 연구의 분석 모집단 (495개) |
| **세세분류** | KSCO 5단계 분류 (한국 자체 확장). 1,270개 |
| **시계열 단절** | 분류 개정으로 인해 이전 데이터와의 시계열 비교가 어려워지는 현상 |
| **잔여 카테고리** | "All Other ..." 등 분류 외 항목을 모아두는 카테고리. SOC가 사용, WA Project는 회피 |
| **잠재적 mismatch** | 신규 분류 체계가 기존 분류의 일부 정보를 포착하지 못할 가능성 |
| **직능수준 (Skill Level)** | 직무 수행에 필요한 교육·훈련 수준. 1~4단계 |
| **직능유형 (Skill Specialization)** | 직무의 성격 차이. 지식 분야·도구·원재료·산출물 4차원 |
| **직무군 (Job Family)** | 유사한 직무유형을 가진 직업의 묶음. 미국 22개, 본 연구는 KSCO 중분류 57개 사용 권고 |
| **직무기술 정의서** | 본 연구의 핵심 산출물. ①직업개요 ②주요업무 ③핵심직무활동 ④표준화직무요소 구조 |
| **표본수 결정 시뮬레이션** | SEM(표준오차)을 시뮬레이션하여 통계적 안정성을 확보하는 최소 표본수 도출 절차 |

|------|------|

| **BGE-m3-ko** | XLM-RoBERTa 기반 한국어 임베딩 모델. 1024차원, 8192 토큰 입력 가능 |

| **KECO** | Korean Employment Classification of Occupations. 한국고용직업분류 |
| **KOR-DALE** | Dale-Chall 한국어 적용 가독성 지표 |
| **KSAO** | Knowledge, Skills, Abilities, Other characteristics. 직무 수행에 필요한 개인 속성 |
| **KSCO** | Korean Standard Classification of Occupations. 한국표준직업분류 |
| **LLM** | Large Language Model. GPT, Claude 등 |
| **NCS** | National Competency Standards |
| **O*NET** | Occupational Information Network. 미국 노동부의 직업정보 시스템 |

| **Round-Robin QC** | 다수 팀이 서로의 결과물을 순차적으로 검토하는 품질관리 방식 |
| **SBERT** | Sentence-BERT. 문장 단위 임베딩 모델 |
| **SEM** | Standard Error of the Mean. 평균의 표준오차 |
| **SMOG Index** | 가독성 지표 (Simple Measure of Gobbledygook). 3음절 이상 단어 수로 측정 |
| **SOC** | Standard Occupational Classification. 미국 표준 직업분류 |

## B. 실전 체크리스트

본 연구 수행 시 단계별로 사용할 수 있는 체크리스트입니다.

### B.1 사업 1개월차 체크리스트

```
□ KSCO 8차 분류항목표 HWPX 다운로드 완료
□ 한국직업사전 데이터 확보 (공공데이터포털)
□ NCS 능력단위 데이터 확보
□ KNOW API 액세스 확보
□ O*NET 30.x 데이터 다운로드
□ SEM 시뮬레이션 1회 완수 (5개 직업 표본)
□ 한국 보정 임계값 결정 (응답자 N, Relevance 임계 등)
□ LLM prototype: 100개 task에 자동분류 시도
□ 인간-AI Kappa 측정 (최소 0.7 확인)
□ 분석가 paired 훈련 (Kappa 0.7 도달)
```

### B.2 TASK 추출 체크리스트 (직업 1개당)

```
□ 통합 코퍼스 작성 완료 (KSCO + 직업사전 + NCS + KNOW + KECO)
□ LLM zero-shot으로 TASK 후보 추출
□ HumRRO Step 1: task 여부 판정 (LLM + 인간 검수 5%)
□ HumRRO Step 2-3: 중복 판정 (임베딩 + cosine similarity)
□ TASK 풀 확정 (직업당 20~40개 권장)
□ 3-tier 분류 적용 (Core / Supplementary / Non-relevant)
□ Core TASK 수 ≥ 8개 확인
□ TASK 진술 동사 시작 / 한국어 자연스러움 확인
```

### B.3 GWA 매핑 체크리스트

```
□ GWA 41개 한글 번역 확정
□ LLM few-shot prompt 작성 완료 (GWA 정의 동봉)
□ 다수결 LLM 분류 (Claude + GPT + Gemini)
□ 1차/2차 GWA 결정
□ 인간 분석가 검수 (30% 표본)
□ 인간-AI Kappa ≥ 0.70 확인
□ GWA 프로파일 시각화 (직업당 GWA별 TASK 수 막대그래프)
```

### B.4 DWA 도출 체크리스트

```
□ 직무군(KSCO 중분류) 1차 분할 완료
□ GWA 산하 task 집합 추출
□ 임베딩 계산 (BGE-m3-ko, 1024차원)
□ UMAP 차원 축소 (10차원)
□ HDBSCAN 클러스터링 (min_cluster_size=3)
□ 5대 품질 기준 검증:
  □ Homogeneity ≥ 0.70
  □ Outlier rate ≤ 5%
  □ Cluster Uniqueness ≤ 0.50
  □ Specificity 검토 (LLM + 인간)
  □ Cluster Size ≥ 3 task, ≥ 2 occupation
□ LLM 초안 작성 (3개 초안)
□ 인간 분석가 최종 확정
□ 8대 작성 규칙 자동 검증 통과
□ Round-Robin QC (1차 + 2차)
```

### B.5 IWA 도출 체크리스트

```
□ DWA pool 준비 (GWA 분할 없음)
□ DWA 임베딩 계산
□ 클러스터링 (군집 최소 크기 1 DWA 허용)
□ LLM IWA 초안 작성
□ Single-DWA IWA 처리 (placeholder 라벨)
□ ID 체계 부여 (GWA + ".I" + 2-digit)
□ Cross-Family IWA 식별
```

### B.6 직무기술 정의서 출시 체크리스트

```
□ ① 직업개요 작성 (3~5 문장)
□ ② 주요업무내용 작성 (5~10 항목)
□ ③ 핵심직무활동 (TASK 목록 + DWA 매핑)
□ ④ 표준화직무요소 (GWA·IWA·DWA 프로파일)
□ 직업 간 전환 가능성 분석 (공유 DWA 수)
□ 가독성 (KOR-DALE 8학년) 통과
□ 외부 전문가 1차 검토 완료
□ Round-Robin QC 2회 완료
```

## C. 연습문제

본 스터디 자료의 핵심 개념을 점검하는 연습문제입니다.

### C.1 개념 확인 (선택형)

**문제 1**. 다음 중 GWA(Generalized Work Activity)에 해당하는 진술은?
- ① "환자의 활력징후를 측정한다"
- ② "정보를 수집한다 (Getting Information)"
- ③ "처방약물을 정맥 경로로 투여한다"
- ④ "Snellen 시력표를 사용해 환자 시력을 검사한다"

> **정답·해설**: ② — GWA는 직업 비특수의 가장 일반적 활동. ①은 다소 일반적이지만 의료 맥락 포함, ③④는 직업특수 task

**문제 2**. WA Project가 2014년에 NLP를 거부한 핵심 이유는?
- ① 인건비가 NLP보다 저렴해서
- ② Task 진술의 구조적 변동성으로 인한 신뢰도 우려
- ③ NLP 기술이 영어만 지원해서
- ④ 미국 노동부의 정책 방향

> **정답·해설**: ② — "task statement structure is so variable..." 핵심 인용. 2014년 BERT 이전 NLP의 한계

**문제 3**. HumRRO의 분석가 간 Cohen's Kappa는?
- ① 0.55
- ② 0.70
- ③ 0.88
- ④ 1.00

> **정답·해설**: ③ — Landis & Koch 분류로 "거의 완전한 일치"

**문제 4**. DWA의 최소 크기 권고는 (미국 기준)?
- ① 2 task / 2 occupations
- ② 4 task / 3 occupations
- ③ 10 task / 5 occupations
- ④ 15 task / 10 occupations

> **정답·해설**: ② — Cross-occupational linking과 장기 안정성 확보

**문제 5**. 본 연구 8개월 사업기간에서 권고되는 한국 보정 DWA 최소 크기는?
- ① 4 task / 3 occupations (미국 그대로)
- ② 3 task / 2 occupations
- ③ 1 task / 1 occupation
- ④ 10 task / 5 occupations

> **정답·해설**: ② — 한국 데이터 규모(KSCO 495 세분류) 고려한 하향 권고

### C.2 적용 문제 (서술형)

**문제 6**. 다음 task 진술을 GWA 41개 중 1차·2차 선택을 제시하고 이유를 설명하시오.

> "건축물의 도면을 검토하여 구조적 안전성을 평가하고 설계 변경 권고안을 작성한다"

> **정답·해설 예시**:
> - 1차 GWA: "Analyzing Data or Information" — 도면 검토와 안전성 평가가 분석 활동의 핵심
> - 2차 GWA: "Documenting/Recording Information" — 권고안 작성 측면
> - 3차 후보: "Making Decisions and Solving Problems"
> - 이유: task 진술이 다활동(분석 + 결정 + 기록)을 포함. 1차 활동은 분석 평가

**문제 7**. 다음 두 DWA 진술 중 8대 작성 규칙을 더 잘 준수한 것을 고르고 이유를 설명하시오.

A. "환자의 신체 상태를 모니터링하고 필요시 의사에게 보고하기 위해 활력징후·증상·반응 등을 정기적으로 관찰하는 활동을 수행한다"
B. "환자의 신체 상태와 반응을 관찰한다"

> **정답·해설**: B
> - A의 문제: ①너무 길어 가독성 저하, ②"수행한다"로 끝나 모호 동사 사용, ③목적절 "보고하기 위해" 포함, ④다활동(관찰+보고)
> - B는 동사 시작 ✓, 단일 활동 ✓, 적정 추상도 ✓, 가독성 8학년 ✓

**문제 8**. 본 연구에서 LLM zero-shot 분류를 채택할지 인간 검수 100%로 갈지 결정하는 핵심 지표 두 가지를 들고, 각 지표의 임계값을 제시하시오.

> **정답·해설 예시**:
> - 지표 1: 인간-AI Cohen's Kappa — 임계 0.70 이상이면 LLM 채택, 미만이면 인간 검수 비중 증가
> - 지표 2: F1 Score — 임계 0.82 이상이면 자동분류 채택. Precision ≥ 0.85, Recall ≥ 0.80
> - 보조 지표: hallucination rate ≤ 5%

### C.3 시뮬레이션 문제

**문제 9**. KSCO 세분류 "공인회계사"(KSCO 코드는 가정) 1개 직업을 잡아서, 다음 정보로 직무기술 정의서 일부를 작성해 보시오.

```
[주어진 정보]
- KSCO 직업 정의: 기업·기관의 재무상태와 경영성과를 감사하고, 회계·세무 자문을 제공한다.
- 한국직업사전 주요업무: 회계감사 수행, 재무제표 검토, 세무신고서 작성, 회계자문, 재무 컨설팅
- NCS 능력단위: 외부감사, 내부감사, 세무신고, 회계자문, 재무분석
```

**과제**:
1. TASK 후보 8개 추출 (LLM 역할로 작성)
2. 각 TASK를 GWA 41개 중 1차에 매핑 (Part 2 §2.2 GWA 4대 범주 참고)
3. 가장 빈도가 높을 것 같은 GWA 3개 식별

> **모범답안 예시**:
> 
> TASK 후보:
> - T1: 기업의 재무제표를 회계기준 준수 관점에서 검토한다 → Analyzing Data or Information
> - T2: 회계감사 절차에 따라 증빙자료를 표본 추출하여 검증한다 → Inspecting Equipment, Structures, or Material
> - T3: 감사 결과를 감사보고서 형태로 작성한다 → Documenting/Recording Information
> - T4: 세무신고서를 작성하고 관할 세무서에 제출한다 → Documenting/Recording Information
> - T5: 고객 기업의 재무 상태에 대해 자문을 제공한다 → Communicating
> - T6: 회계 처리 오류를 발견하면 수정 방안을 제시한다 → Making Decisions and Solving Problems
> - T7: 감사 일정·범위를 사전 계획한다 → Scheduling Work and Activities
> - T8: 회계 관련 법규 개정사항을 학습한다 → Updating and Using Relevant Knowledge
>
> 빈도 높은 GWA 3개:
> 1. Analyzing Data or Information
> 2. Documenting/Recording Information
> 3. Communicating

### C.4 발표 Q&A 대비

**문제 10**. 다음 질문에 대해 1분 답변(약 200자)을 준비하시오.

> "Q: 미국 WA Project는 14명이 12개월 이상 걸린 작업입니다. 한국이 6명·8개월로 동등한 결과를 낼 수 있다는 근거는 무엇입니까?"

> **모범답안 예시**:
> "미국이 168 person-month인 반면 한국은 48 person-month로 약 30% 자원입니다. 본 연구는 다음 3가지 효율 레버를 활용합니다.
> 첫째, 2014년 미국이 거부한 NLP·LLM 기술이 2026년에는 인간 수준으로 발달했습니다. HumRRO Decision Tree의 task 판정과 중복 판정에서 LLM이 90% 이상 정확도를 보이며, 인간 분석 시간을 70% 절감할 수 있습니다.
> 둘째, 본 사업은 일부 중분류만 시뮬레이션하는 것으로 범위가 한정되어 있어, 전체 1만 task를 한 번에 처리할 필요가 없습니다.
> 셋째, O*NET 41 GWA·332 IWA·2,087 DWA를 출발점으로 활용하여, 미국이 11년에 걸쳐 한 일을 재발명하지 않습니다."

**문제 11**. 다음 질문에 1분 답변하시오.

> "미국 67% 임계는 미국 데이터의 시뮬레이션 결과입니다. 한국에서는 사업 1개월차에 K-NCS·KECO 데이터로 자체 SEM 시뮬레이션을 수행하여 한국 보정 임계를 도출할 계획입니다. 한국 직업의 incumbent 다양성이 미국보다 작을 가능성이 있어, 분포 검토 결과에 따라 60~67% 사이에서 결정할 것입니다. 단, 분류 임계의 구조(3-tier)와 척도(5점)는 동일하게 유지하여 국제 비교가능성을 확보합니다."
