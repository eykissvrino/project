## 1. 에이전트 팀 구성

### 팀 A: 학습 콘텐츠 생성
**역할**: 강의 내용 정리, 이론 요약, 개념 비교, 사례 리서치

**사용 예시:**
```
"노사관계법 핵심 조항 10가지 정리해줘"
"전략적 HRM 모델 3가지 비교표 만들어줘"
"성과평가 방법론 MBO vs OKR vs BSC 비교 분석해줘"
"한국 노동법과 미국 노동법 주요 차이점 정리해줘"
```

### 팀 B: 과제 제작
**역할**: PPT, Word, Excel 등 과제물 직접 제작

| 스킬 | 용도 | 예시 명령 |
|------|------|-----------|
| `/pptx` | 발표자료 | "노사관계 사례분석 발표 PPT 15장 만들어줘" |
| `/docx` | 보고서/에세이 | "인적자원관리 트렌드 분석 보고서 A4 10장 작성해줘" |
| `/xlsx` | 데이터 분석 | "보상 벤치마킹 데이터 분석 시트 만들어줘" |
| `/pdf` | 정리노트 | "중간고사 핵심 요약 PDF 만들어줘" |

### 팀 C: 시험 준비
**역할**: 예상문제 출제, 퀴즈, 모범답안, 개념 테스트

**사용 예시:**
```
"노사관계 중간고사 예상문제 출제해줘 (객관식 10 + 서술형 5)"
"성과평가·보상 OX 퀴즈 30문제 만들어줘"
"인적자원관리 서술형 예상문제 모범답안 작성해줘"
"3과목 통합 핵심 키워드 100개 정리해줘"
```

### 팀 D: 실무 인사이트
**역할**: 이론↔실무 연결, 기업 사례, 최신 트렌드

**사용 예시:**
```
"삼성전자 인사제도 분석해줘"
"2025-2026 한국 기업 HR 트렌드 리서치해줘"
"카카오 성과평가 제도 변화 사례 정리해줘"
"글로벌 기업 노사관계 우수 사례 조사해줘"
```

### 팀 E: 일정/프로젝트 관리
**역할**: 마감일 관리, 학습 일정, 리마인더

**연동 도구:**
- 📆 **Google Calendar**: 과제 마감일, 시험일 등록
- 📓 **Notion**: 강의 노트, 참고자료 관리
- ⏰ **Schedule**: 주간 학습 리마인더 설정

## 2. 상황별 워크플로우

### 📋 워크플로우 1: 매주 강의 학습 사이클

```
[수업 전]
  "이번 주 {과목명} 예습할 내용 정리해줘"
  → 핵심 개념 사전 학습 노트 생성

[수업 후]
  "오늘 {과목명} 수업 내용 복습 정리해줘"
  → 강의 내용 기반 복습 노트 생성 (강의자료 업로드 시 더 정확)

[주말]
  "이번 주 3과목 크로스 리뷰 해줘"
  → 과목 간 연계 개념 정리
```

### 📋 워크플로우 2: PPT 과제 제작

```
Step 1: 주제 리서치
  "노사관계에서 {주제} 관련 자료 조사해줘"

Step 2: 구조 설계  
  "발표 PPT 개요 잡아줘 (15분 발표, 15장)"

Step 3: PPT 생성
  "/pptx {주제} 발표자료 만들어줘"

Step 4: 피드백 & 수정
  "3번째 슬라이드에 사례 더 추가해줘"
```

### 📋 워크플로우 3: 사례분석 보고서

```
Step 1: 기업/사례 리서치
  "{기업명} {주제} 사례 조사해줘"

Step 2: 이론 프레임워크 적용
  "{이론명} 관점에서 이 사례를 분석해줘"

Step 3: 보고서 작성
  "/docx 사례분석 보고서 작성해줘"

Step 4: 검토
  "보고서 논리 흐름 검토하고 개선점 제안해줘"
```

### 📋 워크플로우 4: 시험 준비 (D-21 프로세스)

```
[D-21] 핵심 개념 정리
  "{과목명} 1~7주차 핵심 개념 정리 노트 만들어줘"

[D-14] 과목 연계 & 심화
  "3과목 핵심 개념 연계 맵 만들어줘"
  "이론별 주요 학자와 핵심 주장 정리해줘"

[D-7] 예상문제 & 답안 연습
  "{과목명} 중간고사 예상문제 20문제 출제해줘"
  "서술형 모범답안 작성 연습 도와줘"

[D-3] 최종 정리
  "{과목명} 시험 직전 1페이지 핵심 요약 만들어줘"
  "취약 부분 집중 퀴즈 만들어줘"
```

## 3. 과목별 맞춤 활용법

### 노사관계 (윤동열 교수)
- **특성**: 법률 + 판례 + 실무 사례 중심
- **추천 학습법**: 
  - 노동법 조문 정리 → 판례 매칭 → 실무 적용 사례
  - "근로기준법 제{X}조 관련 주요 판례 정리해줘"
  - "최근 1년 노사분쟁 주요 사례 조사해줘"

### 성과평가·보상 (윤동열 교수)
- **특성**: 이론 프레임워크 + 설계 실습 + 계산
- **추천 학습법**:
  - 평가 모델 비교 → 보상 설계 시뮬레이션 → 기업 사례
  - "직무평가 방법 4가지 비교해줘 (서열법, 분류법, 점수법, 요소비교법)"
  - "연봉제 vs 직능급 vs 직무급 장단점 분석해줘"

### 인적자원관리 (정혜정 교수)
- **특성**: 전략적 HRM + 최신 트렌드 + 광범위
- **추천 학습법**:
  - HRM 모델 체계적 학습 → 기능별 심화 → 전략 연계
  - "하버드 모델 vs 미시간 모델 vs 게스트 모델 비교해줘"
  - "전략적 HRM에서 VRIO 분석 적용 사례 찾아줘"

## 5. DATA 폴더 활용법

`DATA/` 폴더에 넣으면 좋은 자료:
- 📄 강의계획서 (실라버스) — 과제, 시험 일정 자동 추출
- 📄 강의 자료 (PDF/PPT) — 내용 기반 정리 노트 생성
- 📄 과제 지시문 — 맞춤 과제 작성 가이드
- 📄 교재 목차/챕터 — 학습 범위 매핑

> DATA 폴더에 자료를 넣고 "DATA 폴더에 있는 자료 분석해줘"라고 요청하세요!
