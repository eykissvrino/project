# 1. 참고 양식 분석

## 1-1. 시앤피·대우 컨설팅 제안발표 템플릿 (6개 자료 분석)

분석 대상: 시앤피(GITC·상하수도협회·화학융합시험연구원), 대우(한국특허전략개발원·대우인력·한기대)

| 요소 | 공통 패턴 |
|---|---|
| **표지** | 큰 제목 + `[제안발표자료]` 부제 + `발주기관/제안기관` 명기 + 하단 양측 로고. 사선 도형·이미지 밴드 활용 |
| **Contents** | "Contents" 대형 타이틀 + 긴 가로 라인. 로마숫자(Ⅰ Ⅱ Ⅲ) 대분류 + 1·2·3 소분류 + 페이지번호 |
| **섹션 표지** | 큰 로마숫자 + 섹션명, 이미지/퍼즐 배경 |
| **본문 좌상단** | **네이비 박스 카테고리 라벨**(예: "제안 개요", "Framework", "Module 1") + 굵은 세로 액센트 바, 옆에 세부 제목 |
| **본문 우상단** | 목차 위치 표시 (예: `Ⅱ. 과업수행 계획 / 2. 세부 수행 방안`) |
| **거버닝 메시지** | 본문 상단에 **파란 강조어가 섞인 1~2줄 요약 문장** + 가로 구분선 |
| **본문 영역** | 회색 박스, 컬러 헤더 표, Module–Step 다이어그램, As-Is/To-Be 대비 |
| **Framework 슬라이드** | 전체 추진체계를 Module 1~4 / Step 1~12로 **한 장에** 압축 |
| **하단** | 페이지번호 (`- 8 -` 형식) |
| **컬러** | 네이비/블루 메인 (시앤피는 그린 액센트 병용) |

## 1-2. 맥킨지 등 해외 컨설팅펌 구조 원칙

| 원칙 | 적용 방법 |
|---|---|
| **Action Title (거버닝 메시지)** | 슬라이드 제목이 곧 결론 — 완전한 문장. 제목만 이어 읽어도 스토리라인이 완성 |
| **Pyramid Principle** | 결론 먼저 → 근거 나중. SCQA(상황-전개-질문-답) 흐름 |
| **One Message per Slide** | 슬라이드당 핵심 메시지 1개 + 그것을 입증하는 본문만 |
| **MECE 구조화** | 중복·누락 없는 분류. 표·2x2·프로세스 플로우로 시각화 |
| **Exhibit·Source 규율** | 도표 번호 부여, 하단 출처 명기 |
| **절제** | 데이터·구조로 설득. 장식·아이콘 최소화 |

## 1-3. 결합 전략 — "두 양식의 장점만"

- **뼈대(구조·내비게이션)**: 시앤피/대우 양식 → 로마숫자 섹션, 좌상단 카테고리 박스, 우상단 목차 위치, Framework 한 장 압축. → 교수·동료에게 익숙하고 "컨설팅 보고서"의 신뢰감.
- **두뇌(메시지·논리)**: 맥킨지 원칙 → 모든 슬라이드 제목을 거버닝 메시지(완전한 문장)로. 제목만 이어도 스토리. Pyramid·MECE.
- **결과물**: "한국형 컨설팅 제안서의 외형"에 "맥킨지식 논리 전개"를 얹은 케이스 분석 발표자료.

# 2. 핵심 변경 — 7S 제외, '제도·구조·문화' 3대 진단축으로 대체

기존 v1은 McKinsey 7S를 진단의 척추로 썼으나, **7S를 제외**하고 HR 컨설팅 실무에서 더 직관적인 **「제도(System) · 구조(Structure) · 문화(Culture)」 3대 축**으로 재구성한다.

| | As-Is 진단 (Ⅱ장) | To-Be 재설계 (Ⅲ장) | 결론 (Ⅴ장) |
|---|---|---|---|
| **제도 System** | Stack Ranking(강제 서열화) | 상시 피드백·매니저 재량 보상 | 3축 정합성 |
| **구조 Structure** | 사일로 "Confederation of Fiefdoms" | One Microsoft — 횡단 협업 | 종합표로 |
| **문화 Culture** | Know-it-all / Fixed Mindset | Growth Mindset / Learn-it-all | 입증 |

- 진단(병리) → 처방(재설계) → 정합성(결론)이 **같은 3축으로 일관**되게 흐른다 → 스토리라인이 선명.
- 문화 '유형'의 이동은 **Cameron & Quinn 경쟁가치모형**으로 보강(7S 아님, 사용 OK).
- 변화관리 해석은 **Kotter 8단계 · Schein 문화론**, 이론 기반은 **Carol Dweck Growth Mindset** 유지.
