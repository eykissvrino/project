Week 16 — 보상 설계 개인 과제 발표

과제 안내

  1. 아래 보상 제도 프레임워크를 참고해 여러분 조직의 보상 제도 현황–개선 방안을 정리하세요.
  2. 모든 Step을 하지 않아도 됩니다. 개선하고자 하는 단계 몇 개만 해도 됩니다. 단, 왜 해당 Step에 집중하는지 이유가 명확해야 하고, 그만큼 더 depth 있는 설계를 해야 합니다.
  3. 각 Step별로 별도 장표에 작성하고, 내부 경영자에게 보고한다고 생각하여 구체적인 현황과 방안 설계를 할수록 좋은 평가를 받습니다.

과제 작성 양식

  • AS-IS는 추상적 표현 없이 실제 사례·수치·경험을 담아 구체적으로 작성
  • TO-BE는 단순 희망이 아닌, AS-IS 문제의 원인 분석을 바탕으로 도출

( 🖼️ 보상 제도 과제 프레임워크 도식 — 원본 노션 페이지 참조 )

Step 1. 보상 철학

우리 회사가 보상을 왜, 어떤 목적으로 하는지에 대한 경영진의 생각. ("성과에 따라 차등 지급", "시장 최상위 유지", "보상으로 인재 유지" 같은 큰 방향과 신념)

  • AS-IS: 보상 철학이 말로라도 존재하는지(아니면 그때그때 다른지) / 경영진이 보상에 대해 어떤 생각인지 / 그 생각이 구성원에게 전달되는지
  • TO-BE: 어떤 철학을 새로 세우거나 명확히 해야 하는지 / 수립·강화해야 하는지 / 왜 바꿔야 하는지

Step 2. EVP (Employee Value Proposition) 설계

구성원이 우리 회사에 다니는 이유 — 연봉만이 아니라 성장 기회·문화·안정성·의미 등 "왜 여기서 일하는가".

  • AS-IS: 구성원이 얻고 있다고 느끼는 것 / 회사가 내세우는 것과 실제 느끼는 것의 일치 여부 / 경쟁사 대비 EVP 강·약점
  • TO-BE: 앞으로 제공하고 싶은 핵심 가치 / 그 가치를 선택한 이유(전략·채용 타겟·니즈)

Step 3. 보상 원칙

보상을 결정할 때 실제로 적용하는 기준과 룰. (철학="왜 보상하는가", 원칙="어떤 기준으로 결정하는가". 예: "내부 형평성보다 외부 경쟁력 우선", "직급이 아닌 기여도 기준", "결정 과정 투명 공유")

  • AS-IS: 실제 작동하는 기준 / 일관 적용 여부 / 구성원 납득 여부
  • TO-BE: 새로 세우거나 강화할 원칙 / 해결되는 문제 / 지키기 위해 필요한 것

Step 4. 보상 구조 — 전체 설계

우리 회사 보상의 전체 그림. (기본급·인센티브·복리후생 비중, 고정·변동 비율 등)

  • AS-IS: 기본급/성과급/복리후생 비율·구성 / 장점·문제점 / 경쟁사·업계 대비 수준
  • TO-BE: 전체 구조 변경 방향 / 이유 / 예상 효과·리스크

Step 5. 급여 설계 (Entry · Renewal · 성과급)

입사 시 연봉 결정, 재직 중 연봉 인상, 성과 보너스 설계.

  • AS-IS: 입사 연봉 기준(협상? 직급 테이블? 전 직장?) / 인상 시기·기준 / 성과급 유무·산정·납득
  • TO-BE: 각각에서 무엇을 바꿔야 하는지 / 현재 방식의 문제 / 개선 후 기대 효과

Step 6. 포상 & 복리후생

급여 외 모든 것 — 포상(칭찬·시상·인정)과 복리후생(건강보험·식대·교육비·유연근무 등). 돈이 아닌 방식으로 동기를 어떻게 높이는가?

  • AS-IS: 포상 제도 유무·작동 여부 / 복리후생 항목 / 실제 이용·만족 여부
  • TO-BE: 포상 방식 변경 / 복리후생 추가·삭제 / 이유·기대 효과

발표 일정 및 시간

  • 발표일: 6월 17일 (수)
  • 발표 시간: 15분~20분
