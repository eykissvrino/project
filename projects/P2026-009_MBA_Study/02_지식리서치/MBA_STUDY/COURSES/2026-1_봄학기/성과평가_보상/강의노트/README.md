## 핵심 내용 맵

- **보상 철학·인사시스템 구성체계**: 자기충족 예언, 인적자원관리의 의미, 추상화 수준(Principle·Policy·Practice), 일관성의 3차원, 구성형태(configuration)·창발성 → 01
- **임금체계 일반**: 임금의 특수성(미래·상승·현금성), 보상의 분류(경제적/비경제적, 통상임금·기본급·수당), EVP, 임금수준 결정 요인, 연공급·직무급·성과급 장단점, 평생직장 모델, HBR "성과대로 받지 않는다" → 02
- **연봉제 설계 실무**: 비누적/누적/혼합 연봉제, 5단계 설계 과정, 시장임금선·임금정책선(선도/매칭/추종), Pay grade·range·중복비율, 정액/정률피치, 급여정책선 6형태, Pay zone·콤파율 산식, Merit/Promotion increase → 04
- **공정성 이론**: Adams 공정성 이론(산출·투입·비교), 분배(형평·평등·필요)·절차·상호작용 공정성, 급여 공개 vs 비밀, 공정성 설문 문항, 공정한 보너스 의사결정, HBR 동료급여 학습효과 → 05
- **인센티브 이론**: Pay=a+b×PM, 인센티브 강도와 측정오류·리스크, 두 위험요소, 총보상 같다고, 기대이론, PFP 인식이론, Reward/Penalty/Floor-Cap/Lump-sum 설계, 집단성과배분·스캔론플랜·이익공유, I-deals, 학습조직(4I) → 06
- **실무 과제 프레임워크(6 Steps)**: 보상철학 → EVP → 보상원칙 → 보상구조 → 급여설계 → 포상·복리후생 → 07
- **읽기자료(과제1)**: 글로벌 직무기반 보상체계 — 직무분류·직무평가(Korn Ferry)·직급 도출·이행·Target 보상수준(퍼센타일) → 08
