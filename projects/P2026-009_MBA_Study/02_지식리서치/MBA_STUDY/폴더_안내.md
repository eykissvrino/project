## 최상위 구성

| 폴더/파일 | 용도 |
|-----------|------|
| `COURSES/` | **내가 만든 작업물** — 강의노트·과제·시험준비·참고자료를 학기→과목별로 보관 |
| `DATA/` | **원본 자료함** — 강의계획서·강의 PDF/PPT 등 다운로드한 raw 자료 (학기·과목별) |

| `AGENT_MANUAL.md` | 학습 에이전트 활용 매뉴얼 |
| `CURRICULUM_MAP.md` | 수강 이력·과목 연계 맵 |
| `MBA_DASHBOARD.html` | 학습 대시보드 |

## COURSES 폴더 규칙

```
COURSES/{학기}/{과목}/
  ├─ 강의노트/    수업 요약·정리 노트
  ├─ 과제/        제출 과제물 (+ _archive/ 에 이전 버전)
  ├─ 시험준비/    예상문제·요약
  └─ 참고자료/    기타 보조자료
```

- **`_archive/`**: 같은 과제의 이전 버전·초안을 모아둔 곳. 최종본만 각 `과제/` 바로 아래에 둠.
- **원본 vs 작업물**: 교수자가 배포한 원본 강의자료는 `DATA/`, 내가 정리·작성한 결과물은 `COURSES/`.
