## 1. 한 줄 정의

> **"한국 전통의 따뜻한 도자기 빛 위에, 한자 도장과 한글 서예가 맞물린 단정한 정성."**

## 2. 컬러 팔레트

라벨에서 추출한 핵심 컬러:

| 컬러 | 용도 | HEX 추정 | 비고 |
|------|------|----------|------|
| **Wolinga Cream** | 메인 배경 (베이지·도자기 빛) | `#E8D5B7` ~ `#D9BFA0` | 따뜻한 도자기 톤 |
| **Wolinga Sand** | 그라데이션 (배경의 깊이) | `#C9A87C` ~ `#A98863` | 모래·황토 |
| **Stamp Red** | 로고 도장 / 강조 포인트 | `#8B2A1F` ~ `#A02E22` | 전통 옥새 빨강 |
| **Ink Black** | 한자·한글 서체 | `#1F1A14` | 진한 먹색 |
| **Soft White** | 텍스트 박스·여백 | `#F5EFE3` | 따뜻한 흰색 |

> 모든 컬러는 **무채색·차가운 톤 일체 배제**. 차가운 회색·순백색은 월인가 정체성과 충돌.

## 3. 로고 시스템

### 3.1 메인 로고 — 月印家(월인가) 도장
- 형태: 빨간 원형 도장에 흰색 한자 4자
- 배치: 항상 라벨/콘텐츠의 좌측 상단 또는 중앙 좌측
- 한자 4자: 월(月) 인(印) 가(家)
- 의미: "달의 자취가 깃든 집" — 양조의 시간·정성·가족
- 사용 제한: 도장 내부에 어떤 텍스트도 추가 금지

### 3.2 보조 로고 — 한글 워드마크
- "월인가 술 빚는 날" — 본 사명
- 서체: 단정한 명조계열 또는 손글씨체 (라벨 하단 사용 사례)
- 배치: 라벨 하단·콘텐츠 마무리 서명 위치
- 영문 표기 시: 부제로 작게 "WOLINGA"

## 4. 타이포그래피

### 4.1 메인 타이포 — "국화주" 한글 서예
- 라벨 중심부에 큰 한글 서예체로 배치
- 분위기: 손으로 빚은 듯한 묵직함, 단정함
- 단어 간격 넓게(여백이 곧 정성)
- 부제는 작게 ("탁주", "약주" 등)

### 4.2 정보 타이포 — 산세리프 명조 혼용
- 표시정보(법정 표시사항)는 명조체 또는 깔끔한 산세리프
- 보디 카피(SNS·블로그)는 명조체 우선

### 4.3 영문 표기
- "500ml Alc 10%" 형식의 짧은 영문 정보만
- 영문 카피·캠페인 메시지는 한글이 우선, 영문은 보조

## 5. 패턴·장식 요소

### 5.1 한국 전통 모티프
- **구름 무늬**: 라벨 좌측 상단·우측 하단에 배치 (라벨 디자인 근거)
- **산수 라인**: 좌측 하단의 옅은 곡선 = 한국적 풍경 추상화
- 패턴은 **아주 옅게**, 메인 메시지를 가리지 않음

### 5.2 사용 원칙
- 패턴은 **서브 액센트**, 메인 비주얼이 되면 안 됨
- 모든 패턴은 도자기 빛 베이지 배경 위에서만 작동
- 파스텔·네온·금속 광택 등은 일체 사용 안 함

## 6. 사진·이미지 톤

### 6.1 양조장 일상 사진
- 시간대: 새벽·이른 아침·늦은 오후 (부드러운 빛)
- 빛: 자연광 우선, 차가운 인공광 회피
- 질감: 손·나무·도자기·천 같은 따뜻한 텍스처 노출
- 색감: 따뜻한 베이지·갈색·따뜻한 흰색 톤

### 6.2 제품 사진
- 배경: 무지·자연 텍스처 (린넨·종이·나무)
- 라이팅: 사이드 라이트로 라벨 음영 살리기
- 소품: 호두·국화·계절 식물 자연스럽게 (강요 X)

### 6.3 페어링 사진
- 음식이 주, 술은 곁에
- 식탁의 일상감(헝겊 위·도자기 위)
- 손이 한 번 들어오면 따뜻함이 살아남

### 6.4 절대 안 쓰는 비주얼
- ❌ 선명한 채도의 컬러 그래픽 (네온·형광)
- ❌ 차가운 회색·순백색 배경
- ❌ 화려한 모션 그래픽·번쩍임
- ❌ 광고형 강조 효과 (큰 화살표·할인 배지)
- ❌ 사람 얼굴 클로즈업으로 미소 강요

## 7. 구도·여백

- **여백을 두려워하지 않는다.** 라벨도 콘텐츠도 빈 공간이 정성을 만든다.
- 한 화면에 **메시지 1~2개**까지만
- 텍스트 정렬: 좌측 정렬 또는 가운데. 양쪽 정렬은 어색해질 수 있어 주의

## 8. 채널별 적용 (요약)

| 채널 | 비주얼 톤 | 추천 활용 |
|------|-----------|-----------|
| 인스타 피드 | 정사각·세로 (4:5) / 자연광 / 1~2 메시지 | 양조장 일상·페어링·제품 컷 |
| 인스타 스토리 | 9:16 / 라벨 클로즈업 + 카피 1줄 | 행사·신제품 알림 |
| 블로그 | 가로 1200px / 사진 3~5컷 흐름 | 양조 일지·페어링 칼럼 |
| 상세페이지 | 세로 긴 폭 / 헤드 이미지 + 단락 사진 | SKU별 스토리 |
| 보도자료 | 가로 / 라벨 정면컷 + 양조장 풍경 1컷 | 미디어 배포용 |
| 패키지·기프트 | 도자기빛 무지 박스 + 빨간 도장 띠 | 사계주 시그니처 적용 |
