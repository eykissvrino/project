## ⏱ 사용자가 5분 안에 마칠 4단계

### Step 1. 남은 폴더 3개 생성 (2분)

위 마스터 폴더(`월인가 술빚는날`) 안에서 **빈 영역 우클릭** → **새 폴더** → 이름 입력 → 만들기.

| 만들 폴더 이름 |
|----------------|
| `02_가족공유_일상` |
| `03_사령탑_전용` |
| `99_백업` |

> 💡 키보드 단축키: `Shift + F` (새 폴더 빠르게)

### Step 2. v2 운영기록부 업로드 (1분)

1. `01_가족공유_운영기록/` 폴더 진입
2. **신규** → **파일 업로드** 클릭
3. 로컬 파일 선택:
   `C:\Users\eykis\OneDrive\vrin_AI_hub\projects\P0000_001_월인가술빚는날\00_AI_체계\03_지식베이스\ops\templates\월인가_운영기록부_마스터_v2.xlsx`
4. 업로드 완료 대기

### Step 3. 구글시트로 변환 (1분)

1. 업로드된 `월인가_운영기록부_마스터_v2.xlsx` 우클릭
2. **연결 앱 → Google 스프레드시트로 열기**
3. 자동 변환 완료 후 **저장**
4. 변환된 구글시트가 같은 폴더에 생김 (원본 xlsx는 백업으로 보존 또는 삭제 가능)

> 💡 변환 결과: 11개 시트 모두 + 드롭다운·자동 합계 수식 유지

### Step 4. 가족 공유 (1분)

> ⚠️ AI는 공유 권한 설정을 대신 처리하지 않습니다 (개인정보·보안 정책).
> 사용자가 직접 진행해 주세요.

1. 변환된 구글시트(또는 `01_가족공유_운영기록/` 폴더 자체)에 **공유 버튼** 클릭
2. 가족 이메일 추가 (어머니·아버지·태균이)
3. 권한: **편집자**
4. **알림 전송** 메시지 (선택):

```
어머니 아버지, 태균아 안녕!
월인가 운영 기록부를 만들어뒀어. 
직접 입력하실 필요 없고, 평소처럼 카톡으로 보내주시면 내가 정리할게요.
```
