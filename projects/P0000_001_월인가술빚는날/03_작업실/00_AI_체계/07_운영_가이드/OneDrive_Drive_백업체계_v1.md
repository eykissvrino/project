# 🔄 OneDrive ↔ 구글 드라이브 백업 체계 v1

> **두 곳에 모두 저장** — 원본은 OneDrive(사령탑 작업), 가족 공유·백업은 구글 드라이브.
> 한 곳이 사고 나도 다른 곳에 살아있도록.

---

## 0. 핵심 원칙 — 어떤 자료가 어디에 사나

| 자료 유형 | 원본(Source of Truth) | 백업·공유 | 갱신 빈도 |
|-----------|----------------------|-----------|----------|
| **사령탑 AI 작업물** (`00_AI_체계/`) | OneDrive | 분기 zip → Drive | 분기 |
| **운영 기록부 v2** | 구글시트 (구글 드라이브) | PDF 월간 → OneDrive | 매월 |
| **양조장 사진·영수증** | 구글 드라이브 (가족 공유) | 백업 안 함 | — |
| **면허·법무 문서** | OneDrive 원본 + Drive 사본 | 둘 다 보존 | 변경 시 |
| **콘텐츠 발행본** | 발행 채널이 원본 / Drive 사본 보존 | OneDrive에는 작업물만 | 발행 시 |
| **로고·라벨·미디어킷** | OneDrive + Drive (사본) | 둘 다 보존 | 변경 시 |

> 💡 **운영 기록부는 구글시트가 원본**입니다. xlsx 파일은 백업용. 가족이 매일 보는 곳이 원본.

## 1. 매일 자동 동기화 (필요한 부분만)

### 추천: Google Drive for Desktop 설치

설치 후 윈도우 탐색기에서 G:\내 드라이브\월인가 술빚는날\ 으로 마운트.
**자동 양방향 동기화** → 사령탑이 OneDrive에서 작업한 게 G:\에 복사하면 즉시 Drive에 반영.

### 설치 절차 (10분, 한 번만)
1. https://www.google.com/drive/download/ 에서 다운로드
2. 설치 → 본인 계정 로그인
3. 동기화 폴더 선택 → "내 드라이브" 전체 또는 `월인가 술빚는날`만
4. 윈도우 탐색기에서 G:\내 드라이브\월인가 술빚는날\ 보이면 완료

**효과:** OneDrive와 Drive 사이에 파일 복사·이동이 윈도우 탐색기 안에서 끝남.

## 2. 매주 일요일 — 사령탑 백업 (5분)

| 작업 | 어디서 → 어디로 |
|------|----------------|
| 운영기록부 PDF 다운로드 | 구글시트 → 다운로드 → Drive `99_백업/2026/주간/` |
| 이번 주 산출물 사본 | OneDrive `00_AI_체계/09_세션로그/` → Drive `01_경영_사령탑/05_회의록_메모/` |
| 신규 면허·서식 | OneDrive `04_행정_법무/` → Drive 동일 위치 |

자동화 도구: **Drive for Desktop**이 설치되어 있으면 위 작업은 **드래그앤드롭 또는 복사·붙여넣기**로 1~2분.

## 3. 매월 1일 — 전체 백업 (15분)

### 1) 운영기록부 PDF 백업
1. 구글시트 → 파일 → 다운로드 → **PDF (.pdf)**
2. 전체 시트 옵션 선택
3. 저장 위치: `99_백업/2026/{YYYY-MM}/운영기록부_{YYYY-MM}.pdf`

### 2) OneDrive 작업 폴더 zip 백업
사령탑이 윈도우 탐색기에서:
1. `00_AI_체계/` 폴더 우클릭 → 압축(ZIP)
2. 생성된 zip 파일명: `00_AI_체계_{YYYY-MM}.zip`
3. Drive `99_백업/2026/{YYYY-MM}/` 에 업로드

### 3) 핵심 자산 사본 동기화
- 신규 라벨 → `05_브랜드_자산/02_라벨/현재_사용중/`
- 신규 콘텐츠 발행본 → `06_마케팅_콘텐츠/01_캠페인_연도별/{YYYY}/`
- 월간 KPI 보고서 → `01_경영_사령탑/02_재무_KPI/월간_KPI/{YYYY-MM}.md`

---

## 4. 분기 1회 — 전체 zip 백업 (30분)

분기마다 가족 회의 후 다음 작업:
1. Drive의 `월인가 술빚는날` 폴더 → 우클릭 → 다운로드 (전체 zip)
2. 다운로드된 zip 파일을 OneDrive `99_백업_분기/{YYYY-Q#}.zip` 으로 이동
3. 또는 외장 하드디스크 등 **물리적 백업도 추가** (권장)

> 💡 **분기 백업은 "재해 복구"용**. 구글 계정 잠김·OneDrive 사고 등 극한 상황 대비.

## 5. 연 1회 — 아카이브 (1시간)

## 8. 사고 시 복구 시나리오

### 시나리오 A — 구글 계정 잠김
1. OneDrive `00_AI_체계/`는 살아있음
2. Drive `99_백업/{최근분기}.zip`이 OneDrive에도 있는지 확인
3. 분기 백업으로 재구성

### 시나리오 B — OneDrive 계정 잠김
1. Drive의 `월인가 술빚는날/` 전체가 살아있음
2. 운영 기록부는 구글시트가 원본이라 안전
3. 사령탑 AI 작업물은 분기 zip에서 복구

### 시나리오 C — 둘 다 사고
1. **분기 외장 하드디스크 백업이 있다면** 그것으로 복구
2. **없으면** 최악의 경우 가족 카톡 단톡에 사진·메시지 남아있음

> **권장:** 분기 1회 외장 하드디스크 백업 추가. 가장 저렴한 보험.
