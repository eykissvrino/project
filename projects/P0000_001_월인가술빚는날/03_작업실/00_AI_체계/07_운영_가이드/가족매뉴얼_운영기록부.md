- ✅ **요약 시트 3종 신규** — 매번 합계 계산 안 해도 됨

- ✅ **SUMIFS 자동 합계** — 데이터 입력 시 즉시 갱신
- ✅ **매년 새 파일 만들 필요 없음** — 한 파일에 누적

## 2. 구글시트 변환 (5분)

본 xlsx 파일을 **구글시트로 변환**해서 가족이 함께 쓰기:

1. **구글 드라이브** → `🟢 가족공유_운영기록/` 폴더 진입
2. **파일 업로드** → `월인가_운영기록부_마스터_v1.xlsx` 선택
3. 업로드 완료된 파일 우클릭 → **Google 스프레드시트로 열기**
4. 자동 변환됨 → 변환된 시트는 그대로 두고 **원본 xlsx는 삭제**(또는 백업으로 보존)
5. **공유 버튼** → 가족(어머니·아버지·태균이) 이메일 추가, 권한: 편집자
6. 시트 이름을 `월인가 운영기록부 (Master)`로 변경

> 💡 **드롭다운 메뉴·자동 합산이 그대로 유지됩니다.** 셀 색상도 유지.

## 3. 가족별 사용법

### 🌙 어머니·아버지 (부모님)

**직접 입력 안 하셔도 됩니다.** 평소처럼 양조하시고, 다음 4가지만 사령탑(이석주)에게 전달:

| 상황 | 보내실 정보 | 어떻게 |
|------|------------|--------|
| 원료가 들어옴 | "○월 ○일 / 품목 / 수량 / 매입처 / 금액" | 카톡 한 줄 + 사진 1장 |
| 양조 단계 변화 | "오늘 누룩 깨움" / "병입 50병" 같은 한 마디 | 카톡 + 사진 1장 |
| 출고·판매·시음 | "약주 2병 손님 김○○에게 / 25,000원" | 즉시 카톡 |
| 월말 재고 | 월말에 양조장 재고 한 번 둘러보고 사진 | 월말 카톡 |

> 시트 직접 입력은 권하지 않습니다. **양조에 집중하시면 됩니다.**

### 🧭 이석주 (사령탑)

- 받은 카톡·통화 내용을 그날 안에 해당 시트에 입력
- 매월 1일 04 재고관리 마감 점검
- 매월 25일 03 출고판매기록 합산 → 주세 신고 작업
- 분기 1회 06 시음QC 검토 + 외부 자가품질검사 의뢰

### 🌾 이태균 (술 빚는이)

- 시제품·실험은 02 양조일지의 "시제품" 구분에 별도 행
- 박람회·체험 행사 진행 시 07 고객체험에 직접 입력
- 양조 현장 이슈 발생 시 사령탑에 즉시 보고

### 🤖 AI 팀

- **재무 매니저**: 03 출고판매 → 월간 KPI 자동 보고
- **행정 매니저**: 03 합산 → 분기 주세 신고서 초안
- **콘텐츠 디렉터**: 02 양조일지 → 콘텐츠 소재로 활용

## 5. 시트별 핵심 입력 팁

### 01 원료수불부
- **드롭다운 활용** — 구분(입고/사용/폐기), 품목(쌀/누룩/국화 등) 자동 선택
- 단가만 입력하면 **금액은 자동 계산**
- 매입처는 "성명·상호" 형식 (법정 의무 사항)

### 02 양조일지
- **배치ID** 형식: `2026Q2-001` (분기-순번)
- 한 배치당 한 행만. 담금일 → 제성일 사이의 메모는 비고에
- 시제품도 같은 시트, 주종에 "시제품"으로

### 03 출고판매기록 (가장 자주 입력)
- 발생 즉시 입력이 원칙 (분기 합산이 주세 신고 baseline)
- **드롭다운**: 채널(7종), SKU(현재 4종)
- 단가 입력하면 **금액 자동 계산**
- 분기 끝나면 합계 행에서 자동 합산

### 04 재고관리
- 월 1행 원칙 (월별로 누적)
- **이월 = 전월 이월 + 입고 - 사용** (자동 계산)

### 05 부산물폐기
- 처리 방식 드롭다운 (사료·퇴비·자가소비·위탁폐기 등)
- 관련 배치ID와 연결하면 양조일지와 추적 가능

### 06 시음QC
- 시음·자가품질·외부검사 모두 같은 시트
- 도수·pH 등 측정값 가능한 한 정확히

### 07 고객체험 ⚠️
- **개인정보 마스킹**: 이름은 "김○○", 연락처는 일부만
- 동의 여부 필수 체크
- 외부 공유 절대 금지

## 6. 분기·월간 자동 흐름 (v2 — 자동 요약 활용)

```
매월 1일  →  04 재고관리 월말 마감 + 08 월별요약 자동 갱신 확인
매월 25일 →  09 분기요약 보고 → 주세 신고서 초안 (분기 종료 다음 달)
분기 종료 →  09 분기요약의 해당 분기 행 → 신고서 baseline
연 1회   →  10 연도요약으로 KPI 회의 + 농업경영체 자격 갱신
```

### v2의 강점: 매번 합계 직접 계산 안 해도 됨

- v1: 03 시트 끝 합계 행을 매번 확인
- v2: 09 분기요약 시트에서 **연도·분기별로 자동 합산** (5년치 미리 행 준비됨)

예시 — 2026년 2분기 주세 신고 (7월 25일까지):
1. 09 분기요약 시트 열기
2. `2026 / Q2` 행 확인 → 총 매출·주세·교육세 합계 자동 표시
3. 그 숫자를 신고서에 사용
4. H열(신고 상태)에 "신고완료" 표시

## 7. 보존·백업 (지속 운영)

- 본 시트는 **5년+ 누적 사용** — 매년 새 파일 만들지 않음
- 매월 1일 사령탑이 PDF 다운로드 → `99_백업/{YYYY}/` 보관
- 분기마다 전체 zip 백업 (구글드라이브 다운로드 → 로컬)
- **5년 누적 시점에 대응:**
  - 옵션 A) 그대로 계속 누적 (구글시트는 1만 셀 이상 무리 없이 처리)
  - 옵션 B) `_Archive_{시작연도-종료연도}.xlsx`로 사본 분리 + 본 파일은 계속 사용
- **행 부족해질 때:** 사령탑이 행 추가 + 수식 복사. 또는 본 v2.x 갱신 요청

## 8. 첫 시범 운영 (1개월)

**Week 1**
- xlsx 업로드 → 구글시트 변환 → 가족 공유
- 가족 카톡에 변환된 시트 링크 공유
- 부모님과 짧게 통화: "이렇게 해두었어요, 평소처럼 보내주시면 돼요"

**Week 2~3**
- 사령탑이 매일 카톡·통화 받은 내용을 시트에 입력
- 부족한 정보가 있으면 부모님께 한두 번 추가 확인

**Week 4 (월말)**
- 04 재고관리 첫 마감
- 1개월 운영 회고 — 어떤 시트가 잘 쓰였고 어떤 게 안 쓰였는지
