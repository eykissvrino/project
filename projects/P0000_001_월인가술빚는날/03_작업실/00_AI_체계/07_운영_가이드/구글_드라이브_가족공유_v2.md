# 📂 구글 드라이브 가족공유 시스템 v2

> v1(옵션 B 기반) + 법령 의무 기록부 영역을 통합한 **가족 4인 운영 시스템**.
> 부모님은 양조에 집중, 사령탑은 외부에 집중, 의무 기록은 가족이 함께 채운다.

---

## 1. 전체 폴더 구조 (3 영역)

```
[Google Drive] / 월인가 술빚는날/
│
├── 🟢 가족공유_운영기록/          ← ★ 의무 기록부 영역 (가족 함께 채움)
│   ├── 00_사용가이드/             가족 매뉴얼·카톡 안내 문구
│   ├── 01_원료수불부/             원료 입고·사용 기록 (의무 ①②③)
│   ├── 02_양조일지/               양조·발효 일지 (의무 ③④⑤)
│   ├── 03_출고판매기록/           반출·판매 기록 (의무 ⑦ + 주세 신고)
│   ├── 04_재고관리/               월말 마감·재고 (의무 ⑧)
│   ├── 05_부산물폐기물/           부산물 기록 (의무 ⑥)
│   ├── 06_시음QC/                 자가품질·시음 노트
│   └── 07_고객체험명단/           단골·시음회 (개인정보 주의)
│
├── 🟡 가족공유_일상/              ← 부담 없이 쓰는 일상 영역
│   ├── 사진_갤러리/               양조 단계·시제품 사진
│   ├── 영수증_매입/               월별 폴더, 사진 업로드만
│   └── 단톡_백업/                 중요 카톡 이미지 보존
│
└── 🔴 사령탑_전용/                ← 이석주 + AI 백오피스 영역
    └── (OneDrive와 동일 구조 — 00_AI_체계 등)
        ※ 사령탑 작업 메인은 OneDrive, Drive는 백업·공유용
```

## 2. 영역별 권한 매트릭스

| 폴더 | 부모님 | 이석주 | 이태균 | AI |
|------|--------|--------|--------|-----|
| 🟢 가족공유_운영기록/ | ✅ 편집 (해당 시트만) | ✅ 편집 | ✅ 편집 | ✅ 읽기 |
| 🟡 가족공유_일상/ | ✅ 편집 (사진 업로드) | ✅ 편집 | ✅ 편집 | ✅ 읽기 |
| 🔴 사령탑_전용/ | ❌ | ✅ 편집 | 🟡 (선택) | ✅ 편집 |

> 🔒 **민감정보(개인정보·면허번호·계좌)** 는 사령탑_전용에만 보관. 가족공유 영역에서는 마스킹.

## 3. 의무 기록부 운영 원칙

### 3.1 누가 어디를 채우나

| 시트 | 1차 입력자 | 사령탑 정리 |
|------|-----------|------------|
| 01_원료수불부 | 부모님 (입고 시 카톡) → 사령탑이 입력 | 사령탑 |
| 02_양조일지 | 부모님 통화·사진 → 사령탑이 입력 | 사령탑 |
| 03_출고판매기록 | 사령탑 (주문·매출 발생 시) | 사령탑 |
| 04_재고관리 | 부모님 월말 점검 → 사령탑 입력 | 사령탑 |
| 05_부산물폐기물 | 부모님 (월 1회 보고) | 사령탑 |
| 06_시음QC | 부모님 (시음 후) → 사령탑 정리 | 사령탑 |
| 07_고객체험 | 사령탑 (체험·시음회 운영 시) | 사령탑 |

> 💡 **부모님은 "보고"만**. 시트 직접 입력 강요 X. 카톡·통화·종이 메모 → 사령탑 정리.

### 3.2 입력 흐름 예시

```
부모님: [카톡] "오늘 찹쌀 50kg 들어옴, 대농 김씨네서 받음"
        ↓
사령탑: 01_원료수불부에 입력 (일자·품목·수량·매입처·단가)
        ↓
AI: 월말에 자동 합산 + 04_재고관리 시트로 연동
```

## 4. 분기·월간 자동화 흐름

### 4.1 매월 25일 (주세 신고 직전)
1. 03_출고판매기록 → 자동 합산 (분기 분)
2. 사령탑이 월별주류반출명세서 + 주류 수불상황표 작성
3. 행정 매니저 AI가 검수
4. 신고 → 결과를 04_재고관리에 반영

### 4.2 매월 1일 (월간 마감)
1. 04_재고관리 시트의 자동 마감 함수 작동
2. 02_양조일지 + 01_원료수불부 → 04 갱신
3. 재무 매니저 AI가 월간 KPI 보고 (1쪽)

### 4.3 분기 1회
1. 03 출고판매 → 분기 주세 신고
2. 06 시음QC → 자가품질검사 점검
3. 행정 매니저 AI가 다음 분기 캘린더 업데이트

```
어머니, 아버지, 태균아 안녕!

우리 양조장 운영을 가족이 함께 정리할 수 있도록
구글 드라이브에 폴더를 만들었어. 링크 보낼게.
[Drive 링크]

복잡할 거 없고, 평소처럼 카톡에 사진·메모만 보내주시면
내가 정리해서 시트에 입력할게.

부모님은 양조에만 집중하시면 돼요.
나머지는 내가(+ AI 팀이) 다 처리할게! 😊
```

**원료 입고 시 부모님께:**
```
원료 들어왔을 때 이렇게만 보내주세요!
"○월 ○일 / 찹쌀 50kg / 대농 김씨네 / ○만원"
사진도 한 장 같이 보내주시면 더 좋아요.
```

**출고·판매 시 부모님께:**
```
누가 사가면 그 자리에서 한 줄만!
"○월 ○일 / 약주 375ml ○병 / 손님 김○○ / 25,000원 ×N"
또는 그냥 카톡 사진 한 장도 OK.
```

## 6. 보존·백업

- 모든 시트는 **5년 보존** 원칙 (주류 면허·세무 일관)
- 매월 1일 사령탑이 그 달의 시트를 PDF로 변환 → `99_백업/{YYYY-MM}/` 보관
- 분기마다 전체 zip 백업
- 민감정보 (개인정보·계좌) 외부 노출 금지
