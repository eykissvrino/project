# 🟢 구글 드라이브 셋업 체크리스트 (옵션 B · 30분 완료)

> 사용자(이석주)가 직접 따라하면서 체크하는 가이드. 끝나면 Drive에서 가족·외부 협업이 시작된다.

---

## 적용 옵션: **B. 역할 분리**
- **OneDrive (현재 사용 중)** — 사령탑 작업의 메인 원본 (`00_AI_체계/`, `사업 행정 관리/`)
- **Google Drive (지금 셋업)** — 가족 공유 + 외부 공유 + 양조 일지 사진 업로드용

---

## ✅ 30분 작업 흐름

### Step 1. 마스터 폴더 생성 (3분)

1. drive.google.com 접속 (이석주 본인 계정)
2. **새로 만들기 → 폴더** → 이름: `월인가 술빚는날`
3. 색상: 갈색 또는 주황 계열 (눈에 잘 띔)

### Step 2. 하위 폴더 6개 생성 (5분)

`월인가 술빚는날/` 안에 다음 폴더들 만들기:

```
월인가 술빚는날/
├── 01_양조_일지/         ← 부모님 사진 업로드용 (단방향)
│   └── 2026-05/         ← 매월 폴더 자동 생성 예정
├── 02_시제품_갤러리/     ← 사진·메모 비공식
├── 03_콘텐츠_발행본/     ← 최종 발행 SNS·블로그 백업
├── 04_외부_공유/         ← 거래처·미디어용 (링크 공유)
│   ├── 미디어킷/
│   └── 거래처용/
├── 05_가족_공유참고/     ← 부모님 보기용(읽기 권한)
└── 99_백업/              ← OneDrive 백업본
    └── 2026/
```

✅ 체크: 6개 최상위 폴더 생성 완료 ☐

### Step 3. 부모님 카톡으로 양조 일지 폴더 공유 (5분)

1. `01_양조_일지/2026-05/` 우클릭 → **공유**
2. 부모님(어머니·아버지) 구글 계정 추가
   - 어머니 계정 (사용 중이신 Gmail): _______________
   - 아버지 계정 (사용 중이신 Gmail): _______________
3. 권한: **편집자**
4. **링크 복사**해서 가족 카톡방에 다음 메시지와 함께 붙여넣기:

```
어머니, 아버지 양조장 사진 올리실 때 여기로 올려주세요!
[Drive 링크]
복잡하면 그냥 카톡 단톡에 사진 보내주셔도 돼요. 제가 정리할게요. 🙂
```

✅ 체크: 부모님 카톡으로 링크 전달 ☐

> 💡 부모님이 Drive 사용 부담스러우시면 **카톡으로 사진 보내시는 방법**을 그대로 두셔도 됩니다. 사령탑이 정리합니다.

### Step 4. 외부 공유 정책 기본값 설정 (5분)

`04_외부_공유/` 폴더 우클릭 → **공유** → **링크 공유** 설정:
- 권한: **링크가 있는 모든 사용자 → 보기**
- 다운로드·인쇄·복사 비활성화 (옵션) ☐

✅ 체크: 외부공유 폴더 기본 정책 설정 ☐

### Step 5. OneDrive ↔ Drive 동기화 작업 흐름 메모 (5분)

매주·매월 실행할 동기화 규칙 — 사령탑(이석주)만 알면 됨:

| 빈도 | 작업 |
|------|------|
| 즉시 | 콘텐츠 발행 시 → `03_콘텐츠_발행본/`에 사본 업로드 |
| 주 1회 | OneDrive `08_캠페인/`의 새 자료 → Drive `03_콘텐츠_발행본/`로 사본 |
| 월 1회 | OneDrive `01_설계_문서/` + `03_지식베이스/` zip 백업 → Drive `99_백업/2026/` |
| 분기 1회 | 전체 Drive 구조 점검·정리 |

> 자동화 도구(예: Backup and Sync, Drive for Desktop)를 쓰면 이 작업은 자동화됩니다.

✅ 체크: 동기화 작업 흐름 이해 ☐

### Step 6. (선택) Google Drive for Desktop 설치 (10분)

자동 동기화로 OneDrive처럼 쓰고 싶다면:

1. https://www.google.com/drive/download/ 에서 Drive for Desktop 다운로드
2. 설치 후 본인 계정 로그인
3. 동기화 폴더 선택 → `월인가 술빚는날` 마운트
4. 로컬에서 `G:\내 드라이브\월인가 술빚는날\` 형태로 접근 가능

> 이 단계는 선택사항. 안 해도 무방.
