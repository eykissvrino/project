# 🤝 부모님 ↔ 사령탑 정보 흐름 합의서 (초안)

> **이 합의서의 목적은 부모님께 새 일을 만드는 것이 아니다.**
> 평소 하시던 행동(통화·카톡·손글씨)을 그대로 두고, 사령탑이 디지털화하는 약속이다.

---

## 1. 합의 골자

| 누구 | 무엇을 한다 |
|------|--------------|
| **부모님** | 평소처럼 양조 · 시음 · 손님 응대 / 양조 일지는 손글씨 · 카톡 사진 · 전화로 전달 |
| **이석주(사령탑)** | 정기 통화·방문으로 듣고 정리 / 사진·일지를 디지털화 / 외부 일은 전부 책임 |
| **AI 팀** | 이석주가 정리한 자료를 분석·문서화·콘텐츠화 |

**원칙:** 부모님께 새 도구·새 절차·새 입력을 강요하지 않는다.

---

## 2. 3가지 정보 채널 (부모님 부담순)

### ① 정기 통화·방문 — 부담 0
- **빈도:** 주 1~2회 (현재 통화 빈도와 같거나 비슷)
- **내용:** 양조 진행 상황·재고·시음 후기·손님 이야기·재료 부족 등
- **사령탑 후속작업:** 통화 직후 메모 → `03_지식베이스/ops/journal/{YYYY-MM-DD}.md`로 정리

### ② 카톡 사진 한 장 — 부담 1
- **빈도:** 양조 단계 바뀔 때마다 가족 단톡에 사진 1장
- **메시지 형태 예시:**
  ```
  "오늘 누룩 깨움"
  "약주 거름 시작"
  "병입 50병 완료"
  ```
- **사령탑 후속작업:** 사진 + 한 줄 → AI가 양조 일지 자동 정리, 콘텐츠 소재로 활용

### ③ 손글씨 일지 → 월말 사진 — 부담 0 (이미 쓰던 방식)
- **빈도:** 월말 1회, 부모님이 쓰시던 일지를 이석주가 촬영
- **사령탑 후속작업:** OCR + 디지털 일지 통합 → 발효 데이터 누적

> 부모님은 ①, ②, ③ 중 **편하신 만큼만 하셔도 된다.** 안 해도 양조에 지장 없음.

---

## 3. 사령탑이 부모님께 드리는 약속

1. **양조 본업을 절대 방해하지 않는다.** AI 도구 학습·새 앱 설치 강요 금지.
2. **부모님 결정 사항은 부모님 결정.** AI 의견은 사령탑이 거른 후 전달.
3. **외부 일(세무·면허·정부지원·고객 응대·콘텐츠)은 사령탑이 책임진다.**
4. **민감 정보(개인 명의·계좌·면허번호)는 외부에 노출되지 않는다.**
5. **분기 1회 양조장에서 가족 회의** — 사령탑 운영 보고 + 부모님 의견 청취.

---

## 4. 부모님께 드리는 부탁 (선택)

다음 중 하실 수 있는 것만 골라주세요.

- [ ] 양조 단계가 바뀔 때 카톡에 사진 1장 보내기
- [ ] 한 달에 한 번 손글씨 일지 마지막 페이지 보여주기
- [ ] 시제품을 만드시면 한 모금씩 시음 후기를 단톡에 남기기
- [ ] 새 손님이 자주 오시면 어떤 분이었는지 한 줄 공유
- [ ] (위 모두가 부담스러우시면) 통화 때 그냥 평소처럼 말씀해주시기

> 한 가지도 안 하셔도 됩니다. 평소처럼 양조하시면 사령탑이 다 정리합니다.

## 5. 사령탑이 매주 드리는 보고

부모님께 매주 일요일 카톡으로 한 줄씩 정리 보고:

```
이번 주 사령탑 요약 (주{n}/2026):
- 매출: ○○만원 (전주 대비 ±%)
- 이번 주 콘텐츠: 인스타 ○건, 블로그 ○건
- 다음 주 일정: ○월 ○일 ○○ 행사
- 부모님께 부탁: ○○○ (있을 때만)
```

## 6. 합의 절차

이 합의서를 다음 단계로 부모님과 정리한다.

1. **인쇄해서 양조장에 두고** 가볍게 함께 읽기
2. **부담스러운 항목 표시** — 부모님이 빨간 펜으로 X 표시
3. **수정해서 v1.1 작성** — 부모님 의견 반영
4. **시작 시점 확정** — 시범 1개월 → 회고 → 정착
