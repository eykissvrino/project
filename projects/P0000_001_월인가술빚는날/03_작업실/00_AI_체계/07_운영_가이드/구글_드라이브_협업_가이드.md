## 1. 전체 구조

구글 드라이브에 다음 구조로 폴더를 동기화한다.
로컬 OneDrive(`C:\Users\eykis\OneDrive\vrin_AI_hub\projects\P0000_001_월인가술빚는날`)와 **동일한 트리** 를 유지하는 것이 핵심.

```
[Google Drive] / 월인가 술빚는날/
├── 00_AI_체계/                    ← 사령탑 운영 (가족 공유 X, 이석주 전용)
│   └── (로컬 폴더와 동일)
├── 사업 행정 관리/                ← 가족 공유 (읽기 권한)
├── 양조 일지/                     ← 부모님 사진 업로드용 (단방향)
│   └── {YYYY-MM}/
├── 시제품 갤러리/                 ← 사진·메모 비공식
├── 콘텐츠_발행본/                 ← 최종 발행 콘텐츠 백업
└── 외부_공유/                     ← 거래처·미디어에 공유할 자료
```

## 3. 동기화 방식

### 3.1 OneDrive ↔ Google Drive 양면 동기화 (권장 옵션)

**옵션 A — 단일 원본 + 수동 백업 (가장 단순)**
- 원본: **OneDrive (현재 사용 중)** → AI 작업이 빠른 곳
- 백업: 주 1회 구글 드라이브에 압축 업로드
- 장점: 충돌 없음, 단순
- 단점: 백업이 느림

**옵션 B — Google Drive를 가족 공유 영역만 사용**
- OneDrive: `00_AI_체계/`(사령탑 작업) + 모든 산출물 원본
- Google Drive: `양조 일지/`, `시제품 갤러리/`, `외부_공유/` 등 가족·외부 공유 영역만
- 이석주가 양쪽 동기화 담당
- 장점: 역할 분리 명확
- 단점: 두 곳 관리

**옵션 C — Google Drive 단일 원본 (Drive for Desktop 활용)**
- 모든 폴더를 구글 드라이브에 두고, Drive for Desktop으로 로컬 마운트
- AI는 마운트된 로컬 경로로 접근
- 장점: 단일 원본
- 단점: 인터넷 끊기면 작업 중단

> **추천: 옵션 B.** 사령탑 작업의 빠르기는 OneDrive에서, 가족·외부 공유는 Google Drive에서.

### 3.2 파일 이동 규칙
- 사령탑 산출물이 **외부 공유 단계**에 도달하면 → `외부_공유/`에 사본
- 양조 사진이 **콘텐츠 소스로 채택**되면 → 사령탑 작업 폴더로 사본 이동
- 원본은 항상 한 곳에만 — 사본임을 표시

## 4. 파일 명명 규칙 (모든 폴더 공통)

```
{YYYY-MM-DD}_{영역}_{대상}_{버전}.{확장자}

예시:
2026-05-09_콘텐츠_인스타_신제품약주_v1.md
2026-05-09_재무_월간KPI_2026-04_v1.md
2026-05-09_보도_5월시음회_v2.docx
2026-05-09_라벨_약주신제품_v3.png
```

**규칙:**
- 일자는 항상 ISO 형식(YYYY-MM-DD)
- 한글·영문 혼용 가능, 공백은 `_`로
- 버전은 `v1, v2, ... v_final` 형태
- 큰 변경마다 v 증가, 자잘한 수정은 같은 버전 덮어쓰기

## 5. 가족·외부 공유 정책

### 가족 공유
- 부모님과는 카톡 단톡으로 빠르게 → 정리는 이석주가 → 영구 보존은 Drive
- 부모님께 Drive 링크를 보낼 때는 **항상 폴더 단위** (개별 파일 X)
- 부모님은 Drive 사용을 강제받지 않음. **카톡 → 이석주 → Drive** 흐름이 기본

### 외부 공유 (거래처·미디어·정부)
- `외부_공유/`에 사본 → 그 폴더 안에서만 링크 공유
- 공유 권한: **링크 보유자 보기**만 (편집·다운로드 제한 추천)
- 공유 만료일 설정 (Drive 기능 활용)

## 7. AI(Claude)와 Drive 연결

현재 AI는 **로컬 파일(OneDrive)에 직접 접근**한다.
구글 드라이브 직접 연동이 필요할 경우, 다음 중 하나를 사용:

| 방식 | 권장도 | 설명 |
|------|--------|------|
| **Google Drive Desktop으로 로컬 마운트** | 🟢 즉시 가능 | 로컬 폴더처럼 보이게 하면 AI가 동일하게 접근 |
| **Google Drive MCP 연결** | 🟡 검토 후 도입 | 클라우드 직접 접근. 권한·민감정보 정책 점검 필요 |
| **사용자 수동 업로드/다운로드** | 🟢 단순 | 주요 산출물만 사용자가 직접 |

> 권장: 1단계로 Drive Desktop 마운트, 2단계로 MCP 직접 연결 검토.
