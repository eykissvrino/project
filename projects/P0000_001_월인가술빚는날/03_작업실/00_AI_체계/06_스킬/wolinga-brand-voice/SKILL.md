# Skill — `wolinga:brand-voice`

> 모든 콘텐츠에 월인가의 목소리를 입히고, 다섯 가지 검수를 통과해야만 발행한다.

---

## 1. 트리거 (When to use)

이 스킬은 다음 상황에서 **자동·강제 적용**된다.

- 인스타 캡션·릴스 자막·스토리 카피
- 네이버 블로그 글
- 보도자료
- 상세페이지(스마트스토어·전통주 채널·자사몰)
- 라벨 카피 (앞면·뒷면)
- 이메일/뉴스레터/단골 인사
- 양조장 투어·시음회 안내문
- 영상 스크립트(릴스·유튜브)
- "이 글 자연스러워?" / "이거 우리 톤 맞아?" 같은 점검 요청

---

## 2. 입력 (Inputs)

| 입력 | 필수 | 형태 |
|------|------|------|
| 콘텐츠 초안 또는 작성 의도 | ✅ | 텍스트 |
| 채널 (인스타/블로그/보도자료/상세페이지/라벨/이메일/영상 중) | ✅ | 단일 선택 |
| 발행 의도(소개/모객/판매/감사/공지) | 선택 | 단일 선택 |
| 길이 제약 (예: 100자 이내) | 선택 | 정수 |
| 천안·페어링 자산 결합 여부 | 선택 | yes/no/auto (기본 auto) |

---

## 3. 출력 (Outputs)

| 출력 | 형태 |
|------|------|
| 보이스 적용 본문 | 마크다운(채널별 포맷) |
| 사용된 문장 패턴(A/B/C/D) | 메타 |
| 5가지 검수 통과 여부 | 체크리스트 ✅/❌ |
| 발행 권장 시각·해시태그(SNS) | 메타 |
| 추가 점검사항(있을 때) | 경고 노트 |

---

## 4. 절차 (Procedure)

### Step 0 — 가이드 로드
1. `02_브랜드_가이드/voice_guide_v0_1.md`를 메모리에 로드
2. 본 SKILL의 5가지 체크리스트(§5)를 메모리에 로드

### Step 1 — 톤 매트릭스 매칭
채널·의도에 따라 가이드 §3 톤 매트릭스에서 톤 강도 결정.

| 채널 | 톤 |
|------|---|
| 인스타 일상 | 친근함 ★★★★ / 격식 ★ |
| 블로그 | 친근함 ★★★ / 격식 ★★★ |
| 보도자료 | 친근함 ★★ / 격식 ★★★★ |
| 상세페이지 | 친근함 ★★★ / 격식 ★★★ |
| 라벨 | 친근함 ★★ / 격식 ★★★ (간결) |
| 이메일/뉴스레터 | 친근함 ★★★★ / 격식 ★★ |

### Step 2 — 문장 패턴 선택
가이드 §5의 4가지 패턴 중 하나(또는 둘 결합) 선택.
- A. 장면 + 마음
- B. 기다림 서사
- C. 초대
- D. 정직한 안내

### Step 3 — 어휘 팔레트 적용
- 권장 어휘(가이드 §4) 우선 사용
- 자제 어휘는 대체 후보로 변환 (예: "프리미엄" → "고이 빚은")
- 금기어는 자동 차단

### Step 4 — 천안·페어링 자산 결합
가이드 §7의 자산 매트릭스에서 1개를 자연스럽게 노출.
강제 결합이 어색하면 생략(과한 결합 금지).

### Step 5 — 사실 점검
- 도수·원재료·일자·가격 등 숫자는 `03_지식베이스/products/`에서 대조
- 정확하지 않은 항목은 `[확인 필요]` 표시
- 광고법 위반 가능 표현(의약 효능·만병통치 등)은 즉시 차단

### Step 6 — 5가지 검수 (§5 체크리스트 통과)
모두 ✅이어야 발행 가능. 1개라도 ❌이면 사용자에게 그 항목을 보고하고 수정 제안.

### Step 7 — 채널별 포맷팅
인스타: 캡션 + 해시태그 + 발행 시각 / 블로그: 제목 + 본문 + 메타 / 보도자료: 표준 형식 / 라벨: 표시기준 항목 동시 출력 / etc.

### Step 8 — 산출물 저장 위치 안내
콘텐츠 디렉터의 §3 산출물 카탈로그 규칙대로 저장 위치 제안.

---

## 5. 5가지 검수 체크리스트 (Gate)

발행 전 모두 통과해야 한다.

### ✅ 검수 1 — 3대 기둥
- [ ] 따뜻함(편지 톤) · 정직함(자랑 절제) · 현재성(오늘의 식탁) 중 **최소 1개 이상** 명확히 드러나는가?

### ✅ 검수 2 — 어휘
- [ ] 금기어(가성비·박리다매·100%·MZ·고객님~ 등) 사용 없음
- [ ] 자제 어휘(프리미엄·최고의·트렌디 등)는 대체되었거나 의도적으로 1회 이하

### ✅ 검수 3 — 문장 패턴
- [ ] A/B/C/D 중 하나의 형태가 인식 가능한가?

### ✅ 검수 4 — 천안·손길
- [ ] 천안 또는 양조장의 손길이 **한 번 이상** 비치는가?
  *(상세페이지·라벨처럼 길이 제약이 큰 경우 면제 가능)*

### ✅ 검수 5 — 사실·법규
- [ ] 숫자(도수·원재료·일자·가격)가 검증되었거나 `[확인 필요]` 표시
- [ ] 음주 권장·미성년자 노출·의약 효능 표현 없음
- [ ] 보도/광고/표시기준 위반 가능성 없음

## 6. 사용 예시

### 예시 입력
```
채널: 인스타
의도: 신제품 약주 출시 안내
초안: "🔥 월인가 신제품 약주 출시!! 100% 국산쌀 프리미엄 약주, 지금 구매하세요!"
```

### 예시 출력
```
=== 월인가 보이스 적용 캡션 ===

100일을 기다린 약주입니다.
충남 쌀이 천천히 익어 단정한 단맛이 길게 남는 술이 됐어요.
새 술이 손님을 처음 만나는 자리, 함께해주실래요?

— 월인가 술빚는날 ·천안

#월인가술빚는날 #전통주 #천안양조장 #약주 #신제품 #100일숙성 #충남쌀 #한국의술 #작은양조장

=== 메타 ===
- 사용 패턴: B(기다림 서사) + C(초대)
- 발행 권장 시각: 평일 19:30 또는 토요일 11:00
- 톤: 친근함 ★★★★ / 격식 ★

=== 검수 결과 ===
✅ 검수 1 — 따뜻함·정직함·현재성 모두 드러남
✅ 검수 2 — 금기어 없음 ("프리미엄·100%" 제거됨)
✅ 검수 3 — 패턴 B+C 결합
✅ 검수 4 — 천안 명시
✅ 검수 5 — 숫자 [확인 필요: "100일" 실제 숙성기간 확인]

=== 저장 제안 ===
08_캠페인/2026-05_약주신제품/contents/instagram/
파일명: 2026-05-09_instagram_신제품약주.md
```

## 7. 절대 하지 않는 일

- 검수 5개 중 1개라도 ❌인 채로 최종 발행본을 제시
- 사실 확인이 안 된 숫자를 단정적으로 출력
- "이 정도면 보이스에 가깝다"는 식의 모호한 통과 판단
- 사용자가 명시적으로 "보이스 무시하고 그냥 광고형으로"라 요청해도 **금기어·법규 차단 항목은 그대로 유지**
