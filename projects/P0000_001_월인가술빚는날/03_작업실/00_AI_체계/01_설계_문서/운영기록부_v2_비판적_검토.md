## 1️⃣ 법적 관점 — 정말 안전한가?

### 1.1 주류 면허법 시행령 §25 8항목 충족도

### 1.2 약점 — 법적 리스크 3가지

#### 🔴 리스크 A: 인적사항 컬럼이 자유 텍스트
- **현재:** "대농 김○○ (천안)" 같은 한 줄 자유 입력
- **법령 요구:** 성명, 주소, 사업자번호(법인), 연락처 등 **구체적 인적사항**
- **위험 시점:** 세무조사·면허 점검 시 "기록 부실" 지적 가능
- **개선:** 별도 컬럼(상호/대표/사업자번호/주소/연락처)으로 분리

#### 🟡 리스크 B: 마스킹 권장의 양면성
- **현재 가이드:** 개인정보 보호 위해 수취인 마스킹 권장
- **법령:** 수취인 인적사항을 **기록**할 의무
- **충돌:** 마스킹된 기록이 법령상 "기록 의무" 충족하는가? 모호함
- **개선:** 시트는 정확히 기록 + 외부 공유 시에만 마스킹 (2-tier 관리)

#### 🟡 리스크 C: 세금계산서·매출 증빙 연계 없음
- 03 출고판매 한 행 → 어떤 세금계산서와 연결되는지 추적 불가
- 세무사 검토 시 "이 매출이 어떤 거래인가" 역추적 어려움
- **개선:** 세금계산서 번호·인보이스 번호 컬럼 추가

### 1.3 보존 기간 명확화 필요

| 자료 | 일반 권장 보존 |
|------|----------------|
| 주류 장부 | **5년** (세법 기본·세무조사 시효) |
| 세금계산서 | **5년** |

## 2️⃣ 경영관리 효율성 — 정말 일을 빠르게 만드는가?

### 2.1 강점

1. **자동 합계** (08·09·10) — 분기 신고 시간 단축
2. **드롭다운** — 일관성 보장
3. **5년+ 누적** — 매년 새 파일 X
4. **법령 의무 한 곳에** — 사령탑 머리 절감
5. **부모님 직접 입력 부담 0** — 학습 곡선 없음

### 2.2 약점 — 효율성을 갉아먹는 5가지

#### 🔴 약점 1: **사령탑 1인 입력 의존 = 병목**
- 모든 카톡·통화·종이가 사령탑을 거쳐 시트로
- 사령탑 1주만 빠져도 → 누락·소급 입력 부담
- **현실 시나리오:** 한 달 바쁘면 시트 한 달치 밀림 → 분기 신고 직전 야근

#### 🔴 약점 2: **시트가 11개 = 인지 부담**
- 부모님은 절대 안 봄 (시트 자체가 위협적)
- 사령탑도 "이 정보가 어느 시트?" 매번 헷갈림
- 신규 SKU 출시 시 → 02·03·04·06 4개 시트 동시 갱신 필요

#### 🟡 약점 3: **카톡→시트 자동화 없음**
- 사령탑이 매번 손으로 옮김 = 매주 30분~1시간 반복 노동
- 이건 정확히 AI가 자동화해야 할 일인데 미구현
- **권고:** 카톡 메시지 → AI 호출 → 시트 행 자동 생성 워크플로

#### 🟡 약점 4: **이상 감지·알림 없음**
- 마이너스 재고, 누락된 일자, 비정상 수치 등 자동 경고 X
- 분기 끝나서야 "어 이상한데?" 발견
- **권고:** 조건부 서식·검증 규칙·알림 추가

#### 🟡 약점 5: **시각화 거의 없음**
- 08·09·10 요약 시트는 표만
- 매출 추세선, 채널별 파이 차트, SKU별 비중 차트 등 없음
- 매월 KPI 보고 시 사령탑이 수동으로 그래프 만들어야

#### 🟢 약점 6: **마스터 데이터 분리 안 됨** (자산화 영역과 겹침)
- SKU 정보·거래처·직원이 시트 안에 텍스트로 흩어짐
- 한 번 거래처가 바뀌면 → 모든 행 수정 불가능
- **권고:** 별도 마스터 시트 (SKU·거래처·직원) → ID로 참조

## 3️⃣ 데이터 자산화 — 5년 후 가치 있을까?

### 3.1 핵심 질문 — "5년 후 이 데이터로 무엇이 가능한가?"

이상적으로는 다음이 가능해야 합니다:
- 발효 패턴 학습 → 품질 예측
- 채널·SKU별 매출 예측 → 생산 최적화
- 고객 LTV·이탈 예측 → 마케팅 효율
- 시즌·날씨·이벤트별 수요 분석
- 부자재 단가·환율 등 외부 변수와 매출의 상관관계

### 3.2 v2로 가능한가? — 솔직히

| 분석 영역 | v2로 가능? | 부족한 것 |
|----------|-----------|-----------|
| 매출 추세 | 🟢 가능 | 시각화만 추가하면 됨 |
| SKU별 비중 | 🟢 가능 | 시각화·필터 |
| 채널별 수익성 | 🟡 부분 | 원가 데이터를 시트에서 직접 못 봄 |
| 발효 품질 예측 | 🔴 불가 | 온도·습도·시간 단위 데이터 부재 |
| 고객 LTV·이탈 | 🔴 불가 | 고객 ID 없음, 반복 구매 추적 불가 |
| 시즌·날씨 상관 | 🔴 불가 | 외부 데이터 import 구조 없음 |
| 부자재 단가 영향 | 🟡 부분 | 단가 변동 시점만 알면 됨 |

### 3.3 데이터 자산화 약점 3가지

#### 🔴 약점 7: **정량적 시음 척도 없음**
- 06 시음QC가 "관능(향)·관능(맛)" 자유 텍스트
- 5점 척도, 9점 척도 등 정량적 평가 시스템 없음
- → 5년 후 "어떤 배치가 좋았나" 정량 비교 불가
- **권고:** 향·맛·바디·균형·여운 5축 9점 척도

#### 🔴 약점 8: **고객 ID 시스템 없음**
- 07 고객체험에 이름은 있지만 고유 ID 없음
- "김선생님"이 여러 거래에 나오면 → 같은 사람인지 모름
- 반복 구매·LTV 추적 불가
- **권고:** 고객 ID 컬럼 추가 (마스킹된 해시 ID)

#### 🟡 약점 9: **외부 데이터 import 구조 없음**
- 스마트스토어 매출, 카드결제, 날씨, 환율 등을 시트에 자동 가져오는 흐름 없음
- 모두 수동 입력 → 누락·오류 가능
- **권고:** 구글시트 IMPORTDATA, IMPORTHTML, Apps Script 활용 가이드

## 5️⃣ v4.0 개선 권고안

### 5.1 우선순위 P0 (법적 안전 — 즉시)

1. **인적사항 분리 컬럼**
   - 01 원료수불부 매입처 → 상호/대표/사업자번호/주소/연락처 5컬럼
   - 03 출고판매 수취인 → 동일 5컬럼
   - 외부 공유 시 마스킹 별도 시트(`07_고객체험_공유본`) 자동 생성

2. **세금계산서·인보이스 번호 컬럼**
   - 03 출고판매에 "세금계산서번호" 컬럼 추가
   - 분기 신고 시 매칭 검증 가능

3. **밑술·술덧 별도 추적**
   - 02 양조일지에 "밑술/술덧" 행 종류 추가 또는 별도 시트

### 5.2 우선순위 P1 (효율성 — 1~2개월)

4. **카톡 → 시트 AI 자동화 워크플로**
   - 사령탑이 카톡 메시지를 AI에 그대로 붙여넣기
   - AI가 어느 시트의 어느 컬럼에 들어갈지 자동 변환
   - 사령탑은 검토 후 한 번에 시트에 행 추가

5. **마스터 데이터 시트 분리** (신규)
   - `SKU_마스터/` — SKU ID, 이름, 가격, 마진, 라벨 정보 등
   - `거래처_마스터/` — 거래처 ID, 인적사항 전체
   - `직원_마스터/` — 가족 4인 + 외부 협력자
   - 기록부의 다른 시트는 이 마스터를 **ID로 참조** (VLOOKUP)

6. **조건부 서식·검증 규칙**
   - 마이너스 재고 → 빨간색 강조
   - 일자 누락 → 노란색
   - 비정상 수치 → 자동 경고

### 5.3 우선순위 P2 (자산화 — 3~6개월)

7. **시각화 대시보드 시트** (신규)
   - 매출 추세선·SKU 비중 파이·채널별 막대 차트
   - 구글시트 내장 차트로 즉시 가능

8. **정량적 시음 척도** (9점 5축)
   - 06 시음QC에 점수 컬럼 5개 추가
   - 5년 누적 시 배치 간 비교 분석 가능

9. **고객 해시 ID 시스템**
   - 07 고객체험에 이름+연락처 해시한 고유 ID 컬럼
   - 반복 거래 추적 가능, 개인정보 보호 동시 가능

10. **외부 데이터 import 가이드**
    - 스마트스토어 매출 CSV 자동 가져오기 (Apps Script)
    - 날씨 데이터 API import
    - 분기 자동 보고서

운영기록부를 더 발전시키는 대신, **전용 도구로 옮길 수 있는가**?

| 도구 | 강점 | 약점 | 월 비용 | 추천 시점 |
|------|------|------|---------|----------|
| **현 구글시트 v2/v4** | 무료·자유도·가족 이미 사용 | 자동화·시각화 한계 | 0원 | **지금 (3년)** ★ |
| **Notion** | 데이터베이스+문서 통합·시각화 우수 | 한국어 검색·법적 양식 부재 | 무료~₩12,000 | 데이터 자산화 단계 |
| **Airtable** | 진짜 데이터베이스·자동화 강력 | 한글 약함·학습 곡선 | 무료~$24 | 5년 시점 |
| **이카운트 ERP** | 한국형 회계·세금계산서 통합·세무사 친화 | 양조 특화 X·UI 무거움 | 월 ₩30,000~ | 매출 月1억 시점 |
| **더존 SaaS** | 세무·회계 완벽·법령 자동 반영 | 비쌈·소상공인 과잉 | 월 ₩50,000~ | 매출 月3억 시점 |
| **국세청 홈택스 직접** | 무료·공식 | 양조·재고 미지원 | 0원 | 세무 신고만 |

### 6.1 한 줄 권고

> **현 단계: 구글시트 v2 → v4 개선이 가장 가성비.**
> **3년 후 (매출 月3,000만 이상): Airtable 또는 이카운트로 데이터 이관 검토.**
> **5년 후 (매출 月1억+): 전용 ERP 도입 검토.**

- 효과: 3년 후 데이터 자산화 가능, 사령탑 부담 절반

### 옵션 C — 외부 도구 이관 (Airtable 또는 이카운트)
- 비용: 월 ₩12,000 ~ ₩50,000
- 부담: 마이그레이션 1개월, 가족 재교육
- 권장: 매출이 月1,000만 이상 안정화된 후

## 8️⃣ 결론 — 사용자의 "최선인가?"에 대한 답

**아니요, v2는 최선이 아닙니다.**
"현 단계에서 가능한 최선"이 더 정확한 표현입니다.

- **법적으로는** 큰 문제 없지만 인적사항·세금계산서 보강 필요
- **효율성은** 사령탑이 흔들리면 무너지는 구조
- **자산화는** 1~2년치 누적은 자료, 3년 이상은 분석 가치 약함

**진짜 최선은:**
1. 지금: v4 P0 (법적 안전 보강) 즉시 적용
2. 1년: v4 P1 (효율성·자동화) 점진 적용
3. 3년: 외부 도구 이관 검토
