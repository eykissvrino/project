# 월인가 술빚는날 — AI 경영 체계 마스터 설계 (v1.0)

> 가족 4인 양조장이 1인 인력으로 다인 업무를 감당하기 위한 AI 에이전트·스킬·지식베이스 통합 설계도

| 항목 | 내용 |
|------|------|
| 작성일 | 2026-05-09 |
| 작성자 | 이석주(술 길잡이) ·  AI 설계 파트너 |
| 버전 | v1.0 — 마스터 설계 |
| 다음 검토 | Phase 0 종료 시점 |

---

## 1. 설계 철학 (3원칙)

1. **가족 4인 역할에 1:1 매핑** — 누가 어떤 AI를 어떻게 쓸지 처음부터 명확.
2. **전통주 산업 특수성 우선 반영** — 주류면허·주세·통신판매 특례 등 일반 비즈니스 AI 솔루션이 못 다루는 영역을 핵심에 배치.
3. **단계적 도입** — MVP → 확장 → 고도화 3단계. 각 단계마다 "이걸 안 하면 망한다"가 아니라 "이걸 하면 1주 시간이 빈다"가 도입 기준.

---

## 2. 비즈니스 가치사슬 ↔ 4인 역할 매핑

월인가 술빚는날의 일은 크게 6개 가치사슬로 흐릅니다. 각 단계에 가족 누가 주축인지 정리하면 다음과 같습니다.

| 가치사슬 단계 | 핵심 활동 | 1차 책임자 | 2차 협업자 |
|---------------|-----------|------------|------------|
| ① 생산(Production) | 원재료·양조·발효·여과·숙성·병입 | 술 빚는장인 | 술 빚는이 |
| ② 품질·재고 | 시음·QC·재고·출고 | 술 빚는장인 | 술 빚는이·온기지기 |
| ③ 브랜딩·콘텐츠 | 스토리·SNS·블로그·보도자료·굿즈 | **술 길잡이** | 온기지기 |
| ④ 판매·유통 | D2C(스마트스토어·전통주채널)·도매·체험 | 온기지기 | **술 길잡이** |
| ⑤ 고객(CRM) | 응대·후기·시음회·단골관리 | 온기지기 | 술 빚는이 |
| ⑥ 행정·재무·규제 | 주류면허·주세·세무·정부지원사업 | 온기지기 | 술 빚는장인 |

> **시사점** — 사용자(이석주, 술 길잡이)는 ③ 브랜딩과 ④ 판매전략이 본업. AI 체계 첫 도입의 ROI가 가장 큰 영역도 여기입니다.

## 3. AI 에이전트 아키텍처

### 3.1 전체 구조 (3 Layer)

```

│  Layer 0 — 오케스트레이터(중앙 관제)                         │

└─────────────────────────────────────────────────────────────┘
        │            │             │             │
        ▼            ▼             ▼             ▼
┌──────────────┬──────────────┬──────────────┬──────────────┐

├──────────────┼──────────────┼──────────────┼──────────────┤
│ 🌙 술 온기지기│ 🍶 술 빚는장인│ 🧭 술 길잡이 │ 🌾 술 빚는이 │
│   AI         │   AI         │   AI         │   AI         │
│ (김지은/대표)│ (이제동/이사)│ (이석주/전략)│ (이태균/현장)│

        │            │             │             │

└─────────────────────────────────────────────────────────────┘
```

### 3.2 4대 역할 전문 에이전트

#### 🌙 술 온기지기 AI — "양조장의 따뜻한 얼굴" (김지은 대표)

| 영역 | 핵심 기능 |
|------|-----------|
| 일일 운영 | 아침 브리핑(매출·문의·일정), 주간 KPI 대시보드 |
| 고객 응대 톤 | "온기"가 살아있는 1차 응답 초안 작성 |
| 시음회·방문객 | 양조장 투어 시나리오, 단체 예약 응대, 시음 코스 추천 |
| 의사결정 지원 | 신제품·가격·채널 결정 시 데이터·옵션 비교표 제공 |

#### 🍶 술 빚는장인 AI — "발효 데이터 동반자" (이제동 이사)

| 영역 | 핵심 기능 |
|------|-----------|
| 양조 일지 | 음성/사진 입력 → 디지털 일지 자동화 (당도·온도·pH) |
| 레시피 관리 | 배합비·발효시간·숙성조건 버전관리(레시피 형상관리) |
| 이상 감지 | 발효 곡선 이탈 시 알림 + 과거 사례 추천 |
| 원재료 | 쌀·누룩·부재료 발주 캘린더, 거래처 단가 비교 |
| 품질관리 | HACCP 체크리스트, 시음 평가 기록 |

#### 🧭 술 길잡이 AI — "브랜드와 전략의 내비게이터" (이석주, 사용자)

| 영역 | 핵심 기능 |
|------|-----------|
| 콘텐츠 제작 | 인스타그램·블로그·유튜브 캡션·스크립트(브랜드 보이스 일관) |
| 페어링·스토리 | 제품×음식 페어링 콘텐츠, 양조 스토리, 계절 큐레이션 |
| 보도·PR | 보도자료, 미디어킷, 행사 소개글 |
| 시장·경쟁 | 전통주 시장 트렌드, 경쟁사 모니터링, 가격대 분석 |
| 정부지원사업 | 농림축산식품부·중기부·지자체 지원사업 발굴·신청서 초안 |
| 기획 문서 | 사업계획서, IR 덱, 캠페인 브리프 |

> **이 에이전트가 사용자(이석주)의 메인 도구**. 가장 먼저·가장 깊이 만들 가치가 있는 에이전트.

#### 🌾 술 빚는이 AI — "현장의 손과 눈" (이태균)

| 영역 | 핵심 기능 |
|------|-----------|
| 일일 체크리스트 | 양조장·창고·출고 동선 체크, 사진 기록 |
| 시제품 실험 | 신제품 아이디어·소량 테스트 기록·시음 후기 정리 |
| 현장 콘텐츠 | 작업 사진·영상 자동 캡션 → 술 길잡이로 전달 |
| 행사·박람회 | 부스 운영 체크리스트, 시음 응대 스크립트 |

### 3.3 공통 지원 에이전트 (4인 공유)

#### 📜 행정 집사 AI — 주류 산업 규제 전담

전통주 양조장의 진짜 무게는 **규제**에 있습니다. 일반 사업체 AI는 못 다룹니다.

- 주류면허(탁주·약주·소주) 갱신·변경 알림
- 주세 신고 일정·서식 가이드(매월 25일)
- 주류 라벨 표시기준(주류 종류, 도수, 원재료 함량 등) 검수
- 통신판매 주류 특례(전통주는 온라인 판매 가능) 절차
- 식품위생법·HACCP·환경 인허가 일정
- 정부지원사업 마감 캘린더(찾기·요약·신청서 초안)

#### 💰 재무 집사 AI

- 원가계산서 업데이트(이미 보유 중인 `원가계산서_230302.pdf` 기반)
- 월 매출·채널별 수익성 분석
- 부가세·종합소득세·주세 일정 알림
- 가성비 vs 프리미엄 SKU 마진 비교

#### 💬 CS 집사 AI

- 카카오톡·인스타·스마트스토어 문의 1차 응대 초안
- FAQ 자동 학습(자주 받는 질문 클러스터링)
- 후기·리뷰 모니터링 + 답글 초안

#### 🔍 리서치 집사 AI

- 전통주 트렌드, 페어링 트렌드, 경쟁 양조장 모니터링
- 미디어 멘션 추적
- 페어링 음식·계절 키워드 풀

## 4. 스킬(Skill) 카탈로그

스킬은 "어떤 작업을 어떻게 하는지에 대한 모범 사례"의 묶음입니다. **자체 제작 스킬**과 **기존 스킬 활용**을 조합합니다.

| 스킬 ID | 한 줄 설명 | 우선순위 |

## 5. 지식베이스(Knowledge Base) 구조

> AI 에이전트가 참조할 "회사의 두뇌". 한 번 정리해두면 모든 에이전트가 일관되게 답합니다.

```
P0000_001_월인가술빚는날/
├── 00_AI_체계/                          ← 신규 폴더 (이번 설계로 생성)
│   ├── 01_설계_문서/                    ← 본 마스터 설계
│   ├── 02_브랜드_가이드/                ← 보이스·비주얼·스토리
│   ├── 03_지식베이스/
│   │   ├── recipes/                     레시피 (탁주·약주·소주별 배합·발효 조건)
│   │   ├── products/                    SKU·가격·라벨·페어링
│   │   ├── customers/                   단골·시음회 참석자(개인정보 주의)
│   │   ├── regulations/                 주류면허·주세·라벨 표시기준
│   │   ├── ops/                         생산·재고·HACCP SOP
│   │   ├── partners/                    유통처·체험프로그램
│   │   └── finance/                     원가·매출 데이터
│   ├── 04_프롬프트_템플릿/              ← 자주 쓰는 요청 모음
│   └── 05_스킬_레지스트리/              ← 자체 제작 스킬
├── 사업 행정 관리/                      ← 기존
└── (앞으로 추가될 영업/생산/마케팅 폴더)
```

**기존 자산 → 지식베이스 매핑 예시:**
- `사업 행정 관리/02_제조면허증/*.pdf` → `regulations/licenses/`
- `사업 행정 관리/03_로고/` → `02_브랜드_가이드/visual/`
- `사업 행정 관리/원가계산서_230302.pdf` → `03_지식베이스/finance/`
- `사업 행정 관리/01/제품 생산공정도.pptx` → `03_지식베이스/ops/`

## 6. 단계별 구축 로드맵

### Phase 0 — 기반 정비 (지금 ~ 2주)

**목표:** AI 도입 전 토양 만들기.

- [ ] 워크스페이스 폴더 표준화 (위 5번 구조)
- [ ] 기존 자료(사업자등록·면허·로고·원가) 인덱싱
- [ ] **브랜드 보이스 가이드 v0.1** 작성 (목소리·금기어·예시문)
- [ ] 사용 도구 결정·연결 (스마트스토어, 인스타, 노션 등)
- [ ] 가족 4인 AI 활용 가이드 1쪽

### Phase 1 — MVP "통증 1순위 자동화" (1~2개월)

**목표:** 사용자(술 길잡이) 본업의 70%를 AI로 절반 시간에.

- [ ] 술 길잡이 AI 작동: 콘텐츠·SNS·보도자료·페어링
- [ ] 행정 집사 AI: 주류면허·주세·정부지원사업 캘린더
- [ ] 양조 일지 디지털 템플릿 (술 빚는장인용)
- [ ] CS 집사 AI: 자주 묻는 질문 응답 초안
- [ ] 월간 매출·채널 KPI 1쪽 대시보드

### Phase 2 — 통합 "가족 협업 OS" (3~6개월)

**목표:** 4인이 같은 정보로 일하게.

- [ ] 4개 전문 에이전트 모두 작동
- [ ] 재고-매출-원가 통합 대시보드
- [ ] D2C 운영 자동화(스마트스토어·전통주갤러리·와인앤모어 등)
- [ ] 시음회·체험 캠페인 자동화
- [ ] 단골 고객 세그먼트 마케팅

### Phase 3 — 고도화 "데이터 의사결정" (6~12개월)

**목표:** 양조와 영업의 데이터 자산을 무기화.

- [ ] 발효 데이터 패턴 분석(품질 예측·이상 감지)
- [ ] 고객 LTV·이탈 예측
- [ ] B2B(레스토랑·호텔·페어링) 채널 확장
- [ ] 수출 가능성 검토(시장·규제·물류)

| 협업 | 권장 | 노션(Notion) | 가족 4인 공동 위키 |
| 디자인 | 권장 | 캔바(Canva) | 빠른 시각 자산 생산 |
| 일정 | 권장 | 구글 캘린더 | 양조·발효·행사 일정 |
| 데이터 | 권장 | 구글시트 또는 Airtable | 재고·고객·매출 |
| 전통주 채널 | 선택 | 와인앤모어, 전통주갤러리, 더술닷컴, 대동여주도 | 전통주 특화 D2C |

## 8. 사용자 의사결정이 필요한 9가지

설계를 한 단계 더 발전시키기 위해 사용자(이석주)께 다음을 여쭙고 답을 기다립니다.

1. **사업 단계** — 오픈 직전 / 초기 운영 / 성장기 중 어디에 더 가까운가요?
2. **현재 매출 채널** — 이미 운영 중인 채널(스마트스토어·체험 등)이 있나요?
3. **온라인 자산** — 인스타·블로그·홈페이지 중 보유 또는 운영 중인 것?
4. **부모님 디지털 친숙도** — AI 기반 도구 사용에 거부감 정도?
5. **첫 1순위 통증** — Phase 1에서 가장 먼저 해결되어야 할 단 하나?
6. **예산 톤** — 무료/저비용 위주? 일부 유료 도구 도입 가능?
7. **데이터 보유** — 양조 일지·고객 명단·후기 등 디지털화된 자료가 얼마나 있는지?
8. **향후 1년 목표** — 매출액·SKU 수·체험 인원 등 구체 목표?
9. **하지 말아야 할 것** — 절대 기계화·자동화하면 안 되는 영역(예: 양조 직관, 핵심 인사 대면)?

## 9. 자체 검증 (Self-QA)

### 강점
- 가족 4인 역할에 1:1 매핑 → 도입 후 책임 구분 자연스러움
- 전통주 산업 특수 규제(주류면허·주세·통신판매 특례) 우선 반영
- 기존 스킬 70% 재활용 + 자체 제작 30% → 구축 비용·기간 최소화
- 단계적 도입 → "안 하면 큰일"이 아닌 "하면 시간이 빈다" 기준

### 가정·리스크
- **부모님 디지털 친숙도 미확인** → 술 온기지기·술 빚는장인 AI는 음성·짧은 입력 위주 권장
- **데이터 축적 정도 미확인** → Phase 3 머신러닝 부분은 데이터 6개월 이상 누적 후 시작 권장
- **온·오프라인 채널 운영 현황 미확인** → Phase 1 MVP의 일부 항목이 후순위로 이동 가능
- **개인정보 처리** — 단골 고객 DB는 개인정보보호법 대상. AI 학습용으로 평문 저장 금지

### 개선 여지
- 본 설계는 v1.0(전체 청사진). 9번의 의사결정 답변 후 v1.1에서 우선순위·규모 재조정 필요
- 분기별 회고 + 메모리 시스템(`memory/`)에 학습 누적 권장
