## 1. 한 줄 요약

## 4. AI(Claude)가 이 폴더에서 일할 때 워크플로우

### 일반 원칙
1. **항상 본 README + `01_설계_문서/`의 최신 v* 문서를 먼저 읽는다.**
2. **콘텐츠 작성 시** `02_브랜드_가이드/` + `06_스킬/wolinga-brand-voice/`를 강제 적용.
3. **사실 확인이 필요할 때** `03_지식베이스/`의 해당 도메인을 먼저 검색.
4. **새로운 요청은 어떤 AI 동료(`05_AI_팀/`)의 일인지 먼저 분류.**
5. **산출물은** 적절한 위치에 저장 + `09_세션로그/`에 일자별 요약 추가.

### 산출물 위치 규칙
| 산출물 | 저장 위치 |
|--------|-----------|
| SNS·블로그 캡션 초안 | `08_캠페인/{캠페인명}/contents/` |
| 보도자료 | `08_캠페인/{캠페인명}/pr/` |
| 사업계획서·IR 덱 | `01_설계_문서/strategic/` |
| 정부지원사업 신청서 | `03_지식베이스/regulations/gov-programs/{사업명}/` |
| 월간 KPI 보고 | `03_지식베이스/finance/monthly/{YYYY-MM}/` |
| 부모님 통화·방문 메모 | `03_지식베이스/ops/journal/{YYYY-MM-DD}.md` |
