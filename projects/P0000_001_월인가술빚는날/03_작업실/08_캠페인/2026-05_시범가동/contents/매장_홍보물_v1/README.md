## 2. 어떻게 쓰나요?

### A. 매장 가격표 인쇄

1. `01_매장_가격표.html` 더블클릭 → 크롬으로 열림
2. 키보드 `Ctrl + P` (인쇄)
3. **대상**: PDF로 저장 또는 직접 프린터
4. **용지**: A4
5. **여백**: 없음 (또는 "최소")
6. **배경 그래픽**: ✅ 켜기 (★ 중요 — 도자기빛 배경이 함께 인쇄됨)
7. 인쇄 미리보기에서 1장 안에 깔끔하게 들어가면 인쇄

> 💡 **추천**: 두꺼운 흰색 또는 미색 인쇄용지(120g 이상)에 인쇄해 가게 벽에 액자 또는 클립으로 부착.

### B. 전단지 인쇄·접지

1. `02_홍보_전단지.html` 열기 → `Ctrl + P`
2. 같은 인쇄 설정 (배경 그래픽 ✅)
3. **양면 인쇄**: 프린터에서 "양면 인쇄" 옵션 켜기. 또는 PDF로 저장 후 인쇄소에 의뢰
4. **인쇄소 발주 시**: "A4 양면 컬러, 무광 또는 반광택 종이, 150~200g" 추천

> 💡 인쇄소 의뢰 시 PDF 저장:
> `Ctrl + P` → 대상을 **"PDF로 저장"** → 파일로 보관 → 인쇄소 업로드

### C. SNS 카드뉴스 (인스타그램용)

1. `03_SNS_카드뉴스.html` 열기
2. 크롬 확대 100% (`Ctrl + 0`)
3. **방법 ①** — 윈도우 캡쳐 도구:
   - 시작 메뉴에서 "캡쳐 도구" 실행
   - 카드 한 장(1080×1080) 영역을 사각형으로 잘라내기
   - PNG로 저장
   - 5장 모두 동일하게 캡쳐
4. **방법 ②** — 크롬 개발자 도구 (정확):
   - 카드 위에서 마우스 우클릭 → **검사**
   - HTML에서 `<div class="card">` 위 우클릭 → **노드 스크린샷 캡처**
   - 자동으로 1080×1080 PNG 다운로드
5. 인스타그램 앱에서 게시물 5장 시리즈로 업로드

## 3. 디자인 컨셉

브랜드 가이드 (`02_브랜드_가이드/visual_guide_v0_1.md`) 기반:

- **컬러**: 도자기빛 베이지(`#EFDDC2`~`#D2B488`) · 도장 빨강(`#8B2A1F`) · 먹색(`#1F1A14`)
- **타이포**: Nanum Myeongjo(명조) + Nanum Brush Script(서예) — 한국 전통 분위기
- **장식**: 한지 노이즈 텍스처 + 모서리 구름 무늬 (브랜드 가이드 §5.1)
- **로고**: 가로형/세로형 둘 다 활용 (`月印家` 도장 + "술 빚는 날" 서예체)
- **여백**: 넉넉히 (브랜드 가이드 §7 — "여백을 두려워하지 않는다")

### 카피 톤
브랜드 가이드 §4 "프리미엄/럭셔리" 외래어는 자제하고, 대신:
- "고이 빚은", "정성껏 익힌", "천천히 익은"
- "한 잔의 편지", "사계절을 한 모금에"
- "한 잔, 같이 드시러 오시겠어요?" (CTA — 브랜드 보이스 패턴 C)

→ **고급감은 살리되 자랑·과시 톤은 배제** (편지 톤 유지)

## 5. 수정·재발행

### 가격이 바뀌면
각 HTML 파일에서 `25,000`, `12,000`, `70,000`, `19,000` 숫자만 찾아서 변경.

HTML 안에서 한국어 텍스트를 찾아 직접 수정. 다만 브랜드 보이스 가이드 (`voice_guide_v0_1.md`) 의 §4 어휘 권장·자제 목록을 참고하세요.
