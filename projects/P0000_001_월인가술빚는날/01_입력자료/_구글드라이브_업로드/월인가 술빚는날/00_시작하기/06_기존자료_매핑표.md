## 4. 이동 방식

### 방법 A — 사령탑이 직접 복사
- OneDrive에서 파일 우클릭 → 복사
- 구글 드라이브 웹에서 새 위치 진입 → 붙여넣기 (Ctrl+V) 또는 업로드

### 방법 B — Drive for Desktop 활용
- Drive for Desktop으로 G:\ 마운트
- 윈도우 탐색기로 드래그앤드롭

### 방법 C — 한꺼번에 zip 압축 후 업로드
- 기존 자료 폴더를 zip → 구글 드라이브 업로드 → 압축 풀기

## 5. 중요 — 원본 유지 vs 이동

| 자료 유형 | 권장 |
|-----------|------|
| 면허·사업자등록 등 공식 문서 | **사본**을 구글 드라이브에. **원본**은 OneDrive 보존 |
| 로고·라벨 등 작업 가능 자산 | **사본**을 구글 드라이브에 (편집은 OneDrive에서) |
| 영수증·일상 사진 | 구글 드라이브로 **이동** (OneDrive 비우기) |
| AI 작업 산출물 | **OneDrive 원본**, Drive는 발행본 사본만 |

> **원칙:** 사령탑의 작업 메인은 OneDrive. 구글 드라이브는 가족·외부 공유 용도.
