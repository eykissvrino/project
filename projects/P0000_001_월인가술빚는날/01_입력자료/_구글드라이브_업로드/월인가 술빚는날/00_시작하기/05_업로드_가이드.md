## 가장 빠른 방법: 폴더 통째 업로드 (5분)

### 사전 확인
- 이미 만들어진 구글 드라이브 폴더: `드라이브 / 월인가 술빚는날` (https://drive.google.com/drive/folders/10gsu6e7hEF5cp6BqOZX0-o_OONSjD9Rt)
- 이미 만들어진 하위: `01_가족공유_운영기록/` (앞서 자동 셋업 때)
- 현재 본 폴더는: `C:\Users\eykis\OneDrive\vrin_AI_hub\projects\P0000_001_월인가술빚는날\_구글드라이브_업로드\월인가 술빚는날\`

### Step 1. 기존 빈 폴더 정리 (1분)

이전 자동 셋업으로 만든 `01_가족공유_운영기록` 폴더는 비어있고, 새 체계의 `03_운영_기록부`로 대체될 예정.

- 옵션 A) 그대로 두고 새 체계 옆에 둠 (둘 다 보존)
- **옵션 B) 삭제 후 새 체계만** (권장)

기존 폴더 우클릭 → "휴지통으로 이동".

### Step 2. 본 폴더 전체 선택 (1분)

1. 윈도우 탐색기로 다음 경로 열기:
   `C:\Users\eykis\OneDrive\vrin_AI_hub\projects\P0000_001_월인가술빚는날\_구글드라이브_업로드\`
2. `월인가 술빚는날` 폴더가 보임 → 이 폴더를 통째로 선택

### Step 3. 구글 드라이브로 드래그앤드롭 (3분)

방법 1 — **폴더 자체를 드래그**
1. 브라우저에서 구글 드라이브 `내 드라이브` 페이지 열기 (마스터 폴더의 부모)
2. 윈도우 탐색기의 `월인가 술빚는날` 폴더를 → 브라우저 창으로 드래그
3. "폴더와 그 안의 모든 파일을 업로드하시겠습니까?" → **확인**
4. 자동으로 폴더 트리 + 파일 전부 업로드 시작
5. 진행률 표시줄 확인 (66 폴더 + 71 파일이므로 약 1~3분)

**⚠️ 기존에 만든 `월인가 술빚는날` 폴더가 있어서 이름 충돌 가능.** 두 가지 해법:
- 해법 A) 기존 폴더를 먼저 휴지통으로 보내고 새로 업로드
- 해법 B) 본 폴더 안의 내용물(11개 최상위 폴더)을 기존 `월인가 술빚는날` 폴더 안으로 드래그

> 💡 **추천: 해법 B**. 기존 폴더 ID·링크 그대로 유지됨.

### Step 4. 운영기록부 → 구글시트 변환 (2분)

업로드 완료 후:
1. `월인가 술빚는날 / 03_운영_기록부/` 진입
2. `월인가_운영기록부_마스터_v2.xlsx` 우클릭

4. 자동 변환 → 저장
5. 변환된 시트가 같은 폴더에 생김

## 대체 방법: zip으로 압축 후 업로드 (안전)

대용량 폴더 업로드가 불안할 때:

1. 윈도우 탐색기에서 `월인가 술빚는날` 폴더 우클릭 → **압축 (ZIP)**
2. 생성된 `월인가 술빚는날.zip` 파일을 구글 드라이브에 업로드
3. 업로드 후 (참고: 구글 드라이브는 zip을 자동 풀어주지 않음)
   - 별도 도구 사용: ZIP Extractor 부가기능
   - 또는 zip 파일만 보관하고, 폴더 작업은 로컬에서 → 동기화 도구 사용

> 권장은 **Step 3 드래그앤드롭**. zip은 추가 단계가 필요.
