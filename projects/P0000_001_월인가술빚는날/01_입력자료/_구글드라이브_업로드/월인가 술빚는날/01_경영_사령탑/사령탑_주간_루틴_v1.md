# 🧭 사령탑 주간 루틴 (누락 방지 + 부모님 신뢰 유지)

> **목적:** 가족 4인의 모든 정보가 매주 안전하게 디지털화되도록 사령탑이 지키는 7일 사이클.

---

## 매일 (월~토, 5분)

- [ ] 가족 단톡 확인 → 오늘 들어온 양조·매출·재고 메시지 있는지
- [ ] 있으면 즉시 운영기록부 해당 시트에 입력 (또는 메모해뒀다 일요일 일괄)
- [ ] 사진은 `02_제품_양조/03_양조일지_월별/{YYYY-MM}/` 또는 `09_가족공유_일상/사진_갤러리/`에 저장

---

## 일요일 정리 (30분, 절대 빠지지 말 것)

### 1단계 — 단톡 일괄 정리 (10분)
- [ ] 이번 주 카톡 메시지 다시 훑기
- [ ] 운영기록부 01·02·03·05·06 시트에 빠짐없이 입력
- [ ] 사진·영수증을 적절한 폴더로 분류

### 2단계 — 누락 점검 (5분)
- [ ] **재고 흐름 점검:** 입고 - 사용 - 출고 = 이월 (말이 됨?)
- [ ] **양조 일지 점검:** 부모님 통화·방문 메모 있는지
- [ ] **시음·QC:** 새 배치 시음 노트 누락 없는지

### 3단계 — 부모님께 주간 보고 카톡 (10분)
- [ ] 아래 [주간 보고 양식](#주간-보고-양식) 채워서 가족 단톡에 발송
- [ ] 부모님이 답장 안 하셔도 OK (읽기만 해도 의미 있음)

### 4단계 — 백업 (5분)
- [ ] 운영기록부 구글시트의 변경사항 자동 저장 확인
- [ ] OneDrive `00_AI_체계/` 신규 자료를 Drive `01_경영_사령탑/`으로 동기화 (선택)

---

## 주간 보고 양식

매주 일요일 가족 단톡에 보내는 한 줄 보고.

```
🌙 월인가 사령탑 주간 보고 (5월 둘째 주)

📊 매출
  · 이번 주: ○○만원 (전주 ±%)
  · 가장 잘 나간 SKU: ○○○

✍ 콘텐츠
  · 인스타 ○건 발행 (좋아요 ○○)
  · 블로그 ○편

📅 다음 주 일정
  · ○월 ○일: ○○ 행사

🙏 부모님께 부탁
  · ○○○ (있을 때만, 없으면 생략)

— 이번 주도 정성스럽게 빚어주셔서 감사합니다.
```

### 톤 가이드
- **간결하게** — 부모님이 30초 안에 읽으실 수 있게
- **감사로 마무리** — "정성스럽게 빚어주셔서 감사합니다" 같이
- **부탁은 짧고 구체적으로** — "음, 부탁이라기보다…" 같은 모호한 표현 X
- **숫자가 안 나오는 주는 OK** — "조용한 한 주였어요" 같이

## 누락 의심 시 대처

만약 운영기록부 행이 부족하게 느껴진다면:

| 의심 | 대처 |
|------|------|
| "이번 달 매출이 너무 적은데?" | 03 시트의 채널 필터 확인. 누락된 거래 있나 부모님께 짧게 확인 |
| "원료 입고 기록이 비었네?" | 부모님 방문 시 영수증 확인 (`09_가족공유_일상/영수증_매입/`) |
| "양조일지가 띄엄띄엄?" | 다음 통화 때 "최근 몇 번 담그셨어요?" 가볍게 |

**원칙:** 부모님 탓하는 톤 절대 X. "내가 정리를 늦게 했네"라는 톤으로.

## 사령탑이 흔들릴 때

> 사령탑(이석주)도 사람. 한 주 빠질 수 있습니다.

**1주일 빠진 경우:**
- 일요일 정리에 2~3시간 들여서 두 주 정리
- 부모님께 "한 주 늦었어요" 짧게 사과

**1개월 빠진 경우:**
- 즉시 AI 팀 4명 호출하여 누락 데이터 복구 도움 받기
- 분기 회의 때 시스템 개선 논의 (사령탑 부담 줄일 방법)

**3개월 이상 빠진 경우:**
- 시스템 자체 재설계 필요 — 사령탑 외 한 명이 더 도와야 함 (태균이?)
