> v4(15시트, 과잉) → v5(5시트, 현실).
> "술 팔 때 한 줄, 양조할 때 한 줄, 그게 끝."

## 1. 한 줄 요약

> **양조장 스마트폰에서 `01_매일_기록` 시트를 열고 한 줄씩 적기.** 끝.

## 4. 7가지 분류 (드롭다운에서 선택)

- **매출** — 양조장 방문 손님 (개인)
- **도매** — B2B 거래처 (레스토랑·바틀샵 등)
- **원료입고** — 쌀·누룩·국화·병 등 들어옴
- **양조** — 담금·발효·거름·병입 등 단계 변화
- **시음** — 가족 시음·외부 시음회
- **부산물** — 주박·폐기물
- **재고조정** — 분실·파손·재고 차이
- **기타** — 위에 안 맞으면

---

## 5. 거래처 등록 — B2B만

개인 손님(양조장 방문)은 **등록 안 함**. 메모에 "방문 손님"만 적으면 끝.

B2B(레스토랑·바틀샵·도매)는:
1. 02_거래처 시트에 새 행 추가
2. ID 부여 (V-001 / B-001 / D-001 형식)
3. 상호·대표·연락처·주소 한 줄로
4. 01_매일_기록 메모 컬럼에 ID 적기 (예: "B-001")

---

## 6. 월말 재고 — 월 1회

월말에 양조장 한 번 둘러보고 SKU별 남은 병 수·원료 남은 양만 03 시트에 한 행씩.

```
2026-05 / 탁주 500 / 40 / 병 / 어머니 확인
2026-05 / 약주 375 / 12 / 병 / 어머니 확인
2026-05 / 찹쌀     / 25 / kg / 어머니 확인
```

---

## 7. 분기 주세 신고 — 분기에 한 번

매 분기 종료 다음 달 25일까지 (4/25, 7/25, 10/25, 다음해 1/25):
1. 04_분기_정리 시트 열기
2. 해당 분기 행의 "매출 합계·도매 합계" 확인 (자동)
3. 행정 매니저 AI 호출 → 신고서 초안 → 세무사 검토 → 신고
4. 신고 상태 컬럼에 "신고완료" 표시

- **v2** (11시트): 휴지통으로 OK (이미 archive 처리됨)
- **v4** (15시트): 휴지통으로 OK

v5에 누락된 정보(예: 5축 시음 점수·고객 해시 ID)는 **나중에 필요할 때** 추가 가능. 지금은 단순함이 우선.

## 9. 자주 묻을 만한 질문

### Q. 분류가 애매한 거 (예: 무료 샘플 증여)
→ "기타" + 메모에 자세히

### Q. 단가가 들쑥날쑥 (할인·세트 판매)
→ 실제 받은 금액만 적으면 됨. 단가 안 적어도 OK

### Q. 사진은 어떻게?
→ 메모에 "+ 사진"만 적고 사진은 09_가족공유_일상/사진_갤러리/에 저장

### Q. 양조 일지가 더 자세해야 하지 않나?
→ 일단 분류 "양조"로 단계만 적기. 추후 필요하면 별도 시트 추가

### Q. 카톡 메시지 정리는?
→ 카톡 입력 5문장(00_시작하기 폴더)대로 가족이 보내면, 사령탑이 카톡 → 01 시트로 그대로 한 줄씩
