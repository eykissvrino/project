## 3. M1·M2·M3 마스터 시트 — 가장 중요한 변화

### M1 SKU 마스터
- 제품 정보(가격·마진·라벨)의 단일 진실 출처
- 가격 변경 시 → 여기에서만 수정 → 다른 시트 자동 갱신
- 7개 SKU 정보가 미리 입력되어 있음

### M2 거래처 마스터 ★ 법적 핵심
- **법령 §25 인적사항 기록 의무 충족용**
- 컬럼: 거래처ID / 구분 / 상호 / 대표자 / 사업자번호 / 주소 / 전화 / 이메일 / 첫거래일 / 상태 / 비고
- ID 체계: V-XXX(공급) / B-XXX(B2B) / C-XXX(소비자) / D-XXX(도매)
- 다른 시트에서는 **거래처ID만 입력** → 상호·사업자번호 자동 채움

### M3 직원 마스터
- 가족 4인 (P-001 ~ P-004) 미리 입력
- 외부 협력자(세무사·디자이너 등) 추가 가능

## 4. v2 → v4 마이그레이션 가이드

### 단계 1 — 새 파일 업로드 (5분)
1. 구글 드라이브 `03_운영_기록부/` 폴더 진입
2. v4 xlsx 업로드: `월인가_운영기록부_마스터_v4.xlsx`
3. 우클릭 → 연결 앱 → Google 스프레드시트로 열기 → 저장

### 단계 2 — 기존 v2 데이터 이관 (사용자 선택)

#### 옵션 A — 깨끗하게 새 시작 (권장)
- v2에 입력된 데이터가 아직 적다면 (1~2주 분량) → v4에 처음부터 입력
- 단순·실수 없음

#### 옵션 B — 데이터 이관
- v2의 03_출고판매·01_원료수불부 데이터를 v4로 복사·붙여넣기
- ⚠️ 컬럼 순서가 다르니 주의 (인적사항 분리·거래처ID 추가 등)
- 거래처 이름이 들어있는 셀은 → M2에 한 번 등록 후 → v4 거래처ID 컬럼에 ID 입력

### 단계 3 — M2 거래처 마스터 채우기 (사용자 직접, 30분)

현재 거래 중인 거래처를 등록:
1. **원료 공급처** (V-XXX) — 쌀 농가·누룩 공방 등
2. **B2B 거래처** (B-XXX) — 레스토랑·바틀샵 등
3. **단골 소비자** (C-XXX) — 마스킹 이름 + 동의 여부만
4. **도매·유통** (D-XXX)

### 단계 4 — 가족에게 다시 공유 (5분)
- v4 시트 공유 → 가족 편집자 권한
- v2 시트는 백업으로 보존 (또는 휴지통)
- 가족 카톡에 "운영기록부 v4로 업그레이드했어요" 안내

## 5. 사령탑 일상 워크플로 (v4 기준)

### 처음 거래처가 등장할 때
1. M2 거래처 마스터에 새 행 추가 (거래처ID 부여)
2. 인적사항 5컬럼 채우기 (가능한 만큼만)
3. 01 또는 03 시트에 거래 기록 시 → 거래처ID만 입력

### 이미 등록된 거래처와 거래 시
- 01/03 시트의 거래처ID 컬럼에 ID 입력 (예: V-001)
- 상호·사업자번호는 자동으로 채워짐 (VLOOKUP)

### 신규 SKU 출시
1. M1 SKU 마스터에 새 행 추가
2. 03 시트의 SKU ID 드롭다운에 자동 반영

### 시음 후
1. 06 시음QC 시트에 행 추가
2. 향·맛·바디·균형·여운 각 1~9점 입력
3. 종합 점수 자동 계산 + 컬러 스케일로 시각화

### 월말
1. 04 재고관리 마감 → 마이너스 재고 있으면 빨강으로 보임
2. 08 월별요약 자동 갱신 확인
3. 11 대시보드의 매출 추세선 확인

### 분기 종료 다음 달 25일
1. 09 분기요약의 해당 분기 행 확인
2. 주세 신고서 작성 (행정 매니저 AI 호출)
3. H열에 "신고완료" 표시

## 6. 자주 묻을 만한 질문

### Q1. M2에 거래처를 매번 등록해야 하나요?
A. 처음 거래 시 한 번만. 이후엔 거래처ID만 입력하면 됩니다.

### Q2. 단골 손님인데 사업자번호 모르면?
A. 비워두셔도 됩니다. 단 법령상 사업자 거래처는 사업자번호 필수.

### Q3. 시음 점수 9점 척도가 어렵습니다.
A. 처음엔 1·5·9 세 단계로만 시작해도 OK. 익숙해지면 1~9 모두 활용.

### Q4. 고객 해시 ID는 어떻게 만드나요?
A. 임의 형식. 예: "H-김선생-01", "H-자주오심-02". 같은 사람은 같은 ID 사용.

### Q5. 외부 공유 시 M2 거래처 마스터는?
A. **절대 외부 공유 금지.** 필요 시 마스킹 뷰 별도 시트를 사령탑이 수동 생성.

## 7. v4가 해결한 v2의 약점 9가지 (재확인)

| # | v2 약점 | v4 해결 방법 |
|---|---------|--------------|
| 1 | 인적사항 자유 텍스트 | M2 거래처 마스터 → 5컬럼 분리 |
| 2 | 밑술·술덧 추적 미흡 | 01 구분 드롭다운 확장 |
| 3 | 마스킹↔기록 충돌 | M2는 정확히 기록 + 외부 공유 시만 마스킹 |
| 4 | 세금계산서 연계 없음 | 01·03에 세금계산서번호 컬럼 |
| 5 | 사령탑 1인 병목 | 별도 [자동화 워크플로](v4_카톡_AI_자동화.md) 가이드 |
| 6 | 이상 감지 없음 | 04 조건부 서식 + 06 점수 컬러스케일 |
| 7 | 정량 시음 척도 없음 | 06 5축 9점 + 종합 자동 |
| 8 | 고객 ID 없음 | 07 해시 ID + 03 고객ID 컬럼 |
| 9 | 마스터 데이터 분리 없음 | M1·M2·M3 신규 시트 |
