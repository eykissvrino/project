## 2. POS 단말기 + 현금영수증 (이번 주)

### POS 단말기 설치 시
POS 단말기 사업자(스마트로·KIS·KICC 등)가 방문해서 설치하면서:
- ✅ **카드결제 가맹점** 자동 가입
- ✅ **현금영수증 가맹점** 자동 가입 (요청)
- ✅ 단말기에 사업자 정보 등록

### POS 설치 시 미리 준비할 서류
- 사업자등록증 (PDF)
- 통장 사본 (정산 입금 계좌)
- 신분증
- 임대차 계약서 (필요시)

### 단말기 사업자에게 꼭 물어볼 3가지
1. **현금영수증 가맹점 가입도 같이 처리되나요?** (보통 YES)
2. **수수료율은?** (체크카드 0.5~1%, 신용카드 1~3%)
3. **정산 주기는?** (보통 D+2 또는 D+3)

### 카드결제 시 흐름
손님이 카드 결제 →
- 단말기에서 카드 승인
- **자동으로 매출 데이터가 카드사에 보존**
- 정산금이 통장에 입금 (2~3일 후)
- → **법령 §25 인적사항 기록 의무 자동 충족** (카드사가 거래 보존)

### 현금영수증 발급 시점
- 손님이 요청하면 **휴대폰 번호 입력 → 발급**
- 거래금액 10만원 이상 시 (의무업종이면 자동 발급 권장)
- 미요청 거래는 **자진발급** ("010-000-0000" 같은 임의번호 X, 그냥 미발급으로)

### 의무발행 여부 확인
- 직전 과세기간 매출 24백만원 이상 → 의무 가맹점 가입
- 신생업체는 처음에는 의무 아닐 수 있지만 **자발적 가입 권장** (소비자 신뢰)
- 주류 의무발행업종 여부는 **국세청 홈택스 → 가맹점 조회**에서 확인 권장

## 3. 홈택스 전자세금계산서 (1주~1개월)

### 언제 필요한가?
- **B2B 거래처(레스토랑·바틀샵·도매)와 거래 시**
- 거래처가 "세금계산서 발행해 주세요" 하면 즉시
- 처음 1년은 의무 아니더라도 **거래처 신뢰·세무 관리 위해 발급 권장**

### Step 1 — 사전 준비 (1회만, 30분)

**필요한 것 2가지:**
1. **공동인증서(구 공인인증서)** — 사업자용
   - 발급처: 거래은행(농협 등)
   - 비용: 무료~연 1.1만원
   - 발급 후 USB 또는 PC에 저장
2. **홈택스 사업자 가입**
   - https://www.hometax.go.kr 접속
   - 사업자등록번호로 회원가입
   - 공동인증서 등록

### Step 2 — 첫 발급 절차 (5분/건)

```
홈택스 로그인 (공동인증서)
  ↓
[조회/발급] 메뉴
  ↓
[전자(세금)계산서]
  ↓
[발급] → [건별 발급]
  ↓
공급받는 자(거래처) 정보 입력
  · 사업자번호
  · 상호
  · 대표자명
  · 주소
  · 이메일
  ↓
거래 정보 입력
  · 작성연월일
  · 품목 (예: "월인가 사계주 소주 375ml")
  · 수량·단가·공급가액·세액
  ↓
발급 → 거래처 이메일로 자동 전송
```

### Step 3 — 정기 관리
- 매월 25일 부가가치세 신고와 자동 연계
- 분기마다 발급 내역 다운로드 → v6 분기 통합 시 활용
- **세무사 연계 권장** — 세무사가 자동 관리

### 거래처에게 받아둘 정보 (M2_거래처 마스터에 미리 등록)
- 사업자번호
- 상호
- 대표자명
- 사업장 주소
- 세금계산서 받을 이메일

## 4. 네이버 스마트스토어 — 전통주 통신판매 (1~2개월)

### 좋은 소식: 농업경영체 = 자격 충족 ✅

월인가 술빚는날은 **농업경영체로서 지역 농산물 주원료**로 제조 → 통신판매 특례 자격 자동 보유.

### 어려운 점: 관할 세무서 사전 승인 필요

일반 상품과 달리 **주류는 통신판매 시작 15일 전까지 관할 세무서장에게 신청·승인** 받아야 함.

### 단계별 절차 (예상 6~8주)

#### Week 1 — 관할 세무서 통신판매 승인 신청
1. **천안 관할 세무서**(천안세무서)에 방문 또는 우편
2. 제출 서류:
   - 주류 통신판매 승인 신청서
   - 사업자등록증 사본
   - 주류 제조면허증 사본 (탁주·약주·소주)
   - 농업경영체 등록증명서
   - 통신판매업 신고증 (정부24에서 미리 신청)
3. 사전 승인까지 약 **15일~1개월**

#### Week 2 — 통신판매업 신고
- 정부24(www.gov.kr) → 통신판매업신고
- 무료, 온라인 신청, 즉시 발급

#### Week 3~4 — 네이버 스마트스토어 입점
1. 스마트스토어 회원 가입 (사업자)
2. **카테고리: 전통주** 선택
3. 필요 서류 제출:
   - 사업자등록증
   - 통신판매업 신고증
   - **주류 제조면허증 + 세무서 통신판매 승인서**
   - 통장 사본
4. 입점 심사 약 1주

#### Week 5~6 — 상품 등록·운영 준비
1. 제품 상세페이지 (콘텐츠 디렉터 AI 활용)
2. 사진·라벨 이미지 (`05_브랜드_자산/`에서)
3. 가격·배송·반품 정책
4. **성인인증 시스템 활성화** (필수)
5. **주류통신판매기록부** 양식 준비 (구입자 인적사항·일자·수량·금액)

#### Week 7~8 — 시범 운영
- 첫 한 달은 가족·지인 대상 시범
- 배송·CS·문제점 파악
- 그 후 공식 오픈

### 주의사항 ⚠️
- 미성년자 판매 절대 금지 (성인인증 필수)
- 주류통신판매기록부는 분기 신고와 함께 세무서 제출
- 상품 라벨·표시기준 모두 준수 (행정 매니저 AI 검수)

## 5. 4종 시스템 셋업 완료 후 — v6 Layer 2 작동

셋업 완료 시점에 v6의 Layer 2가 완성됩니다:

```
손님이 양조장 방문 → 카드 결제
  → POS 매출 + 카드사 자동 보존 (법적 인적사항 자동)
  → 사령탑이 v5 01_매일_기록에 한 줄 추가

레스토랑이 도매 주문 → 세금계산서 발행
  → 홈택스 자동 보존 (법적 인적사항 자동)
  → 사령탑이 v5 01_매일_기록 + M2_거래처에 한 줄

스마트스토어에 주문 들어옴
  → 네이버 시스템 자동 보존 (법적 인적사항 자동)
  → 사령탑이 일주일·월 단위로 v5에 합계 입력
```

**Layer 2가 완성되면 분기 통합(Layer 3) 작업이 가능**해집니다.

## 7. 비용 예상

| 항목 | 초기 비용 | 월간 |
|------|-----------|------|
| POS 단말기 | 0~10만원 (제공 시 무료) | 임대료 1~3만원 |
| 카드 수수료 | — | 매출의 1~3% |
| 홈택스 공동인증서 | 0~1.1만원/년 | — |
| 통신판매업 신고 | 0 | — |
| 세무서 통신판매 승인 | 0 | — |
| 스마트스토어 입점 | 0 | 수수료 약 5~6% |
| 세무사(권장) | — | 월 5~10만원 |

**총 초기 비용:** 약 0~15만원 (POS 사업자에 따라)
**월 운영비:** 매출 약 3~10% (수수료) + 세무사 5~10만원
