# OKR vs MBO vs KPI vs BSC 비교

## 개요

| 방법론 | 등장 | 핵심 |
|--------|------|------|
| MBO (Management By Objectives) | 1954, Drucker | 목표에 의한 관리, 합의된 연간 목표 |
| KPI (Key Performance Indicators) | 1980s~ | 핵심 성과지표, 측정·모니터링 |
| BSC (Balanced Scorecard) | 1992, Kaplan & Norton | 재무·고객·프로세스·학습 4관점 |
| OKR (Objectives & Key Results) | 1970s Intel → Google 2000s | 도전적 목표 + 측정가능한 KR |

## 비교 매트릭스

| 항목 | MBO | KPI | BSC | OKR |
|------|-----|-----|-----|-----|
| 주기 | 연간 | 상시 | 연간/분기 | 분기 |
| 목표 성격 | 합의/달성가능 | 측정 위주 | 균형 (4관점) | 도전적 |
| 달성률 기대 | 90~100% | 100% | 80~100% | 60~70% (도전성) |
| 보상 연계 | 강함 | 강함 | 보통 | 약함 (의도적) |
| 공개성 | 본인+상사 | 부분 공개 | 임원 중심 | 전사 공개 |
| 적합 조직 | 안정적 운영 | 운영 모니터링 | 전략 실행 | 빠른 변화 (Tech) |

## 각 방법론 상세

### MBO (Management By Objectives)

#### 구조
- 전사 목표 → 본부 → 팀 → 개인 (Cascading)
- 연초 합의 → 중간 점검 → 연말 평가

#### 장점
- 합의된 목표 → 공정성 인식
- 명확한 평가 기준
- 보상 연계 직관적

#### 단점
- 도전성 약화 (낮은 목표 합의)
- 정량 KPI 외 가치 측정 어려움
- 환경 변화 대응 느림

#### 한국 적용
- 한국 대다수 기업의 표준
- 정량 KPI 비중 70%+ 일반적
- 한국적 관대화 평가와 결합 → 변별력 약화

### KPI (Key Performance Indicators)

#### 구조
- 직무별 핵심 지표 정의
- 정량 모니터링 (Dashboard)
- 목표 vs 실적 비교

#### 장점
- 측정 명확
- 모니터링 용이
- 시각화 (Dashboard)

#### 단점
- 측정 가능한 것만 KPI화 → 중요한 것 누락 가능
- "Game the metric" (지표만 맞추는 행동)
- 정성적 가치 미반영

#### 한국 적용
- MBO와 결합 (MBO 항목 = KPI)
- BSC와 결합 (4관점 KPI)

### BSC (Balanced Scorecard)

#### 4관점
1. **재무 (Financial)**: 매출, 이익, ROI
2. **고객 (Customer)**: 만족도, 점유율, 충성도
3. **내부 프로세스 (Internal Process)**: 효율, 품질, 혁신
4. **학습·성장 (Learning & Growth)**: 직원 역량, 시스템, 문화

#### Strategy Map
- 관점 간 인과관계 시각화
- 학습·성장 → 프로세스 → 고객 → 재무

#### 장점
- 균형 잡힌 시각
- 전략과 실행 연계
- 비재무지표 가치 인정

#### 단점
- 구축 복잡
- 4관점 외 항목 누락 가능
- 한국에서 형식화 경향

#### 한국 적용
- 2000년대 도입 붐 → 현재 정착·진화
- 본부·팀 단위 BSC, 개인은 MBO 결합
- 공공기관 평가에 영향

### OKR (Objectives & Key Results)

#### 구조
```
Objective (정성, 도전적, 영감적)
├── Key Result 1 (정량, 측정가능)
├── Key Result 2 (정량, 측정가능)
└── Key Result 3 (정량, 측정가능)
```

#### 예시
- **O**: "고객이 우리 제품을 일주일에 5번 이상 쓰게 만든다"
  - **KR1**: 주간 활성 사용자(WAU) 50% 증가
  - **KR2**: 평균 사용 빈도 주 3회 → 5회
  - **KR3**: NPS 30 → 50

#### 운영
- 분기 주기
- 전사 공개 (Google 사례)
- 평가/보상과 분리 (의도적)
- 70% 달성 = 성공 (도전성)

#### 장점
- 도전적 목표 추구
- 정렬 (Alignment) 강화
- 빠른 학습·조정

#### 단점
- 보상 연계 어려움
- 평가자/피평가자 모두 적응 필요
- 운영 안 되면 그냥 KPI와 동일

#### 한국 적용
- 2015년 이후 IT·스타트업 중심 도입
- 한국 대기업도 일부 도입 (LG CNS, SK 등)
- 평가/보상 연계 강한 한국에서 운영 어려움 → MBO와 혼용 경향

## 컨설팅 시 선택 가이드

| 조직 특성 | 추천 |
|-----------|------|
| 안정적 운영, 정량 KPI 명확 | MBO + KPI |
| 전략 실행 강화 필요 | BSC + MBO |
| 빠른 변화, IT/스타트업 | OKR (+ KPI for 운영) |
| 한국 전통 대기업 | MBO 강화 + BSC 일부 |
| 글로벌 본사 보유 | 본사 방식 + 한국 적응 |

## 혼합 모델 (현실적 권장)

대부분 한국 기업에서는 단일 방법론보다 **혼합 모델**이 현실적:
- 전사·본부: BSC 또는 OKR (전략 연계)
- 팀: MBO (합의된 목표)
- 개인: MBO + KPI (보상 연계)
- 평가: 정량 70% + 정성 30%
