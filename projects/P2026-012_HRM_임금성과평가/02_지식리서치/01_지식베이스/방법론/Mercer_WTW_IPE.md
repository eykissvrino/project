# Mercer / WTW IPE (International Position Evaluation)

## 개요
Mercer가 개발한 글로벌 직무평가 방법론. WTW(Willis Towers Watson)도 유사 체계 운영.
전 세계 4,000개 이상 기업에서 활용. **글로벌 일관성** 확보가 강점.

## 5개 평가 요소

### 1. Impact (영향력)
조직 성과에 미치는 영향의 크기·범위
- **Contribution**: 직접/간접 기여 (5단계)
- **Organization Size**: 조직 규모 (매출, 인원 등)

### 2. Communication (의사소통)
요구되는 의사소통의 복잡성·중요성
- **Communication Skills**: 정보 전달 / 설명 / 설득 / 협상 (5단계)
- **Frame**: 내부 / 외부 / 고위직 / 정부 등

### 3. Innovation (혁신)
요구되는 창의성·문제해결 수준
- **Innovation Required**: 기존 방식 적용 → 응용 → 새로운 방법 개발 (5단계)
- **Complexity**: 다루는 이슈의 복잡성

### 4. Knowledge (지식)
요구되는 지식·전문성의 깊이·폭
- **Knowledge Depth**: 기초 → 전문가 (5단계)
- **Knowledge Breadth**: 단일 분야 → 다분야 통합
- **Teams**: 관리 인원 수 (Specialist는 N/A)

### 5. Risk (리스크) — 옵션
의사결정 리스크 (선택적 요소)
- 재무 / 평판 / 안전 / 규제 리스크

## 점수·등급 산정

### Point 계산
- 각 요소별 등급 (A~E) → 점수 (예: A=50, B=100, C=200, D=400, E=700)
- 합산 → Total IPE Score

### Position Class (PC) 매핑
- IPE Score → Position Class (PC) 40~70 정도
- PC = Grade

### Global Grading System (GGS) 연계
- PC → GGS Band (예: GGS Band 4~12)

## 적용 프로세스

### 1. 사전 준비
- JD 정비 필수
- 평가위원회 구성 (인사 + 사업 + 외부전문가)
- 평가위원 IPE 교육

### 2. Anchor Job 평가
- 시장 매칭 가능한 대표 직무 10~20개
- 위원회 합의 평가

### 3. 전 직무 평가
- 위원별 개별 평가 → 종합 토의
- 일관성 검증 (Anchor 기준)

### 4. 결과 검증
- Cluster (과집중) / Cliff (등급 간 점수차 과대) 회피
- 직무 간 정합성 확인

## 장단점

### 장점
- 글로벌 일관성 (다국적 기업 적합)
- 시장 매칭 풍부 (Mercer DB 연계)
- 체계적·논리적

### 단점
- 복잡 (5요소 × 다층 등급)
- 평가위원 교육 필요
- 라이선스 비용 (Mercer 컨설팅 활용 시)

## 한국 시장 적용

### 적합 케이스
- 글로벌 본사 보유 기업
- IPO·해외 진출 추진 기업
- 직무급·직무 기반 HR 전환 기업

### 주의 사항
- 한국 호봉제 직군과의 충돌
- 평가위원 교육 시간 충분 확보
- 시장 매칭 시 한국 데이터 보완 필요
