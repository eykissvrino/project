# Hay Guide Chart-Profile Method

## 개요
1950년대 Edward Hay가 개발. 현재 Korn Ferry가 보유. 전 세계 가장 오래되고
널리 쓰인 직무평가 방법론. **3요소 × Profile Pattern** 이 특징.

## 3개 평가 요소

### 1. Know-How (전문지식·기술)
직무 수행에 요구되는 지식·기술의 합계
- **Technical Know-How** (기술 깊이): 8단계 (A~H)
- **Managerial Breadth** (관리 폭): 4단계 (I~IV)
- **Human Relations Skills** (대인관계): 3단계 (1~3)

총 8 × 4 × 3 = 96개 조합 → 점수표 매핑

### 2. Problem Solving (문제해결)
사고를 통해 결론에 도달하는 능력
- **Thinking Environment** (사고 환경): 자유도 (A~H, 8단계)
- **Thinking Challenge** (사고 도전): 복잡성 (1~5)

Problem Solving Score = Know-How × Percentage

### 3. Accountability (책임)
의사결정의 영향과 그 영향의 크기
- **Freedom to Act** (행동 자유도): 8단계 (A~H)
- **Magnitude** (영향 규모): 매출·예산 등 (1~6)
- **Impact** (영향 형태): Remote / Contributory / Shared / Primary

## Profile Pattern

Hay Method의 독특한 점: 3요소의 **상대적 비중**으로 직무 유형 진단

- **Up Profile (P > A)**: Problem Solving > Accountability
  - 분석·전문가 직무 (Research, Analyst)
- **Down Profile (A > P)**: Accountability > Problem Solving
  - 라인 관리자, 영업 직무
- **Level Profile (P = A)**: 균형
  - 기능 관리자

## 점수 → Hay Grade

- Total Hay Points 산출
- Hay Grade 매핑 (통상 10~25 Grade)
- 글로벌 Hay DB 시장 매칭 가능

## 적용 프로세스

### 1. JD 정비

### 2. 평가위원 교육
- Hay Method 이해 (1~2일)
- Case Study 실습

### 3. 평가 실행
- Slotting 방식 (Anchor Job 기준 상대 평가)
- 또는 Direct Scoring

### 4. Profile 검증
- 직무 유형과 Profile이 정합되는가
- 라인 매니저인데 Up Profile → 재검토

## 장단점

### 장점
- 가장 오래된 방법론 (검증·신뢰)
- Profile로 직무 유형까지 진단
- Korn Ferry 시장 데이터 활용

### 단점
- 점수 매핑이 복잡 (Lookup Table 다수)
- Technical Know-How 8단계의 한국식 적용 어려움
- 라이선스 비용

## 한국 시장 적용

### 적합 케이스
- 전통적 컨설팅 선호 (대기업·금융권)
- 정밀한 직무 가치 진단 필요
- Manager vs Specialist 명확화

### 주의 사항
- 한국 호봉체계와 충돌
- 평가위원 교육 시간 (1~2일 소요)
- Profile Pattern 한국 적용 시 일부 변형 필요
