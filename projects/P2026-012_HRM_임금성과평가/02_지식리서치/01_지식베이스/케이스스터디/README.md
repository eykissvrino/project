# 케이스 스터디 (Case Study) — 프로젝트 학습 누적

본 폴더는 **실제 프로젝트에서 학습한 인사이트·노하우·실패 사례**를 누적
하는 공간입니다. 매 프로젝트 종료 시 핵심 학습을 1~2 페이지로 정리·축적
하여 다음 프로젝트에서 재활용합니다.

## 작성 표준 양식

```markdown
# [Case 제목]

## 프로젝트 개요
- 클라이언트 유형 (산업, 규모) - 익명 처리
- 프로젝트 영역 (임금/평가/직무평가 등)
- 기간 / 팀 구성
- 적용 방법론

## 클라이언트 상황 (Situation)
- 핵심 이슈
- 도전과제

## 접근 방법 (Approach)
- 방법론 선택 이유
- 단계별 활동

## 핵심 발견 (Key Findings)
- 진단 결과 핵심
- 의외/예상치 못한 발견

## 솔루션·산출물 (Solution)
- 제도 설계 핵심
- 차별화 포인트

## 성과 (Results)
- 정량 효과
- 정성 효과
- 안착 정도

## 학습 (Lessons Learned)
- 잘된 점 (다음에도 적용)
- 못한 점 (개선 필요)
- 일반화 가능한 인사이트

## 재사용 가능한 산출물
- 템플릿화 가능한 양식
- 시뮬레이션 모델 등
```

## 케이스 분류 (예시)

분류 가능한 디멘션:
- **클라이언트 유형**: 대기업/중견/중소/스타트업/공공/금융
- **산업**: 제조/IT/서비스/금융/유통/공공
- **프로젝트 영역**: 임금/평가/직무평가/조직설계/HR 전반
- **방법론**: Mercer IPE / Hay / 한국형 / OKR / MBO

## 케이스 운영 원칙

1. **익명화 필수**: 클라이언트명·인명 식별 정보 모두 제거
2. **실패도 가치**: 안 된 것·재시도한 것도 학습
3. **재사용 명시**: 어떤 산출물이 템플릿화 가능한지 명시
4. **정기 리뷰**: 분기 1회 케이스 리뷰, 패턴 도출
