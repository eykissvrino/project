# 통상임금 — 판례·실무 가이드

⚠️ **본 자료는 컨설팅 사전 검토용입니다. 실제 적용 전 인사노무사/변호사
정식 자문 필수.**

## 통상임금의 의의

### 정의 (근로기준법 시행령 제6조)
근로자에게 정기적·일률적·고정적으로 지급되는 임금

### 활용
- 연장근로수당, 야간근로수당, 휴일근로수당, 연차휴가수당 산정 기준
- 임금구조 설계 시 통상임금 영향 사전 검토 필수

## 핵심 판례

### 2013.12.18 대법원 전합 (2012다89399)
**가장 중요한 통상임금 판례. "정기상여금도 통상임금에 포함될 수 있다"**

#### 요건 (3가지 충족)
1. **정기성**: 정기적으로 지급
2. **일률성**: 일정한 조건을 충족한 모든 근로자에게 지급
3. **고정성**: 실제 근무성과 무관하게 사전 확정

#### 신의칙 (Trust & Faith)
- 노사가 통상임금에서 제외하기로 합의
- 사용자가 그 합의 신뢰
- 갑작스러운 청구로 회사에 중대한 경영상 어려움

→ 신의칙 인정 시 과거 미지급분 청구 제한

### 이후 주요 판례

#### 정기상여금
- 분기·반기·연 1회 지급도 정기성 인정
- 단, 지급일 재직자만 받는 조건은 고정성 부정 (예: "지급일 현재 재직자")

#### 식대·교통비
- 전 직원에게 일률 지급 → 통상임금 포함
- 출퇴근 거리 비례 → 일률성 부정 가능

#### 명절수당
- 지급일 현재 재직자 조건 → 고정성 부정
- 모든 직원 일률 지급 → 통상임금 포함

#### 복리후생비
- 일률 지급 (예: 통신비 월 5만원) → 통상임금
- 신청자만, 영수증 첨부 → 통상임금 X

## 통상임금 산입 판단 매트릭스

| 항목 | 통상임금 포함 |
|------|--------------|
| 기본급 | 100% 포함 |
| 직급/직책수당 | 포함 (일률·정기·고정 시) |
| 정기상여금 (재직조건 X) | 포함 |
| 정기상여금 (재직조건 O) | 제외 (현재 판례) |
| 식대 (전직원 일률) | 포함 |
| 식대 (실비 정산) | 제외 |
| 명절 상여 | 통상 제외 (재직조건) |
| 자녀학자금 | 제외 (조건부) |
| 성과급 (변동) | 제외 |
| 시간외수당 | 제외 |

## 임금구조 설계 시 영향

### 통상임금 확대 시 영향
- 시간외수당·연차수당 증가
- 인건비 5~15% 증가 가능
- 임금격차·평가 분포 영향

### 대응 전략

#### 전략 A. 통상임금 재정의
- 정기상여금 → 기본급 흡수 (통상임금화 명시)
- 통상임금 명시 → 법적 리스크 제거
- 효과: 인건비 일시 증가, but 미래 예측 가능

#### 전략 B. 임금항목 재설계
- 정기상여금 → 변동 인센티브화 (실적 연동)
- 식대·복리후생 → 비통상임금화 (조건부 지급)
- 효과: 통상임금 최소화, but 정합성 검토 필요

#### 전략 C. 시간외수당 포괄
- 포괄임금제 적용 (특정 직무, 노사 합의)
- 단, 판례상 포괄임금제 엄격 해석 추세
- 효과: 통상임금 영향 차단, but 법적 리스크

### 통상임금 영향 시뮬레이션 (필수)
임금 변경 시:
- 시간외수당 영향 (월 평균 OT 시간 × 통상시급)
- 연차수당 영향 (미사용 연차 × 통상시급)
- 퇴직금 영향 (평균임금 ≥ 통상임금 원칙)
- 인건비 총액 변화 (3년 예측)
