# 취업규칙 — 관리·변경 가이드

## 개요
- **근거**: 근로기준법 제93조 (취업규칙 작성·신고), 제94조 (변경 절차)
- **대상**: 상시 10인 이상 사업장은 필수 작성·신고
- **신고 기관**: 관할 고용노동지청

## 필수 기재사항 (제93조)

1. 업무 시작·종료 시각, 휴게시간, 휴일, 휴가
2. 임금 (결정·계산·지급방법, 산정기간, 지급시기, 승급)
3. 가족수당의 계산·지급방법
4. 퇴직
5. 퇴직급여, 상여금·최저임금
6. 식비, 작업용품 등 부담
7. 교육
8. 안전·보건
9. 근로자의 직장 내 괴롭힘 예방·발생 시 조치
10. 표창·제재
11. 그 밖에 모든 근로자에게 적용되는 사항

## 변경 절차 (제94조)

### 일반 변경 (유리한 변경)
- 근로자 **의견 청취**
- 의견서 첨부하여 노동지청 신고

### 불이익 변경 (Disadvantageous Change)
**근로자 과반수 동의 필수** (제94조 단서)

#### 불이익 변경 판단 기준
- 임금·근로조건이 종전보다 불리해지는 경우
- 일부 항목 유리, 일부 불리 → 종합적으로 불리한지 판단

#### 동의 절차
1. **노조 있는 경우**: 노조 동의 (조합원 과반수 노조 시)
2. **노조 없거나 과반 미달**:
   - 근로자 과반수의 집단적 의사결정 방식
   - 회의 방식, 부서별 회의 후 종합
   - 사용자 개입 없는 자유로운 의견 교환

#### 동의 없는 변경 시
- 변경 효력 없음 (소급 무효)
- 기존 취업규칙 적용

### 사회통념상 합리성 법리 (예외)
- 노조 동의 없어도 변경 가능한 경우
- 단, 매우 엄격하게 해석
- 사회통념상 합리성 + 변경 필요성 + 근로자 보호 등 종합 판단
- **실무상 의존 불가**, 동의 절차 진행 권장

## HR 컨설팅 시 자주 관여하는 변경

### 임금구조 변경
- 호봉제 → 직무급/직책급 전환
- 정기상여금 → 기본급 흡수 (통상임금 영향)
- 수당 통폐합

→ **거의 모든 케이스 불이익 변경 가능성 高** → 동의 절차 필수

### 평가제도 변경
- 평가-보상 연계 강화 (등급별 차등 인상)
- 강제분포 도입
- 저성과자 PIP·해고

→ **불이익 변경 판단 케이스별 다름**, 사전 검토 필수

### 정년·근무시간 변경
- 임금피크제 도입 → 명백한 불이익 변경
- 근무시간 단축·근무지 변경

→ **불이익 변경 명백**, 동의 필수

## 동의 절차 실무

### Step 1. 변경안 설명
- 변경 내용·이유·영향 명확 설명
- 1주일 이상 충분한 시간 부여

### Step 2. 의견 수렴 회의
- 부서별 회의 (또는 전체 회의)
- 사용자(임원·인사) 개입 최소화
- 회의록 작성

### Step 3. 동의 투표
- 무기명 비밀 투표 권장
- 과반수 동의 확인
- 동의서 작성·보관

### Step 4. 노동지청 신고
- 변경 사유서
- 동의서 사본
- 신·구 취업규칙 대조표

## 흔한 실수

### 1. 의견 청취와 동의 혼동
- 유리한 변경: 의견 청취만 OK
- 불이익 변경: 동의 필수

### 2. 동의 방식 부적절
- 개별 서명만으로 부족 (집단적 의사결정 X)
- 부서장 통한 우회 동의 → 무효 가능

### 3. 일부 항목만 통보
- 종합 영향 평가 누락
- 유불리 종합 판단 필요

### 4. 신고 누락
- 노동지청 신고 안 하면 행정 처벌 가능
- 신고 시 시행 (또는 통보) 시점 명시

## 컨설팅 시 체크리스트

- [ ] 변경 항목이 불이익 변경인지 판단
- [ ] 노조 유무·조합원 비율 확인
- [ ] 동의 절차 일정 확보 (최소 2~4주)
- [ ] 의견 수렴 방식 사전 협의
- [ ] 동의서 양식·기록 관리
- [ ] 노동지청 신고 절차 확인
- [ ] `labor-law-expert` + 외부 노무사 자문
