## 보고서 작성 원칙

### 톤·매너
- 객관적·분석적·논리적
- 단정형 결론 + 근거 명시
- 익명성 보장 (인터뷰 인용 시)
- 강점·약점 균형

### 시각화 우선
- 데이터: 차트·표·Heat Map
- 프로세스: 흐름도
- 매트릭스: 2x2 또는 다차원
- 텍스트 비중 최소화

### 분량 가이드
- Executive Summary: 2~3p
- 본문: 30~50p
- Appendix: 별도
- 전체: 50~100p (PPT 기준)

## 슬라이드 디자인

### Title 작성 (가장 중요)
- 결론을 제목에 (예: "평가제도는 운영 부담이 과중함")
- 동사·결론형 (예: "직무 간 임금 격차가 시장 대비 과대함")
- "현황", "분석" 같은 무의미 제목 X

### Slide Body
- 왼쪽 위 → 오른쪽 아래 흐름
- 1 슬라이드 1 메시지
- Visual + Text 균형 (3:7 권장)
- Source / Footnote 명시

### Color Code
- 강조: 빨강 (이슈)
- 긍정: 파랑/녹색
- 중립: 회색
- 클라이언트 컬러 활용

## 자체 검증 체크리스트

- [ ] Executive Summary로 단독 의사결정 가능한가
- [ ] 모든 발견에 데이터 + 인터뷰 + 시사점 구성되었는가
- [ ] Top Message가 1줄로 요약되는가
- [ ] MECE인가 (중복·누락 X)
- [ ] 인터뷰 익명성 보장되었는가
- [ ] 모든 숫자에 출처·시점이 있는가
- [ ] 강점·약점이 균형되었는가
- [ ] 권고사항이 실행 가능한가
- [ ] 슬라이드 Title이 결론형인가
