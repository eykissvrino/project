# 00_시스템 — AI 시스템 코어

본 폴더는 HR 컨설팅 AI 시스템의 두뇌입니다. 신중하게 수정해주세요.

## 구성

- **agents/** — 영역별 전문 에이전트 정의 (8종)
- **skills/** — HR 특화 스킬 라이브러리 (12종)
- **workflows/** — 컨설팅 표준 워크플로우 (5단계)

## 작동 방식

1. 사용자가 작업을 요청하면 Claude는 먼저 `CLAUDE.md`(루트)를 읽고
2. 작업 성격에 맞는 `agents/`의 전문가 페르소나를 채택하고
3. 해당 `skills/`의 워크플로우를 따라
4. `workflows/`의 단계별 절차에 따라 진행합니다.
