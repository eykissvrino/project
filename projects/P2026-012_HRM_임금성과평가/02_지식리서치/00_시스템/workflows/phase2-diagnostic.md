# Phase 2: As-Is 진단

## 목적
클라이언트 조직의 현황을 객관적으로 진단하고, 핵심 이슈와 근본원인을 도출한다.

## 주요 활동

### 2.1 자료 수집
- 인사 데이터 (3년치) 수집·정제
  - 인원, 임금, 평가 결과, 이직, 채용 등
  - 개인식별 정보 마스킹
- 규정·매뉴얼·조직도 수집
- 단협·과거 컨설팅 자료 (있다면)

### 2.2 정량 분석
- 인사 데이터 분석:
  - 인원 구성 (직급·근속·연령·성별)
  - 임금 분포 (직급·직무별)
  - 평가 결과 분포
  - 이직률 (자발/비자발, 직급별)
- 벤치마크 비교 (`salary-benchmarking` 스킬, `research-analyst`)

### 2.3 인터뷰
- 인터뷰 대상 확정 (계층별 10명 이상)
- 인터뷰 가이드 작성
- 1:1 인터뷰 진행 (60~90분)
- FGI (선택)

### 2.4 문서 분석
- 인사규정·취업규칙 분석
- 평가·임금 규정 검토
- `labor-law-expert` 협업하여 법적 이슈 검토

### 2.5 진단 종합
- 갭 분석 (As-Is vs To-Be 목표상)
- 이슈 트리 (Issue Tree)
- 근본 원인 분석 (5 Whys, Fishbone)
- 우선순위 (Impact × Urgency)

### 2.6 진단 보고
- 중간 보고 (스폰서·Steering Committee)
- 진단 보고서 작성 (`hr-diagnostic` + `consulting-report` 스킬)

|--------|------|

## 체크리스트

- [ ] 정량 + 정성 + 문서 분석 삼각검증
- [ ] 인터뷰 표본이 계층별 적절 (10명 이상)
- [ ] 외부 벤치마크 포함
- [ ] 증상이 아닌 근본원인 분석
- [ ] 강점·약점 균형
- [ ] 권고사항 우선순위화
- [ ] Executive Summary 단독 가독성
