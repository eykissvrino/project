# Workflows — 컨설팅 표준 워크플로우

HR 컨설팅 프로젝트의 5단계 표준 흐름과 단계별 산출물·체크리스트.

## 5단계 표준 흐름

```
[Phase 1] Kickoff       → 제안서, 착수보고서, 프로젝트 계획
[Phase 2] As-Is 진단    → 현황 분석, 인터뷰, 갭 분석
[Phase 3] To-Be 설계    → 제도 설계, 시뮬레이션, 검증
[Phase 4] 실행 지원     → 매뉴얼, 변화관리, 교육자료
[Phase 5] 안착 점검     → 운영 점검, 보완, 최종 보고
```

각 Phase는 단일 워크플로우 문서로 정리:

- `phase1-kickoff.md` — 프로젝트 시작 단계
- `phase2-diagnostic.md` — 진단 단계
- `phase3-design.md` — 설계 단계
- `phase4-implementation.md` — 실행 지원 단계
- `phase5-stabilization.md` — 안착 점검 단계

## 프로젝트 폴더 구조 (각 프로젝트에 적용)

```
03_프로젝트/[클라이언트명_프로젝트명]/
├── 00_프로젝트개요.md           ← 프로젝트 한눈에
├── 01_kickoff/                  ← Phase 1
│   ├── 제안서/
│   ├── 착수보고서/
│   └── 프로젝트계획/
├── 02_진단/                     ← Phase 2
│   ├── 인터뷰/
│   ├── 데이터분석/
│   ├── 벤치마크/
│   └── 진단보고서/
├── 03_설계/                     ← Phase 3
│   ├── 제도설계서/
│   ├── 시뮬레이션/
│   └── 검증/
├── 04_실행지원/                 ← Phase 4

│   ├── 변화관리/
│   └── 교육자료/

    ├── 최종보고서/
    ├── 인계자료/
    └── 점검리포트/
```
