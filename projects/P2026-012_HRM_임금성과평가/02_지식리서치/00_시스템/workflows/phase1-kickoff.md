# Phase 1: Kickoff (프로젝트 시작)

## 목적
프로젝트의 명확한 정의·범위·일정·산출물을 클라이언트와 합의하고, 작업 기반을 셋업한다.

## 주요 활동

### 1.1 제안·수주 (수주 전)
- RFP 분석
- 제안서 작성 (`proposal-writing` 스킬)
- 제안 PT
- 견적·계약 협상

### 1.2 착수 (수주 후)
- 착수보고 (Kickoff Meeting)
  - 프로젝트 목표·범위·산출물 재확인
  - 일정·마일스톤
  - 협력 체계 (스폰서, PM, 카운터파트)
  - 의사결정 거버넌스 (Steering Committee)
- 자료 요청서 발송 (필요 자료 리스트)
- 인터뷰 일정 협조 요청

### 1.3 프로젝트 운영 셋업
- 프로젝트 폴더 생성: `03_프로젝트/[클라이언트명_프로젝트명]/`
- 프로젝트 개요 문서 (`00_프로젝트개요.md`) 작성
- 정기 미팅 셋업 (Weekly Status, 격주 Steering)

## 체크리스트

- [ ] 프로젝트 목표가 SMART한가
- [ ] 범위(Scope)가 명확한가 (In/Out)
- [ ] 산출물 리스트가 합의되었는가
- [ ] 마일스톤·납기가 합의되었는가
- [ ] 클라이언트 카운터파트가 명확한가
- [ ] 의사결정 거버넌스가 정의되었는가
- [ ] 자료 요청·인터뷰 협조가 확보되었는가
