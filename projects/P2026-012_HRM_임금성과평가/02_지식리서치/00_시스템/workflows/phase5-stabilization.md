# Phase 5: 안착 점검 (Stabilization)

## 목적
도입된 제도가 의도대로 운영되는지 점검하고, 미세 조정 및 후속 과제를 식별한다.

## 주요 활동

### 5.1 운영 모니터링 (도입 후 3~6개월)
- KPI 모니터링:
  - 평가 분포 (vs 강제분포 룰)
  - 평가 소요시간 (vs 추정치)
  - 임금 변동 분포 (vs 시뮬레이션)
  - 이의제기 건수
  - 이직률 (도입 전후)
- 정기 운영 점검 회의 (월별)

### 5.2 직원 피드백
- 만족도 서베이 (도입 3개월·6개월 후)
- 평가자·피평가자 인터뷰
- 노조·노사협의회 의견

### 5.3 미세 조정
- 운영 부담 과중 → 절차 간소화
- 평가 분포 왜곡 → 캘리브레이션 강화
- 공정성 인식 부족 → 커뮤니케이션 강화
- 시스템 결함 → IT 보완

### 5.4 최종 보고
- 안착 점검 보고서
- 향후 운영 권고사항
- 후속 과제 로드맵 (1~3년)

### 5.5 인계 (Handover)
- 인사팀 인계 (매뉴얼·툴킷·교육 자료 일체)
- 운영 책임자 지정
- 정기 자체 점검 사이클 합의

## 표준 산출물

| 산출물 | 비고 |
|--------|------|
| 운영 모니터링 KPI 대시보드 | |
| 만족도 서베이 결과 분석 | |
| 안착 점검 보고서 | 임원 보고 |
| 미세 조정안 | |
| 후속 과제 로드맵 | |
| 인계 자료 (Handover Package) | 매뉴얼·툴킷·교육·KPI |

## 체크리스트

- [ ] 도입 3~6개월간 KPI 모니터링이 진행되었는가
- [ ] 직원 만족도가 조사되었는가
- [ ] 평가 분포 등 핵심 지표가 의도대로인가
- [ ] 운영 부담이 추정 대비 적정한가
- [ ] 미세 조정 필요사항이 식별·반영되었는가
- [ ] 인사팀 인계가 완료되었는가
- [ ] 후속 과제(1~3년)가 식별되었는가
