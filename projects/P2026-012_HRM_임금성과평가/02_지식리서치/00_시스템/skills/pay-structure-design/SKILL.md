# SKILL: Pay Structure Design (임금구조 설계)

## 목적
호봉제 ↔ 직무급 ↔ 성과급 등 임금구조 신규 설계 또는 전환을 체계적으로 수행한다.

## 트리거
- "임금체계 재설계", "직무급 도입", "호봉제 폐지"
- "Pay Band 설계", "임금구조 전환"
- "연봉제 도입", "성과급 비중 확대"

## 사전 입력 (Inputs)

| 필수/선택 | 항목 | 비고 |
|-----------|------|------|
| 필수 | 현행 임금규정 | 기본급·수당·상여금 구조 |
| 필수 | 전 직원 임금 데이터 | 직급·근속·연봉 (개인식별 제거) |
| 필수 | 조직도·직급체계 | 현행 직급 수, Span of Control |
| 필수 | 경영진 의도 | 왜 바꾸려 하는가 (성과주의/공정성/유연성) |
| 선택 | 직무평가 결과 | 직무급 설계 시 필수 |
| 선택 | 시장 임금 데이터 | 외부경쟁력 검증 |
| 선택 | 노조 단협 | 노조 사업장 필수 |

## 표준 워크플로우

### Step 1. 현행 진단 (As-Is)
- 임금구조 분해: 기본급 / 정기수당 / 변동수당 / 상여금 / 복리후생
- 통상임금 산입 항목 확인 → `labor-law-expert` 협업
- 직급별·근속별·직무별 임금 분포 시각화 (Box Plot)
- 임금격차 분석:
  - 직급간 격차 (Compression Ratio)
  - 동일 직급 내 분산 (Coefficient of Variation)
  - 임금 역전(Inversion) 사례
- 시장경쟁력 점검 (있다면): Compa-ratio

### Step 2. 설계 원칙 (Design Principles)
- 임금 철학 정의:
  - 성과 차등 강도 (Pay for Performance 강/중/약)
  - 외부 vs 내부 형평성 우선순위
  - Lead / Match / Lag (시장 대비 포지셔닝)
- Pay Mix 설계:
  - Base : Variable : Benefits 비중 결정
  - 직급·직무별 차등 (Sales 변동급↑, 지원직 안정성↑)

### Step 3. 구조 설계 (Structure Design)

#### Option A. 호봉제 유지 + 단순화
- 호봉 수 축소 (40호봉 → 20호봉)
- 호봉 간 인상폭 조정 (정액 → 정률)
- 적용: 안정성 중시 조직, 노조 강한 조직

#### Option B. 직무급 도입 (Job-Based)
- Pay Grade 수 결정 (5~9 등급)
- 등급별 Pay Band 설계:
  - Min / Mid / Max
  - Spread (Mid 기준 Max-Min %) - 통상 40~60%
  - Overlap (인접 등급간 중복) - 통상 30~50%
- 직무평가 결과 → Grade 매핑

#### Option C. 직책급 도입 (Position-Based)
- 직책별 (팀장/그룹장/본부장) 직책수당
- 직책 부여·해임 시 처우 변동 룰

#### Option D. 성과급 강화 (Performance-Based)
- 변동급 비중 확대 (10% → 20~30%)
- 평가 등급 → 인센티브 매트릭스
- Bonus Pool 산정 (이익 연동)

### Step 4. 시뮬레이션
- 전 직원 개인별 영향 계산 (현재 임금 → 신제도 임금)
- 분포 분석:
  - 임금 인상자 / 동결자 / 인하자 비율
  - 직급·직무·근속별 영향
- 인건비 총액 영향 (3년 예측)
- 이행기 옵션 시뮬레이션:
  - Red Circle (신제도 Max 초과자 처우)
  - Green Circle (신제도 Min 미달자 처우)
  - Pay Protection 기간 (보통 2~5년)

### Step 5. 법적 검토
- `labor-law-expert` 협업:
  - 통상임금 영향
  - 취업규칙 불이익 변경 여부
  - 노조 단협 위반 여부
  - 동의 절차 (과반수 동의)

### Step 6. 이행 로드맵
- Phase 1: 신제도 설계 확정 (현재)
- Phase 2: 노사 협의·취업규칙 변경 (3~6개월)
- Phase 3: 신제도 시행 + Pay Protection (Year 1~3)
- Phase 4: 완전 전환 (Year 3~5)

## 품질 체크리스트

- [ ] 현행 진단에 모든 임금 항목이 분해되었는가
- [ ] 임금 분포가 시각화되었는가 (Box Plot, Heat Map)
- [ ] 신제도 적용 시 개인별 영향 100% 계산되었는가
- [ ] 인상자/동결자/인하자 비율이 명시되었는가
- [ ] 인건비 영향 3년 예측이 포함되었는가
- [ ] 통상임금·취업규칙 변경 법적 영향이 검토되었는가
- [ ] 이행기(Pay Protection) 옵션이 제시되었는가
- [ ] 의사결정자 입장의 Pros/Cons가 명확한가
