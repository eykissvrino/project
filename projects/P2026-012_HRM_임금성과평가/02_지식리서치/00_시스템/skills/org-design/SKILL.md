# SKILL: Org Design (조직설계)

## 목적
조직구조·R&R·RACI·권한위임을 통합 설계하여 전략 실행 효율성을 제고한다.

## 트리거
- "조직설계", "조직개편", "조직 재편"
- "R&R 재정의", "RACI 작성", "권한위임"

## 사전 입력
- 회사 전략·중기 계획
- 현행 조직도·정원
- 본부/팀별 미션 (있다면)
- 기존 권한위임표 (있다면)

## 표준 워크플로우

### Step 1. As-Is 진단
- 현행 조직도 분석:
  - 계층 수 (Layers)
  - 통제범위 (Span of Control)
  - 기능 중복·공백
- 의사결정 흐름 진단 (인터뷰 기반)
- 정보 흐름 진단 (회의체, 보고체계)

### Step 2. 조직 유형 결정
- **Functional**: 기능별 (개발/영업/마케팅)
  - 장점: 전문성, 효율
  - 단점: 사일로
- **Divisional**: 사업/제품/지역별
  - 장점: 책임 명확, 시장 대응
  - 단점: 중복, 규모 비효율
- **Matrix**: 기능 × 사업
  - 장점: 협업, 자원 활용
  - 단점: 책임 모호, Two Boss
- **Hybrid**: 위 조합

### Step 3. To-Be 조직 설계
- 본부/팀 신설·통폐합·이동
- 조직도 작성
- 정원 산정 (Workload 기반 또는 벤치마크)
- Span of Control 적정화 (6~10명)

### Step 4. R&R 정의
- 본부/팀별:
  - **미션** (Why exists)
  - **주요 책임** (Key Responsibilities) - 5~8개
  - **인접 조직과의 경계** (Boundary)
- 1 페이지 R&R Sheet 작성

### Step 5. RACI Matrix
- 주요 의사결정·실행 항목 식별
- R/A/C/I 매핑
- 갈등 영역 식별·해소

### Step 6. 권한위임 (DoA)
- 의사결정 항목 × 직책 매트릭스
- 금액 한도 (Spending Authority)
- 인사 권한 (채용, 평가, 승진)
- 결재 라인 단순화 (원칙: 3단계 이내)

### Step 7. 이행 계획
- 조직 변경 일정
- 인력 재배치 계획
- 신임 리더 임명
- 커뮤니케이션 플랜

## 산출물

1. 조직 진단 보고서
2. To-Be 조직도
3. 본부/팀 R&R 정의서
4. RACI Matrix
5. 권한위임표 (DoA Table)
6. 조직 이행 로드맵

## 품질 체크리스트

- [ ] 전략과 조직구조가 정합되는가
- [ ] Span of Control이 적정한가
- [ ] 기능 중복·공백이 해소되었는가
- [ ] RACI에서 A(Accountable)가 항상 단일인가
- [ ] DoA가 명확하고 단순한가 (3단계 결재 원칙)
- [ ] 이행 시 핵심인력 이탈·공백 리스크가 검토되었는가
