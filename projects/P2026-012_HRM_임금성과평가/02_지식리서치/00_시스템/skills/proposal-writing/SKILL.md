# SKILL: Proposal Writing (제안서 작성)

## 목적
RFP 또는 영업 기회에 대응하는 컨설팅 제안서를 작성한다.
"우리가 적임자임을 증명"하고, "How"를 명확히 제시한다.

## 트리거
- "제안서 작성", "Proposal"
- "RFP 대응", "PT 자료"

## 사전 입력
- RFP 또는 클라이언트 요청사항
- 클라이언트 정보 (산업, 규모, 현황)
- 견적 가이드 (Day Rate, 팀 구성)
- 유사 프로젝트 레퍼런스

## 표준 워크플로우

### Step 1. RFP 분석
- 클라이언트가 진짜 풀고 싶은 문제는? (RFP 행간 읽기)
- 의사결정자는 누구이며 무엇을 중시?
- 평가 기준 우선순위
- 마감일·예산 제약

### Step 2. Win Theme 정의
- "우리가 이기는 이유" 1~3개
- 차별화 포인트 (We vs They)
- 클라이언트 핵심 니즈와 매칭

### Step 3. 제안서 구조

#### 표준 목차
```
1. Executive Summary (1p)
   - 우리의 이해 + 접근 + 기대효과

2. 프로젝트 배경 및 이해
   - 클라이언트 현황·이슈
   - 우리는 당신을 이해하고 있다

3. 컨설팅 접근방안
   - 방법론 (Mercer/Hay/한국형 등)
   - 주요 단계 (Phase별)
   - 단계별 활동·산출물

4. 일정 (Gantt Chart)

5. 산출물 리스트

6. 팀 구성
   - 조직도 (PM, Lead, Member)
   - 핵심 멤버 약력

7. 회사 소개 / 차별화 포인트

8. 유사 프로젝트 레퍼런스

9. 견적 (Budget)

[Appendix]
- 상세 방법론
- 산출물 샘플
- 회사 자료
```

### Step 4. 슬라이드 작성
- 1 Slide 1 Message
- Visual 우선 (방법론 다이어그램, 일정 Gantt, 팀 구성도)
- 클라이언트 컬러·로고 활용
- 분량: 30~50 슬라이드 (Appendix 제외)

### Step 5. 견적·일정 검토
- 견적: 팀 × Day Rate × Days
- 일정 현실성 (클라이언트 인터뷰·자료수집 시간 고려)
- 산출물 vs 비용 정합성

### Step 6. 자체 검증
- Win Theme이 일관되게 흐르는가
- 클라이언트 RFP 요구사항이 모두 답해졌는가
- 차별화 포인트가 명확한가
- 견적·일정이 현실적인가

## 산출물

1. 제안서 본문 (PPT)
2. Executive Summary (1p)
3. 견적서 (별첨)
4. 회사 소개서 (별첨)

## 품질 체크리스트

- [ ] 첫 슬라이드 5분 안에 핵심 파악 가능한가
- [ ] Win Theme이 명확한가
- [ ] RFP 요구사항이 100% 답해졌는가
- [ ] 방법론이 클라이언트에 맞게 customize 되었는가
- [ ] 팀 구성·이력서가 적합성을 보여주는가
- [ ] 견적이 합리적인가
