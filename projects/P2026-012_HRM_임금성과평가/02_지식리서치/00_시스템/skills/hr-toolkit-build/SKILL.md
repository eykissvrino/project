# SKILL: HR Toolkit Build (실무 툴킷·엑셀모델 개발)

## 목적
설계한 HR 제도가 실무에서 작동하도록 엑셀 기반 시뮬레이터·계산기·관리도구를
개발한다.

## 트리거
- "엑셀 모델 만들어줘", "시뮬레이터 개발"
- "Pay Band 시뮬레이션", "Job Pricing Tool"
- "평가 점수 계산기", "인건비 시뮬레이터"

## 주요 툴킷 유형

### 1. Pay Band Simulator
**용도**: 신임금구조의 Min/Mid/Max, Spread, Overlap 시뮬레이션
**입력**: 등급 수, Mid Anchor (시장가), Spread%, Overlap%
**출력**: 등급별 Min/Mid/Max, Band 그래프
**고급기능**: 직무평가 점수 → 등급 자동 매핑

### 2. Job Pricing Model
**용도**: 직무평가 결과 + 시장임금 → 직무별 적정 임금
**입력**: 직무 리스트, 평가점수, 시장 P25/P50/P75
**출력**: 직무별 권장 임금 (Lead/Match/Lag 옵션)

### 3. 개인별 임금 영향 시뮬레이션
**용도**: 신제도 도입 시 개인별 임금 변화
**입력**: 직원별 현 임금, 신제도 룰
**출력**: 개인별 신 임금, 인상자/동결자/인하자 분포
**고급기능**: Pay Protection 옵션, 이행기 시나리오

### 4. 인건비 예측 모델 (3년)
**용도**: 인원·임금인상률·구조변화 반영 3년 인건비
**입력**: 직급별 인원·임금, 시나리오 (인상률·승진율·이직률)
**출력**: 연차별 인건비 추정

### 5. 평가 점수 계산기
**용도**: 다요소 평가의 가중 점수·등급 산정
**입력**: 평가 항목·가중치·점수
**출력**: 종합 점수, 등급, 분포

### 6. 캘리브레이션 도구
**용도**: 평가 후 분포 조정 시뮬레이션
**입력**: 평가자별 분포, 강제분포 룰
**출력**: 조정 전·후 분포 비교

### 7. Merit Matrix Calculator
**용도**: 평가 등급 × 임금 분위 → 인상률
**입력**: Matrix 룰, 직원별 등급·임금
**출력**: 직원별 인상률·인상액

### 8. Total Rewards Statement Generator
**용도**: 개인별 총 보상 명세서 (Base + Variable + Benefits)
**입력**: 직원 데이터
**출력**: 개인별 1페이지 명세서

## 표준 개발 워크플로우

### Step 1. 요구사항 정의
- 누가 사용? (HR / 임원 / Line Manager)
- 어떤 의사결정? (설계 시뮬레이션 / 운영)
- 사용 빈도? (1회용 / 매년 / 매월)

### Step 2. 아키텍처 설계
- **3-Layer 구조**:
  - **Input Sheet**: 사용자 입력 (노란색)
  - **Calculation Sheet**: 계산 로직 (회색, Protected)
  - **Output Sheet**: 결과 시각화 (파란색)
- 시트 분리, 명확한 명명

### Step 3. 수식·로직 구현
- 명명된 범위(Named Range) 활용
- 조건부 서식 (Conditional Formatting)
- 데이터 유효성 (Data Validation)
- 오류 처리 (IFERROR)

### Step 4. 시각화
- 차트: Box Plot (분포), Bar (비교), Line (트렌드)
- Heat Map (조건부 서식 활용)
- Dashboard 시트 (KPI 카드)

### Step 5. 사용자 매뉴얼
- 시트별 설명
- 입력 가이드
- 결과 해석 가이드
- FAQ

### Step 6. 테스트
- 극단 값 (0, 음수, 매우 큰 값)
- 빈 셀, 텍스트 입력
- 입력 데이터 변경 시 결과 갱신 확인

## 산출물
