# SKILL: HR Diagnostic (HR 전반 진단)

## 목적
HR Value Chain 전반에 걸친 종합 진단을 수행하여 강점·약점·이슈를 도출하고
To-Be 방향성을 제시한다.

## 트리거
- "HR 진단", "인사 진단", "현황 분석"
- "전반 HR Transformation", "HR 마스터플랜"
- "As-Is 분석", "갭 분석"

## 사전 입력 (Inputs)

| 필수/선택 | 항목 |
|-----------|------|
| 필수 | 회사 개황 (업종, 규모, 매출, 인원, 조직도) |
| 필수 | 회사 전략·중기 사업계획 |
| 필수 | 인사규정·취업규칙 일체 |
| 필수 | 인사 데이터 (인원, 이직, 임금, 평가 - 3년치) |
| 권장 | 인터뷰 대상 리스트 (경영진~실무자) |
| 권장 | 기존 직원만족도 조사 결과 |
| 선택 | 단체협약 (노조 있을 시) |

## 표준 워크플로우

### Step 1. 진단 프레임 확정
- **HR Value Chain** 기반 (권장):
  ```
  Talent Acquisition → Onboarding → Development → Performance
  → Reward → Engagement → Retention/Exit
  ```
- **Galbraith Star** (조직 통합 진단 시):
  Strategy, Structure, Process, Reward, People

### Step 2. 정량 진단 (Data Analysis)
- **인력 현황**:
  - 인원: 총원, 직급별, 직무별, 성별, 연령대별, 근속별
  - 학력·전공 분포
  - 외주·파견 비중
- **채용 메트릭**:
  - 채용 인원 (3년 추이)
  - Time-to-Fill, Cost-per-Hire
  - 직급별 채용 경로 (공채/경력/추천)
  - 신입 1년 이내 이탈률
- **이직률**:
  - 자발/비자발, 직급별, 근속별, 부서별
  - 이직 사유 (Exit Interview 데이터 있다면)
- **임금·인건비**:
  - 인건비 비중 (매출 대비)
  - 인당 평균 인건비
  - 직급별 임금 분포 (Box Plot)
  - 임금 인상률 (3년)
- **평가**:
  - 등급별 분포 (회사·부서·평가자별)
  - 평가-보상 연계도
  - 평가-승진 연계도
- **교육**:
  - 인당 교육시간·교육비
  - 교육 영역 분포
- **승진**:
  - 직급별 평균 근속·승진 소요년수
  - 승진율, 정체율

### Step 3. 정성 진단 (Interview)
- **인터뷰 가이드** 설계 (계층별):

| 대상 | 핵심 질문 |
|------|-----------|
| CEO/임원 | 인재상, 사업전략 vs HR 정합성, HR 우선 이슈, 미래상 |
| 본부장 | 인력 운영 애로사항, 평가·보상 문제, 조직 이슈 |
| 팀장 | 평가·1on1 부담, 우수인재 보유 어려움, 제도 운영 현실 |
| 실무자 | 동기부여, 공정성 인식, 성장 기회, 잔류 의향 |

- 대상 표본 (10명 이상 권장, 계층별 분산)
- 인터뷰 운영:
  - 1:1, 60~90분
  - 익명성 보장 약속
  - 인용 시 발언자 특정 금지
- FGI 보조 활용 (실무자 4~6명 그룹)

### Step 4. 문서 분석 (Documentation Review)
- 인사규정·취업규칙 → 현행 제도 명문화 수준
- 평가규정 → 평가 운영 정합성
- 임금규정 → 임금구조 분해
- 단체협약 → 노사 협의 사항
- 인사위원회·승진위원회 기록 → 의사결정 실태

### Step 5. 외부 벤치마크
- `research-analyst` 협업
- 동종업계·동규모 HR 메트릭 비교
- 글로벌 HR 트렌드 시사점

### Step 6. 갭 분석 (Gap Analysis)

| 영역 | As-Is | To-Be (목표상) | Gap | 우선순위 |
|------|-------|---------------|-----|---------|
| 채용 | ... | ... | ... | ... |
| 평가 | ... | ... | ... | ... |
| 보상 | ... | ... | ... | ... |
| (이하) | | | | |

- 우선순위 평가: **Impact × Urgency** Matrix

### Step 7. 이슈 도출 & Root Cause
- 발견된 증상(Symptoms) 정리
- 5 Whys 또는 Fishbone Diagram 으로 근본원인 분석
- 이슈 트리 (Issue Tree) 작성

### Step 8. 종합 진단·시사점
- HR Maturity 평가 (Level 1~5)
- 강점(Strengths) + 약점(Weaknesses) 균형
- Top 5~10 Key Findings
- 권고사항 우선순위 (Quick Win / Mid-term / Long-term)

### Step 9. 보고서 작성
- `consulting-report` 스킬 활용
- Executive Summary 2~3페이지
- 본문 30~50페이지
- Appendix (인터뷰 리스트, 데이터 상세)

## 산출물 (Outputs)

1. **HR 진단 종합 보고서**
2. **인터뷰 가이드 + 인터뷰 결과 종합**
3. **정량 데이터 분석 자료** (엑셀)
4. **벤치마크 비교 분석서**
5. **갭 분석표**
6. **이슈 트리·Root Cause 분석**
7. **권고사항 로드맵** (Quick Win / Mid / Long)

## 품질 체크리스트

- [ ] 정량 + 정성 + 문서 분석 삼각검증이 되었는가
- [ ] 인터뷰 표본이 계층별로 적절히 분산되었는가 (10명 이상)
- [ ] 외부 벤치마크가 포함되었는가
- [ ] 증상이 아닌 Root Cause까지 분석되었는가
- [ ] 강점과 약점이 균형 있게 제시되었는가
- [ ] 권고사항이 우선순위화되었는가
- [ ] Executive Summary가 단독으로 읽혀 의사결정 가능한가

## 연계 에이전트·스킬
