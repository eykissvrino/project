# Skills — HR 특화 스킬 라이브러리

각 폴더는 하나의 표준화된 HR 컨설팅 워크플로우입니다.
폴더 내 `SKILL.md` 파일이 진입점이며, 필요 시 하위에 참조 자료를 둡니다.

## 스킬 카탈로그

### 임금/보상 영역
- **pay-structure-design/** — 임금구조 설계 (호봉제↔직무급↔성과급 전환)
- **salary-benchmarking/** — 임금 벤치마킹 및 시장경쟁력 분석
- **hr-toolkit-build/** — 임금 시뮬레이터·Job Pricing 모델 등 엑셀 툴킷 구축

### 평가/성과 영역
- **performance-system-design/** — 성과관리 제도 설계 (OKR/MBO/KPI)
- **competency-modeling/** — 역량모델 개발

### 직무/조직 영역
- **job-evaluation/** — 직무평가 (IPE, Hay Method, 한국형)
- **jd-development/** — JD 작성·표준화
- **org-design/** — 조직설계 (구조·R&R·RACI·DoA)

### 진단·통합 영역
- **hr-diagnostic/** — HR 전반 진단

### 산출물 작성 영역
- **proposal-writing/** — 제안서 작성
- **consulting-report/** — 컨설팅 보고서 작성

### 실행 지원 영역
- **change-management/** — 제도 도입 변화관리

## 스킬 작성 표준

각 SKILL.md 는 다음 섹션을 포함:

1. **목적·트리거**: 언제 이 스킬을 발동시키는가
2. **사전 입력 (Inputs)**: 시작 전 필요한 자료·정보
3. **표준 단계 (Workflow)**: Step 1, 2, 3 ... 순서
4. **산출물 (Outputs)**: 완료 시 생성되는 결과물
5. **품질 체크리스트**: 결과물이 제대로 됐는지 검증 항목
6. **연계 에이전트·스킬**: 함께 호출하면 좋은 것들
