# SKILL: Performance System Design (성과관리 제도 설계)

## 목적
조직 전략과 개인 성과를 연계하는 성과관리 시스템을 설계한다.
OKR/MBO/KPI/BSC 등 적절한 프레임워크를 선택·조합한다.

## 트리거
- "성과관리 제도 도입/재설계"
- "평가제도 개편", "OKR 도입", "MBO 정비"
- "역량평가 신설", "다면평가 도입"
- "캘리브레이션 체계화"

## 사전 입력 (Inputs)

| 필수/선택 | 항목 | 비고 |
|-----------|------|------|
| 필수 | 현행 평가규정 | 평가 축·등급·주기 |
| 필수 | 평가 결과 분포 (3년) | 등급별·부서별 |
| 필수 | 평가 활용 영역 | 보상/승진/육성 |
| 필수 | 조직 전략·KPI 체계 | 캐스케이딩 출발점 |
| 선택 | 직원 만족도 조사 | 제도 이슈 파악 |
| 선택 | 평가자 인터뷰 | 운영 부담·정확성 |

## 표준 워크플로우

### Step 1. 진단 (Current State)
- 평가 운영 실태:
  - 평가자 1인당 피평가자 수
  - 평가 소요시간 (평가자/피평가자)
  - 평가 회의·캘리브레이션 횟수
- 평가 분포 분석:
  - 등급별 비율 (S/A/B/C/D)
  - 부서별 등급 분포 편차
  - 평가자별 관대화·중심화 패턴
- 운영 이슈:
  - 형식적 평가 (Forced Distribution 무시)
  - 평가자 부담 (시간·심리)
  - 결과 활용 미흡 (보상·승진 미연계)
  - 피드백 부재 (1-on-1 부족)

### Step 2. 설계 원칙 결정
- **평가 목적 명확화**:
  - 보상 차등 (Pay for Performance)
  - 승진 자료
  - 육성·피드백
  - 동기부여
  → 주된 목적이 무엇인가?
- **평가 철학**:
  - 절대평가 vs 상대평가
  - 도전적 목표 vs 달성 가능 목표
  - 결과 중심 vs 행동 중심

### Step 3. 평가 축 설계

#### 성과(What) 평가
- **KPI/MBO 방식**:
  - 연초 목표 설정 → 연말 달성도 평가
  - 정량 KPI 비중 (50~70%)
  - SMART 원칙: Specific, Measurable, Achievable, Relevant, Time-bound
- **OKR 방식**:
  - Objective (정성, 도전적) + Key Results (정량 3~5개)
  - 70% 달성을 "성공"으로 (도전성 확보)
  - 분기별 운영

#### 역량(How) 평가
- 역량 사전 활용 (`competency-modeling` 스킬)
- 핵심역량 (전사 공통) + 리더십역량 (관리직) + 직무역량 (직무별)
- BARS 등 행동 척도 적용

#### 비중 결정
- 성과 : 역량 비중 (예: 70:30, 60:40)
- 직급별 차등 가능 (상위직 성과↑, 하위직 역량↑)

### Step 4. 평가 등급·분포 설계
- 등급 수: 5등급 (S/A/B/C/D) 또는 7등급
- 분포 룰:
  - 강제분포 (Forced): 예) 10/20/40/20/10
  - 권고분포 (Guideline): 위 비율을 권고
  - 자율분포 (Free): 평가자 재량
- 캘리브레이션:
  - 부서장 회의에서 분포 조정
  - 직급별 캘리브레이션 (시니어 평가자 다수)

### Step 5. 평가 주기·프로세스
- **연간**: 단순, 부담 적음, but 피드백 지연
- **반기**: 균형, 가장 일반적
- **분기**: 피드백 빈도↑, but 부담↑ (OKR 적합)
- **상시(Continuous PM)**: GE 등 글로벌 트렌드

표준 흐름:
```
[목표설정] → [중간점검 1-2회] → [자기평가] → [1차 평가] → [캘리브레이션]
→ [2차 평가] → [결과 확정] → [면담·피드백] → [이의제기]
```

### Step 6. 평가자 - 피평가자 매핑
- 1차 평가자: 직속상사
- 2차 평가자: 차상위
- 다면평가 (선택):
  - 상사 / 동료 / 부하 / 자기평가 비중
  - 통상 360도는 육성용으로만, 보상 직접 연계 X

### Step 7. 결과 활용 설계
- 보상 연계:
  - Merit Matrix: 등급 × 임금 분위 → 인상률
  - 인센티브 배분
- 승진 연계:
  - 승진 후보 자격 (직전 N년 평가)
  - 패스트트랙 (S등급 연속자)
- 육성 연계:
  - IDP (Individual Development Plan)
  - 교육·코칭 연계
  - 저성과자 PIP

### Step 8. 운영 인프라
- 평가 시스템 (수기 → 엑셀 → 솔루션)
- 평가자 교육 (필수)
- 평가 매뉴얼 (평가자용 + 피평가자용)
- 1-on-1 가이드
- 피드백 대화 스킬 교육

### Step 9. 시뮬레이션·검증
- 가상 데이터로 신제도 운영 시뮬레이션
- 평가자 부담 추정 (1인당 시간)
- 분포 시뮬레이션 (현재 vs 신제도)
- Quick Win 부서 파일럿 운영 검토

## 산출물 (Outputs)

1. **성과관리 제도 진단보고서**
2. **성과관리 제도 설계서** (To-Be)
3. **평가지표 풀 (KPI Library)** — 직무별 표준 KPI
4. **역량모델** (별도 스킬 산출물)
5. **평가 운영 매뉴얼** (평가자/피평가자)
6. **캘리브레이션 가이드**
7. **평가자 교육자료** (PPT)
8. **1-on-1 / 피드백 가이드**
