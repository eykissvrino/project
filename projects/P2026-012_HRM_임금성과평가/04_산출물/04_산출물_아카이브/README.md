## 아카이빙 절차 (프로젝트 종료 시)

### Step 1. 케이스 스터디 작성
- `01_지식베이스/케이스스터디/` 에 1~2 페이지 케이스 작성
- 학습·노하우 추출

### Step 2. 재사용 산출물 추출
- 우수한 산출물 → `02_템플릿/` 에 양식화
- 엑셀 모델 → `02_템플릿/엑셀모델/` 에 일반화 버전

### Step 3. 폴더 정리
- 불필요한 임시 파일 삭제
- 개인식별 정보 재마스킹
- 폴더명 최종 정리: `[클라이언트약칭]_[프로젝트영역]_[YYYY]`

### Step 4. 아카이브 이동
- `03_프로젝트/[프로젝트명]/` → `04_산출물_아카이브/[YYYY]/[프로젝트명]/`

### Step 5. 인덱스 업데이트
