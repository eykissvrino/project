# 03_프로젝트 — 진행 중인 프로젝트

본 폴더에 각 프로젝트별 작업 공간을 만듭니다.

## 폴더 명명 규칙

```
[클라이언트약칭]_[프로젝트영역]_[YYYYMM]
예: ABC상사_임금체계_202605
    XYZ공기업_평가제도_202604
    DEF벤처_HR전반_202606
```

## 표준 프로젝트 폴더 구조

새 프로젝트 시작 시 아래 구조 복사:

```
[프로젝트명]/
├── 00_프로젝트개요.md           ← 한눈에 보기
├── 01_kickoff/                  ← Phase 1
│   ├── 제안서/
│   ├── 착수보고/
│   └── 계획/
│
├── 02_진단/                     ← Phase 2
│   ├── 인터뷰/
│   │   ├── 인터뷰_가이드/
│   │   ├── 인터뷰_노트/         (익명화)
│   │   └── 인터뷰_결과종합.md
│   ├── 데이터분석/
│   │   ├── raw/                 (원본, 마스킹)
│   │   └── analysis/
│   ├── 벤치마크/
│   └── 진단보고서/
│
├── 03_설계/                     ← Phase 3
│   ├── 옵션비교/
│   ├── 제도설계서/
│   ├── 시뮬레이션/
│   └── 검증/
│       └── 법적검토/
│
├── 04_실행지원/                 ← Phase 4
│   ├── 매뉴얼/
│   ├── 변화관리/
│   │   ├── 커뮤니케이션/
│   │   └── 교육자료/
│   └── 시스템요건/
│
├── 05_최종산출물/               ← Phase 5
│   ├── 최종보고서/
│   ├── 인계자료/
│   └── 점검리포트/
│
└── communication/               ← 클라이언트 소통 이력
    ├── meetings/                (회의록)
    └── emails/                  (주요 이메일)
```

- **기간**: YYYY-MM-DD ~ YYYY-MM-DD
- **PM**: 이석주
- **팀**: [멤버 리스트]

## 클라이언트 정보
- **산업**: [업종]
- **규모**: 매출 ___, 인원 ___

## 프로젝트 종료 처리

1. `05_최종산출물/`에 최종 결과물 정리
2. **케이스 스터디 작성**: `01_지식베이스/케이스스터디/` 에 학습 내용 1~2p 정리
3. **재사용 가능한 산출물 추출**: `02_템플릿/` 에 양식화
4. 전체 프로젝트 폴더를 `04_산출물_아카이브/[YYYY]/` 로 이동
