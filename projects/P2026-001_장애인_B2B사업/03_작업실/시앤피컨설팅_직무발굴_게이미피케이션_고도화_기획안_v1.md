## 1. 설계 배경 및 원칙

### 1-1. 작년 자료에서 검증된 것 (유지)

- **3시간 / 5단계 흐름** (사업안내 → 워크숍개요 → 장애 이해 → 우리회사 들여다보기 → 직무발굴 게임)
- **공감 칩(Chip) 보상 시스템** (1pt / 5pt / 10pt 차등 투표권)
- **Ground Rule 3원칙** (정답 없음 / 비판 금지 / 편견 없이 보기)
- **질문카드 21종 자산** ("정확함이 필요한 순간", "체력이 강점이 되는 일", "착한 기업 소문내기" 등)
- **씨앗카드_직무** 보조도구 (아이디어 막힐 때 칩으로 교환)

### 1-2. 고도화 포인트 (개선)

| 진단 | 고도화 방향 |
|------|------------|
| 아이스브레이킹이 **개인 소개**에 머무름 (해시태그·밸런스카드) — 인식 개선 효과 약함 | 미스터리 아티스트형 **편견 자각 게임**으로 전환 |
| 직무발굴 게임이 **질문카드 단일 메커니즘** — 발산 다양성 한계 | "꼬치 조합" 메커니즘 추가 — 조직 R&R × 가치영역의 **이종 조합**으로 발산 폭 확대 |
| 질문카드가 **나열식**이라 우선순위·시간 운영이 어려움 | 21종 카드를 **6개 카테고리**로 재분류 + 라운드제 도입 |
| 게임 산출물이 **포스트잇 더미**로 끝남 — 다음 단계로 연결 약함 | **직무 후보 카드 시트**(아이디어 + 카테고리 + 가치영역 + 평가점수) 표준화 |

### 1-3. 3개 게임의 설계 철학

> **"편견을 깨고 → 가능성을 펼치고 → 현장에 꽂는다"**

```
[편견 아티스트]   →   [직무 꼬치 챌린지]   →   [씨앗에서 직무로]
   인식 전환            발산 (Divergence)         수렴 (Convergence)
   "사고의 틀 깨기"     "조합으로 폭 넓히기"      "현장으로 꽂아넣기"
```

## 3. GAME 1. 편견 아티스트 (Bias Artist)

### 3-1. 게임 컨셉 — 라이헌트 "미스터리 아티스트" 메커니즘

라이헌트 미스터리 아티스트의 원형 메커니즘을 그대로 차용합니다.

> **벤치마킹 원형**:
> 대부분의 플레이어는 **같은 카드(예: '루피')**를 받지만,
> 한 명(마피아)만 **관련 있지만 살짝 다른 카드(예: 루피와 비슷하지만 다른 인물/이미지)**를 받습니다.
> 모두 5초 동안 동시에 그림을 그리고,
> 다른 사람들 그림을 보며 **"누가 다른 카드를 받았는지(마피아)"**를 추리합니다.

이 메커니즘이 장애인 인식 개선에 강력한 이유:
- 5초의 짧은 시간 → **머릿속 첫 이미지(=무의식적 편견)**가 그대로 종이에 나옴
- 같은 카드를 받은 사람들끼리도 **그림이 미묘하게 다름** → "같은 단어도 머릿속 이미지가 다 다르다" 체험
- 마피아 추리를 통해 **누구의 그림이 통념과 가까운지/먼지**가 자연스럽게 드러남

### 3-2. 게임 목적

- 장애인·장애인 직무에 대한 **무의식적 첫 이미지(편견)**를 본인 그림으로 시각화
- 같은 단어를 두고도 **사람마다 머릿속 이미지가 다르다**는 것을 체험
- 마피아 카드를 통해 **"장애인 직무 = ○○일 것이다"**라는 좁은 프레임을 흔듦
- 이후 직무발굴 단계의 다양성·수용성 기반 마련

### 3-3. 구성품

| 항목 | 수량 / 사양 | 설명 |
|------|------------|------|
| 주제 카드 세트 (Theme Set) | 12세트 (1세트 = 메인카드 N장 + 마피아카드 1장) | 1라운드당 1세트 사용 |
| A4 종이 + 굵은 마커 | 인원수만큼 | 5초 안에 그릴 수 있도록 굵은 펜 권장 |
| 마피아 지목판 | 인원수만큼 | 라운드별 추리 결과 동시 공개용 |
| 토론 카드 (Reveal Card) | 12장 (세트당 1장) | 라운드 종료 후 "사실은…" 메시지 |
| 모래시계(5초·30초) | 2개 | 드로잉/추리 타이머 |

#### 주제 카드 세트 — 핵심 설계

각 세트는 **메인 카드(다수가 받음) + 마피아 카드(한 명만 받음)**의 페어로 구성. 마피아 카드는 메인과 **관련 있지만 살짝 다른** 단어 — 그래서 그림이 비슷하게 나올 수도, 결정적 디테일에서 갈릴 수도 있도록 설계.

핵심 트릭은 **"마피아 카드를 통해 통념을 흔드는 것"**입니다.

#### 12라운드 카드 세트 예시

| # | 라운드 컨셉 | 메인 카드 (다수) | 마피아 카드 (1명) | 학습 포인트 (Reveal) |
|---|------------|------------------|-------------------|----------------------|
| 1 | 워밍업 — 같은 단어 | "직장인" | "직장인" *(전원 동일)* | "같은 단어인데도 그림이 다 달랐죠? — 같은 주제, 다른 머릿속" |
| 2 | 직무 통념 흔들기 | "장애인 직무" | "직장인 직무" | "두 그림이 비슷한가요, 다른가요? — 사실 본질은 같습니다" |
| 3 | 직무 폭 흔들기 | "단순 반복 직무" | "장애인 직무" | "혹시 두 그림이 닮아 있나요? — 그게 우리 머릿속 첫 이미지" |
| 4 | 능력 통념 흔들기 | "장애인 동료" | "신입사원 동료" | "동료를 그릴 때 머릿속에 떠오른 차이는 무엇이었나요?" |
| 5 | 직무 다양성 | "사무실에서 일하는 사람" | "사무실에서 일하는 장애인" | "장애인을 떠올리니 그림이 어떻게 달라졌나요?" |
| 6 | 환경 통념 | "회사 휴게실" | "장애인 휴게실" | "왜 다른 그림이 되었을까요? 우리 회사는 같은 공간 아닌가요?" |
| 7 | 직무 영역 | "바리스타" | "장애인 바리스타" | "그림에 무엇이 추가/제거됐나요? — 이미 곳곳에 있는 직무" |
| 8 | 지원수단 통념 | "AI와 일하는 사람" | "장애인과 AI" | "AI는 장애인 보조도구일까요, 모두의 동료일까요?" |
| 9 | 능력 강점 | "꼼꼼한 사람" | "발달장애 직장인" | "두 단어, 사실 같은 사람을 가리킬 수도 있습니다" |
| 10 | 고객 통념 | "고객 응대 직원" | "청각장애 직원의 고객 응대" | "응대 = 말하기? — 시각·문자·디지털 응대도 응대입니다" |
| 11 | 미래 직무 | "AI 콘텐츠 검수자" | "발달장애 콘텐츠 검수자" | "스마일게이트·네이버 등 실제 사례입니다" |
| 12 | 마무리 — 통합 트릭 | "우리 회사 동료" | "우리 회사 동료" *(전원 동일)* | "처음 라운드처럼 같은 단어. 1라운드와 비교하면 그림이 어떻게 달라졌나요?" |

> **운영 팁**: 12라운드 전부 진행하지 않고 **5–6 라운드**만 선택해 진행 (30분 한정). FT가 워크숍 톤에 맞춰 라운드를 고름. 1라운드(워밍업)와 12라운드(마무리)는 필수.

### 3-4. 진행 방법 (30분)

```
[1단계] 세팅 (3분)
  • 4–6명 1조. A4 + 마커 배부
  • FT가 룰 설명:
    "라이헌트 미스터리 아티스트라는 게임을 변형했습니다.
     매 라운드 여러분은 카드를 한 장씩 받습니다.
     대부분은 같은 카드, 한 명만 살짝 다른 카드를 받습니다.
     5초 동안 그 카드를 그림으로 그리고,
     그림을 보며 '누가 다른 카드(마피아)를 받았는지' 추리합니다."

[2단계] 라운드 반복 (4분 × 5–6라운드)
  매 라운드 흐름:
  ① [카드 분배 — 10초]
     • FT가 카드를 비공개로 배포
     • 1명만 마피아 카드, 나머지는 메인 카드
     • (1라운드와 마지막 라운드는 전원 같은 카드)

  ② [드로잉 — 5초] ★ 핵심
     • FT 신호로 동시에 그림 시작
     • 5초 안에 그릴 수 있는 굵은 마커 사용
     • 글자·기호 금지, 오직 그림만

  ③ [공개 + 추리 — 30초]
     • 모두 동시에 그림 공개
     • 30초 동안 그림을 비교
     • FT 신호에 맞춰 마피아 지목판 동시 공개

  ④ [정답 공개 + Reveal 메시지 — 1분 30초]
     • 마피아 정체 공개 (점수는 매기지 않음, 토론용)
     • FT가 Reveal 카드 낭독:
       예) "두 카드는 '직장인 직무'와 '장애인 직무'였습니다.
            그림에서 어떤 차이가 보였나요?
            …사실, 본질은 같은 일입니다."

  ⑤ [짧은 코멘트 — 1분]
     • 그림이 가장 다르게 나온 사람 / 마피아로 의심받은 사람 1–2명에게:
       "왜 그렇게 그렸어요?"
     • 비난 톤이 아닌 **호기심 톤**

[3단계] 마무리 인사이트 (2분)
  • FT 마무리:
    "5초 안에 손이 그려낸 그림 = 우리 머릿속 첫 이미지입니다.
     같은 단어도 사람마다 다르고,
     '장애인'이라는 한 글자가 더해지는 순간 그림이 달라지기도 합니다.
     오늘 워크숍은 그 첫 이미지를 흔들어보는 자리입니다."
  • Ground Rule 3원칙으로 연결
```

### 3-5. 진행자(FT) 가이드

- **5초 엄수.** 길어지면 머리로 검열하면서 그림 — 첫 이미지가 안 나옴
- **점수·승패 없음.** 마피아를 맞히는 게임이 아니라 **그림 비교가 본질**
- 마피아로 지목된 사람을 **놀리거나 비난 금지** — 항상 호기심 톤
- Reveal 카드 메시지는 **사실 정보 + 가벼운 질문**으로 마무리 (강의 톤 금지)
- 1라운드(워밍업)에서는 마피아 없음을 끝에 공개 → 충격 효과 + 본 게임 몰입
- 마지막 라운드(마무리)도 마피아 없음 → 1라운드와 같은 단어로 비교: "처음 그림과 지금 그림이 어떻게 달라졌는지" 자기 변화를 직접 보게 함
- 카드 뒷면에 **실제 사례·QR 영상 링크** 첨부 (스마일게이트 발달장애 게임테스터, 시각장애 바리스타, 한유아 메타휴먼 등)

### 3-6. 산출물

- 라운드별 그림 (조별로 사진 촬영해 보관)
- "내 첫 이미지" 메모 (워크숍 종료 후 회수, 익명) — 인식 개선 컨설팅 보고서 부록
- 1라운드와 12라운드 그림 **Before/After 비교** — 변화 시각자료

## 4. GAME 2. 직무 꼬치 챌린지 (Job Skewer Challenge)

### 4-1. 게임 컨셉

꼬치의 달인 보드게임의 **"색상 조건에 맞춰 재료를 빠르게 끼우는"** 메커니즘을 변형. 우리는 재료를 **회사 R&R + 가치영역 + 지원수단** 키워드로 치환하고, 색상 조건을 **"이번 라운드의 직무 발굴 미션"**으로 부여합니다.

> **핵심 변경**: 단순 속도 게임이 아니라 — **꼬치 = 직무 가설**. 꼬치를 만들면 그 조합이 어떤 신규 직무 아이디어가 될 수 있는지 **30초 안에 발의**해야 칩 획득.

### 4-2. 게임 목적

- 작년 워크숍의 한계였던 **"키워드 단일 진입(질문카드)"**을 보완 → 사업영역 × 가치영역의 **이종 조합**으로 발산 폭 확대
- "장애인 직무 = 단순 반복"이라는 좁은 프레임 탈출 → AI/ESG/임직원복지/고객경험까지 가치영역 확장
- 빠른 발의 + 동료 평가 → **결정의 부담 없이 양으로 발산**

### 4-3. 구성품

| 카드 종류 | 색상 | 수량 | 내용 예시 |
|-----------|------|------|-----------|
| 🔴 **R&R 재료카드 (Red)** | 빨강 | 60장 | "재고 정리", "문서 스캔", "콘텐츠 검수", "바리스타 음료 제조", "고객 안내", "데이터 입력", "회의실 준비", "메일링", "교내 우편" 등 — 회사가 실제로 수행하는 단위업무(Task) |
| 🟡 **가치영역카드 (Yellow)** | 노랑 | 40장 | "고객 서비스 품질", "임직원 복지", "ESG 가치 실현", "AI 활용", "다양성·포용", "효율 개선", "감동 서비스", "브랜드 가치" |
| 🟢 **장애유형카드 (Green)** | 초록 | 30장 | "지체장애", "시각장애", "청각장애", "발달장애", "지적장애", "정신장애" — 각 유형별 강점 한 줄 첨부 |
| 🔵 **지원수단카드 (Blue)** | 파랑 | 30장 | "AI 자동화 도구", "근로지원인", "환경 조정", "직무 코치", "음성 변환", "협업 챗봇" |
| 꼬치 막대 (점수판) | — | 12개 | 4가지 색을 끼울 수 있는 보드 |
| 공감 Chip | 1/5/10pt | 인원수 × 10개 | 작년 시스템 계승 |
| 미션 카드 (라운드 조건) | — | 10장 | 라운드별 꼬치 조건 |

#### 미션 카드 (꼬치 조건) 예시

| # | 라운드 미션 | 필요 재료 |
|---|------------|-----------|
| 1 | "Quick Win 직무" — 즉시 도입 가능한 단순 적합 직무 | 🔴 + 🟢 |
| 2 | "고객 감동 직무" — 고객 경험을 끌어올리는 직무 | 🔴 + 🟡(고객 서비스 품질) + 🟢 |
| 3 | "AI 협업 직무" — AI와 사람이 함께 하는 직무 | 🔴 + 🟡(AI 활용) + 🔵 |
| 4 | "ESG 히어로 직무" — ESG·사회적 가치 직무 | 🔴 + 🟡(ESG 가치 실현) + 🔵 |
| 5 | "임직원 복지 직무" — 사내 만족도를 높이는 직무 | 🔴 + 🟡(임직원 복지) + 🟢 |
| 6 | "사각지대 직무" — 누구도 책임지지 않던 일 | 🔴 + 🟢 + 🔵 |
| 7 | "Future Job" — 미래형, 새로 만드는 직무 | 🔴 + 🟡 + 🔵 (자유 조합) |

### 4-4. 진행 방법 (50분)

```
[1단계] 세팅 (5분)
  • 4–6명 1조. 카드 더미 색상별로 가운데 배치
  • 각자 공감 칩 10개 (1pt×5, 5pt×3, 10pt×2)
  • FT가 1번 미션 카드 공개

[2단계] 라운드 진행 (7분 × 6라운드 = 42분)
  매 라운드 흐름:
  ① FT가 미션 카드 공개 — "이번 라운드는 [Quick Win 직무]입니다.
                          🔴 R&R + 🟢 장애유형으로 꼬치 만드세요!"
  ② [발의 페이즈 — 4분]
     • 참가자는 미션 조건에 맞춰 재료카드를 모아 꼬치를 만든다
     • 꼬치를 완성한 사람부터 손을 들고 발의:
       "저는 🔴재고정리 + 🟢시각장애 꼬치를 만들었습니다.
        '시각장애인 음성 인식 기반 재고 정리 직무'를 제안합니다.
        반복 패턴 + 음성 라벨링 강점을 활용하면…(30초)"
  ③ [평가 페이즈 — 2분]
     • 다른 참가자들이 공감 칩으로 점수 부여 (1/5/10pt)
     • 발의자는 받은 칩만큼 점수 획득
     • 모든 발의 끝나면 다음 라운드
  ④ [메모 페이즈 — 1분]
     • FT 보조원이 발의된 직무 후보를 '직무 후보 시트'에 기록
       (꼬치 구성 / 직무명 / 발의자 / 받은 칩)

[3단계] 정산 (3분)
  • 누적 칩 1위 발표 + 작은 시상
  • 발의된 30+개 직무 후보 카드를 수집해 GAME 3로 인계
```

### 4-5. 칩 분배 규칙 (작년 시스템 계승 + 보완)

- 1pt = "오! 괜찮은 아이디어"
- 5pt = "와! 너무 좋은 생각"
- 10pt = "대박, 어떻게 이런 생각을!"
- **신규 룰**: **자기 자신에게 칩 부여 금지** + **모든 칩을 라운드 종료 시점에 소진하지 못하면 0pt 처리** → 평가 적극성 확보

### 4-6. FT 운영 팁

- **양 > 질**: 6라운드 동안 **30개 이상의 직무 가설**이 나오는 것이 1차 목표
- 발의가 막힐 때: "꼭 새로운 직무가 아니어도 됩니다. **기존 직무를 다르게 묶거나 자르면 무엇이 될까요?**"
- 가치영역카드(🟡)를 빠뜨리는 조에는 의도적으로 가치 미션을 더 부여 → ESG·AI까지 끌어내기

### 4-7. 산출물

**[직무 후보 시트] — 라운드별 자동 누적**

| 라운드 | 꼬치 구성 (R&R + 가치 + 유형 + 지원) | 제안 직무명 | 발의자 | 받은 칩 |
|--------|-------------------------------------|-------------|---------|---------|
| R1 | 재고정리 + 시각장애 | 음성 라벨 재고 관리자 | 김OO | 16pt |
| R2 | 회의실 준비 + 임직원 복지 + 발달장애 | 미팅 케어 호스트 | 이OO | 22pt |
| ... | ... | ... | ... | ... |

이 시트가 **GAME 3의 입력값**이 됩니다.

## 5. GAME 3. 씨앗에서 직무로 (Seed to Job) — 질문/씨앗카드 v2

### 5-1. 게임 컨셉

작년 21종 질문카드와 씨앗카드 자산을 계승하되, **카테고리 분류 + 라운드제 + 페인포인트 매칭**의 세 축으로 고도화합니다.

GAME 2에서 발산된 30+개 직무 가설 중 일부를, **현장의 페인포인트와 짝지어 검증**하고, **TOP 3 후보**로 수렴합니다.

> **벤치마킹**: 작년 자료의 "공감 Chip + 질문카드 + 씨앗카드_직무" 시스템을 유지하되, **카드를 카테고리화**하고 **3 라운드 구조**를 도입.

### 5-2. 게임 목적

- 발산된 아이디어를 **현장 니즈 기반**으로 검증 (페인포인트 매칭)
- "좋은 아이디어"와 "실행 가능한 아이디어"를 **함께 평가**
- 다음 모듈(M3 적합직무 선정)에 넘길 **TOP 3 직무 후보**를 도출

### 5-3. 카드 재구성: 21종 → 6 카테고리

작년 21종 질문카드를 **6개 카테고리**로 재분류했습니다.

| 카테고리 | 색상 | 작년 카드 매핑 | 카드 수 |
|----------|------|----------------|---------|
| **A. 효율 개선** | 회색 | 덜어내면 더 좋은 것 / 일 폭탄 구조 요청 / 같은 루틴이 반복되는 일 / 자잘한 정리왕 | 6장 |
| **B. 고객 경험** | 빨강 | 고객을 놀래켜라 / 고급스러움을 만드는 디테일 / 고객의 불편을 줄여주는 역할 / 의사소통이 중요한 순간 | 6장 |
| **C. 임직원 복지** | 노랑 | 기분 좋아지는 시작 / 조용히 집중할 수 있는 일 | 4장 |
| **D. ESG·다양성** | 초록 | 착한 기업 소문내기 / 아무도 안 해봤지만 신세계 | 4장 |
| **E. 강점·감각** | 파랑 | 정확함이 필요한 순간 / 체력이 강점이 되는 일 / 뛰어난 감각을 활용해보자 / 꾸준함으로 신뢰를 주는 일 / 세심하게 구분하고 분류하는 일 / 반복과 루틴이 필요한 순간 | 8장 |
| **F. 미래·AI** | 보라 | 상상의 나래 / 예술 감각이 빛나는 순간 | 4장 |

**합계 32장** (기존 21종을 분할·증보)

### 5-4. 신규 카드: 페인포인트 카드 (Pain Point Card)

GAME 2에서 발의된 직무를 검증하기 위한 **현장 페인포인트 카드 16장**.
"우리 회사 들여다보기" 단계에서 도출된 페인포인트로 보완.

예시:
- 🔥 "비서가 부족해서 임원 일정 관리가 누락된다"
- 🔥 "콘텐츠 검수가 외주라서 비용·품질 모두 불만"
- 🔥 "임직원 복지센터 운영자가 없어 사용률이 낮다"
- 🔥 "ESG 보고서 데이터 수집을 매년 야근으로 한다"
- 🔥 "신입사원 온보딩 멘토링이 부서마다 들쑥날쑥"

### 5-5. 씨앗카드 (계승 + 보완)

작년 "씨앗카드_직무"는 그대로 유지하되, **씨앗 카드 = GAME 2에서 발의된 직무 후보 카드**가 되도록 연결합니다.

→ GAME 2 산출물(30+개 직무 후보 시트)을 카드 형태로 출력해 GAME 3에서 재사용.

### 5-6. 진행 방법 (50분)

```
[라운드 1] 페인포인트 매칭 (15분)
  • FT가 페인포인트 카드 6장을 테이블에 펼침
  • 각 조는 GAME 2 직무 후보 카드 중 페인포인트와 매칭되는 것을 선택
  • "이 페인포인트를 [○○ 직무]로 풀어보겠습니다" 발표 (조별 2분)
  • 다른 조는 공감 칩 부여
  • 산출물: 페인포인트–직무 매칭 시트

[라운드 2] 카테고리 챌린지 (20분)
  • 6개 카테고리 카드(A~F) 중 4장을 무작위로 뽑음
  • 각 카테고리에서 1개씩, 총 4개의 직무 후보 추가 발의
  • "꾸준함으로 신뢰를 주는 일" 카테고리 → "월말 정기 데이터 정합성 점검 직무" 식
  • 발의 후 공감 칩 평가
  • 핵심: GAME 2에서 가벼웠던 카테고리(예: F. 미래·AI)를 의도적으로 강화

[라운드 3] TOP 3 선정 (15분)
  • 지금까지 발의된 모든 직무 후보를 칩 점수 순으로 정렬
  • 상위 5개에 대해 "장애친화 직무 적합성 매트릭스" 5축 평가
    축: 직무가치 / 과업명확성 / 표준화 / 지원가능성 / 환경적합성
    각 축 1–5점, 만점 25점
  • TOP 3 직무 후보 확정
  • 시상 + 다음 단계 안내
```

### 5-7. 적합성 매트릭스 (현재 기획안 04번 게임 통합)

| 평가 축 | 정의 | 점수 기준 |
|---------|------|-----------|
| 직무가치 | 회사·고객·사회에 주는 가치의 크기 | 1=상징적 / 5=경영 임팩트 |
| 과업명확성 | 업무 단위·산출물의 정의 가능성 | 1=모호 / 5=SOP 작성 가능 |
| 표준화 | 반복·예측 가능성 | 1=비정형 / 5=완전 표준화 |
| 지원가능성 | 직무 코치·도구·환경 조정 용이성 | 1=특수 인프라 필요 / 5=즉시 도입 |
| 환경적합성 | 물리·심리·문화적 환경 적합도 | 1=장벽 다수 / 5=현재 환경에서 가능 |

### 5-8. 산출물

## 8. 진행자(FT) 매뉴얼 — 핵심 체크리스트

### 8-1. 시작 전 (T-30분)

- [ ] 카드 더미 색상별 분리 확인 (R/Y/G/B)
- [ ] 미션 카드 순서 셔플

- [ ] 적합성 매트릭스 시트 6부 인쇄
- [ ] 직무 후보 시트 보조원 1명 사전 브리핑

### 8-2. GAME 1 진행 시 주의

- "B 카드 받은 사람"을 비난하는 분위기로 흐르지 않도록
- 토론 단계에서 **"왜 그렇게 생각했나요?"**를 반드시 묻기 (편견은 누구에게나 있다)
- 마지막 라운드 모두 같은 단어 트릭은 **시간이 부족하면 스킵 가능**

### 8-3. GAME 2 진행 시 주의

- 30초 발의 시간 엄수 — 길어지면 **양 발산 어려움**
- 칩이 한 사람에게 쏠리면 **"3라운드부터는 다른 사람에게 1번 이상 줘야 함"** 룰 도입
- "꼭 새로운 직무여야 한다"는 부담 주지 않기

### 8-4. GAME 3 진행 시 주의

- 페인포인트 카드는 **사전 인터뷰**로 회사 맞춤 카드 추가 권장
- 적합성 매트릭스는 **합의 점수**가 아닌 **개별 점수 평균** — 토론 시간 단축
- TOP 3는 칩 점수 + 매트릭스 점수 **가중 평균** (칩 60%, 매트릭스 40%)
