# outputs 폴더 구조 안내

> 최종 정리: 2026-06-11

## 기본 원칙
- 기업 산출물은 **`번호_기업명/`** 낱개 폴더에 보관합니다 (가나다순 01~08).
- 각 기업 폴더 안 **`00_기업정보/`** 에는 기업에서 **받은 자료**(회사소개서, 조직도, 기관소개 등)를 모읍니다. 앞으로 과업 시 참고용.
- 작업 결과물(직무카드, 후보군 도출결과·보고서 등)은 기업 폴더 바로 아래에 둡니다.

## 폴더 구성

```
outputs/
├── 00_프로젝트관리/     # 8개 기업 공통 관리 문서
│   ├── 2026_선도기업_프로젝트성과관리시트_v1.0.xlsx
│   ├── 2026_선도기업_컨설팅_관리.xlsx
│   ├── 2026_선도기업_기업분배_v2.xlsx
│   └── 2026_선도기업_현황분석.xlsx
│
├── 01_성불복지회/
│   ├── 00_기업정보/      # ← 기업에서 받은 자료 보관
│   └── (산출물 파일)
├── 02_어보브반도체/
├── 03_인천국제공항보안/
├── 04_자동차손해배상진흥원/
├── 05_케이티서비스남부/
├── 06_태광/
├── 07_한국국제교류재단/
├── 08_해양환경공단/
│   └── 각 기업 폴더 동일 구조 (00_기업정보 + 산출물)
│
├── _공통양식/           # 인터뷰 문항 등 기업 공통 양식
├── 공단보고/            # 공단 제출용 보고·발표 자료
└── _archive/           # 생성 스크립트, 중복본, 옛 빈 폴더 등 보관
```

## 기업에서 받은 자료를 넣는 방법
해당 기업의 **`번호_기업명/00_기업정보/`** 폴더에 그대로 넣으면 됩니다.
예) 케이티서비스남부 회사소개서를 받으면 → `05_케이티서비스남부/00_기업정보/`

## 참고
- `_archive/` 안의 `_빈_*`, `_빈골격_*` 폴더는 정리 과정에서 비워진 옛 폴더입니다.
  OneDrive 동기화 폴더라 자동 삭제가 막혀 남아있으니, **탐색기에서 `_archive` 폴더째 또는 `_빈_*` 항목을 직접 삭제**하셔도 됩니다.
- `한국장애인고용공단_공단샘플/` 은 선도기업이 아닌 공단 자체 샘플 직무카드라 archive로 옮겼습니다.
- 제안발표자료 PDF는 `data/2026/` 에 원본이 있어 outputs의 중복본을 archive로 옮겼습니다.
