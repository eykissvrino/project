**작성자**: HR솔루션팀 이석주 + Claude AI

---

## 1. 프로젝트 개요

### 배경
2026년 시앤피컨설팅 조직 개편에 따라 각 사업본부가 독립적인 서브 홈페이지를 운영하는
체계를 구축 중이다. 직업능력컨설팅본부는 HRM·HRD·AX(AI Transformation) 3개 서비스 영역을
통합 제공하는 본부로, 기존 Railway 초안을 전면 재설계하여 전문적이고 신뢰성 높은 디지털
소개 채널을 구축한다.

### 왜 전면 재설계인가
기존 초안은 기능적으로 완성되어 있으나:
- "warm startup orange" 색조가 공공기관 컨설팅사 이미지와 어긋남
- 서비스 페이지 설명 깊이 부족 (문제→해결→실적 흐름 미완성)
- 사업실적 표현 방식이 신뢰도 전달에 부족
- 콘텐츠 구성이 타겟 독자(공공기관 담당자)의 의사결정 흐름 미반영

## 5. 페이지별 설계

### 5.1 홈 (`/`)

| 섹션 | 배경 | 내용 |
|------|------|------|
| Hero | Dark Navy | H1 3행 (font-light) + 서브 카피 + CTA 2개 |
| Trust Strip | 흰색 | 통계 4개: 500+ 컨설팅 · 200+ 기관 · 15yr+ 경력 · 98% 만족도 |
| Services Overview | Surface(크림) | 3열 카드, hover 시 서비스 컬러 border 나타남 |

[CTA1] 컨설팅 문의   [CTA2] 사업실적 보기 →

### 5.2 서비스 허브 (`/services`)

세 서비스를 세로 전체 패널로 (각 패널 vh 60%). 기본: 서비스명+부제목.
호버: 핵심 키워드 + "자세히 보기 →". 배경: Navy → Teal → Slate.

---

### 5.3 HRM 컨설팅 (`/services/hrm`)

**구조: 공감 → 해결책 → 프로세스 → 신뢰 → CTA**

| 섹션 | 내용 |
|------|------|
| Hero (Navy) | `HRM` 레이블 + `직무 중심 인사관리` H1 |
| Pain Points | 연공급 한계 / 경영평가 대응 / 직무급 전환 의무 |
| 솔루션 4개 | 직무분석 · 직무평가 · 보수체계 · 조직설계 |
| 프로세스 | 수평 4단계: 진단 → 설계 → 도입 → 안정화 |
| 신뢰 지표 | `300+` 공공기관 · `150+` 직무분석 · `97%` 재계약률 |
| 관련 실적 | Portfolio HRM 3건 카드 (자동 필터) |
| CTA | `직무분석 컨설팅 상담 신청` → /contact |

HRD 페이지: 동일 구조, Teal 컬러. 추가: 패러다임 전환 도식.
AX 페이지: 동일 구조, Slate 컬러. 추가: AX 성숙도 5단계 시각화.

### 5.4 사업실적 (`/portfolio`)

- **현행 테이블 → 카드 그리드 전환**
- 상단 탭 필터: `전체 | HRM | HRD | AX`
- 각 카드: 카테고리 뱃지 + 기관명(타이포) + 프로젝트명 + 기간 + 한 줄 개요
- 클릭 → 모달: tasks + results 상세
- 빈 결과 시 빈 상태 메시지 표시
- 헤더: `12건 주요 프로젝트 | HRM 5건 · HRD 4건 · AX 3건`

---

### 5.5 본부소개 (`/about`)

- 미션·비전 (카피 교체)
- **3개 팀 소개 섹션 추가**: 공공기관컨설팅팀 / HR솔루션팀 / AX컨설팅팀
- 연혁 타임라인 (세로, 좌우 교차, 2010~2025)

### 5.6 문의 (`/contact`)

**필드**: 이름 · 기관명 · 직위 · 연락처 · 이메일 · 관심 서비스(체크박스) · 문의 내용

**Phase 1**: 클라이언트 유효성 검사만 (전송 없음 — 현행 유지)
**Phase 2**: Resend 또는 FormSubmit 연동 예정

우측 패널: 전화 · 이메일 · 주소 · 웹사이트

## 8. 구현 순서

1. **`globals.css`** — CSS 변수 전면 교체 (현재→목표 값)
2. **`constants.ts`** — TEAMS 배열, CLIENTS_FEATURED 배열 추가
3. **Header / Footer** — dark navy 재설계
4. **홈 페이지** — Hero, Trust Strip, Services, Clients Strip, CTA Banner
5. **서비스 허브** (`/services`) — 3패널 인터랙션
6. **HRM 서비스** — Pain Points, 솔루션, 프로세스, 신뢰 지표
7. **HRD 서비스** — 동일 + 패러다임 전환 다이어그램
8. **AX 서비스** — 동일 + 성숙도 5단계 시각화
9. **포트폴리오** — 카드 그리드 + 모달
10. **About, Contact** — 팀 소개, 폼 필드 확장
11. **Framer Motion** — 스크롤 진입 페이드인, 통계 카운트업
12. **검수** — 모바일 375px, 빌드 에러, 링크 동작
13. **배포** — Railway push
