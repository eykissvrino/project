## Ⅰ. Executive Summary — 한 장 요약

### 진단 한 줄
> **"시앤피는 고객에게 HR 체계(조직·직무·평가·교육)를 파는 전문기관이지만, 정작 자사의 HR 체계는 미정비 상태다. 86~92명·85.9억 규모로 성장했으나 운영은 소기업 관행에 머물러, 전사를 묶어줄 '코어 기능(전략HR·PMO·KM)'이 비어 있고 그 부담이 본부장·컨설턴트 개인에게 전가되며 순이익률이 16.1%→3.6%로 악화됐다."**

### 핵심 진단 5선 (영역 교차)
| # | 핵심 문제 | 영역 | 심각도 |
|---|-----------|:---:|:---:|
| 1 | **Corporate Center 부재** — 전략HR·PMO·지식관리(KM) 기능이 통째로 빔. 경영지원 2명의 행정 수준 | 조직·전반 | ●●● |
| 2 | **직무체계(Job Architecture) 없음** — "팀은 있으나 직무가 없다". 일련번호 팀(컨설팅1~7), 직무·직급 혼재 | 직무 | ●●● |
| 3 | **평가-보상 연결고리 단절** — 센터 단위 평가만 존재, 전사 캘리브레이션·보상연동 규정 부재(open loop) | 평가·보상 | ●●● |
| 4 | **단일 사다리 — 전문가 트랙 부재** — 수석 승진=독자수주 2억 필수. 석·박사 전문가(이탈 최다=선임)의 성장 천장 | 직무·역량·문화 | ●●● |
| 5 | **자기 방법론 미적용 + AI 리스킬링 공백** — 외부에 파는 역량모델·교육로드맵·KM을 내부 미적용(cobbler's children) | 역량·교육 | ●●○ |

### 권고 방향 한 줄
> **자사를 "0호 고객사"로 선언하고, ① 비어 있는 코어기능(Corporate Center)을 먼저 채운 뒤 ② 직무체계를 세우고 그 위에 평가·보상·역량·문화를 정합시킨다. 외부 판매 방법론(NCS·직무분석·교육로드맵)을 내부에 역적용해 저비용·고신뢰로 전환한다.**

### 통합 우선순위 (무엇부터)
1. **[즉시·저저항] PMO·전략HR 코어 신설** + **자사 교육로드맵 1page** + **캘리브레이션 세션 도입** ← Quick-win
2. **[3–6개월] 직무체계(직군·직무·직급 매트릭스) + 전문가/관리자 이원 트랙** 확정
3. **[6–12개월] 평가-보상 연동(Pay Band·인센티브·IC트랙)** + **KM·AI 리스킬링** + **문화·몰입 진단**
4. **[전 단계 병행] @LEG 노동법 검토**(취업규칙 불이익변경)·**문화 변화관리**(수용성)

## Ⅱ. As-Is 통합 진단 — 근본원인(Root Cause) 구조

6개 영역의 문제는 흩어진 증상이 아니라 **3개의 공통 뿌리**에서 갈라져 나온다.

```
[뿌리 1] 코어기능 공백        →  본부 사일로·중복수주·가동률 저하·KM 부재 → 순이익률 악화
 (전략HR·PMO·KM 부재)

[뿌리 2] 직무체계 부재        →  평가·보상·교육·승진의 "공통 언어" 없음 → 모든 HR이 리더 재량
 (Job Architecture 결핍)        → 채용·평가·육성 일관성/공정성 저하

[뿌리 3] 자기 방법론 미적용    →  역량모델·교육로드맵·KM을 외부엔 팔고 내부엔 미적용
 (cobbler's children)          → 도제식 과의존·암묵지·핵심인재 이탈
```

### 영역별 As-Is 성숙도 종합
| 영역 | 성숙도 | 핵심 근거 |
|------|:---:|-----------|
| 조직구조 | **취약** | 3개 컨설팅 본부 기능중복(직무분석 공통), 일련번호 팀, 4계층 과다, 경영혁신본부장 SoC≈8 과대 vs 경영지원 2명 과소 |
| 직무체계 | **취약(L1)** | 직군·직무·JD 부재, 직무·직급 혼재, 단일 사다리. 직급만 최근 정비 |
| 평가 | 항목·면담 **양호(B/B+)** / 정합성 **취약(D)** | 센터 1on1·항목설계 우수, 그러나 전사 캘리브레이션·다면평가 부재 |
| 보상 | **취약(D)·[검증필요]** | 평가→보상 매핑 규정 부재(open loop), Pay Band·수주 인센티브·IC트랙 미확인 |
| 역량·교육 | **취약(L1~L2)** | 역량모델·교육로드맵·KM·AI리스킬링 공백, 도제식 과의존 |
| 조직문화 | **가설·[검증필요]** | 시장+위계 과대 / 관계·혁신 결핍 → 번아웃·이직·사일로 (OCAI 실측 필요) |

### 인력 현황 (확인된 사실)
- 임직원 **약 86~92명** *(인원현황 2025.01 본부합계 86 vs 기말과제 92 — [검증필요] 정합)*, **석·박사 51%**, 1990년대생 40%, 근속 중앙값 약 2.5년 *(기말과제 기준, [검증필요])*
- 직급분포 **(92명 기준: 컨설턴트 트랙 79 + 고문/지원직 13)**: 주임 16 · 선임 28 · 책임 17 · 수석 18
- **이탈 최다 구간 = 선임(28명, 최대집단) → 책임 4년 구간** (근속 2.5년과 중첩) ← 단일 사다리·성장정체의 구조적 발현
- 재무: 그룹 매출 85.9억(2024), **순이익률 16.1%→3.6% 악화** ← 조직 비효율(중복·저가동률)과 정합

## Ⅲ. To-Be 통합 개선안 — 5대 영역 정합 설계

> 설계 철학: **Galbraith Star Model** — 구조·직무·평가보상·역량·문화는 따로 고칠 수 없다. 하나의 정합된 시스템으로 설계한다. 순서는 **"빈칸 먼저, 중복 나중 / 직무 먼저, 제도 나중"**.

### 1. 조직 — 시장축 사업부 + 전사 공유 Corporate Center
- **컨설팅 본부 시장축 재편**: 3개 본부의 중복기능(직무분석 등)을 고객/서비스라인 기준으로 재배치, 일련번호 팀(1~7) → 서비스라인 팀. 공공·직업능력개발은 진입장벽 자산이므로 독립 사업부 유지.
- **Corporate Center 신설(최우선)**: **PMO**(수주~수행~종료·가동률·품질 통합) · **전략HR/People Ops**(경영지원 행정 → 전략HR 격상) · **사업개발(BD)·고객관리** · **Knowledge Center/QA**.
- **전문가 풀(Expert Pool) 센터화**: 시니어를 본부 소속이 아닌 전사 풀로 두고 프로젝트 경량 매트릭스 배정 → 사일로 해소.
- **관계사 5사**: 통합이 아닌 **거버넌스 정렬**(수주 룰 명문화 + 교차판매 채널 + One-CNP 단일 고객창구).
- 향후: 운영 안정 후 프로젝트 매트릭스로 점진 진화. *(상세: 01_조직구조)*

### 2. 직무 — 컨설팅펌형 Job Architecture (직군 × 직급 매트릭스)
- **3직군**: 컨설팅직군 / 연구개발직군 / 사업지원직군(HR 신설 포함) → 각 직무 → 직급(L1 주임 ~ L5 수석) **2차원 분리**(직무·직급 혼재 해소).
- **이원 커리어 트랙(Dual Ladder)**: L3(선임) 이후 **전문가 트랙(Expert/IC, 영업 비필수)** vs **관리자/파트너 트랙**. 두 트랙 동등 위상·보상 → "수석=영업 2억"의 단일 천장 제거 (선임 이탈 구간 직접 처방).
- **NCS 기반 표준 JD**: 5대 핵심직무 우선 표준화(직무목적·R&R·수행준거·요구역량+행동지표·자격).
- **스킬 레이어는 단계적**: 직무체계 확정 후 스킬태그→스킬갭→인재마켓 순(강요 금지). *(상세: 02_직무체계)*

### 3. 평가·보상 — 끊긴 3대 고리(전사정합·캘리브레이션·보상연동) 연결
- **평가 이원화 + 프로젝트축**: (A)성과평가[가동률·영업익/마진·수주·CSAT·지식기여] + (B)역량평가[승진·밴드] + (C)**전사 캘리브레이션 세션**(부서 간 등급 정렬). 현 "상사 지시 이행률"은 성과지표에서 제외.
- **우수자산 유지**: 정교한 1on1 면담(B+)은 계승·정례화.
- **보상 직무·성과 기반 전환**: 직무평가(Hay)→**직급별 Pay Band**, 시장 벤치마킹(50~75p), **평가등급→목표보너스율 매핑테이블**로 open loop 차단, **수주·프로젝트 인센티브 + IC트랙 보상**.
- ⚠ **노동법**: 임금체계 전환은 취업규칙 불이익변경(근로기준법 §94) → **@LEG leg-labor 사전검토 필수**(아래 Ⅴ). *(상세: 03_평가보상)*

### 4. 역량·교육 — 외부 방법론의 내부 역적용
- **컨설턴트 3대 역량군**: A.컨설팅역량(공통) · B.도메인역량(직무분석·ADDIE·NCS) · C.디지털/AI역량 → 직급별 프로파일.
- **70-20-10 육성 로드맵**: 도제식(70)의 강점 유지 + 빠진 정형교육(10)·코칭(20) 보강. **온보딩 부트캠프** + 직급별 과정.
- **지식경영(KM)**: 방법론 라이브러리 + 사례 DB + 프로젝트 종료 시 회고·등록 의무화 → 신입가속·지식보존·AI토대 동시 해결.
- **AI 리스킬링 3트랙**(전사기본·업무특화·상품화) → AX 신사업과 dogfooding 선순환. *(상세: 04_역량교육)*

### 5. 조직문화 — 시장형 강점 유지 + 관계·혁신 주입
- **핵심가치·일하는 방식** 참여형 정립(가치→행동지표→평가·온보딩 임베드).
- **몰입 드라이버**(성장·소속·웰빙·인정) 기반 리텐션, **번아웃 관리**(동시 프로젝트 상한·회복기·리더 모델링), **스테이 인터뷰**.
- **One Firm 지식공유**로 사일로 해소, **심리적 안전감**(노사협의회·고충처리실 "작동" 지표화).
- **변화관리(ADKAR×Kotter 12개월)** + 분기 펄스 서베이로 정착 추적. *(상세: 05_조직문화)*

### 영역 간 정합 매트릭스 (핵심 연결점)
| 이 영역이… | 이 영역의 전제가 된다 |
|------------|------------------------|
| 직무체계(직군·직급 정의) | → 평가단위·Pay Band·역량모델·Career Path **전부의 기준** |
| Corporate Center(전략HR·PMO) | → 평가·보상·교육·KM을 **운영할 주체** |

| 평가-보상 연동 | → 문화(공정성 신뢰)·직무(밴드 기준)와 정합해야 작동 |

| 단계 | 기간 | 핵심 과제 (영역) | 산출물 | 비고 |
|------|------|------------------|--------|------|
| **0. 데이터 실사** | ~1개월 | 정원·겸직·보상규정·타사업장 평가규정·가동률·이직률 수집 → [검증필요] 다수 해소 | 정밀 As-Is 데이터셋 | 모든 단계 전제 |

| **2. 골격 (직무 먼저)** | 3~6개월 | **직무체계(직군·직무·직급) + 이원 커리어 트랙** 확정 / NCS 기반 5대 핵심 JD | Job Architecture 맵·표준 JD·커리어맵 | 제도의 기준 |
| **3. 제도 정합 + 진화** | 6~12개월+ | **Pay Band·인센티브·IC트랙**(→취업규칙 개정) / **KM·AI 리스킬링** / **문화진단·변화관리** / 본부 시장축 재편 | 보상체계·KM·AI가이드·문화로드맵·To-Be 조직도 | @LEG 검토 동반 |

**1원칙**: 한 번에 갈아엎지 않는다 — **빈칸(코어) 먼저 채우고, 중복(본부)은 나중에. 직무 먼저 세우고, 제도는 그 위에.**

## Ⅴ. 거버넌스 · 리스크 · 노동법

### 노동법 사전검토 (@LEG leg-labor 필수)
1. **취업규칙 불이익변경(근기법 §94)** — 호봉→직무·성과급, 보상연동 강화는 일부 불이익 가능 → **근로자 과반수 동의** 필요(미동의 시 무효 리스크). 노사협의회 존재 → 협의 절차 점검.
2. **기득이익 보호** — 경과조치·grandfathering로 불이익 최소화.
3. **인센티브 임금성** — 정기·일률·고정 인센티브는 통상/평균임금 산입 가능(퇴직금·수당 영향) → 설계 전 검토.
4. **평가 공정성·차별금지** — 평가가 보상·인사 근거가 될 경우 객관성·절차정당성 입증.
5. **평가데이터 개인정보·근로감시** 이슈 점검.

### 변화관리 리스크
- 본부장 권한 축소 저항 → 사업부장/Center장 **역할 격상으로 흡수**
- 매트릭스 이중보고 갈등 → 권한위임 가이드(금액·리스크·일상 3기준) 사전 명문화
- 과설계(86명에 풀매트릭스) → 경량 매트릭스로 시작, KPI 검증 후 확장
- HR개편 불안 → 인식 단계 선제 소통 + 직급별 What's-in-it-for-me 메시징
