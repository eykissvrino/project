# 브리프 — 시앤피컨설팅 HR 체계 개선

> Frame/Plan 산출물. 착수 전 과업·범위·성공기준 정의. (2026-06-16)

## 1. 과업 (What)
시앤피컨설팅 그룹의 **내부 HR 체계 전반**을 진단하고 개선안을 도출한다.
(주의: 고객사 HR 컨설팅이 아니라 **시앤피 자기 자신의 내부 HR** 개선)

## 2. 범위 (Scope) — 풀스택
| 영역 | 핵심 질문 |
|------|-----------|
| 조직 | 5개 사업장 구조·R&R이 사업전략에 맞는가? |
| 직무 | 직무체계·직무기술서가 정비돼 있는가? |
| 평가·보상 | 현 개인평가계획이 공정·전략정합적인가? 보상은 시장경쟁력이 있는가? |
| 교육·역량 | 컨설턴트 역량개발 체계가 있는가? |
| 조직문화 | 몰입·일하는 방식·이직 이슈는? |

## 3. 성공기준 (Definition of Done)
1. As-Is 현황진단서 (정량+정성, @BAR A등급)
2. 핵심과제 우선순위 (대표님 합의)
3. To-Be 개선안 + 실행 로드맵
4. 최종 보고서/덱 (@DEL 완성, @BAR 검증)

## 4. 제약·전제
- 중견~중소 규모 컨설팅 전문기업 / 노무법인 포함 그룹
- 기존 자산(조직재설계안·개인평가계획·손익) 적극 재활용 → 제로베이스 금지
- 노동법 적법성(취업규칙·임금) 반드시 leg-labor 검토
