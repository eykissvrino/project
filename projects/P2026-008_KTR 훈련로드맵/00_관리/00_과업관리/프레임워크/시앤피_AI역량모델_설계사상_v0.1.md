## 0. 왜 이 문서인가 — 큰 틀 설계의 필요성

### 0.1 현황 인식
- KTR 과업 S3 산출물(AI 직무역량 모델)을 **단발성 산출물**로 끝낼 것인가, **시앤피의 사업 자산**으로 만들 것인가
- AX B2B 사업(제조업·화학·바이오·서비스업 등 다업종 컨설팅)에서 매번 처음부터 AI 역량 모델을 설계할 수는 없음
- **사용 가능한 메타 프레임워크 + 산업별 커스터마이징 메커니즘**이 있어야 시앤피의 사업 효율과 차별성 확보

### 0.2 본 문서의 위상

## 1. 모델의 사용자·목적

### 1.1 1차 사용자
| 사용자 | 활용 목적 |
|---|---|
| **시앤피 PM/PL/연구원** | 신규 AX 컨설팅 프로젝트 착수 시 AI 역량 모델 도출 기반 |
| **KTR (협약기업)** | 산업전환 공동훈련센터 교육과정 설계 기준 |
| **고객사 HR/HRD 담당자** | 자사 직원 AI 역량 진단·교육 설계 |
| **고객사 사업기획·전략** | AX 추진 시 직원 역량 인벤토리 작성 |

### 1.2 모델이 답해야 하는 4가지 질문
1. **WHAT** — 우리 직원에게 필요한 AI 역량은 무엇인가
2. **WHO** — 어떤 직무·수준의 직원에게 어떤 역량이 필요한가
3. **HOW** — 그 역량은 어떻게 교육·평가·인증하는가
4. **GROW** — 시간이 지나면서 어떻게 갱신·확장하는가

## 2. 설계 5대 원칙

### 원칙 1 — 스킬 기반 (Skill-based, not Competency-based)
- "무엇을(What)" 보다 "어떻게(How)"
- **김은경 외(2024)** 비판 채택: 역량 모델은 일반적·과거 지향적, 빠른 환경 변화 미반영
- 스킬 진술문 구조: **「가치 기반 전문지식 + 책무 명 + 직무행동」**

### 원칙 2 — 모듈형 3계층 (Modular 3-Tier)
```
직무영역 (대분류)  ← 산업 무관 공통
   ↓
책무 (중분류)      ← 일부 산업 공통, 일부 특화
   ↓
스킬 (진술문)      ← 산업·기업·직무별 커스터마이징
```
→ **상위 계층의 안정성 + 하위 계층의 유연성** 동시 확보

### 원칙 3 — 수준 차등 (3-Level Differentiation)
KTR 제안서 §Step7 수준체계와 정합:
- **Lv1 선제대응**: AI 기초 이해·정보 탐색·분석 — 변화 감지·준비
- **Lv2 전환**: AI를 직무에 적용·업무 방식 전환·문제 해결
- **Lv3 정착**: AI 활용 고도화·자동화·성과 창출·운영 체계 내재화

→ 같은 영역·책무 안에서도 직급·경험·산업 성숙도에 따라 차등 스킬 적용

### 원칙 4 — 증강 우선 (Augmentation-first)
WEF FoJR 2025: 고용주 **85%**가 AI를 인간 역할 대체가 아닌 **증강(Augmentation)**에 사용
- 우리 모델은 "AI 도구 사용법"이 아닌 **"AI와 협업해 더 나은 의사결정·산출물을 만드는 능력"**에 초점
- 영역4(AI 협업 자동화·의사결정 지원)에 명시적 반영

### 원칙 5 — 확장 가능 (Extensible)
- 산업별 특화 책무·스킬을 **플러그인** 형태로 추가 가능
- 신기술 등장 시(예: AGI, 멀티모달, 자율 에이전트) 영역 추가 또는 영역 내 책무 추가로 확장
- 폐기 메커니즘: 사용되지 않는 스킬은 매년 또는 격년 갱신 시점에 archive

## 3. 모델의 기본 구조 — 3축 × 4영역 × 3계층 × 3수준

### 3.1 메타 프레임워크: 3축

```
              [축2] 데이터 흐름
                     │
                     │  자동화
                     │  의사결정
                     │  분석
                     │  수집·요약
                     │
[축3] 직무 맥락 ────┼──── [축1] AI와의 관계
공통────────특화      활용────협업────증강
```

**축1: AI와의 관계**
- 활용 (Use) — AI 도구를 효율 개선 수단으로 사용
- 협업 (Collaborate) — AI와 분업·검증·반복 개선
- 증강 (Augment) — AI 결과를 비판적으로 검토·통합해 더 높은 가치 창출

**축2: 데이터 흐름**
- 정보 수집·요약
- 데이터 분석·시각화
- 콘텐츠·문서 생성
- 의사결정 지원·자동화

**축3: 직무 맥락**
- 공통 (전 직무 적용) — 사무·기획·교육 공통 기초
- 특화 (산업·직무별) — 생산·품질·R&D·ESG·영업 등 도메인 특화

### 3.2 4대 영역 (3축의 교차 결과)

| 영역 | 명칭 | 축1 | 축2 | 축3 | KTR 수준 |
|---|---|---|---|---|---|
| 1 | **AI 활용 정보 탐색·요약** | 활용 | 수집·요약 | 공통 | Lv1 |
| 2 | **AI 활용 데이터 분석·시각화** | 활용→협업 | 분석 | 특화 | Lv2 |
| 3 | **AI 활용 콘텐츠·문서 생성** | 협업 | 생성 | 공통 | Lv1~Lv2 |
| 4 | **AI 협업 업무 자동화·의사결정 지원** | 협업→증강 | 자동화·의사결정 | 특화 | Lv2~Lv3 |

→ **이 4대 영역은 산업 무관 공통**. 모든 시앤피 적용 사례가 이 4대 영역을 출발점으로 삼는다.

### 3.3 3계층 구조 (영역 → 책무 → 스킬)

| 계층 | 단위 | 김은경 비율 | 시앤피 표준 | 정합 NCS |
|---|---|---|---|---|
| 대분류 | 직무영역 | 5개 | **4개** (3축 교차 + WEF 정합) | NCS "직무" |
| 중분류 | 책무 | 영역당 3개 | **영역당 2~4개** (확장 가능) | NCS "주요업무" |
| 진술문 | 스킬 | 책무당 평균 1.7개 | **책무당 2~3개** | NCS "책임 및 역할" |

**스킬 진술문 표준**: 「가치 기반 전문지식 + 책무 명 + 직무행동」 (김은경 외, 2024, p.11)
- 예: 「Python 데이터 분석 라이브러리와 ChatGPT를 활용해 / 생산 공정 데이터의 / 패턴을 분석한다」

### 3.4 3수준 체계 (Lv1·Lv2·Lv3)

| 수준 | 정의 | 행동 특징 | 평가 |
|---|---|---|---|
| **Lv1 선제대응** | 변화 감지·기초 활용 | AI 도구를 지도 없이 활용 / 한계 인식 / 출처 검증 | 산출물 일관성·기본 활용 빈도 |
| **Lv2 전환** | 직무 적용·문제 해결 | AI를 직무 워크플로에 통합 / 데이터 기반 의사결정 / 협업적 개선 | 직무 KPI 개선도·교차 검증 |
| **Lv3 정착** | 고도화·체계 내재화 | AI 시스템 설계·검증 주도 / 조직 표준 정립 / 윤리·리스크 거버넌스 | 조직 성과·내재화 지표 |

## 4. 산업·기업별 확장 메커니즘

### 4.1 확장의 3가지 자유도

```
[자유도1] 책무 추가·삭제
  영역 4 (자동화·의사결정)에 산업별 책무 추가
  예: 화학 → "공정 최적화 AI 활용"
  예: 화장품 → "AI 활용 브랜드 트렌드 예측"
  예: 의료기기 → "AI 활용 인허가 문서 자동 생성"

[자유도2] 스킬 진술문 산업 맥락 치환
  공통 스킬 "AI 활용 시장 정보 수집"
   → KTR: "친환경 바이오화학 시장 정보를 수집한다"
   → 화장품 컨설팅: "글로벌 친환경 화장품 트렌드를 수집한다"
   → 의료기기: "MDR·FDA 인허가 동향을 수집한다"

[자유도3] 수준 체계 산업별 조정
  Lv1·Lv2·Lv3의 기준 행동을 산업의 AI 성숙도에 맞춰 조정
  예: AI 도입 초기 산업 → Lv1 기준 낮춤
  예: AI 선도 산업 → Lv3 기준 엄격화
```

### 4.2 적용 SOP (Standard Operating Procedure)

```
1단계: 본 메타 프레임워크 4대 영역·12 표준 책무 가져오기
2단계: 산업·기업 분석 (산업 트렌드 + 협약기업·고객사 수요조사)
3단계: 영역별 산업 특화 책무 추가/조정
4단계: 책무별 스킬 진술문 도출 (워크숍 7단계 적용 — 김은경)
5단계: 수준 체계 산업별 조정
6단계: 자문회의·전문가 검증
7단계: 핵심 스킬 우선순위 (가치 투표) → 1차 적용 대상 확정
8단계: 교육 콘텐츠·평가 도구 매핑 (M3 영역 — 시앤피 사업 자산 연계)
```

→ 본 SOP가 **시앤피 신규 AX 컨설팅 프로젝트의 표준 절차**

## 5. KTR 적용 — 친환경 바이오화학 (S3 v1.0의 의미)

KTR 과업의 S3 산출물은 본 메타 프레임워크의 **첫 번째 산업 적용 사례**이자 **모델 검증 사례**.

| 메타 프레임워크 | KTR 적용 (S3 v1.0 골격) |
|---|---|
| 4대 영역 | 동일 채택 |
| 영역당 책무 표준 3개 | 영역당 3개 (총 12개) |
| 책무 추가 (자유도1) | 영역4에 **친환경 바이오화학 특화** 책무 추가 검토 — 예: "AI 활용 친환경 소재 개발 가속화" |
| 스킬 진술문 산업 치환 (자유도2) | 모든 스킬을 친환경 바이오화학 맥락으로 작성 |
| 수준 체계 조정 (자유도3) | 친환경 바이오화학 산업의 AI 성숙도 (중간 단계 — 삼일PwC 2026 분석 반영) |
| 검증 메커니즘 | 자문회의 3회 + 협약기업 수요조사 |

### KTR 적용 시 검증해야 할 메타 가정
- 4대 영역이 친환경 바이오화학 직무를 충분히 커버하는가? (커버 못 하면 → 영역 추가 또는 책무 확장)
- 3수준 체계가 협약기업(중소·중견)의 현실에 맞는가? (삼일PwC: 중소는 품질·설비 모니터링부터 단계 접근)
- 12 표준 책무 중 협약기업이 1순위로 요구하는 것은? (M2-S5 수요조사 4사분면 매트릭스)

## 6. 시앤피 AX B2B 사업 활용 시나리오

### 시나리오 A. 신규 AX 컨설팅 수주 시
- 본 프레임워크를 제안서 §접근법 핵심 차별성으로 제시
- "산업 무관 메타 프레임워크 + 산업 특화 확장 메커니즘 + 적용 SOP 보유"
- KTR 적용 사례를 레퍼런스로 제시

### 시나리오 B. 고객사 AI 역량 진단 (정기·1회성)
- 4대 영역 × 3수준 = 12셀의 진단 매트릭스를 표준으로 사용
- 직원별 자가진단 + 관리자 평가 + 객관 평가(테스트·과제) 3원 데이터
- 산업·직무별 벤치마크 (시앤피 누적 데이터) 비교 리포트

### 시나리오 C. AI 교육 콘텐츠 라이브러리
- 12 표준 책무 × 3수준 = 36개의 표준 교육 모듈 라이브러리 구축
- 산업별로 사례·실습만 치환 → 빠른 커스터마이징
- 교육 효과 측정 표준 (Pre/Post 진단 매트릭스)

### 시나리오 D. 정부·공공 기관 사업 (KTR형)
- 산업전환·평생교육·고용노동 사업의 표준 모델로 입찰 경쟁력 확보
- 본 프레임워크를 **시앤피의 IP**로 보호·축적
