# 위험 관리

> 본 과업의 발생 가능 위험(Risk)을 식별·평가하고 대응 계획을 관리. 제안서 v5.0 §3 사업관리방안 정합.

## 1. 위험 관리 흐름 (제안서 정의)

```
Issue 파악 → 대응 담당 선정 → Issue 해결 요청 → Issue 해소 관리 → Issue 해소 확인 → 결과 승인
```

**R&R**: PM 유대훈 / PL 조예슬 / 연구(보조)원 이석주·안은하·허상희 / 사업 사후관리 지원
