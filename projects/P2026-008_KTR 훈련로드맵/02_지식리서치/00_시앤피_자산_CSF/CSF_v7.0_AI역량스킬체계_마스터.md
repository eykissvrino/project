## 3. 수준 체계 (BARS, 3단)

| 수준 | 명칭 | 정의 |
|---|---|---|
| **L1** | 활용 (Apply) | AI를 도구로 사용해 정해진 업무를 수행한다 |
| **L2** | 응용·검증 (Adapt & Verify) | AI 결과를 검증·조정하고 비정형 상황·워크플로우에 응용한다 |
| **L3** | 설계·선도 (Design & Lead) | 새 활용·표준·업무 전환을 설계하고 조직에 확산한다 |

**예시 — D03 대화형 데이터 분석**
- L1: 기본 집계·비교를 질문으로 수행한다
- L2: 가설 기반 다각 분석과 한계 해석을 수행한다
- L3: 조직 셀프 분석 문화를 구축한다

## 4. 활용 모드 (미래대응 축)

| 모드 | 정의 | 인간 위치 |
|---|---|---|
| 자동화 Automation | 사람이 정의한 작업을 AI가 대신 수행 | 정의·확인 |
| 증강 Augmentation | AI가 사고·창작·판단을 보조·확장 | 함께 수행 |
| 에이전트 Agency | AI가 목표 받아 자율 계획·실행 | 위임·감독 |

AI 진화는 모드 무게중심 이동(자동화→증강→**에이전트**)을 *태그 전환*으로 흡수. ⑥ 영역과 11개 🟡부상 스킬이 에이전트 프론티어를 명시.

## 5. 페르소나 (적용 렌즈)

```
  상위 분기  빌더(B) ─ ⑤⑥ 자동화·에이전트 구축 (소수 정예)
            전환리더(T) ─ 재설계·확산·거버넌스 ★AX 시그니처
  ─────────────────────────────────────
  공통 진급  프랙티셔너(P) ─ 직무에 AI 능숙 적용
            활용자(U) ─ 기반 + 기초 활용 (전 직원)
```

페르소나는 척추가 아니라 **렌즈** — 스킬을 학습경로로 묶고(교육), 조직 인력분포를 진단하고(측정), 직무에 매핑한다(적용). 각 페르소나 = (영역×수준×모드) 요구 셀의 묶음.

## 6. ★ 스킬 거버넌스 — 살아있는 층

스킬은 급변하는 AI 환경에 **유기적으로 대응**하도록 상태·버전·이력으로 관리된다. 상위 3계층(안정)은 그대로 두고 스킬만 갱신한다.

### 6.1 스킬 생애주기
🟡 부상(Emerging) → 🟢 활성(Active) → 🟠 개정(Evolving) → 🔻 일몰예정(Sunset) → ⚫ 폐기(Retired, ID 보존·재사용 금지)

> 현재 **🟡부상 11개** = AG01~AG06(에이전트·시스템) + R02 딥리서치 + R07 RAG + M07 설계보조 + W02 시민개발 + W03 시스템연동. 2026 최대 스킬 갭에 대응.

### 6.2 스킬 메타데이터
스킬 ID(불변) · 명칭(국·영) · 정의 · 소속(4계층) · 수준 BARS · 모드 · 페르소나 · **상태 · 버전 · 신설일 · 최종개정 · 현재 표현형(도구·기법) · 대체 스킬 · 변경사유**

### 6.3 갱신 주기

| 주기 | 무엇을 | 건드리는 층 |
|---|---|---|
| **상시** | AI 트렌드·도구·문헌·자문 모니터링 → 변경 제안 풀 | — |
| **분기 마이너** (v7.1, 7.2…) | 스킬 추가, 표현형·정의·태그 갱신, 상태 변경 | 스킬만 |
| **연 1회 메이저** (v7→v8) | 스킬셋 재편, 폐기 확정, 역량 조정 | 스킬셋·역량 |
| **5년** | 역량군·골격 재검토 | 전체 |

**변경 유형**: 추가(Add) · 수정(Modify) · 통합(Merge) · 분리(Split) · 일몰(Sunset)
**운영 주체**: 시앤피 CSF Design Authority + SME 자문 (고객별 커스텀은 별도 분기)
→ 변경 이력은 Excel '변경관리대장' 시트에 누적. **이 갱신 체계 자체가 시앤피의 차별성·수익 모델**(연간 개정·재진단 서비스).
