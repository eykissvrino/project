## 1. 체계 총괄

### 1.1 한 장 구조

```
                    시앤피 AI 스킬맵 (6역량군 · 12역량 · 14Skillset · 39Skill)

〔Band T · 전환〕★시앤피 시그니처      T. AI 업무 전환 (6스킬)
                                      ├ T1 업무 재설계 — 적용지점·재설계·효과측정
                                      └ T2 확산·리딩 — 사례화·코칭·팀 표준
                                            ▲
〔Band A · 실무〕업무활동 4영역         A1 정보·지식 (8) | A2 문서·콘텐츠 (6)
  — 스킬의 본체 (25스킬)               A3 데이터·분석 (6) | A4 자동화·에이전트 (5)
                                            ▲
〔Band F · 기본기〕전 직원 토대         F. AI 활용 기본기 (8스킬)
                                      ├ F1 AI에 일 시키기 — 지시·대화·재사용
                                      └ F2 결과 책임지고 쓰기 — 검증·보정·안전·윤리
```

- **측정**: 스킬당 행동지표(BOS) 3문항 × 빈도 5점 + 숙련수준(BARS) L1인지~L5전파 — 총 **BOS 117문항·BARS 195앵커**
- **내구성**: 스킬명은 업무활동 기반 기술 중립. 도구·기법은 **'현재 표현형' 태그에 격리, 연 1회 갱신**
- **산업 적용**: 39스킬은 산업 불문 마스터. 적용처(KTR 등)는 ①요구 스킬 선택 ②직무별 요구수준 설정 ③표현형에 도메인 도구 기입만 변경

### 1.2 수준 체계 (KIRD·IBM 정합)

| Lv | 명칭 | 정의 |
|---|---|---|
| L1 | 인지 | 알고 있으며 안내에 따라 시도한다 |
| L2 | 활용 | 정해진 업무에 독립적으로 정기 수행한다 |
| L3 | 적용 | 상황에 맞게 조정·판단하며 능숙하게 수행한다 |
| L4 | 통합 | 팀 업무 체계에 통합하고 타인을 지도한다 |
| L5 | 전파 | 새 방식·표준을 만들어 조직에 확산한다 |

## 3. 스킬 기반 HR 운용

```
① 진단      BOS 117문항(빈도) + BARS 수준 판정 → 개인 스킬 프로파일
② 갭분석    직무별 Job-Skill Profile(요구 스킬×요구 수준) – 현재 = 갭
③ 교육매칭  갭 스킬 → Skillset 단위 모듈 매칭 (1 Skillset = 교육과정 1개)
④ 인증      PBL 산출물로 BARS 수준 인증 → 스킬 배지
⑤ 환류      조직 스킬 대시보드 → 채용·배치 활용 + 연 1회 인벤토리 개정
```

**내구성 운영** — 척추(역량군·역량)는 ~5년 유지, Skill·표현형은 연 1회 개정(추가·폐기·교체). 개정 서비스 자체가 시앤피 수익 모델.
