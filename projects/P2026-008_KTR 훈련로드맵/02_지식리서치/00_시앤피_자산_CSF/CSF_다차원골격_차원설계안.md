## 0. 전체 골격 한눈에

```
   ┌──────────────────────────────────────────────────────────────────┐
   │  차원1  AI 활용 영역 (WHAT)   ← 스킬이 사는 척추 · 전 산업 공통    │
   │         [기반] AI 협업 기본기                                       │
   │         ① 탐색·학습  ② 분석·판단  ③ 창작·설계  ④ 소통·협업  ⑤ 자동화·에이전트 │
   ├──────────────────────────────────────────────────────────────────┤
   │  차원2  숙련 수준 (HOW DEEP)  ← 3단: L1 활용 → L2 응용·검증 → L3 설계·선도 │
   ├──────────────────────────────────────────────────────────────────┤
   │  차원3  활용 모드 (HOW)       ← 자동화 · 증강 · 에이전트(위임) ★미래대응 │
   └──────────────────────────────────────────────────────────────────┘
              ↘ 적용 렌즈
   ┌──────────────────────────────────────────────────────────────────┐
   │  차원4  역할 페르소나 (WHO)   ← 스킬을 학습경로로 묶고 조직을 진단 (척추 아님) │
   └──────────────────────────────────────────────────────────────────┘

   하나의 스킬 = [영역] 안에서 / [수준]만큼 / [모드]로 발현, [페르소나]별로 묶임
```

이 구조의 의미: **"무엇을(영역) × 얼마나(수준) × 어떻게(모드)"가 스킬을 정의하고, "누가(페르소나)"가 그것을 적용한다.** v4.0(영역)과 v5.0(페르소나)이 서로 다른 차원으로 비로소 화해한다.

## 1. ★ 차원1 — AI 활용 영역 (제안)

### 1.1 조직 논리

전 산업 범용성은 **"전문 업무의 보편 가치흐름"**에서 나온다(Google·학계 Heptagon이 입증한 과업 추상화). 어느 산업·직무든 일은 다음 흐름을 거친다:

```
   [기반] AI와 협업하는 기본기 (모든 영역의 토대)
        │
   ① 찾고 이해한다 → ② 분석·판단한다 → ③ 만들고 설계한다 → ④ 소통·협업한다 → ⑤ 실행·자동화한다
   (탐색·학습)        (분석·판단)         (창작·설계)         (소통·협업)        (자동화·에이전트)
```

→ **1개 공통 기반 + 5개 활용 영역**. 기반은 횡단(모든 영역에 작동), 5영역은 가치흐름.

### 1.2 영역 정의

| 영역 | 국문 / 영문 | 정의 (이 영역에서 AI로 하는 일) |
|---|---|---|
| **기반** | **AI 협업 기본기** (Core Fluency) | AI에 의도를 전달(지시·맥락)하고, 결과를 검증하며, 책임 있게 쓰는 모든 활용의 토대 |
| **①** | **탐색·학습** (Research & Sensemaking) | 필요한 정보·지식·동향을 AI로 찾고 이해하고 학습한다 |
| **②** | **분석·판단** (Analytics & Decision) | 데이터·현상을 AI로 분석·예측해 의사결정에 활용한다 |
| **③** | **창작·설계** (Creation & Design) | 문서·콘텐츠·설계·코드 등 산출물을 AI로 생성·완성한다 |
| **④** | **소통·협업** (Communication & Collaboration) | 번역·회의·커뮤니케이션·관계를 AI로 매개해 협업한다 |
| **⑤** | **자동화·에이전트** (Automation & Agents) | 반복·다단계 업무를 AI 워크플로우·에이전트로 자동 실행한다 |

> '전환·재설계'는 영역이 아니라 **수준 L3 + 페르소나(전환리더)**에 둔다(중복 방지). '윤리·책임'은 별도 영역이 아니라 **기반에 내장 + 모든 영역 횡단**.

같은 5영역이 7개 산업에서 **각자의 구체 업무**로 채워진다 — 영역은 공통, 내용은 직무 특화.

|---|---|---|---|---|---|

## 2. 차원2 — 숙련 수준 (3단 확정)

글로벌 다수가 3단이며, 질적 도약점은 **"사용 → 검증·관리 → 설계·선도"**(SFIA·Deloitte·학계 공통).

| 수준 | 명칭 | 정의 (질적 경계) | 글로벌 정합 |
|---|---|---|---|
| **L1** | **활용** (Apply) | AI를 도구로 사용해 **정해진 업무를 수행**한다 | Foundational / Use |
| **L2** | **응용·검증** (Adapt & Verify) | AI 결과를 **검증·조정**하고 비정형 상황·워크플로우에 **응용**한다 | Intermediate / Evaluate·Manage |
| **L3** | **설계·선도** (Design & Lead) | 새 활용·표준·**업무 전환을 설계**하고 조직에 **확산**한다 | Advanced / Design·Lead |

→ 도약점이 명확: L1은 "쓴다", L2는 "믿어도 되는지 가리고 바꾼다", L3은 "새로 만들고 퍼뜨린다". 에이전트 시대 핵심 역량(검증·감독)은 **L2의 경계**에 위치.

## 3. 차원3 — 활용 모드 (★미래대응 핵심)

각 스킬이 **AI를 어떤 방식으로 쓰는가**를 태그한다. 이 축이 미래대응을 구조에 내장한다.

| 모드 | 정의 | 인간의 위치 |
|---|---|---|
| **자동화** (Automation) | 사람이 정의한 작업을 AI가 **대신 수행** | 정의·확인 |
| **증강** (Augmentation) | AI가 사람의 사고·창작·판단을 **보조·확장** (협업) | 함께 수행 |
| **에이전트·위임** (Agency) | AI 에이전트가 목표를 받아 **자율적으로 계획·실행** | 위임·감독 |

**왜 이게 미래대응인가**
- **Agency(위임)를 처음부터 1급 모드로** 박으면, 에이전트 시대가 와도 구조를 안 바꾼다 — 스킬의 무게중심이 자동화→증강→**위임**으로 이동하는 것을 *모드 태그 전환*으로 흡수(Anthropic·SFIA 원칙).
- 같은 영역·수준의 스킬도 모드가 진화한다. 예: ②분석·판단 / L2 — 2025년엔 '증강'(사람이 AI와 분석), 2027년엔 '에이전트'(분석 에이전트에 위임·감독). **영역·수준은 불변, 모드만 갱신.**
- 기술·도구명은 스킬 카드의 '현재 표현형'에만(연 1회 갱신). → 3중 방어(영역 불변 / 모드로 진화 흡수 / 표현형으로 도구 격리).

## 4. 차원4 — 역할 페르소나 (고민안)

### 4.1 페르소나의 위치 — 척추가 아니라 적용 렌즈

페르소나는 스킬을 만드는 축이 아니라, 만들어진 스킬 매트릭스를 **(a) 학습경로로 묶고 (b) 조직 인력을 진단하고 (c) 직무에 매핑**하는 렌즈다(BCG·McKinsey 방식). 이게 v5.0 페르소나가 "옳았지만 위치가 틀렸던" 지점이다.

### 4.2 어떻게 설정할까 — 2가지 모델 + 추천

| 모델 | 페르소나 | 성격 | 강점 | 약점 |
|---|---|---|---|---|
| **A. 성숙 진급형** | 리터러시→프랙티셔너→빌더→트랜스포머 | 누적 진급 | 학습 로드맵·승급 직관적 | 모두가 한 줄로 올라간다는 가정(현실은 분기) |
| **B. 기능 역할형** (BCG) | 사용자·구축자·방향자·관리자 | 동시 역할 | "무엇을 소유하나" 명확 | 진급·성장 서사 약함 |

**추천 — 하이브리드 (C): 공통 진급 + 상위 분기**

```
        ┌─────────────────────────────────────────────┐
  상위   │   ┌ AI 빌더(Builder) ─ 자동화·에이전트·도구 구축  │  ← 전문 분기
  분기   │   │                                              │     (소수 정예)
        │   └ AI 전환리더(Transformer) ─ 재설계·확산·거버넌스 │  ★AX 시그니처
        ├─────────────────────────────────────────────┤
  공통   │   AI 프랙티셔너(Practitioner) ─ 직무에 AI 능숙 적용 │  ← 전 직원 성장
  진급   │   AI 활용자(User) ─ 기본기+기초 활용                │     (broad fluency)
        └─────────────────────────────────────────────┘
```

- **공통 트랙(User→Practitioner)**: 전 직원이 밟는다 (broad fluency). 글로벌 공통 = '전 직원 펜리시'.
- **상위 분기(Builder / Transformer)**: 모두가 빌더가 될 필요 없음. 기술 구축(Builder)과 조직 전환(Transformer)으로 **전문 분기** = 글로벌 공통 '소수 정예 + 거버넌스 분리'(BCG Steward·McKinsey elite).
- 이 하이브리드가 연구의 **"전 직원 펜리시 + 소수 빌더 이원 트랙"**을 그대로 구현하고, AX 전환(Transformer)을 최상위에 둬 시그니처를 살린다.

각 페르소나 = **(영역 × 수준 × 모드) 매트릭스에서 요구되는 셀의 묶음**. 예: 활용자 = 전 영역 L1 / 프랙티셔너 = 자기 직무 영역 L2 / 빌더 = ⑤자동화 L3·Agency / 전환리더 = 전 영역 L3 + 재설계.

> **고민 포인트(사용자 결정)**: 페르소나를 4개 하이브리드(추천)로 갈지, 단순 진급형 4단(A)으로 갈지, 기능 역할형(B)으로 갈지.

## 5. 네 차원이 어떻게 조립되나 (예시 — ②분석·판단 영역)

| | L1 활용 | L2 응용·검증 | L3 설계·선도 |
|---|---|---|---|
| **스킬 예시** | 데이터를 AI로 기초 분석한다 | AI 분석 결과를 검증·조정해 의사결정에 쓴다 | 부서 분석 워크플로우를 재설계·표준화한다 |
| **주 모드** | 증강 | 증강→에이전트 | 에이전트 |
| **주 페르소나** | 활용자 | 프랙티셔너 | 전환리더/빌더 |
| **산업 적용(반도체)** | 수율 데이터 기초 분석 | 결함 원인 분석 검증 | 수율 분석 파이프라인 설계 |

→ 한 영역이 수준·모드·페르소나로 입체화되며, 산업을 입히면 직무 스킬이 된다. **이 한 칸이 작동하면 6영역 전체가 같은 방식으로 전개된다.**

## 6. 미래대응이 구조에 내장된 방식 (요약)

1. **불변층**: 영역(가치흐름)·수준(인지 도약)·페르소나(역할) = 기술 무관 → 모델이 바뀌어도 유지
2. **진화 흡수**: 모드축(자동화→증강→**에이전트**)이 변화를 *태그 전환*으로 흡수
3. **도구 격리**: 구체 기법·제품은 '현재 표현형'에만 → 연 1회 갱신
4. **갱신 거버넌스**: 영역·수준 ~5년 고정 / 모드·스킬·표현형 연 1회 개정 (Bersin velocity)
