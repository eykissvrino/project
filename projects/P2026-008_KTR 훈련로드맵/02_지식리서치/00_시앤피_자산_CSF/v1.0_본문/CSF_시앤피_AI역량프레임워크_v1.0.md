# CSF — 시앤피 AI 역량 프레임워크
## CnP Skill Framework for AI Capability

**Version**: 1.0 (초안)
**작성**: 2026-05-29 (금)
**저작·소유**: 시앤피컨설팅 (㈜대우인력경영컨설팅)
**위상**: **산업·직무·과업 무관 진정한 범용 모델** — 시앤피 AX B2B 사업 핵심 자산

---

## 0. 본 프레임워크의 위상

### 0.1 무엇이 아닌가
본 CSF는 **다음이 아닙니다**:
- KTR 친환경 바이오화학 직무역량 모델이 ❌
- 특정 산업·기업·직무의 맞춤형 모델이 ❌
- 특정 AI 도구 사용법 매뉴얼이 ❌
- 채용·인사 평가 기준이 ❌ (그렇게 활용 가능하나 1차 목적 아님)

### 0.2 무엇인가
본 CSF는:
- **모든 산업, 모든 직무, 모든 과업·워크플로우**에 적용 가능한 **AI 활용·융합 스킬의 보편 분류 체계**
- 시앤피 종합 AX 컨설팅 자산 체계의 **3번째 단계** (개인 차원)
- 어떤 As-is/To-be 워크플로우든 **CSF에 매핑하면 필요 AI 스킬이 자동 도출**되는 매핑 인프라

### 0.3 시앤피 종합 AX 자산 체계 안에서의 CSF

```
[1] 기업 차원 AX 진단 (시앤피 보유, 산인공 2026)
    7영역: 전략·조직·인재·문화·데이터·인프라·거버넌스
    4수준: Lv1 인식 → Lv2 → Lv3 → Lv4
                    ↓ "인재" 영역 진단 결과가 약한 경우
                    ↓
[2] 업무 차원 As-is/To-be 워크플로우 재설계 (시앤피 보유)
    핵심 업무별 As-is → To-be 매트릭스
    "필요 교육훈련" 항목 도출
                    ↓ To-be 수행에 필요한 직원 AI 역량 추출 필요
                    ↓
[3] 개인 차원 CSF (★ 본 문서) ★★★
    AI 활용·융합 스킬의 보편 분류 체계
    워크플로우 → CSF 매핑 → 필요 스킬 자동 추출
                    ↓ CSF 스킬에 대응하는 교육 모듈 필요
                    ↓
[4] 훈련 차원 PBL 훈련로드맵 (시앤피 보유)
    "실제 업무 데이터·산출물 기반 프로젝트 학습"
    CSF 스킬당 PBL 모듈 매핑
```

→ CSF는 **AX 진단의 인재 영역과 워크플로우 재설계의 교육훈련 산출을 연결하는 핵심 허브**

## 1. CSF의 설계 사상 (7 원칙)

### 원칙 1 — 산업·직무·과업 완전 중립
- 본문에 어떤 산업·기업·직무 고유명사도 포함하지 않음
- 영역명·책무명·스킬 진술문 모두 추상적·보편적 표현
- 산업 특화는 별도 "적용 가이드"로 분리

### 원칙 2 — 스킬 기반 (Skill-based)
- 역량(Competency) ≠ 스킬(Skill) 구분 명확화
- "무엇을(What)" 보다 "어떻게(How)"
- 진술문 표준: 「**가치 기반 전문지식 + 책무 + 직무행동**」 (김은경 외, 2024)

### 원칙 3 — O*NET 4-카테고리 + 거버넌스 = 5대 영역
- 글로벌 직업 표준 (O*NET)의 4 Work Activity Categories 채택
- AI 시대 핵심으로 거버넌스 별도 영역 추가
- Microsoft도 자사 AI Skills Framework에 O*NET 4-카테고리 채택

### 원칙 4 — 활용·융합·전환 3-Level (Microsoft·Gartner 정합)
- Lv1 **AI 활용** (AI Use): 기존 업무에 AI 도구 적용
- Lv2 **AI 융합** (AI Integration): AI와 협업하는 새 업무 방식
- Lv3 **AI 전환** (AI Transformation): AI로 인한 직무·조직 재설계

### 원칙 5 — 4단 매핑 자유도
산업 → 직무 → 과업 → 워크플로우 → CSF
각 단계마다 맞춤화 가능. CSF 본문은 가장 상위 추상 단위만.

### 원칙 6 — 시앤피 AX 자산 체계 정합
- AX 진단 7영역의 "인재" 영역 상세화
- 워크플로우 재설계의 "필요 교육훈련" 추출 도구
- PBL 훈련로드맵의 모듈 분류 기준

### 원칙 7 — 확장 가능 & 갱신 가능
- 신기술 등장(AGI·멀티모달·자율 에이전트) 시 영역 추가 또는 책무 추가
- 미사용 스킬은 매년 갱신 시 archive
- 적용 사례 누적 → 산업별 표준 책무 라이브러리 구축

## 3. CSF 3계층 구조

```
대분류: 영역 (Domain) — 5개
   ↓
중분류: 책무 (Responsibility) — 영역당 2~4개, 총 약 15개
   ↓
진술문: 스킬 (Skill) — 책무당 2~3개, 총 약 36개
```

**스킬 진술문 표준 (한국어)**:
```
「[가치 기반 전문지식] + [책무 명] + [직무행동]」
예: 「업무 자료 검색·요약 AI 도구를 활용해 / 업무 관련 정보를 / 수집·요약한다」
```

**영문 매핑**: NIST NICE Framework T·K·S (Task·Knowledge·Skill) 호환 가능 구조

## 5. CSF 수준 체계 — 3-Level (시앤피 AX 진단 4수준과 정합)

### CSF Lv1 — AI 활용 (AI Use)
- **정의**: 기존 업무 워크플로우에 AI 도구를 보조적으로 활용
- **행동 특징**: 도구 사용법 숙지 / 한계 인식 / 결과 검증 / 출처 확인
- **AX 진단 정합**: Lv1 AX 인식·Lv2 AX 도입 단계
- **Microsoft 정합**: AI Business Professional
- **Gartner 정합**: Executive Awareness / Specialized (User)

### CSF Lv2 — AI 융합 (AI Integration)
- **정의**: AI와 협업하는 새로운 업무 방식을 직무에 통합
- **행동 특징**: AI를 워크플로우에 내장 / 데이터 기반 의사결정 / 협업적 개선 / AI 결과의 직무 맥락 해석
- **AX 진단 정합**: Lv3 AX 확산 단계
- **Microsoft 정합**: AI Transformation Leader
- **Gartner 정합**: Agentic AI Skills (Implementer)

### CSF Lv3 — AI 전환 (AI Transformation)
- **정의**: AI로 인한 직무·조직·서비스 자체의 재설계 주도
- **행동 특징**: AI 시스템 설계·검증 주도 / 조직 표준 정립 / 윤리·리스크 거버넌스 / 다중 에이전트 오케스트레이션
- **AX 진단 정합**: Lv4 AX 정착 단계
- **Microsoft 정합**: Agentic AI Business Solutions Architect
- **Gartner 정합**: AI Transformation Architect

### 수준 적용 원칙
- 같은 영역·책무 안에서도 직급·경험·산업 성숙도에 따라 차등 스킬 적용
- 모든 스킬에 Lv1·Lv2·Lv3 진술문 3종 작성 (행동 수준 차등)
- 영역5(거버넌스)는 모든 수준에서 필수

## 6. CSF 매핑 메커니즘 — 산업/직무/과업/워크플로우 → CSF

### 4단 매핑 자유도

```
[자유도 1] 산업 적용
  CSF + 산업 특화 책무·스킬
  예) 친환경 바이오화학 → 영역3에 "AI 활용 친환경 소재 개발 보고서 생성" 책무 추가
  예) 의료기기 → 영역5에 "MDR·FDA 인허가 문서 AI 검증" 책무 강화
  예) 금융 → 영역2에 "AI 신용 평가 모델 활용" 책무 추가

[자유도 2] 직무 적용
  CSF + 직무별 수준 차등
  예) R&D → 영역1·2·5 중심
  예) 생산·품질 → 영역2·3 중심
  예) 마케팅·기획 → 영역1·3·4 중심
  예) 관리자 → 영역4·5 중심

[자유도 3] 과업 적용
  CSF + 과업별 스킬 진술문 치환
  예) "보고서 작성" 과업 → 영역3.1 스킬 3종 적용
  예) "설비 점검" 과업 → 영역2.2·2.3 스킬 적용

[자유도 4] 워크플로우 적용 (As-is/To-be)
  As-is 워크플로우 분석 → 자동화·고도화 가능 단계 식별 →
  To-be 워크플로우 설계 → 각 To-be 단계의 CSF 스킬 매핑 →
  필요 교육훈련(PBL 모듈) 도출
  예) "데이터 라벨링" As-is(수작업) → To-be(자동화) →
      영역2.1·2.2·5.1 스킬 도출 →
      PBL 모듈 "라벨링 자동화 AI 모델 개발 실습" 매칭
```

### 매핑 SOP (시앤피 컨설팅 신규 수주 시)

```
1. AX 진단 7영역 × 4수준 측정 → 기업 AX 현황 파악
2. 약한 영역의 핵심 업무 As-is 도출 → 워크플로우 재설계 대상 선정
3. To-be 워크플로우 설계 → 자동화·고도화 단계 도출
4. To-be 각 단계를 CSF 영역·책무·스킬에 매핑
5. CSF 스킬 진술문을 산업·기업 맥락에 치환 (자유도 1)
6. 매핑된 스킬에 대응하는 PBL 모듈 라이브러리에서 선택·구성
7. 교육·평가·인증 운영 + 효과 측정 (Pre/Post 진단)
8. 결과를 CSF 누적 DB에 환류 → 모델 갱신
```

## 7. 시앤피 사업 활용 시나리오

### 시나리오 A. 신규 AX 컨설팅 수주
- 시앤피 종합 AX 자산 체계 (4단 사이클) 통합 제안
- 입찰 경쟁사 대비 차별성 = CSF + AX 진단 + 워크플로우 재설계 + PBL 통합

### 시나리오 B. 고객사 정기 AI 역량 진단
- CSF 36 스킬 × 3수준 = 108셀 자가진단 매트릭스
- 산업·직무·기업 벤치마크 (시앤피 누적 DB) 비교 리포트
- 개인·팀·조직 단위 진단

### 시나리오 C. AI 교육 콘텐츠 라이브러리
