## 3. 기반 — Anthropic 4D 기반 원자 스킬 (27)

> AI 개발사가 이미 원자화한 골격을 그대로 차용. 가장 보편·검증된 핵심.

| 역량 (4D) | 스킬셋 | 스킬 |
|---|---|---|
| **G1 위임·판단** (Delegation) | 과업 판단 | F01 문제·목표 정의 · F02 AI 적합성·한계 판단 · F03 과업 분할·위임 설계 |
| | 도구·모드 선택 | F04 AI 도구 선택 · F05 상호작용 모드 선택 |
| **G2 지시·소통** (Description) | 프롬프트 설계 | F06 명확·구체 지시 · F07 역할·페르소나 부여 · F08 출력 형식 지정 · F09 대상·톤 지정 · F10 예시 제공(퓨샷) |
| | 맥락·추론 설계 | F11 맥락·근거자료 제공 · F12 처리 절차 안내 · F13 사고 유도(CoT) |
| | 대화·자산화 | F14 반복·점진 개선 · F15 프롬프트 체이닝 · F16 프롬프트 자산화 |
| **G3 검증·분별** (Discernment) | 산출물 검증 | F17 사실·정확성 검증 · F18 적절성 평가 · F19 논리 일관성 평가 |
| | 과정·행동 검증 | F20 추론·근거 검토 · F21 편향·아첨·드리프트 식별 · F22 개선점 식별·재지시 |
| **G4 책임·거버넌스** (Diligence) | 안전·정보보호 | F23 데이터 민감도 판단·보호 · F24 보안·승인도구 통제 |
| | 투명·책임 | F25 AI 사용 투명 공개 · F26 최종 검증·책임 배포 · F27 윤리·편향·법규 준수 |

각 스킬은 Anthropic 4D 세부역량(Problem/Platform/Task Awareness, Product/Process/Performance Description·Discernment, Creation/Transparency/Deployment Diligence) + 프롬프트 기법(역할·예시·CoT·체이닝)에 1:1 근거.
