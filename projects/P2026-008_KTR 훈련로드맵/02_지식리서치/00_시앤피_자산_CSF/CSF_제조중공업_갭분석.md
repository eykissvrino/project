## 3. 누락의 본질 — 4대 클러스터

현 72스킬은 "화면 앞 지식노동"을 전제한다. 제조는 **물리 세계 + 현장 + 설비**가 추가 차원이고, 이게 통째로 빠졌다.

1. **설비·공정 AI** — 예지보전·공정최적화·적응제어·설비 모니터링
2. **품질·검사 AI(비전)** — AI 비전 검사·수율/이상 분석
3. **물리·자율 시스템** — 로봇/코봇·자율시스템·디지털 트윈
4. **현장·안전 AI** — AR/음성 현장지원·안전/환경 모니터링

이는 Deloitte가 2026 프론티어로 지목한 **"Physical AI"**(물리세계 융합·인간 감독)와 정확히 일치.

## 4. 처방 — ★ 7번째 영역 신설 (추천)

물리·현장 AI는 6개 지식노동 영역에 흩어 넣기엔 결이 다르다(실시간·물리·현장). **별도 영역 ⑦로 신설**하면 제조가 한눈에 보이고 MECE도 깔끔하다. 사무 직군은 Job-Skill Profile에서 ⑦을 선택 안 하면 됨(영역은 superset).

### ⑦ AI 현장·설비·물리 (Physical & Operational AI) — 4역량·11스킬(안)

| 역량 | 스킬셋 | 스킬 |
|---|---|---|
| **7-1 설비·공정 AI** | 설비 운영 | P01 예지보전 운영 · P02 설비·센서 모니터링 |
| | 공정 최적화 | P03 AI 공정 최적화 · P04 적응형 공정 제어 |
| **7-2 품질·검사 AI** | 비전 검사 | P05 AI 비전 품질검사 |
| | 수율·이상 분석 | P06 수율·이상 분석 |
| **7-3 물리·자율 시스템** | 로봇·자율 | P07 로봇·코봇 협업 · P08 자율 시스템 운영 |
| | 디지털 트윈 | P09 디지털 트윈 활용 |
| **7-4 현장·안전 AI** | 현장 작업 | P10 현장 AI 작업지원(AR·음성) |
| | 안전·환경 | P11 AI 안전·환경 모니터링 |

→ 합산 시 체계: **역량군 8 · 역량 18 · 스킬셋 37 · 스킬 83**. 페르소나에 **현장 운영자(Operator)** 추가 검토.

### 대안 B — 기존 영역에 분산
②에 예지보전·비전·수율, ⑤에 공정자동화, ⑥에 로봇·자율·디지털트윈, 신규 "안전" 클러스터. → 6영역 유지하나 제조 가시성↓, 결이 섞임.

**추천: ⑦ 신설** (제조 가시성·MECE·산업 확장성 우위).
