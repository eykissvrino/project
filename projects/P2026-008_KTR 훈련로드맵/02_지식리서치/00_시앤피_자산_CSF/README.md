### 🔑 핵심 결정 (2026-05-29 확정)

CSF는 단순한 "AI 역량 분류"가 아닌 **시앤피 AX 컨설팅 5단계 사이클의 표준 어휘**:

```
① 진단 (AX 7영역) → ② 재설계 (Workflow Rewiring) →
③ 역량 매핑 (CSF 좁은 의미) → ④ 실행 (PBL) → ⑤ 측정·환류
                  ↑
           CSF가 전 단계 관통 표준 어휘
```
