# CSF 수준 체계 — 심층 검토

> **작성**: 2026-05-29 (금) | 이석주
> **위상**: CSF는 AI 역량/스킬의 분류 체계 — 본 문서는 그 안에서 "수준(Level)"을 어떻게 정의할 것인가 검토
> **위상 정정**: "직무 차원"은 CSF 본문 영역이 아님. 응용 가이드로 분리.

---

## 0. 수준 체계가 답해야 할 4가지 질문

1. **무엇이 수준을 가르는가?** (What discriminates levels?)
   - 숙련도 / 자율성 / 복잡도 / 영향 범위 / 인지 단계 — 또는 이들의 조합
2. **몇 단계인가?**
   - 3 / 4 / 5 / 6 / 7 / 8 — 평가 정밀도 vs 복잡도 트레이드오프
3. **어떻게 명명하는가?**
   - 한국어 / 영어 / 추상명사 / 행동동사
4. **어떻게 측정·평가하는가?**
   - 자가진단 / 관찰 / 산출물 / 시나리오 / 인증 시험

## 1. 글로벌 표준 수준 체계 비교 (10가지)

### 1.1 학술·인지 기반

#### Dreyfus & Dreyfus 5단계 (1980, 숙련도)
| Lv | 명칭 | 특징 |
|---|---|---|
| 1 | Novice (초보) | 규칙 따르기, 맥락 미고려 |
| 2 | Advanced Beginner | 일부 맥락 인지, 여전히 규칙 의존 |

## 4. 이석주 추천 — **옵션 X5**

### 추천 이유
1. **명명은 단순 4수준** (Aware·User·Integrator·Designer) — 기억 용이, 산인공 정합
2. **평가는 정밀** — 각 영역의 4수준별 행동 지표 작성 (5영역 × 4수준 = 20셀)
3. **확장 가능** — 추후 5수준(X4)으로 분화 필요 시 Lv3 Integrator를 "Practitioner + Integrator"로 분할 가능
4. **국제 호환** — Microsoft 4단계·OPM 5단계와 매핑 가능

### 옵션 X5의 핵심 구조 — 영역별 4수준 행동 지표 매트릭스 (예시)

```
                Lv1 Aware       Lv2 User         Lv3 Integrator      Lv4 Designer
                ─────────────────────────────────────────────────────────────────────
영역1           검색 도구       정기 검색·       다중 도구·다국어    팀 검색 표준
정보 처리       사용 시도       요약 활용        통합 활용·코칭      설계·자동화
                                                
영역2           AI 분석 결과    데이터 분석에    분석 워크플로우     데이터 거버넌스
분석·의사결정   읽기·이해       AI 통합 활용     설계·운영           ·아키텍처 주도

영역3           초안 도구       정기 산출물      다단계 산출 자동화 자동화 시스템
산출물 생성     시도            AI 활용          ·품질 관리          설계·확산 주도

영역4           AI 협업 도구    회의·소통에      교육·코칭·         AI 협업 표준
협업·소통       관찰            AI 활용          다자간 활용 주도   ·문화 설계

영역5           AI 한계·윤리    개별 결과        팀·프로젝트         조직 거버넌스
거버넌스·윤리   인식            검증·법규 준수   거버넌스 운영       체계 수립·확산
```

→ **5영역 × 4수준 = 20개 셀** + 각 셀당 1~3개 행동 지표·스킬 진술문 = 약 30~60 스킬

## 6. 추가 고려 사항

### 6.1 영역별 수준 적합도
- 영역5(거버넌스·윤리)는 Lv1부터 의무 — 누구나 결과 검증·윤리 인식 필요
- 영역1·3은 Lv1·Lv2가 일반 직원의 도달 목표
- 영역2·4는 Lv2·Lv3이 일반 직원의 도달 목표
- Lv4는 AI 전문가·관리자 수준

### 6.2 수준과 직무군의 관계 (응용)
- 일반 사원: Lv1·Lv2 도달 목표 (영역1·3 위주)
- 중간 관리자: Lv2·Lv3 도달 목표 (영역1·2·3·4)
- 임원·전략가: Lv3·Lv4 도달 목표 (영역2·4·5 위주)
- AI 전문가: 영역2·3 Lv4 + 영역5 Lv3·Lv4
※ 단, 이건 CSF 응용 가이드 영역 — CSF 본문은 직무 무관

### 6.3 평가 도구 가능성
- 자가진단: 5점 척도 (산인공처럼) → 영역별 4수준 산출
- 시나리오 시험: 영역별 4수준 행동 지표를 시나리오로 변환
- 산출물 평가: 직접 PBL 결과물로 수준 인증
- AI 시뮬레이션: AI 도구 활용 실습 평가
