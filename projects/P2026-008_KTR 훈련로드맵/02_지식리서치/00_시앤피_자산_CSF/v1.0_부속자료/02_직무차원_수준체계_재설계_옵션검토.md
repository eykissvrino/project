# CSF v1.0 → v1.1 — 직무 차원 신설 + 수준 체계 재설계 옵션 검토

> **작성**: 2026-05-29 (금) | 이석주
> **위상**: 사용자 지시(2026-05-29): "기업 차원 AX 진단은 산인공 보고서 참고하고, **직무 차원·개인 차원 프레임을 다시 설계**. 3-Level도 다시 설계"
> **목적**: v1.1 확정 전 사용자 선택을 위한 옵션 비교

---

## 0. 시앤피 AX 자산 4단 체계 재정의

```
[1] 기업 차원 (Company)        ← 산인공 AX 진단 7영역×4수준 (시앤피 보유 완료, 그대로 활용)
[2] 직무 차원 (Job/Role)       ← ★ v1.0에 없음 — 신설 필요
[3] 개인 차원 (Individual)     ← CSF 5영역×책무×스킬 (v1.0에서 설계, 수준 체계 재설계 필요)
[4] 훈련 차원 (Training)       ← PBL 모듈 (시앤피 보유)
```

## Part A. 직무 차원 프레임 — 옵션 검토

### A의 역할
- "어떤 직무에 어떤 AI 역량이 어느 정도 중요한가" 매핑하는 차원
- 행: 직무군 / 열: CSF 5영역 → 셀: 중요도 (높음·중간·낮음)
- AX 진단 결과 직무별 우선순위 결정 시 활용

### 옵션 비교

#### 옵션 A1 — 한국 NCS 24 대분류 그대로 차용
- 24개 직무군: 경영·금융·교육 / 농림 / 디자인·문화 / 사회복지 / 영업·판매 / 보건·의료 / 공무·국방 / 회계·세무 / 경비·청소 / 운전·운송 / 음식 / 광업 / 전기·전자 / 기계 / 정보통신 / 식품 / 섬유·의류 / 화학·바이오 / 인쇄·목재 / 환경·에너지 / 건설 / 안전 / 이용·미용 / 연구·개발
- **장점**: 국가 표준 정합 / 모든 직무 포괄
- **단점**: 24개가 과다 / AI 적용도 차이가 큰 직무 혼재
- **시앤피 적합도**: ★★☆☆☆

#### 옵션 A2 — 시앤피 자체 5~8 직무군 (실용·산업 중립)
- 예: ①관리·전략 ②영업·마케팅 ③R&D·기술 ④생산·품질 ⑤지원·인사·재무 ⑥교육·CS ⑦경영진 (선택)
- **장점**: 단순·기억 용이 / 시앤피 컨설팅 실무에 직결 / 모든 산업에 적용 가능
- **단점**: 국가 표준성 약함 / 직무 경계 모호 가능
- **시앤피 적합도**: ★★★★★ (권장)

#### 옵션 A3 — 자동화 가능성 매트릭스 (2축)
- 반복도(낮음↔높음) × 창의도(낮음↔높음) 매트릭스
- 4사분면별 AI 적용 패턴 차이:
  - 반복도 高 × 창의도 低 → 자동화 우선 (영역3·5 중심)
  - 반복도 低 × 창의도 高 → AI 증강 (영역1·2·4 중심)
  - 반복도 高 × 창의도 高 → AI 협업 (영역2·3·4 중심)
  - 반복도 低 × 창의도 低 → AI 도입 보류
- **장점**: 직관적 / 산업 무관 / 워크플로우 분석에 직접 연결
- **단점**: 너무 추상·실제 직무 명명 안 됨
- **시앤피 적합도**: ★★★☆☆ (보조 프레임으로 권장)

#### 옵션 A4 — O*NET 23 Major Groups (국제 표준)
- O*NET 23 직업 대분류 + 한국 매핑
- **장점**: 국제 호환 / 미국 OPM과 정합 / 시앤피 글로벌 사업 대비
- **단점**: 23개 과다 / 한국 직무와 일부 불일치
- **시앤피 적합도**: ★★★☆☆ (영문 확장 시 활용)

#### 옵션 A5 — Hybrid: 시앤피 자체 7 직무군 + O*NET·NCS 매핑
- 시앤피 자체 7군을 메인으로 + 각 직무군에 O*NET·NCS 매핑 표 부록
- **장점**: 실용성 + 국제·국가 호환성 동시
- **단점**: 작업량 증가
- **시앤피 적합도**: ★★★★★ (장기적 권장)

### A 추천 (이석주 판단)
**옵션 A2** (시앤피 자체 7 직무군)을 메인으로 채택하되, **옵션 A3** (자동화 매트릭스)을 워크플로우 분석 보조 프레임으로 병용. **옵션 A5** (Hybrid 매핑)는 v2.0에서 영문화·국제화 시 확장.

### 옵션 A2 — 시앤피 자체 7 직무군 (1차 제안)

| # | 직무군 | 정의 | CSF 5영역 중요도 패턴 (가설) |
|---|---|---|---|
| ① | **경영·전략** | C-Level, 전략 기획, 사업 개발 | 2·5 ★★★ / 1·4 ★★ / 3 ★ |
| ② | **R&D·기술** | 연구 개발, 엔지니어링, 설계 | 1·2·3·5 ★★★ / 4 ★★ |

| ④ | **영업·마케팅** | 영업, 마케팅, 브랜드, PR | 1·3·4 ★★★ / 2·5 ★★ |

## Part B. 수준 체계 재설계 — 옵션 검토

### B의 역할
- 같은 스킬도 직급·경험·산업 성숙도에 따라 행동 수준 차등
- 평가·인증·교육 설계의 기반

### 옵션 비교

#### 옵션 B1 — 3-Level (활용·융합·전환) ★ v1.0에서 채택, **폐기 결정**
- Lv1 활용 / Lv2 융합 / Lv3 전환
- **장점**: 단순 / Microsoft·Gartner 정합
- **단점**: 산인공 4수준과 명명 불일치 / 평가 정밀도 부족 / 사용자 폐기 결정

#### 옵션 B2 — 4수준 (산인공 AX 진단 정합)
- **Lv1 AI Aware** (인식): AI 기초 개념 이해, 일부 도구 시도
- **Lv2 AI User** (도입·활용): 도구를 업무에 도입, 시범 적용
- **Lv3 AI Integrator** (확산·통합): 직무 워크플로우에 AI 내장, 체계 운영
- **Lv4 AI Designer** (정착·전환): AI로 새 업무 방식·시스템 설계 주도
- **장점**: 산인공 4수준(인식·도입·확산·정착) 정확히 정합 / 시앤피 자산 내부 일관성
- **단점**: 4단계가 개인 평가에 너무 거시적일 수 있음
- **시앤피 적합도**: ★★★★★ (권장)

#### 옵션 B3 — 5수준 (Bloom-AI 통합)
- Lv1 인지 / Lv2 활용 / Lv3 적용 / Lv4 분석·평가 / Lv5 창조·전환
- **장점**: 학습 이론 기반 / 교육·평가 정밀
- **단점**: 5단계 복잡 / 산인공과 다름
- **시앤피 적합도**: ★★★☆☆

#### 옵션 B4 — 5수준 (시앤피 AI Bloom+산인공 통합)
- Lv1 AI Aware (이해·인식)
- Lv2 AI User (도구 활용)
- Lv3 AI Practitioner (직무 적용)
- Lv4 AI Integrator (워크플로우 통합)
- Lv5 AI Designer (전환·설계)
- **장점**: 풍부함 + 산인공 정합 부분적 / Microsoft 정합
- **단점**: 5단계 과한가
- **시앤피 적합도**: ★★★★☆

#### 옵션 B5 — SFIA Skills Framework 7수준 (국제 IT 표준)
- Lv1 Follow / Lv2 Assist / Lv3 Apply / Lv4 Enable / Lv5 Ensure&Advise / Lv6 Initiate&Influence / Lv7 Set Strategy
- **장점**: 국제 IT 표준 / 영문화 시 호환
- **단점**: 7단계 너무 많음 / AI 특화 안 됨
- **시앤피 적합도**: ★★☆☆☆

#### 옵션 B6 — 산인공 4수준 + SFIA Lv 매핑 (Hybrid)
- 시앤피 4수준을 메인으로 사용
- SFIA 7수준과 매핑 표 부록 (Lv1→SFIA Lv1·2, Lv2→SFIA Lv3, Lv3→SFIA Lv4·5, Lv4→SFIA Lv6·7)
- **장점**: 실용·국제 호환 동시
- **단점**: 매핑 매트릭스 작업 추가
- **시앤피 적합도**: ★★★★★ (장기 권장)

### B 추천 (이석주 판단)
**옵션 B2 (4수준 산인공 정합)** 메인 + **옵션 B6** v1.5 영문판에서 SFIA 매핑 부록 추가.

### 옵션 B2 — 4수준 상세 (1차 제안)

| 수준 | 명칭 | 행동 특징 | 평가 기준 | 산인공 정합 |
|---|---|---|---|---|
| **Lv1** | **AI Aware** (인식) | AI 도구 존재·기본 사용법 이해 / 시범 시도 / 결과 검증 의식 | 도구 사용 빈도 / 기본 결과물 점검 능력 | AX Lv1 인식단계 |
| **Lv2** | **AI User** (활용) | AI 도구를 정기적으로 업무에 활용 / 한계·편향 인식 / 단일 워크플로우 적용 | 워크플로우 적용도 / 산출물 품질 향상도 | AX Lv2 도입단계 |
| **Lv3** | **AI Integrator** (통합) | AI를 다중 워크플로우에 내장 / 데이터 기반 의사결정 / 협업적 개선 / 동료 코칭 | 직무 KPI 개선도 / 팀 확산도 / 교차 검증 | AX Lv3 확산단계 |
| **Lv4** | **AI Designer** (전환) | AI 시스템·워크플로우 자체를 설계·주도 / 조직 표준 정립 / 윤리·리스크 거버넌스 / 다중 에이전트 오케스트레이션 | 조직 성과 / 내재화 지표 / 거버넌스 운영 | AX Lv4 정착단계 |

## Part C. 개인 차원 (CSF) 5영역 재검토

### v1.0 5영역 (현재)
1. AI 정보 처리
2. AI 분석·의사결정
3. AI 산출물 생성
4. AI 협업·소통
5. AI 거버넌스·윤리

### 검토 포인트
- 5영역이 산업·직무 무관 진정으로 보편적인가? ✅ O*NET 4-카테고리 + 거버넌스 = 보편적
- 영역 간 중복은? → 미세하게 영역2·3·4 사이 경계 모호 가능
- 영역 누락은? → "AI 시스템 직접 개발·구축"이 빠짐 (영역3 일부에 흡수, 다만 명시 약함)

### 옵션 C1 — 현재 5영역 유지 (변경 최소)
- **장점**: 안정성·작업 효율 / 보편성 검증됨
- **단점**: AI 시스템 직접 개발 영역 약함

### 옵션 C2 — 6영역으로 확장 (AI 시스템 개발 분리)
- 1. AI 정보 처리 / 2. AI 분석·의사결정 / 3. AI 콘텐츠 생성 / 4. AI 시스템·자동화 구축 (신규 분리) / 5. AI 협업·소통 / 6. AI 거버넌스·윤리
- **장점**: AI 전문가 트랙 명확 / NCS 생성형 AI 엔지니어링과 정합
- **단점**: 6영역이 비-AI 전문 직원에게 과다

### 옵션 C3 — 5영역 + Technical 트랙 별도
- General 5영역은 모든 직원
- Technical Track (AI 시스템 개발) 별도 트랙으로 추가 (OPM의 14 Technical Competencies 정합)
- **장점**: 비-AI 직원 단순 + AI 전문가 정밀
- **단점**: 모델 복잡도 증가

### C 추천 (이석주 판단)
**옵션 C1 유지** (현재 5영역). AI 시스템 개발은 영역3에 명시적으로 포함. Technical Track은 CSF v2.0 영문판에서 별도 추가 검토.

## Part D. 통합 — v1.1 권장 구조

```
[직무 차원]   시앤피 7 직무군 (A2)
                        ↓
[개인 차원]   CSF 5영역 × 책무 15 × 스킬 36
                        ↓
[수준 차원]   4수준 — AI Aware → User → Integrator → Designer (B2)
                        ↓
[통합 매트릭스]  7 직무군 × 5영역 × 4수준 = 140 셀
                          ↓
[적용 사례]   각 셀에 해당 직무·영역·수준의 표준 스킬 진술문 1~3개
```

→ **총 스킬 풀**: 영역별 평균 7개 책무 미만 × 책무당 2~3 스킬 = **약 30~50개 핵심 스킬** (직무·수준에 따라 다르게 조합)
