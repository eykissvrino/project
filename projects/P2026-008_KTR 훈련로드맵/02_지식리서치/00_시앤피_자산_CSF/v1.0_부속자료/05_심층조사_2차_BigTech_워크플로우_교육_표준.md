## 2. 워크플로우 재설계 방법론 (#26) ★ 핵심

### 2.1 McKinsey "Rewiring" 방법론 ★ 가장 강력
**출처**: "The state of AI: How organizations are rewiring to capture value" (2025.3)

#### 핵심 대비 — Plug-in vs Rewiring
| 차원 | Plug-in Thinking | Rewiring Thinking |
|---|---|---|
| 접근 | 기존 프로세스에 AI 추가 | AI를 계기로 프로세스 **원리부터 재설계** |
| 대상 | 도구 도입 | 프로세스 재구성 |
| 효과 | 부분 개선 | EBIT 근본 변화 |
| 비율 | 일반 기업 80% | **고성과 기업 55%** (2.75배 격차) |

#### 4단계 방법론
1. **단일 워크플로우 선정** — 최고 가치 워크플로우 1개 선택
2. **End-to-end 재설계** — AI를 코어로 전체 재구축
3. **Outcome-based 목표** — "Deploy AI"가 아닌 "고객 유지 X% 향상" / "시장 출시 Y일 단축"
4. **Agent-ready Infrastructure** — RAG + Tool-calling + Guardrails + Audit trails

#### 핵심 데이터
- "EBIT 영향과 가장 강한 상관관계 = **워크플로우 근본 재설계**"
- 고성과 기업: 시니어 리더가 AI 사용 적극 모범 (3배 차이)

### 2.2 Accenture 워크플로우 재설계
**프레임워크**: AI Strategy + AiOps + IPA + GenAI Advisory
**End-to-end 모델**:
- Process Mining (현재 워크플로우 분석)
- Automation Design (자동화 설계)
- GenAI Integration (생성형 AI 통합)
- Ongoing Managed Services

**고객 성과 (은행)**:
- 20-25% 비용 절감
- 80% 통제 자동화
- 70% 계좌 개설 time-to-yes 단축

**Accenture 내부 — AATA (Accenture Advanced Technology Agent)**:
- Agentic AI 통합 플랫폼
- 인간 인력 ↔ 기술 플랫폼 사이 위치

### 2.3 IBM AI Workflow Practice
**프레임워크**: RPA + 데이터 엔지니어링 + AI 오케스트레이션
**고객 성과**:
- Pfizer: 새 프로젝트 20% 비용 회피
- Sixt: 문제 탐지·해결 70% 단축

### 2.4 워크플로우 재설계 공통 SOP (조사 종합)
```
1. Workflow Blueprint Mapping (As-is 문서화)
   - Process Mining 도구 활용
   - 단계별 작업·산출물·시간·비용·인력 정리

2. AI 적용 가능성 분석
   - "AI가 할 수 있는 것" 중심 (기존 워크플로우 감싸기 X)
   - Rewiring 사고로 원리부터

3. To-be 워크플로우 설계
   - End-to-end 재구성
   - Outcome-based 목표

4. Agent-ready Infrastructure
   - RAG·Tool-calling·Guardrails·Audit trails

5. 점진 배포 + 측정
   - 단일 워크플로우 우선
   - EBIT·KPI 추적
```

→ **시사점**: 시앤피 산인공 워크플로우 재설계 방법론이 글로벌 표준(McKinsey·Accenture·IBM)과 정합 — 시앤피 자산이 이미 산업 수준

## 4. 정부·국제표준 (#28)

- **고려 요소**:
  - 기술 지식
  - 경험
  - 교육
  - 사용 맥락
  - 대상자
- **EU AI Office**: 28개 best practice use case 공개

→ **시사점**: AI 리터러시는 **법적 컴플라이언스 의무** — 시앤피 CSF는 EU AI Act 대응 자산이 될 수 있음

## 5. 종합 — 시앤피 범용 AI 역량 모델 골격 (조사 결과 기반)

### 5.1 메타 구조 — McKinsey 3-Layer (확정 권장)

```
┌─────────────────────────────────────────────────────────┐
│  Layer 3 — AI Domain Transformation                     │
│  도메인 특화·조직 변화·전략 주도                          │
│  (Lv4·Lv5: Integrate·Create)                            │
├─────────────────────────────────────────────────────────┤
│  Layer 2 — AI Adoption                                  │
│  워크플로우 Rewiring·도구 통합·직무 단위 적용              │
│  (Lv3·Lv4: Analyze·Integrate)                           │
├─────────────────────────────────────────────────────────┤
│  Layer 1 — AI Literacy ★ EU AI Act 법적 의무             │
│  공통 fluency·기초 활용·윤리 인식                          │
│  (Lv1·Lv2: Know·Apply)                                  │
└─────────────────────────────────────────────────────────┘
```

### 5.2 영역 — Ng et al. 4 Aspects (학술 합의)
1. **Know & Understand** — AI 개념·작동·한계
2. **Use & Apply** — AI 도구 활용·업무 적용
3. **Evaluate & Create** — AI 결과 비판·새 활용 창조
4. **Ethical Issues** — 윤리·편향·책임 (EU AI Act 의무)

→ Layer 1·2·3 모두에 4 aspects 적용 (3 × 4 = 12 셀)

### 5.3 수준 — Bloom-AI 5단계 (사용자 확정 5/29)
- Lv1 Know · Lv2 Apply · Lv3 Analyze · Lv4 Integrate · Lv5 Create
- 5수준 × 스킬당 진술문 5개 (사용자 확정)

### 5.4 세부 역량 — Long & Magerko 17 Competencies (학술 1차 권위)
- 17개 핵심 역량을 4 aspects 안에 배치
- 각 역량마다 5수준 진술문 작성

### 5.5 적용 — Role-based Pathways (Accenture·MS 표준)
- 역할·직무별 맞춤 트랙
- 본 CSF 본문은 영역·역량 (메타) — 직무 매핑은 별도 적용 가이드
