# 시앤피컨설팅 AI 역량체계 — 전체 설계안 (Blueprint) v5.0

## CnP AI Competency System — Master Design Document

**작성**: 2026-05-30 (토) | 이석주
**위상**: **전면 재설계 출발점.** 이전 v2.0~v4.0은 전부 폐기. 본 설계안이 유일한 기준.
**성격**: 본 문서는 *채워진 체계*가 아니라 *설계 골격(blueprint)*. **스킬은 0개** — 척추 확정 후 도출한다.
**규율**: 골격 합의 → 스킬 도출 → 역량기술서·측정 → 산출물(Excel·HTML) → KTR 적용. **순서 역전 금지** (이전 실패의 원인).

## 0. 왜 다시, 무엇이 달라지는가

이전 6개 버전은 모두 "완성된 체계를 먼저 쏟아내고 골격은 사후 정당화"하는 방식이라 반복 실패했다. v5.0은 **골격을 먼저 합의**한다. 본 설계안이 합의되면 그 위에 스킬을 도출하므로, 더는 척추가 흔들리지 않는다.

이번 설계의 3대 결정(사용자 확정):
1. 역량군 척추 = **완전히 새로운 조직 원리** (기존 업무활동축·협업행동축 모두 폐기)
2. 1차 목적 = **시앤피 범용 컨설팅 자산** (산업 무관 마스터, KTR은 첫 적용)
3. 차별성 = **네 가지 모두** — 산업 적용 깊이 · AX 전환 시그니처 · 측정·진단 정교함 · 교육·PBL 연계

## 1. 설계 기준 (확정된 토대)

| 항목 | 확정 내용 |
|---|---|
| **1차 목적** | 시앤피 범용 컨설팅 자산 — 모든 산업에 적용 가능한 AI 활용 역량·스킬 마스터 |
| **활용 3-레이어** | ①범용 마스터(본체) → ②스킬기반 HR 운영도구(진단·매칭·인증) → ③산업 적용(KTR 친환경바이오화학 등) |
| **단위** | **스킬(Skill) 기반** — 지식·태도(K·A)는 스킬 정의·행동지표에 흡수 |
| **형식** | KIRD 「과학기술인 역량사전」 — 역량기술서(정의·행동지표·수준·관련정보) |
| **측정** | BOS(행동 빈도) + BARS(수준 판정) 이원 (KIRD 정합) |
| **수준** | 5단계 (L1 인지 ~ L5 전파) |
| **내구성** | 2층 분리 — 불변 척추(역량군·역량) + 가변 스킬(연 1회 개정), 기술 중립 명명 |

## 2. 설계 원칙 (6)

1. **활용 중심** — "AI를 이해한다"가 아니라 "AI로 일한다"를 측정한다.
2. **산업 범용** — 마스터는 산업 무관. 적용 시 직무별로 *조합·선택*한다(신규 작성 아님).
3. **현업 인식 가능** — 스킬은 현업이 "내가 배울 것"으로 즉시 인지하는 실무 언어.
4. **측정 가능** — 모든 스킬은 BOS·BARS로 평정 가능해야 채택(측정 불가 = 탈락).
5. **내구성** — 척추는 ~5년, 스킬·기법은 연 1회 개정. 도구·제품명은 본문에서 배제.
6. **컨설팅 자산화** — 진단 → 교육 → 인증 → 환류의 운영 사이클로 돌아가는 자산.

## 3. 4대 차별성 — '시앤피만의'를 어디서 만드나 (선택한 4개 모두 반영)

| 차별성 | 설계 반영 방식 |
|---|---|
| **① 산업 적용 깊이** | 마스터 스킬 위에 **Job-Skill Profile 레이어** — 산업·직무별 *요구 스킬 × 요구 수준* 조합으로 맞춤 적용. KTR 친환경바이오화학이 1호 프로파일. |
| **② AX 전환 시그니처** | 척추 최상위에 **'전환' 영역**을 두고, 시앤피 산인공 **Workflow Rewiring·PBL 자산**을 결합. 개인 활용 → 조직 재설계로 잇는 컨설팅 DNA. |
| **③ 측정·진단 정교함** | BOS·BARS 이원 측정 + **조직 AI 인력 분포 진단**(누가 어느 단계에 몇 %) + 성숙도 매핑. 스킬기반 HR의 핵심 무기. |
| **④ 교육·PBL 연계** | **Skillset = 교육모듈 1개**, 척추 단계 = 학습 경로(로드맵), 산인공 **PBL 방법론**으로 수준 인증. |

## 4. 참조 모델 & 폐기 이력

### 4.1 무엇 위에 서는가
| 역할 | 출처 |
|---|---|

| **도출 방법론** | 김은경 외 2024 스킬 모델링 (스킬 진술문 = 측정·교육 단위) |

| **2026 트렌드** | 에이전트(최대 스킬 갭) / 컨텍스트·오케스트레이션 이동 / 멀티모달 |

### 4.2 폐기한 척추 축 (왜 새 축이 필요한가)
| 폐기 축 | 버전 | 폐기 사유 |
|---|---|---|
| 학술 분류 (Know·Use·Evaluate·Ethical) | v2.x | 차용 분류 — "이해" 편중, 시앤피 정체성 없음 |
| AI 협업 행동 (판단·소통·검증·전환·책임) | v3.0 | 추상적 메타 개념 — 현업이 인식 못 함 |
| 업무 활동 (정보·콘텐츠·데이터·자동화) | v3.2·v4.0 | 결은 맞으나 일반적 — 누구나 만드는 분류, 차별성 약함 |

→ **공통 한계**: 세 축 모두 "AI로 무슨 작업을 하나"(과업) 또는 "AI를 어떻게 다루나"(행동)에 머물러, **시앤피 컨설팅 자산으로서의 정체성(전환·진단·육성)**을 담지 못했다. 그래서 **새 축**이 필요하다.

## 5. ★ 새로운 척추 — 핵심 결정

### 5.1 추천 축: **AI 활용 성숙 여정 (AI Maturity Personas)**

> 역량군을 "작업 종류"나 "행동"이 아니라, **개인이 AI와 맺는 관계의 성숙 단계(페르소나)**로 조직한다. 한 사람이 밟아 올라가는 *여정*이자, 조직이 진단하는 *인력 분포 지도*가 된다.

```
        ┌─────────────────────────────────────────────────────────┐
  누적   │  P4. AI 트랜스포머  Transformer   조직의 일하는 방식을    │ ★AX 시그니처
  성장   │      ── 워크플로우 재설계·확산·전환 리딩                  │
   ▲     ├─────────────────────────────────────────────────────────┤
   │     │  P3. AI 빌더       Builder       자동화·도구·에이전트를   │
   │     │      ── 만들어 업무를 확장                                │
   │     ├─────────────────────────────────────────────────────────┤
   │     │  P2. AI 프랙티셔너 Practitioner  내 직무에 AI를 능숙하게   │
   │     │      ── 적용해 성과를 낸다                                │
   │     ├─────────────────────────────────────────────────────────┤
   │     │  P1. AI 리터러시   Literate      전 직원 공통 토대 ──      │
   │     │      이해·기본 활용·검증·책임 (안전하게 쓴다)             │
        └─────────────────────────────────────────────────────────┘
                       (누적형 — 상위는 하위를 포함)
```

| 페르소나 | 정의 | 대상 | 차별성 연결 |
|---|---|---|---|
| **P1 AI 리터러시** | AI를 이해하고 검증·책임 하에 기본 활용 | 전 직원 | 진단 baseline |
| **P2 AI 프랙티셔너** | 내 직무 실무에 AI를 능숙하게 적용 | 실무자 | 산업 적용 깊이 |
| **P3 AI 빌더** | 자동화·도구·에이전트를 제작해 확장 | 파워유저 | 2026 트렌드(에이전트) |
| **P4 AI 트랜스포머** | 팀·조직의 일하는 방식을 재설계·확산 | 리더·전문가 | ★AX 전환 시그니처 |

**왜 이 축이 "완전히 새롭고" 시앤피에 맞나**
- **새롭다**: 과업(무엇)도 행동(어떻게)도 아닌 **"AI와 맺는 관계의 깊이(누가 되는가)"** — 조직 원리가 다르다.
- **4대 차별성과 정합**:
  - 측정·진단 → "우리 조직은 리터러시 60% / 프랙티셔너 30% / 빌더 8% / 트랜스포머 2%" 같은 **인력 성숙 분포**를 바로 그린다.
  - 교육·PBL → 페르소나가 곧 **학습 경로(승급 로드맵)**.
  - 산업 적용 → 직무별로 "이 직무는 P2까지, 저 직무는 P3까지" **요구 페르소나**를 지정.
  - AX 시그니처 → 최상위 P4가 시앤피 컨설팅 정체성.
- **내구성**: 페르소나(척추)는 기술이 바뀌어도 유지. 그 안의 스킬만 개정.

각 페르소나는 KIRD식 3계층(페르소나=역량군 → 역량 → Skillset → Skill)으로 전개된다. (스킬은 척추 확정 후 도출)

### 5.2 대안 축 (검토용)

| 대안 | 척추 | 장점 | 약점 |
|---|---|---|---|
| **B. AX 사이클 미러** | 진단·활용·검증·재설계·측정 (시앤피 5단계 사이클의 개인판) | 컨설팅 자산과 1:1 정합 | v3.0 협업행동축과 유사 — '새 축' 취지 약함 |
| **C. 가치창출 기반** | 효율·품질·통찰·창출·신뢰 (AI가 만드는 비즈니스 가치) | 성과 지향·경영 친화 | 스킬 매핑이 모호, 현업 인식 보통 |

→ **추천은 A(페르소나)**. B는 사이클(조직 컨설팅)에 가깝고, C는 측정이 어렵다. A가 "새 축 + 4대 차별성 + 현업 인식"을 동시에 만족.

## 6. 계층 정의 & 작성 표준 (구조만 — 내용 미충전)

```
역량군 (페르소나 4)
  └ 역량 (페르소나별 핵심 능력 단위)
      └ Skillset (함께 육성·진단·교육되는 스킬 묶음 = 교육모듈 1개)
          └ Skill (측정·매칭의 원자 단위)
              └ 스킬기술서 = 정의 + 세부 스킬 요소 + 산출물 예시
                            + 행동지표(BOS) + 숙련수준(BARS L1~L5)
                            + 현재 표현형(가변) + 근거 출처
```

| 계층 | 정의 | 명명 규칙 |
|---|---|---|
| 역량군 | AI 성숙 페르소나 | 「AI + 역할명」 국·영문 |
| 역량 | 페르소나 내 독립 능력 | 기술 중립 명사구 |
| Skillset | 교육·진단 묶음 단위 | 행위 명사구 |
| Skill | 측정 원자 단위 | 「업무 대상」+「AI 작업」 전문 명사형, 국·영 병기, 제품·기법명 금지 |

**스킬기술서 8필드** (KIRD 역량기술서 확장): 정의 / 세부 스킬 요소 / 산출물 예시 / BOS 3 / BARS 5수준 / 현재 표현형 / 근거 출처 / 소속 경로.

## 7. 측정 체계

- **BOS** (행동관찰빈도) — 스킬별 다차원 행동 3문항 × 5점 빈도 → 진단·Pre/Post
- **BARS** (행동기준평정) — 스킬별 L1~L5 수준 진술문 → 수준 판정·인증
- **5수준**: L1 인지 · L2 활용 · L3 적용 · L4 통합 · L5 전파 (KIRD·IBM 정합)
- **페르소나 분포 진단** (시앤피 시그니처): 개인 스킬 프로파일 → 페르소나 판정 → 조직 분포 대시보드

---

## 8. 도출 방법론 (척추 확정 후 적용)

1. 페르소나별 **AI 활용 직무 행동**을 가치사슬·문헌·트렌드에서 수집
2. **4대 선별기준**(보편성·수요근거·측정가능성·교육가능성) 통과만 스킬로 채택
3. 김은경식 스킬 진술문으로 기술 → BOS·BARS 작성
4. **자문회의 1차(6월) SME 검증** (김은경 7단계 워크숍 준용) → 확정
