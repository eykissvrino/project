## 0. 본 프레임워크의 정의 (확정)

### 0.1 CSF란 무엇인가
**시앤피 AX 컨설팅 종합 자산 체계의 표준 어휘**.

CSF는 단순한 "AI 역량 분류 체계"가 아닙니다. 5단계 컨설팅 사이클(진단·재설계·역량 매핑·실행·측정) **전체를 관통하는 시앤피의 공통 어휘**로, 시앤피의 모든 AX 컨설팅 솔루션이 같은 언어로 소통하게 합니다.

### 0.2 사업 목적과의 정합
- **궁극 목적**: 기업 AX 전환 솔루션 제공
- **CSF의 역할**: 진단 → 재설계 → 역량 매핑 → 실행 → 측정의 **사이클 자체를 운영 가능한 컨설팅 자산**으로 표준화

## 2. 5단계 상세 — 각 단계 정의·산출물·도구·권위

### 2.1 ① 진단 (Diagnose)
| 항목 | 내용 |
|---|---|
| **목적** | 고객 기업의 AX 현재 수준 객관 진단, 약점·기회 영역 도출 |
| **도구** | AX 진단 7영역 (전략·조직·인재·문화·데이터·인프라·거버넌스) × 4수준 (인식·도입·확산·정착) |
| **시앤피 보유 자산** | 산인공 컨소시엄 공동훈련 AX 진단 컨설팅 도구 v2.0 (2026.06 제출) |
| **CSF 표준 어휘 매핑** | 진단의 "인재" 영역을 CSF 4 Aspects (Know·Use·Evaluate·Ethical)로 재해석 |
| **외부 권위 정합** | OECD AI-Ready Workforce / EU AI Act Article 4 (직원 AI 리터러시 의무) |
| **산출물** | AX 진단 보고서 (영역별 점수·종합 단계·강점·취약) |

### 2.2 ② 재설계 (Rewire)
| 항목 | 내용 |
|---|---|
| **목적** | 약점 영역의 핵심 업무 As-is → To-be 재설계, AI 적용 가능 영역 도출 |
| **도구** | Workflow As-is/To-be Rewiring 매트릭스 |
| **시앤피 보유 자산** | 산인공 워크플로우 재설계 사례 (A사·B사 제조업) |
| **CSF 표준 어휘 매핑** | To-be 단계마다 필요 CSF 스킬·수준을 표준 어휘로 표기 |
| **외부 권위 정합** | McKinsey "Rewiring" (Plug-in vs Rewiring, 고성과 55% vs 일반 20%) / Accenture Process Mining + Automation Design / IBM AI Orchestration |
| **산출물** | 재설계 워크플로우 매트릭스 + 단기 자동화 우선순위 + 훈련로드맵 |

### 2.3 ③ 역량 매핑 (Map) — CSF 좁은 의미
| 항목 | 내용 |
|---|---|
| **목적** | To-be 워크플로우 수행에 필요한 직원 AI 역량을 표준 어휘로 정의·측정 |
| **구조** | **3-Layer × 4 Aspects × 5 Levels** |
| **메타 레이어** (McKinsey) | L1 AI Literacy · L2 AI Adoption · L3 AI Domain Transformation |
| **영역** (Ng et al. 2021) | ① Know & Understand ② Use & Apply ③ Evaluate & Create ④ Ethical Issues |
| **수준** (Bloom-AI, 사용자 확정) | Lv1 Know · Lv2 Apply · Lv3 Analyze · Lv4 Integrate · Lv5 Create |
| **세부 역량** (Long & Magerko 2020) | 17 Competencies — 4 Aspects 안에 배치 |
| **진술문 표준** (김은경 2024) | 「가치 기반 전문지식 + 책무 + 직무행동」 + 각 스킬마다 5수준 진술문 5개 |
| **외부 권위** | Ng et al. 2021 (학술) / Long & Magerko 2020 (학술 1차 권위) / McKinsey 3-Layer (컨설팅 표준) / EU AI Act Article 4 (법적 의무) |
| **산출물** | 개인·팀·조직 단위 AI 역량 진단 매트릭스 + 갭 분석 |

### 2.4 ④ 실행 (Execute)
| 항목 | 내용 |
|---|---|
| **목적** | 진단된 갭에 대응한 교육·인증·실무 적용 |
| **도구** | PBL (Project-Based Learning) 모듈 라이브러리 |
| **시앤피 보유 자산** | 산인공 PBL 훈련로드맵 방법론 ("AI 도구 사용법 X, 실제 업무 데이터·산출물 기반 프로젝트") |
| **CSF 표준 어휘 매핑** | PBL 모듈 = CSF 스킬·수준 도달 단위 |
| **외부 권위 정합** | Microsoft AI Skills Navigator (Role-based paths) / Accenture LearnVantage (Personalized pathways) / Coursera (300+ courses, 2026 Top Skills: AI Agents·AI-assisted Design·Critical Thinking) |
| **산출물** | 직원·팀별 맞춤 교육 트랙 + 인증서 + 실무 적용 산출물 |

### 2.5 ⑤ 측정·환류 (Measure & Feedback) — 신설
| 항목 | 내용 |
|---|---|
| **목적** | 컨설팅 성과의 비즈니스 KPI 추적, 사이클 재시작 |
| **도구** | Outcome-based KPI 추적 (McKinsey 표준) |
| **측정 대상** | ① CSF 역량 수준 변화 (Pre/Post) ② 워크플로우 KPI (시간·비용·품질) ③ 비즈니스 KPI (매출·EBIT·고객 만족) |
| **외부 권위 정합** | McKinsey "Outcome-based objectives" / BCG "Silicon Ceiling 해소 측정" / Deloitte "AI ROI Leaders" |
| **산출물** | 측정 리포트 + 다음 사이클 진단 인풋 |
