## 1. 과업수행체계

### 1.1 과업수행체계 개요

제안요청서 과업 내용을 기반으로, 본 사업의 Framework을 **총 3개 Module, 9개 Step**으로 재구조화 합니다.

전년도 과업이 'KTR 산업전환 교육체계의 기반 구축'이었다면, 금년도 과업은 **'기존 교육체계에 AI를 구조적으로 이식하는 체계 고도화'**에 초점을 둡니다. 이에 따라 과업수행의 핵심 논리는 다음과 같습니다.

> **기존 교육과정 Skill 분석 → 산업별 AI Skill Set 도출 → Skill Gap 분석 → 교육체계 개편 → 과정 재설계 및 신규 콘텐츠 설계**

| | **Module 1** | **Module 2** | **Module 3** |
|---|---|---|---|
| **모듈명** | 기존 교육체계 진단 및 AI Skill Set 도출 | AI 융합 교육체계 재설계 및 5개년 로드맵 고도화 | 교육과정 재설계 및 AI 신규 콘텐츠 설계 |
| **핵심 질문** | 현재 체계가 무엇을 가르치고 있으며, 어떤 AI 역량을 얹어야 하는가? | 기존 체계에 AI를 어디에, 어떤 수준으로, 어떤 순서로 이식할 것인가? | 실제로 어떤 과정을 어떻게 바꾸고, 무엇을 새로 만들 것인가? |
| **세부 내용** | · 기존 교육로드맵 수평·수직 체계 분석 | · 기존 Skill × AI Skill 매핑 및 Gap 분석 | · 기존 교육과정 AI 융합 재설계 |
| | · 기존 교육과정별 Skill 도출 및 매트릭스 구축 | · AI 반영 교육체계 개편안 도출 | · AI 반영 기존 교육과정 재설계 |
| | · AI 역량모델링 기반 AI Skill Set 도출 | · 2026~2030 AI 교육 마스터플랜 수립 | · 직무 맞춤형 AI 신규 교육 콘텐츠 설계 |
| **수행방법** | · 문헌분석 · 내용분석 · 전문가 자문 · 연구진 회의 | · 매핑분석 · 설문조사 · 전문가 워크숍(FGI) · 간담회 | · 개발연구 · 전문가 인터뷰 · 연구진 회의 |
| **핵심 산출물** | · 기존 교육과정 Skill Matrix | · 기존 과정-AI Skill 매핑표 및 Gap 분석표 | · AI 반영 교육로드맵 재설계 결과 |
| | · 산업별·직무별 AI Skill Set | · AI 반영 교육체계 개편(안) | · AI 반영 기존 교육과정 재설계 결과 |
| | · 기존 Skill ↔ AI Skill 연계 기준 | · 2026~2030 AI 교육로드맵 및 마스터플랜 | · 직무 맞춤형 AI 신규 교육과정 기획안 |

> ※ 상시 검증체계: 착수협의 → 중간검토(전문가 FGI) → 최종검증(이해관계자 간담회)을 통해 각 Module 산출물의 유효성을 확보합니다.

## 2. 세부 수행방안

### 2.1 Module 1: 기존 교육체계 진단 및 AI Skill Set 도출

> **핵심 질문: 현재 체계가 무엇을 가르치고 있으며, 여기에 어떤 AI 역량을 얹어야 하는가?**

#### Step 1. 기존 교육로드맵 구조 분석

전년도에 수립한 新 교육로드맵의 **수평 체계**(산업군·교육분야)와 **수직 체계**(수준·교육유형)를 분석하여, AI 이식을 위한 구조적 기반을 진단합니다.

**[전년도 수립 新 교육로드맵 체계]**

| 모듈 | 세부 교육분야 | 내용 |
|------|---------|------|
| **모듈1 (인사이트과정)** | 친환경 바이오화학 산업 동향 | 산업동향, 규제 등 인사이트 제공 |
| **모듈2 (실무공통과정)** | 환경경영 / ESG 경영 | 탄소관리, LCA, ESG 데이터 관리, Scope 3 |
| **모듈3 (산업특화과정)** | 바이오플라스틱 R&D / 생산 | 소재 제품화, 사출성형, 분석 실무 |
| | 플라스틱 재활용 생산 | 순환경제, 재활용 인증 |
| | 의료기기 규제 인증 | 인허가, 기술문서, 사이버보안 |
| | 화장품 기획 / 규제 인증 | 브랜딩, 클린뷰티, 안정성 평가 |
| | 정밀화학 규제 대응 | 화학물질 규제 대응, ICP 분석 |

**[수평 체계 분석]**

| 분석 항목 | 분석 내용 | 분석 방법 |
|---------|---------|---------|
| 산업군 분류 | 플라스틱/의료기기/화장품/정밀화학 등 산업군 구분 체계의 적절성 | 전년도 협약기업 분류체계 대조 |
| 교육분야 구성 | 모듈1~3 간 교육분야의 포괄성, 중복, 공백 영역 파악 | 교육과정 내용분석 |
| 직무군 연계 | 산업군별 R&D/생산/품질/규제/경영 등 직무군과의 연계 여부 | 전년도 직무분석 결과 대조 |

**[수직 체계 분석]**

| 분석 항목 | 분석 내용 | 분석 방법 |
|---------|---------|---------|
| 수준 체계 | 산업전환 3수준(선제대응→전환→정착)의 교육 난이도 구분 적절성 | 과정별 난이도 판정 |
| 교육유형 | 세미나/일반/전문 유형의 정의 명확성, 학습경로 연계성 | 과정 유형-내용 매칭 분석 |
| 학습경로 | 수준 간 이수 경로(Lv1→Lv2→Lv3)의 실효성 | 수료율·이수율 데이터 분석 |

- 26년 25개 훈련과정의 **수료율, 만족도, 현업적용도** 분석
- 과정 간 **연계성·중복·공백** 구간 파악
- 수직 체계의 **수준 정의 명확화** 필요 여부 진단

#### Step 2. 기존 교육과정별 Skill 도출 및 매트릭스 구축

기존 25개 교육과정에서 다루고 있는 **핵심 역량(Skill)**을 체계적으로 추출하여, 산업별·과정별 **Skill Matrix**를 구축합니다.

**[Skill 도출 방법]**

| 단계 | 수행 내용 | 투입 자료 |
|------|---------|---------|
| ① 교과목 분석 | 25개 과정별 교과목·학습목표·실습 요소 분석 | 교육과정 커리큘럼, 교재 |
| ② Skill 추출 | 과정별 핵심 역량(지식·기술·태도) 도출 | 내용분석 결과 |
| ③ 산업군 매핑 | 추출된 Skill을 산업군별로 분류·매핑 | 전년도 산업군 분류체계 |
| ④ Matrix 구축 | 산업군 × 교육과정 × Skill의 3차원 매트릭스 완성 | 상기 결과 종합 |

**[기존 교육과정 Skill Matrix 예시]**

| 산업군 | 교육과정 | 핵심 Skill |
|------|--------|---------|
| 플라스틱 | 친환경 소재 제품화 기본 전략 | 바이오플라스틱 소재 이해, 제품화 전략 수립, 시장 분석 |
| 플라스틱 | 바이오플라스틱/엘라스토머 제품 분석 실무 | 물성 측정, 크로마토그래피, 첨가제 분석 |
| 의료기기 | 클린뷰티 화장품 안정성 평가 실무 | 안정성 시험, GMP, 유효성 평가 |
| 공통 | 바이오화학 LCA 기본 실무 | 전과정평가, 탄소발자국 산정, 환경영향 분석 |

### 2.2 Module 2: AI 융합 교육체계 재설계 및 5개년 로드맵 고도화

> **핵심 질문: 기존 체계에 AI를 어디에, 어떤 수준으로, 어떤 순서로 이식할 것인가?**

#### Step 4. 기존 Skill × AI Skill 매핑 및 Gap 분석

Module 1에서 도출한 **기존 교육과정 Skill Matrix**와 **AI Skill Set**을 교차 매핑하여, **유지/보강/개편/신설** 대상을 구분합니다.

**[매핑 분석 프로세스]**

| 단계 | 수행 내용 | 판단 기준 |
|------|---------|---------|
| ① 매핑 | 기존 과정 Skill과 AI Skill 간 1:1 대응 여부 확인 | Skill 유사도, 직무 연관성 |
| ② Gap 식별 | AI Skill 중 기존 과정에서 미다루는 영역 식별 | 미대응 AI Skill 목록 |
| ③ 유형 분류 | 과정별 **유지/보강/개편/신설** 4가지로 분류 | 하단 기준표 참조 |
| ④ 우선순위 | 산업군별·수준별 우선 대응 과정 선정 | 기업 수요, 산업전환 단계 연계 |

**[과정별 대응 유형 분류 기준]**

| 유형 | 정의 | 예시 |
|------|------|------|
| **유지** | 기존 Skill만으로 충분, AI 보강 불필요 | 친환경 제도 이해 세미나 등 인사이트 과정 |
| **보강** | 기존 과정에 AI 모듈 1~2개 추가 | ESG 경영 데이터관리 + AI 자동화 모듈 추가 |
| **개편** | AI 중심으로 과정 구조 전면 재설계 | 바이오플라스틱 생산관리 → AI 스마트 생산관리 |
| **신설** | 기존 과정에 없는 AI 전용 과정 신규 개발 | AI 리터러시 세미나, AI 공정 최적화 실무 등 |

**[매핑 분석 결과표 예시]**

| 기존 교육과정 | 기존 핵심 Skill | 연계 가능 AI Skill | Gap 여부 | 대응 유형 |
|---------|---------|---------|------|------|
| 바이오플라스틱 제품 분석 실무 | 물성 측정, 크로마토그래피 | AI 물성 예측, 데이터 분석 | Gap 有 | **보강** |
| 바이오화학 LCA 기본 실무 | LCA, 탄소발자국 | AI LCA 자동화, 데이터 수집 | Gap 有 | **보강** |
| (미존재) | — | AI 리터러시, 프롬프트 엔지니어링 | 과정 부재 | **신설** |
| (미존재) | — | AI 공정 최적화, 디지털 트윈 | 과정 부재 | **신설** |

#### Step 5. 차세대 AI 반영 교육체계 개편안 도출

Step 4의 Gap 분석 결과를 기반으로, 기존 교육로드맵의 **수평 체계(산업군·교육분야)**와 **수직 체계(수준·교육유형)**를 AI 관점에서 고도화합니다.

**[수평 체계 고도화]**

| 구분 | 전년도(As-Is) | 금년도(To-Be) | 변경 사유 |
|------|---------|---------|---------|
| 산업군 | 4개 분야(분야명 내 혼재) | **산업군 × 직무군** 2축 체계 | AI는 산업뿐 아니라 직무별 적용 차이가 핵심 |
| 교육분야 | 3모듈(인사이트/실무공통/산업특화) | 3모듈 **유지** + 각 모듈에 **AI 레이어** 이식 | 기존 구조의 안정성 유지하면서 AI 확장 |

### 2.4 전문가 검토 및 유효성 확보

| 검증 단계 | 시기 | 검증 대상 | 검증 방법 | 참여 전문가 |
