# 03. 5개년 마스터플랜 (2026~2030)

> **핵심 질문**: 5년간 무엇을 쌓아가야 AI 융합 교육이 "작동"하는가?

---

## 1. 마스터플랜 프레임: 5 Layer × 3 Phase

### 1.1 왜 이 구조인가

"2026년에 과정 3개, 2027년에 5개" 식의 계획은 실행계획이지 마스터플랜이 아닙니다. AI 융합 교육이 실제로 "작동"하려면 **5개의 레이어가 모두 갖춰져야** 합니다. 하나라도 빠지면 교육이 돌아가지 않습니다.

### 1.2 5개 Layer

| Layer | 핵심 질문 | 없으면 어떻게 되는가 |
|-------|---------|---------|
| **L1. 진단·설계 기반** | 기업의 AI 준비도를 어떻게 측정하는가? 어떤 과정을 먼저 전환할지 어떻게 정하는가? | 감으로 과정 만들고, 기업 수요와 동떨어진 교육 |
| **L2. 콘텐츠·과정 체계** | 25개 기존 과정 중 어떤 순서로, 어떤 깊이로 AI를 결합하는가? | 일부 과정만 AI 옷을 입히고 나머지는 방치 |
| **L3. 교수·전달 체계** | AI 결합 과정을 가르칠 강사가 있는가? 교수법은? 실습 인프라는? | 커리큘럼은 있는데 가르칠 사람이 없음 |
| **L4. 기업 참여·연계** | 기업이 왜 이 교육을 보내야 하는가? 현장 데이터를 어떻게 활용하는가? | 과정은 좋은데 수강생이 안 옴 |
| **L5. 성과·환류** | 교육 효과를 어떻게 측정하는가? 결과를 다음 계획에 어떻게 반영하는가? | 해마다 같은 교육 반복, 개선 없음 |

### 1.3 3개 Phase + Gate 조건

| Phase | 기간 | 성격 | 비유 |
|-------|------|------|------|
| **Phase 1: 기반 구축** | 2026~2027 초 | 진단하고, 설계하고, 첫 전환을 시도한다 | 씨앗을 심고 토양을 만든다 |
| **Phase 2: 과정 전환** | 2027~2028 | 본격적으로 과정을 전환하고, 운영하고, 피드백한다 | 줄기가 자라고 열매가 맺힌다 |
| **Phase 3: 생태계 자립** | 2029~2030 | 별도 용역 없이 KTR이 자체적으로 AI 교육을 운영·개선한다 | 숲이 스스로 자란다 |

**Phase 간 이동은 자동이 아닙니다.** 이전 Phase의 핵심 조건이 충족되어야 다음으로 갑니다.

```
Phase 1 ──[Gate 1]──→ Phase 2 ──[Gate 2]──→ Phase 3

Gate 1 조건:
  ✓ AI Readiness 진단 도구 개발 + 50개사 이상 진단 실시
  ✓ Skill Gap 분석 완료 → 과정 전환 우선순위 확정
  ✓ 1차 AI 결합 과정 파일럿 운영 완료 + 피드백 반영
  ✓ 강사 공동강의 모델 1회 이상 검증

Gate 2 조건:
  ✓ AI 결합 과정 10개 이상 정규 운영 중
  ✓ AI 교육 수료 기업 50개사 이상
  ✓ 현업적용률 50% 이상 확인
  ✓ 성과 데이터 기반 과정 개선 1사이클 이상 완료
```

## 2. Phase × Layer 교차 상세

### Phase 1: 기반 구축 (2026~2027 초)

> **이 Phase의 목적**: "뭘 먼저 바꿀지 알고, 바꿀 준비가 된 상태"

| Layer | 과제 | 상세 | 완료 기준 |
|-------|------|------|---------|
| **L1 진단·설계** | AI Readiness 진단 도구 개발 | 기존 산업전환 진단지(5영역 35문항)에 AI 준비도 5영역 추가. 협약기업 진단 실시 | 50개사 이상 진단 완료 |
| | Skill Gap 분석 → 전환 우선순위 확정 | 기존 25개 과정의 Skill 분석 + AI Skill 매핑 → Gap 크기 × 기업 수요 매트릭스 | 전환 우선순위 1~4순위 확정 |
| **L2 콘텐츠** | 1순위 과정 AI 결합 파일럿 | Gap大 × 수요高 과정 3~5개를 선정, AI 모듈 설계 + 파일럿 운영 | 파일럿 3개 이상 운영 + 수정 |
| | AI 결합 교수설계 가이드라인 | 업스킬링/리스킬링 판단 기준, AI 모듈 삽입 방법론, 실습 설계 원칙 문서화 | 가이드라인 확정 |
| **L3 교수·전달** | 강사 AI 역량 강화 | 기존 강사 10명 대상 "AI 도구 활용 워크숍" + "공동강의 모델" 시범 | 강사 10명 AI 워크숍 이수 |
| | 실습 환경 점검 | 실습용 PC, 네트워크, AI 도구 라이선스, 클라우드 환경 필요량 산정 | 인프라 확보 계획 확정 |
| **L4 기업 연계** | AI 교육 필요성 인식 제고 | AI Readiness 진단 과정 자체가 "왜 AI 교육이 필요한가" 인식 계기. AI 적용 성공사례 세미나 | 세미나 2회 이상 |
| **L5 성과·환류** | 성과 측정 체계 설계 | 교육 만족도 + AI 역량 변화(사전-사후) + 현업적용도 측정 체계 설계 | 평가 도구 확정 + 기준선(Baseline) 확보 |

### Phase 2: 과정 전환 (2027~2028)

> **이 Phase의 목적**: "대부분의 과정에 AI가 결합되어 정규 운영되는 상태"

| Layer | 과제 | 상세 | 완료 기준 |
|-------|------|------|---------|
| **L1 진단·설계** | 학습경로 가이드 배포 | 진단 결과 기반 4유형 학습경로 → 기업별 추천 교육 안내 도구 제작 | 100개사 이상 배포 |
| | AI Readiness 중간진단 | 1차 진단 대비 변화 추적 | 70개사 이상 재진단 |
| **L2 콘텐츠** | 2~3순위 과정 순차 전환 | 업스킬링(AI 모듈 추가) / 리스킬링(과정 전면 개편) 실행 | AI 결합 과정 누적 15개 이상 |
| | 콘텐츠 갱신 체계 구축 | 산업 트렌드 변화 → 과정 내용 업데이트 프로세스 | 연 1회 갱신 프로세스 가동 |
| **L3 교수·전달** | 공동강의 본격 운영 | "산업전문가 + AI전문가" 공동강의 모델 정규화 | 공동강의 과정 비율 50% |
| | AI 실습 인프라 구축 | 클라우드 실습환경 + 산업별 샘플 데이터셋 + AI 도구 라이선스 확보 | 실습 환경 정규 운영 |
| **L4 기업 연계** | 기업 현장 데이터 활용 실습 | 협약기업이 자사 데이터를 익명화하여 교육 실습에 제공하는 모델 시범 | 1개 이상 과정에서 현장 데이터 실습 |
| | 교육 후 자사 적용 계획 의무화 | 모든 적용형/심화형 과정 마지막 세션에 "자사 적용 계획 수립" 포함 | 적용형 이상 전 과정 반영 |
| **L5 성과·환류** | 데이터 기반 과정 개선 | 만족도 + 현업적용도 분석 → 저성과 과정 원인 분석 → 콘텐츠/교수법 수정 | 개선 1사이클 완료 |

### Phase 3: 생태계 자립 (2029~2030)

> **이 Phase의 목적**: "별도 외부 용역 없이 KTR이 자체적으로 AI 교육을 기획·운영·개선하는 상태"

| Layer | 과제 | 상세 | 완료 기준 |
|-------|------|------|---------|
| **L1 진단·설계** | 풀사이클 확립 | 진단 → 교육 추천 → 이수 → 재진단 → 경로 조정 자동화 | 풀사이클 정규 운영 |
| | 2028 로드맵 전면 검토 결과 반영 | 산업 변화 + 교육 성과 데이터 반영 → 후반기 과정 포트폴리오 조정 | 로드맵 v2.0 확정 |
| **L2 콘텐츠** | 전 과정 AI 결합 완료 | 유지 대상 제외 전 과정에 AI 요소 통합 | AI 결합 과정 20개+ |
| | 산업 간 AI 교류 과정 | 플라스틱↔화장품↔의료기기 크로스 산업 AI 사례 공유 과정 | 교류 과정 1~2개 |
| **L3 교수·전달** | 강사 자립 운영 | 기존 강사가 AI 모듈을 독립적으로 강의 가능 (공동강의 의존도 탈피) | 자립 강의 비율 70% |
| | 블렌디드 러닝 정착 | Lv.1 온라인 선수학습 + Lv.2~3 오프라인 실습 혼합 모델 | 온라인 비율 30~40% |
| **L4 기업 연계** | 기업-교육기관 공동 AI 교육 모델 | 협약기업이 교육 콘텐츠 공동 개발에 참여. AI 성공사례 발표 | 공동 개발 1회+ |
| | 협약기업 AI 성공사례 확산 | 교육 이수 → 현업 적용 → 성과 달성 기업의 사례 수집·공유 | 사례집 발간 |
| **L5 성과·환류** | 5개년 성과 종합 평가 | AI 교육 ROI 분석. 협약기업 AI Readiness 변화 종합 추적 | 5개년 성과보고서 |
| | 차기 로드맵 설계 근거 마련 | 성과 데이터 → 2031~2035 교육 방향 기초 자료 | 차기 계획 기초 데이터 확보 |

## 4. 로드맵 중간점검 (2028년)

2028년은 **전면 검토의 해**입니다. 이 시점에서:

1. **산업 환경 변화 반영**: 2026~2027 사이 AI 기술 트렌드가 급변했을 가능성. 과정 내용 갱신 필요성 판단
2. **AI Readiness 재진단**: 182개 기업의 AI 준비도가 2년간 어떻게 변했는지 추적
3. **교육 성과 데이터 분석**: 어떤 과정이 효과적이었고, 어떤 과정이 저성과였는지 데이터 기반 분석
4. **후반기(2029~2030) 과정 포트폴리오 조정**: 데이터 기반으로 신규 개발/폐지/개편 결정

> 이것이 마스터플랜이 "계획서"가 아니라 **"살아있는 시스템"**이 되는 핵심 장치
