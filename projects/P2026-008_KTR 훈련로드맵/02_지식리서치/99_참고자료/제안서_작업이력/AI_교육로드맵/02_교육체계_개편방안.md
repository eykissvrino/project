# 02. 교육체계 개편방안

> **핵심 질문**: 기존 3모듈×3수준 교육체계에 AI를 어떻게 이식하는가?

---

## 1. 개편 원칙

| 원칙 | 내용 | 근거 |
|------|------|------|
| **기존 구조 위에 이식** | 3모듈×3수준 유지. AI를 별도 체계로 만들지 않음 | 전년도 KTR 합의 체계 안정성 + 강사·운영 인프라 호환 |
| **AI는 별도 과목이 아니라 기존 Skill에 결합** | 기존 과정의 바이오화학 Skill + AI Skill(R1~R4) = 업스킬링된 과정 | 58.6%가 전담인력 미구성 → AI만 따로 배울 여력 없음 |
| **산업전환이 주축, AI는 레이어** | 센터 정체성 = 산업전환. AI는 전환을 가속하는 도구 | 산업전환 공동훈련센터의 설립 목적 |

---

## 2. 수평 체계: 3모듈 유지

전년도 수립한 모듈 구조를 그대로 유지합니다.

| 모듈 | 교육 분야 | 대상 | AI 이식 방향 | 주요 역량 영역 |
|------|---------|------|---------|---------|
| **모듈1 (인사이트)** | 친환경 바이오화학 산업 동향 | 전 직급 | 산업 동향에 AI 동향을 통합 | **R1** (AI 리터러시) |
| **모듈2 (실무공통)** | 환경경영(탄소관리, LCA) / ESG 경영 | 전 직군 | 실무 과정에 AI 도구 활용 모듈 삽입 | **R2** (데이터) + **R3** (도구) |
| **모듈3 (산업특화)** | 바이오플라스틱R&D·생산 / 재활용 / 의료기기 / 화장품 / 정밀화학 | 산업별 직무 | 직무별 AI 적용 실무 결합 | **R3** (도구) + **R4** (혁신) |

### 수평 체계에서 달라지는 점

| As-Is | To-Be | 변경 사유 |
|-------|-------|---------|
| 산업군 단일축 분류 | **산업군 × 직무군** 2축 체계 | AI는 같은 산업이라도 직무(R&D vs 생산 vs 규제)별 적용이 완전히 다름 |
| 모듈3 내 분류 기준 불일치 (투입물 vs 산출물) | **산출물 기준**으로 통일 | 전년도 시사점 반영 (SQF 산업분류 체계 기준) |

---

## 3. 수직 체계: 산업전환 단계 + AI 레이어

### 3.1 수직축 구조

```
정착 단계 ─────── 기존 Skill(전략·고도화) + AI 혁신 (Transformation)
   │                "AI로 업무 방식 자체를 설계·변경한다"
   │
전환 단계 ─────── 기존 Skill(직무 실무) + AI 적용 (Application)  ← ★ 핵심 타겟 (81.4%)
   │                "AI 도구로 이 업무를 실제로 수행한다"
   │
선제대응 단계 ──── 기존 Skill(기초 이해) + AI 인식 (Awareness)
                     "AI가 뭔지, 내 업무 어디에 쓰일지 안다"
```

### 3.2 교육유형 재정의

| 교육유형 | 정의 | 산업전환 단계 | 실습 비중 | 시간 규모 |
|--------|------|---------|---------|---------|
| **인식형** | 개념 이해 + AI 체험 | 선제대응 | 20% | 4~8H |
| **적용형** | AI 도구 실습 + 직무 적용 | 전환 | **40% 이상** | 8~16H |
| **심화형** | AI 시스템 구축 + 전략 설계 | 정착 | **50% 이상** | 16~32H |

### 3.3 수직 체계에서 달라지는 점

| As-Is | To-Be | 변경 사유 |
|-------|-------|---------|
| 수준 정의 미흡 (입문/중급/고급 → 기준 모호) | 산업전환 단계별 **행동지표 기반** 수준 판정 | "이 수준에서 무엇을 할 수 있어야 하는가" 명확화 |
| 교육유형 정의 부재 (세미나/일반/전문) | **인식형/적용형/심화형** 3유형 + 실습 비중 기준 | AI 교육은 실습 없이 성립 불가 → 유형별 실습 최소 기준 설정 |
| AI 수준이 별도 축 | 산업전환 단계에 **AI가 자연 연동** | AI를 분리하면 "AI 따로, 산업 따로" 교육이 됨 |

## 4. 수평×수직 교차: 전체 교육체계 지도

```
                          수평: 산업분야(모듈)
                  ┌────────────────────────────────────────────┐
                  │ 모듈1          모듈2            모듈3        │
                  │ 인사이트       실무공통          산업특화      │
수                │ (산업동향)     (환경경영/ESG)   (PL/화장품    │
직                │                                /의료기기)    │
:                 ├────────────────────────────────────────────┤
산   정착 ────────│ 산업전략       환경경영전략      직무고도화    │
업   (혁신)       │ + R4 혁신     + R4 전략수립    + R4 설계     │
전   Lv3          │   전환주도      모델구축참여      프로세스혁신  │
환                ├────────────────────────────────────────────┤
단   전환 ────────│ 산업심화       환경경영실무      직무실무      │
계   (적용)       │ + R1 인식     + R2 데이터      + R3 도구     │
     ★81.4%      │   R3 생성AI    R3 도구적용      R3 직무AI    │
     Lv2          ├────────────────────────────────────────────┤
     선제대응 ────│ 산업기초       환경경영기초      직무기초      │
     (인식)       │ + R1 리터러시 + R1 체험        + R1 인식     │
     Lv1          │   개념이해      데이터기초        사례이해      │
                  └────────────────────────────────────────────┘
```

**각 칸 안의 과정**: `기존 바이오화학 Skill` + `해당 수준의 AI Skill` = **업스킬링/리스킬링된 과정**

## 5. 학습경로: 기업 유형별 진입점 자동 매핑

### 5.1 매핑 로직

```
입력: 기업 산업전환 진단 결과 + 수강자 직무 + 경력단계
     ↓
처리: 산업전환 단계 → 수직축 진입점 결정
      직무군 → 수평축 모듈3 내 분야 결정
      경력단계 → 학습 깊이(인식/적용/심화) 조정
     ↓
출력: 추천 학습경로 (과정 순서 + 예상 총 시간)
```

### 5.2 학습경로 유형

| 유형 | 대상 | 경로 | 총 시간 |
|------|------|------|--------|
| **경로 A: 기초 진입** | 선제대응 기업, 신입 | AI 인식 과정(모듈1) → 기초 실무+AI 체험(모듈2) → 수준 재진단 | 16~24H |
| **경로 B: 실무 직행** | 전환 기업, 중급 R&D/기획 | [AI 인식 미이수 시만] → 산업특화+AI 적용(모듈3) | 8~16H |
| **경로 C: 데이터→공정** | 전환 기업, 중급 생산/품질 | AI 데이터 기초(모듈2) → 산업특화+AI 공정(모듈3) | 16~24H |
| **경로 D: 전략·고도화** | 정착 기업, 고급/전문가 | AI 전략 과정 → 산업특화 AI 심화(모듈3) | 16~32H |

> **활용**: "학습경로 가이드"를 산출물로 제작 → KTR 교육담당자가 협약기업에 교육 안내 시 즉시 활용

## 6. 개편 전후 비교 요약

| 구분 | As-Is (전년도) | To-Be (금년도) |
|------|------------|-----------|
| AI 과정 | 0개 | 기존 과정 전체가 AI 결합형으로 전환 (단계적) |
| 수직축 | 산업전환 3단계 (정의 미흡) | 산업전환 3단계 + **AI 레이어 자연 연동** + 행동지표 |
| 수평축 | 산업군 단일축 | **산업군 × 직무군** 2축 |
| 교육유형 | 미정의 | **인식형/적용형/심화형** (실습 비중 기준) |
| 학습경로 | 불명확 | **4유형 맞춤 경로** + 진단 기반 자동 매핑 |
| 과정 설계 | 바이오화학 Skill Only | **기존 Skill + AI Skill 결합** (업스킬링/리스킬링) |
