# 04. 과정전환 우선순위 및 설계

> **핵심 질문**: 25개 기존 과정을 어떤 순서로, 어떤 방식으로 AI와 결합하는가?

---

## 1. 과정 전환의 기본 원칙

**AI 과정을 "새로 만드는" 것이 아니라, 기존 과정의 바이오화학 Skill에 AI Skill을 "결합"합니다.**

| 원칙 | 설명 |
|------|------|
| 기존 Skill 유지 | 바이오화학 직무역량은 그대로 유지. AI가 이를 대체하는 것이 아님 |
| AI는 업무를 더 잘하게 하는 도구 | "AI로 뭘 만든다"가 아니라 "기존 업무에 AI를 얹어 생산성을 높인다" |
| 전부 동시에 바꾸지 않는다 | 우선순위에 따라 순차적으로 전환. 무리한 일괄 전환은 품질 저하 |

---

## 2. 전환 유형: 4가지 판정

25개 과정 각각에 대해 다음 4가지 중 하나로 판정합니다.

| 유형 | 정의 | AI 결합 방식 | 변경 범위 | 강사 변화 |
|------|------|---------|---------|---------|
| **유지** | AI 적용 영역이 없거나 매우 제한적 | 변경 없음 (D1 인식 수준 언급만) | 없음 | 기존 강사 유지 |
| **업스킬링 (보강)** | 기존 Skill 구조 유지 + AI 모듈 1~2개 삽입 | 기존 교시 중 1~2개를 AI 도구 실습으로 교체/추가 | 교시 수준 | 기존 강사 + AI 전문가 공동강의 |
| **리스킬링 (개편)** | AI가 업무 방식 자체를 바꾸므로 과정 전면 재설계 | 과정명·목표·교과목 구조 AI 중심으로 재편 | 과정 전체 | AI 중심 신규 교수설계 필요 |
| **신설** | 기존 과정에 대응 과정이 없는 AI 영역 | 완전히 새로운 과정 개발 | 신규 | 신규 강사 확보 필요 |

## 3. 전환 우선순위 판정 기준

### 3.1 우선순위 매트릭스

```
                         AI 적용 가능성 高
                              │
           ┌─────────────────┼─────────────────┐
           │  2순위           │  ★ 1순위        │
           │  AI 적용은       │         │
           │  가능하지만       │  AI 적용도        │
기업       │  기업 수요가      │  명확하고         │
수요 低    │  아직 약함        │  기업 수요도 높음   │  기업 수요 高
           ├─────────────────┼─────────────────┤
           │  4순위 (유지)    │  3순위           │
           │  당장은           │  수요는 있으나     │
           │  안 건드림        │  AI 접점이 약함    │
           └─────────────────┼─────────────────┘
                              │
                         AI 적용 가능성 低
```

### 3.2 판정 투입 데이터

| 판정 요소 | 데이터 출처 | 측정 방법 |
|---------|---------|---------|
| **AI 적용 가능성** | 01_프레임워크의 73개 스킬(R1~R4) 매핑 | 해당 과정의 기존 Skill에 매핑되는 AI Skill(R1~R4) 수 |
| **기업 수요** | 전년도 산업전환 진단 + AI Readiness 진단 | 진단 응답 기업 중 해당 산업군·직무 기업 비율 |
| **강사 확보 가능성** | 강사 Pool 현황 | 해당 분야 AI 교육 가능 강사 유무 |
| **실습 인프라 요건** | 과정별 AI 도구 필요 목록 | PC/클라우드/라이선스 필요량 |

## 4. 업스킬링 vs 리스킬링 판단 기준

| | 업스킬링 (AI 모듈 추가) | 리스킬링 (과정 전면 개편) |
|---|---|---|
| **판단 기준** | AI가 기존 업무를 **보조**하는 수준. 기존 과정 구조 유지 가능 | AI가 업무 방식 **자체를 변경**. 기존 구조로는 담을 수 없음 |
| **변경 범위** | 교시 1~2개 교체/추가. 총 시간 0~2H 증가 | 과정명·교육목표·교과목 전체 재구성 |
| **판단 질문** | "기존 교과목에 AI 실습을 끼워 넣을 수 있는가?" → Yes | "기존 교과목 순서와 비중이 AI 때문에 근본적으로 달라져야 하는가?" → Yes |
| **예시** | LCA 실무 과정에 "AI LCA 자동화" 교시 1개 삽입 | "스마트 생산관리" → "AI 기반 스마트 생산관리"로 전면 재설계 |
| **강사** | 기존 강사 + AI 전문가 공동강의 | AI 중심 신규 교수설계 + 강사 재교육 |

## 6. AI 모듈 삽입 설계 원칙 (업스킬링 시)

### 6.1 삽입 위치

```
[기존 교시 1] 이론/개념
[기존 교시 2] 실무/실습
         ↓
[★ AI 모듈] AI 도구 체험 또는 AI 실습  ← 기존 실무와 직접 연결되는 위치에 삽입
         ↓
[기존 교시 3] 종합/토론 + "AI 적용 가능성 토론" 추가
```

### 6.2 AI 모듈 구성 템플릿

| 요소 | 내용 | 시간 |
|------|------|------|
| **도입** | "방금 배운 이 업무에서 AI는 어떻게 쓰이고 있는가" — 산업 사례 소개 | 15분 |
| **체험/실습** | 실제 AI 도구 데모 또는 핸즈온 실습 | 45~90분 |
| **토론** | "우리 회사에서는 이걸 어떻게 쓸 수 있을까" | 15~30분 |

### 6.3 실습 설계 수준별 차이

| 산업전환 단계 | AI 실습 수준 | 주요 역량 | 예시 |
|---|---|---|---|
| 선제대응 (인식) Lv1 | **데모 관람 + 간단 체험** | R1 리터러시 | "AI가 이 데이터를 분석하면 이런 결과가 나옵니다" → 결과 해석 연습 |
| 전환 (적용) Lv2 | **핸즈온 실습** (데이터 입력 → AI 도구 실행 → 결과 해석) | R2 데이터 + R3 도구 | 샘플 데이터로 AI 도구를 직접 실행하고 결과를 해석하여 판단 |
| 정착 (혁신) Lv3 | **프로젝트형** (자사 데이터 → AI 분석 → 적용 계획 수립) | R3 도구 + R4 혁신 | 자사 공정 데이터로 AI 모델 구축하고 적용 타당성 분석 |

## 7. 전환 일정 (마스터플랜 Phase와 연동)

| Phase | 전환 대상 | 과정 수 | 기준 |
|-------|---------|--------|------|
| **Phase 1** (2026~27초) | 1순위: Gap大 × 수요高 | 3~5개 파일럿 | LCA, ESG, 스마트생산관리 등 |
| **Phase 2** (2027~28) | 2~3순위: 순차 전환 | 10~12개 추가 | 산업특화 과정 중심 |
| **Phase 3** (2029~30) | 잔여 + 신규 | 나머지 + 신산업 | 유지→업스킬링 전환 재판정 포함 |
