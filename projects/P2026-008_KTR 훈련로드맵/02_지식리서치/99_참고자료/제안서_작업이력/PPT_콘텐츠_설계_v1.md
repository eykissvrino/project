## S05. 과제 1 상세 — AI가 빠진 교육체계

**레이아웃**: 좌측 핵심 숫자 강조 + 우측 설명

**제목**: 과제 1: 교육체계는 갖췄으나, AI가 빠져 있다

| 핵심 데이터 | 값 |
|---------|-----|
| 2026년 운영 훈련과정 | 25개 |
| 그 중 AI 관련 과정 | **0개** |

**설명**:
- 전년도에 수립한 新 교육로드맵(3모듈×3수준)은 바이오화학 산업전환에 특화된 체계
- 그러나 AI 교육과정은 단 하나도 반영되지 않음
- KTR 사업계획서(A권)에 "AI 교육과정 반영 교육로드맵 체계구축"을 금년도 핵심 과업으로 명시
- 기존 교육체계는 친환경·ESG·산업규제 중심 → AI 기술의 직무 변화 대응이 전무

**시사점**: AI를 별도 과정으로 신설하는 것이 아니라, 기존 교육체계 위에 AI를 체계적으로 이식해야 함

## S06. 과제 2 상세 — 182개 협약기업 진단 결과

**레이아웃**: 상단 핵심 숫자 4개 카드 + 하단 막대 차트(전환단계 비율)

**제목**: 과제 2: 182개 협약기업 산업전환 수준 진단 결과

| 지표 | 수치 | 의미 |
|------|------|------|
| 변화 영향 인식 | **97.1%** | 거의 모든 기업이 산업환경 변화를 체감 |
| 전담인력 미구성 | **58.6%** | 변화는 인지하지만 대응 체계 부재 |
| 전환단계 비율 | **81.4%** | 대다수가 전환 진행 중이나 미완료 |
| 선제대응단계 | **14.3%** | AI 리터러시부터 시작해야 하는 기업군 |

**시사점**:
- 81.4%가 전환단계 = **AI 교육의 적기(適期)**
- 그러나 58.6%가 전담인력 미구성 → "AI 전문가 양성"이 아닌 **"현장 실무자의 AI 활용"**이 핵심
- 이 데이터는 전년도 시앤피컨설팅이 직접 수집한 1차 데이터

## S07. 과제 3 상세 — 산업군별 AI 적용 차이

**레이아웃**: 4칼럼 카드 (산업군별)

**제목**: 과제 3: 산업군마다 AI가 바꾸는 업무가 전혀 다르다
**서브**: "바이오화학에 AI를 도입한다"는 추상적 목표가 아니라, 산업군×직무별 구체적 매핑이 필요합니다.

| 산업군 | 비중 | AI가 바꾸는 업무 |
|------|------|--------------|
| 플라스틱 | 13.7% | 배합 최적화, 불량 예측, 물성 시뮬레이션 |
| 화장품 | 18.7% | 제형 안정성 예측, 소비자 트렌드 분석 |
| 의료기기 | 8.3% | 규제문서 자동화, 사이버보안 위협 모델링 |
| 정밀화학 | — | 위험성 평가, 공정 이상징후 탐지 |

**하단 강조**: 이 수준의 구체적 매핑은 **전년도 182개 기업 전수분석 + 3대 산업군 환경분석 데이터 없이는 불가능한 작업**

## S08. 과업 범위 — 3대 과업의 인과 체인

**레이아웃**: 세로 흐름도 (3단계, 화살표 연결)

**제목**: 과업 범위: 3대 과업의 인과 체인
**서브**: 3대 과업은 단순 병렬이 아닌, 각 과업의 결과가 다음 과업의 판단 근거가 되는 인과 구조입니다.

```
┌──────────────────────────────────────────────────────┐
│ [과업 1] 교육체계 분석 + AI 역량 모델링                  │
│ 핵심 질문: 현재 체계의 Skill과 AI Skill의 Gap은?         │
│ 산출물: Skill Matrix, AI Skill Taxonomy, Gap 분석표      │
└───────────────────────┬──────────────────────────────┘
                        ↓ Gap 발견 = 판단의 근거 확보
┌──────────────────────────────────────────────────────┐
│ [과업 2] AI 교육로드맵 재수립                             │
│ 핵심 질문: Gap을 어디에, 어떤 수준으로, 어떤 순서로 메울까?│
│ 산출물: 교육체계 개편안, 5개년 마스터플랜, 학습경로 가이드   │
└───────────────────────┬──────────────────────────────┘
                        ↓ 체계 확정 = 설계도 완성
┌──────────────────────────────────────────────────────┐
│ [과업 3] AI 교육과정 개발 + 커리큘럼                      │
│ 핵심 질문: 실제 교육과정을 어떻게 바꾸고, 무엇을 새로 만들까?│
│ 산출물: 재설계안, 신규 과정 기획안, 상세 커리큘럼            │
└──────────────────────────────────────────────────────┘
```

## S09. 추진 전략 — Skill-Gap 기반 AI 이식 3대 원칙

| 원칙 | 내용 | 근거(데이터) | 왜 우리만 가능한가 |
|------|------|---------|--------------|

## S14. 수행 프레임워크 전체 구조

**레이아웃**: 3칼럼 (Phase 1 / 2 / 3), 각 칼럼 내 Steps + 핵심 의사결정

**제목**: 과업 수행체계: 3 Phase × 핵심 의사결정
**서브**: 각 Phase마다 핵심 의사결정을 명시하고, 그 판단의 근거와 결과가 다음 Phase를 결정합니다.

| | Phase 1. Discover | Phase 2. Design | Phase 3. Develop |

## S17. Phase 1 상세 — Gap 분석 + 우선순위 매트릭스

**과정별 대응 유형 4가지:**

| 유형 | 판정 기준 | 대응 방향 |
|------|---------|---------|
| 유지 | 기존 Skill만으로 충분, AI 적용 영역 없음 | 현행 유지 |
| 보강 | 기존 과정에 AI 모듈 1~2개 추가로 충분 | AI 실습 모듈 추가 |
| 개편 | AI 중심으로 과정 구조 전면 재설계 필요 | 과정명·목표·교과목 재구성 |
| 신설 | 기존 과정에 없는 AI 전용 영역 | 신규 과정 개발 |

**우선순위 판정 매트릭스:**

```
              AI Skill Gap
              小 ─────── 大
  기업수요 高 │ 보강      │ ★ 최우선 개편/신설 (2026년 착수)
             │ (빠른 적용)│
  ───────────┼──────────┼──────────────────
  기업수요 低 │ 유지      │ 개편/신설 (2027~28년 순차)
```

→ 이 판정 로직이 "체계적으로 판단하겠구나" 인상의 핵심
