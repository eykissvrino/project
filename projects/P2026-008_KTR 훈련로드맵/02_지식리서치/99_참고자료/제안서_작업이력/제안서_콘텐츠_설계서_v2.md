**범위**: Ⅱ장 제안개요 + Ⅲ장 과업수행계획 (평가 45점 영역)

## Part 1. 기존 제안서 진단 — 왜 별로인가

### 문제 ① 내용이 뻔하다

| 현재 제안서가 쓰는 말 | 왜 뻔한가 |
|---|---|
| "ADDIE 모형 + Design Thinking 융합" | 교육과정 개발 제안서면 누구나 쓰는 말 |
| "NCS/SQF 기반 AI 역량 프레임워크" | 프레임워크 이름만 있고, 실제로 뭘 어떻게 하겠다는 건지 안 보임 |
| "커크패트릭 4수준 평가모형" | 교과서 인용 수준. KTR에 어떻게 맞출 건지 없음 |
| "AI 기반 소재 물성 예측, 공정 시뮬레이션" | AI 과정 이름만 있지, 바이오화학 현장에서 실제로 어떤 문제를 푸는 건지 안 보임 |
| "학습비용 Zero, 즉시 실행 가능" | 연속 수행 강점을 이 한 줄로만 소비하고 끝 |

**핵심 진단**: 방법론 이름은 많은데 **"그래서 KTR한테 뭐가 다른데?"**에 대한 답이 없다.

### 문제 ② 구조/흐름이 부자연스럽다

**현재 흐름**:
```
Ⅱ장: 사업목표 → 필요성 → 과업범위 → 제안특징(연속수행) → 기대효과
Ⅲ장: 3Module × 9Step → (Step1~9 순서대로 나열) → 산출물 → 인력 → 일정
```

**문제**:
- Ⅱ장에서 "제안특징과 장점"을 먼저 말하는데, 아직 뭘 하겠다는 건지 안 보여준 상태에서 장점을 나열 → 설득력 없음
- Ⅲ장 9 Step이 일렬로 나열되어 있어서, 평가위원이 "이 사람들이 큰 그림을 보고 있나?"를 판단하기 어려움
- Module 간 "왜 이 순서인가"의 논리가 약함 (분석→설계→개발이면 그냥 ADDIE 아닌가?)

### 문제 ③ KTR의 진짜 고민을 안 건드린다

과업지시서 원문:
> "AX(AI 전환) 대응력을 극대화할 수 있는 **차세대 산업전환 교육 표준 모델**을 구축"

이건 단순히 "AI 과목 추가"가 아니라, **교육체계 자체의 패러다임 전환**을 요구하는 것.  
현재 제안서는 이걸 "기존 로드맵에 AI 레이어 추가"로만 접근 → 과업지시서의 야심 수준에 못 미침

## Part 2. 새 콘텐츠 전략

### 전략 1: "KTR의 진짜 문제"에서 출발하라

현재 KTR의 진짜 상황:
- 182개 협약기업 중 **81.4%가 전환단계** (= AI 이전에 산업전환 자체가 진행 중)
- 산업환경 변화 전담인력 미구성 **58.6%** (= 교육 받을 사람이 "AI 전문가"가 아닌 현장 실무자)
- 그런데 과업지시서는 **"AI 교육과정 개발"**을 요구 → 현장 수준과 요구사항 사이의 간극 존재

→ 제안서의 출발점: "182개 기업의 실제 데이터를 직접 수집·분석한 우리만이 답할 수 있는 질문: **바이오화학 현장에서 AI가 실제로 쓰일 수 있는 지점은 어디인가?**"

### 전략 2: "방법론 이름"이 아니라 "의사결정 논리"를 보여줘라

**뻔한 제안서**: "ADDIE 모형을 적용하여 분석→설계→개발을 수행합니다"

**설득력 있는 제안서**: "기존 25개 교육과정이 다루는 Skill과, 산업현장이 요구하는 AI Skill 사이의 Gap을 정량적으로 측정합니다. 이 Gap의 크기와 긴급성에 따라 각 과정을 유지/보강/개편/신설로 분류하고, 한정된 자원(연 25개 과정, 강사 10명)으로 최대 효과를 내는 우선순위를 결정합니다."

→ 방법론 이름이 아니라, **"어떤 판단을 어떤 기준으로 내리겠다"**는 의사결정 로직

### 전략 3: "연속 수행"을 장점 나열이 아니라 "수행방법의 근거"로 쓰라

현재: "전년도에 했으니까 학습비용 Zero" (장점 한 줄로 소비)

새 접근: **연속 수행 데이터가 금년도 과업의 모든 판단 근거가 됨**
- 182개 기업 DB → AI 역량 진단 설계의 기초
- 산업전환 진단 결과(Lv1/2/3 분포) → AI 교육 수준별 대상자 규모 추정 근거
- 3대 산업군 STEP 분석 → AI 적용 가능 영역 도출의 출발점
- 기존 25개 과정 분석 데이터 → AI Skill Gap 분석의 비교 기준(Baseline)
- 강사 10명 + FGI 전문가 8명 → 즉시 검증 가능한 전문가 네트워크

→ "연속 수행"이 **수행방법 자체의 구조적 근거**가 되는 설계

### 전략 4: 과업지시서 핵심 키워드를 구조에 녹여라

| 과업지시서 원문 | 핵심 키워드 | 제안서에서 어떻게 대응할 것인가 |
|---|---|---|
| "AI 도입이 시급한 **우선순위를 선정**" | 우선순위 판단 기준 | Gap 크기 × 기업 수요 × 실현가능성 매트릭스로 보여줌 |
| "직무별로 요구되는 AI **핵심 역량과 스킬셋**" | 역량 모델링 | 범용 AI 역량이 아닌 바이오화학 특화 Skill Taxonomy |
| "**KTR만의 차별화된** 5개년도 로드맵" | KTR 특화 | 기업 유형별 맞춤 학습경로 설계 |
| "**차세대 산업전환 교육 표준 모델** 구축" | 표준 모델 | 단순 과정 나열이 아닌, 재사용 가능한 교육체계 모델 |

## Part 3. 새 제안서 콘텐츠 설계

### ■ Ⅱ장. 제안개요 (과업이해도 10점 + 결과물 구체성 10점)

#### 2.1 과업의 본질 — "AI를 얹는 것"이 아니라 "교육체계를 전환하는 것"

**서술 전략**: 과업을 재정의하여 평가위원에게 "이 업체는 과업을 깊이 이해하고 있다" 인상

> 본 과업은 기존 교육과정에 AI 모듈을 추가하는 단순 확장이 아닙니다.  
> **바이오화학 산업의 직무 구조 자체가 AI로 인해 변하고 있는 현실**을 교육체계에 반영하는 것입니다.

3가지 차원의 전환을 제시:

| 차원 | 기존 체계 (As-Is) | 전환 방향 (To-Be) |
|---|---|---|
| **교육 대상** | "산업전환 대응 인력" | "AI 활용 산업전환 주도 인력" |
| **교육 내용** | 직무별 전문지식 | 직무 전문성 + AI 도구 활용의 융합 |
| **교육 체계** | 3모듈 분리형 | 모든 모듈에 AI가 관통하는 통합형 |

**전년도 데이터로 근거 제시**:
- 97.1%가 산업환경 변화 영향 인식 / 전담인력 미구성 58.6%
  → "AI를 알아야 한다"가 아니라 "**AI로 지금 하는 일을 더 잘 해야 한다**"는 현장 수요
- 따라서 AI 교육 = 별도 과정 신설보다, **기존 직무교육에 AI를 녹이는 것**이 핵심

#### 2.2 과업 범위 — 3대 과업의 논리 체인

과업지시서 3대 과업을 "단순 나열"이 아니라 **"질문 → 답 → 실행"의 연쇄**로 보여줄 것:

```
[과업 1] 현재 무엇을 가르치고 있고, AI로 뭘 더 가르쳐야 하는가?
     ↓ (Gap 발견 = 판단의 근거 확보)
[과업 2] 그 Gap을 메우려면 교육체계를 어떻게 바꾸고, 5년간 어떻게 실행할 것인가?
     ↓ (체계 확정 = 설계도 완성)
[과업 3] 설계도 위에서, 실제 교육과정을 어떻게 만들 것인가?
```

→ 단순 "분석→설계→개발"이 아니라, **각 과업의 결과가 다음 과업의 판단 근거가 되는 인과 구조**

#### 2.3 추진 전략 — Skill-Gap 기반 AI 이식 전략 (★ 15점 핵심)

**전략 한 줄**: "기존 교육과정의 Skill 지도 위에, 바이오화학 산업의 AI Skill을 정확히 매핑하여 Gap을 메운다"

**3대 원칙**:

| 원칙 | 내용 | 근거 | 경쟁사가 못 하는 이유 |
|---|---|---|---|
| **① AI를 별도로 가르치지 않는다** | 기존 직무 Skill에 AI를 얹는다 | 58.6%가 전담인력 없음 → AI만 따로 배울 여력 없음 | 현장 데이터 없이는 "어디에 얹을지" 판단 불가 |
| **② 현장 데이터로 판단한다** | 모든 의사결정에 전년도 1차 데이터 활용 | 182개 기업 전수분석 + 70개사 진단 + FGI 결과 보유 | 신규 업체는 이 데이터를 처음부터 수집해야 함 |
| **③ 우선순위를 정해서 집중한다** | 25개 과정 전부가 아닌, Gap 크기 × 수요 기준 우선 대응 | 한정된 자원(예산 3천, 기간 8개월) | 전년도 교육 운영 데이터가 있어야 우선순위 판정 가능 |

#### 2.4 연속 수행의 전략적 의미

"학습비용 Zero" 대신 → **"전년도 자산이 금년도 모든 판단의 근거"**:

| 전년도 축적 자산 | 금년도 활용 방식 | 이 자산 없으면? |
|---|---|---|
| 182개 기업 기초정보 DB | AI 역량 진단 시 기업별 맞춤 설문 설계 | 기업 조사부터 시작 (약 2개월) |
| 산업전환 진단지 + 70개사 결과 | AI Readiness 모듈만 추가 | 진단도구 전체 신규 개발 |
| 3대 산업군 STEP 분석 | AI 적용 가능 영역 도출의 출발점 | 산업환경분석부터 시작 (약 1.5개월) |
| 25개 과정 상세분석 데이터 | Skill Matrix 구축의 기초 | 교육과정 분석부터 시작 (약 1개월) |
| 新 교육로드맵 3모듈×3수준 | 기존 구조 위에 AI를 이식 | 로드맵 구조 이해부터 시작 |
| 전문가 22명 네트워크 | 착수 즉시 검증·자문 투입 | 전문가 섭외부터 시작 (약 2주) |

→ **"다른 업체가 0에서 시작할 때, 우리는 이미 70%가 완성된 지점에서 출발한다"**

#### 2.5 핵심 산출물과 활용 시나리오

| 산출물 | KTR이 이걸로 뭘 할 수 있는가 |
|---|---|
| **바이오화학 AI Skill Taxonomy** | 향후 신규 과정 기획 시, "어떤 AI Skill이 필요한가"의 기준표 |
| **기존 과정 × AI Skill Gap 분석표** | 25개 과정의 AI 보강/개편/신설 판단 근거 → 연간 교육계획 수립 근거 |
| **AI 반영 5개년 교육 마스터플랜** | 사업계획서에 직접 반영 가능 → 매년 별도 용역 없이 연간 계획 수립 |
| **기업 유형별 AI 학습경로 가이드** | 협약기업이 "우리 회사는 어디서부터?" 질문에 즉시 답변 가능 |
| **상세 커리큘럼 2개 이상** | 강사 섭외·교재 개발에 즉시 착수 가능한 수준 |

### ■ Ⅲ장. 과업수행 계획 (추진전략 우수성 + 수행방법 합리성 = 25점)

#### 3.1 수행 프레임워크 — 3 Phase × 핵심 의사결정

**기존**: 3 Module × 9 Step 순차 나열  
**새 구조**: 3 Phase, 각 Phase마다 **"핵심 의사결정"** 명시

```
═══════════════════════════════════════════════════════════
 Phase 1. Discover                    [5월~7월, 3개월]
 "현재 교육체계의 Skill과 AI Skill의 Gap은 어디인가?"
═══════════════════════════════════════════════════════════

 ┌─ Step 1. 기존 교육체계 Skill 해부
 │    투입: 25개 교육과정 커리큘럼, 수료율·만족도 데이터
 │    방법: 과정별 교과목 분석 → 핵심 Skill(K/S/A) 추출 → Matrix 구축
 │    산출: [산업군 × 교육과정 × Skill] 3차원 매트릭스
 │
 ├─ Step 2. 바이오화학 AI Skill Taxonomy 수립
 │    투입: AI 산업적용 문헌, SQF 직무체계, 전년도 산업분석 결과
 │    방법: 문헌연구 → 산업군별 AI 적용영역 도출 → 직무별 AI Skill 정의
 │    산출: [산업군 × 직무군 × AI Skill × 수준] Taxonomy
 │
 └─ Step 3. Skill Gap 측정 + 우선순위 판정
      투입: Step 1 Skill Matrix + Step 2 AI Skill Taxonomy
      방법: 교차매핑 → Gap 식별 → 유지/보강/개편/신설 분류
      산출: Gap 분석표 + 과정별 대응유형 판정표 + 우선순위 매트릭스

 ★ Phase 1 핵심 의사결정:
    "25개 기존 과정 중, AI 대응이 가장 시급한 과정은 무엇인가?"
    → 판정 기준: Gap 크기 × 협약기업 수요 × 강사 확보 가능성
    → 이 판정 결과가 Phase 2의 전체 방향을 결정

 ▶ 1차 검증: 전문가 자문회의 (AI컨설팅연구소 + 산업전문가)

═══════════════════════════════════════════════════════════
 Phase 2. Design                      [7월~10월, 4개월]
 "교육체계를 어떻게 바꾸고, 5년간 어떤 순서로 실행할 것인가?"
═══════════════════════════════════════════════════════════

 ┌─ Step 4. AI 반영 교육체계 재설계
 │    투입: Phase 1 Gap 분석 결과 + 기존 3모듈 로드맵
 │    방법:
 │      수평: 산업군 분류 유지 + 직무군 축 추가
 │      수직: 산업전환 3수준 × AI 역량 3수준 교차 매트릭스
 │      각 모듈에 AI 과정 배치 (Gap 분석 기반)
 │    산출: AI 반영 교육체계 개편안
 │
 ├─ Step 5. 5개년 AI 교육 마스터플랜 수립
 │    투입: 교육체계 개편안 + 전년도 4개년 계획
 │    방법:
 │      연도별 전략 방향 (도입→확산→고도화→선도→완성)
 │      연도별 신규/개편 과정 배치
 │      소요 자원 연차별 추정

      산출: 기업 유형별 AI 교육 학습경로 가이드
```

#### 3.2 핵심 세부내용 — AI Skill Taxonomy (Phase 1의 핵심)

"바이오화학 산업에서 AI가 구체적으로 뭘 하는가?"에 대한 답:

| 산업군 | 직무 | AI Skill | 현장에서 실제로 하는 일 |
|---|---|---|---|
| **플라스틱** | R&D | AI 소재물성 예측 | 배합비 변경 시 인장강도·충격강도를 ML로 예측 → 실험 횟수 절감 |
| | 생산 | AI 불량 예측 | 사출 공정 온도·압력·시간 데이터로 불량률 사전 예측 |
| | 규제 | AI LCA 자동화 | 전과정평가 데이터 자동수집·산정 |
| **의료기기** | 규제 | AI 규제문서 자동화 | 유사제품 검색·비교분석을 NLP로 자동화 → 인허가 기간 단축 |
| | R&D | AI 임상평가 설계 | Real-world data 기반 임상평가 설계 지원 |
| **화장품** | R&D | AI 제형 안정성 예측 | 원료 조합의 안정성을 예측모델로 사전 검증 → 시험 기간 단축 |
| | 기획 | AI 트렌드 분석 | SNS·리뷰 데이터에서 선호 성분·키워드 자동 추출 |
| **정밀화학** | 안전 | AI 위험성 평가 | 화학물질 데이터 기반 위험성 예측 + 공정 이상징후 탐지 |

→ 이런 수준의 구체성이 있어야 **"바이오화학에서 AI가 뭘 하는지 진짜 안다"**는 인상
