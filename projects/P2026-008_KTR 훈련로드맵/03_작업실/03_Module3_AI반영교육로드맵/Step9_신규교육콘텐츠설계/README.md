# Step 9. 직무 맞춤형 AI 신규 교육콘텐츠 설계

> **책임**: 조예슬 PL · 안은하 / **지원**: 허상희 (콘텐츠)
> **수행 방법**: 개발연구 / 전문가인터뷰 / 연구진회의

## 목적

2026 교육과정 개편안에 미반영된 AI 융합 스킬에 대해 AI 및 바이오화학 산업 전문가와의 협업을 통해 실습 중심 신규 교육 콘텐츠 설계.

## 수행 내용

1. **AI 융합 스킬 반영 여부 검토** (Step 4 융합 스킬셋 대비)
2. **신규 과정 설계**
   - 과정명
   - 교과목
   - 교육내용
   - 개발 시기 (2027 / 2028 / 2029 — 마스터플랜 정합)
3. **산업 전문가 협업**으로 실습 시나리오 구체화

## 신규 과정 설계 구조 (제안서 §Step 9 예시)

| 항목 | 내용 |
|---|---|
| 구분 | R&D / 생산관리 / QA·QC / ESG / 기획 |
| AI 융합 스킬셋 | (예) AI 기반 신소재 개발 |
| 과정명 | AI 활용 신소재 특성 분석 및 개발 방향 도출 실무 |
| 교과목 | ① 소재 데이터 수집·정제 ② AI 기반 소재 특성 비교분석 ③ 실험데이터 인사이트 도출 ④ 제품 적용 가능성 평가 |
| 개발 시기 | 2028 |
