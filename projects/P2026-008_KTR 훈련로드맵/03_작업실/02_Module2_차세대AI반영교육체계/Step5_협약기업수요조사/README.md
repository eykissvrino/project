# Step 5. KTR 협약기업 수요조사

> **책임**: 조예슬 PL / **보조**: 안은하 주임연구원
> **수행 방법**: 개발연구 / 전문가회의 / 설문조사
> **예산**: 답례품 3,000,000원 (30,000원 × 100명) — 이미 책정·확보됨

## 목적

KTR 특화 AI 융합 스킬셋(안)에 대한 협약기업 수요를 조사·분석하여 우선 개편·개발이 필요한 훈련과정 도출 및 마스터플랜·교육과정 개편 근거 확보.

## 조사 설계

| 항목 | 내용 |
|---|---|
| 대상 | KTR 협약기업 담당자 + 최근 3개년 교육 수료생 |
| 방법 | 자기기입식 온라인 설문 (서베이몽키 또는 구글폼) |
| 인센티브 | 응답자 중 랜덤 100명 3만원 상당 답례품 발송 |
| 내용 | ①기업 일반현황 ②응답자 정보 ③AI 융합 스킬별 (필요도/현업적용가능성/시급성) 평가 ④AI 융합과정 발전 방안 주관식 |

## 분석 방법 — 4사분면 매트릭스

```
                  ↑ 현업적용 가능성 평균
                  │
       [개발 검토] │  [★ 개발 1순위]
                  │
   ───────────────┼─────────────── → 필요도 평균
                  │
       [개발 제외] │  [개발·운영 시기 고려]
                  │
```

- 우선순위 = 필요도와 현업적용가능성 평균
- 시급성은 개발 시점 결정 시 별도 반영
