# Step 6. 차세대('26~'30) AI 반영 마스터플랜 고도화

> **책임**: 조예슬 PL / **자문**: 유대훈 PM (전략 자문)
> **수행 방법**: 개발연구 / 전문가회의 / 설문조사 (Step 5 결과 활용)

## 목적

수요조사 결과 및 KTR 산업전환 공동훈련센터 중장기 전략 방향을 종합적으로 고려하여 차세대 AI 반영 교육체계를 고도화하기 위한 중장기 발전 전략 수립.

## 마스터플랜 구조 (제안서 §Step 6)

### 미션
> 친환경 바이오화학 산업의 산업전환과 AX 가속화에 대응하여, 협약기업이 현장에서 바로 활용할 수 있는 직무·수준·산업 단계 기반의 실무형 인재 양성

### 목표
> KTR 산업전환 공동훈련센터를 바이오화학 산업의 친환경·AI 전환을 선도하는 교육 표준 플랫폼으로 고도화

### 3대 추진 전략 (3-Phase)

| Phase | 시기 | 추진 전략 |
|---|---|---|
| **Phase 1** | ~2026 | **AI 융합 교육체계 설계·구축** — 기존 체계·로드맵 개편 방향 / AI 역량체계·스킬셋 / AI 융합 스킬셋 / 차세대 교육체계 재설계 / AI 융합과정 개발 방향 / 단계별 이행계획 |
| **Phase 2** | 2027~2029 | **AI 융합 교육과정 확대·운영** — 신규 AI 융합과정 단계적 확대 / 협약기업 맞춤형 프로젝트형·문제해결형 / 사례·실습·도구 기반 / 산업·직무별 학습경로 / 강사 Pool 확대 |
| **Phase 3** | 2030~ | **친환경·AI 전환 교육 우수 모델** — KTR형 AI 융합 산업전환 교육 모델 표준화 / 협약기업 상시 지원형 교육 플랫폼 / 교육–현업적용–성과창출 연계 체계 내재화 |
