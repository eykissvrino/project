# Step 4. 기존 교육과정 – AI 직무역량 모델 매핑 분석

> **책임**: 이석주 책임연구원 / **연계**: 조예슬 PL
> **수행 방법**: 개발연구 / 전문가회의 / 설문조사

## 목적

KTR 기존 교육과정별 스킬을 AI 직무역량과 매핑하여 스킬별 AI 적용 우선순위와 실행 방향을 체계적으로 도출.

## 수행 내용

### 매핑 매트릭스
- 행 = 기존 25개 과정별 스킬
- 열 = AI 직무역량 스킬 (Step 3 결과)
- 표기:
  - **○** = AI 적용 가능
  - **◎** = AI 적용 권장
  - 음영 = 중장기 적용 과제 (모델/시스템 구축 필요)
  - 단색 = 단기 적용 과제 (학습 데이터 필요)
  - 무색 = 바로 적용 가능

### KTR 특화 AI 융합 스킬 도출
```
기존 과정 스킬 + AI 스킬 = KTR 특화 AI 융합 스킬

예) 친환경 화장품 브랜딩 기획 (기존 스킬)
    + AI 활용 보고서·기획서 초안 작성 (AI 스킬)
    + AI 활용 경쟁사·시장 정보 수집 (AI 스킬)
    = AI 기반 친환경 화장품 브랜딩 기획 (융합 스킬)
```

### AI 융합 스킬셋 구조
- 스킬셋 정의
- 분류 (R&D / 생산관리 / QA·QC / ESG / 기획)
- 세부 스킬
- 스킬 정의
