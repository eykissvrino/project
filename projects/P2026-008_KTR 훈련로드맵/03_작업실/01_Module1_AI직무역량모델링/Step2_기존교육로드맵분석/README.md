# Step 2. 기존 친환경 바이오화학 교육로드맵 분석

> **책임**: 이석주 책임연구원
> **수행 방법**: 문헌분석 / 연구진회의 / 전문가회의

## 목적

KTR 산업전환 공동훈련센터의 26년 운영 25개 과정 세부 내용을 분석하여 교과목별 핵심 스킬 도출 및 기능 단위 AI 연계 방향 검토.

## 수행 내용

1. 26년 운영 예정 25개 과정의 교과목별 내용 분석
2. 교육 내용 기반 **수행행동 중심 스킬** 도출
3. 유사 스킬 통합 → **스킬셋(Skill-set)** 구성
4. 스킬별 핵심 기능 분류 (데이터 분석·사례 수집·기획·자료 정리·시장 분석 등)
5. 기능별 AI 연계 방향 검토 (분석·생성·예측·자동화·의사결정 지원)

## 스킬 도출 원칙 (김은경 외 2024 정합)

각 스킬은 3요소 포함:
- **전문지식**: 해당 스킬 수행에 필요한 핵심 지식
- **적용 맥락**: 어떤 직무·상황에서 발휘되는지
- **행동 수준**: 실제로 할 수 있는 행위 ("~할 수 있다")
