
## 2. 4대 영역 v0.5

### 영역 1. AI 활용 정보 탐색·요약

| 항목 | 내용 |
|---|---|
| **정의** | 업무 수행에 필요한 정보·자료를 AI 도구를 활용해 효율적으로 탐색·수집·요약·정리할 수 있는 역량 |
| **핵심 활동** | 산업 동향·시장 정보·기술 자료·법령·논문 검색 / 다국어 자료 번역·요약 / 출처 검증·인용 정리 |
| **대상 직무** | 전 직무 공통 (특히 R&D, 기획, 사무·관리) |
| **AI 도구 예시** | ChatGPT, Perplexity, Claude, NotebookLM, Elicit, Semantic Scholar |
| **수준 위치** | Lv1 선제대응 단계의 기초 역량 |
| **1차 출처** | WEF New Economy Skills (Foundational Digital Skills) |

### 영역 2. AI 활용 데이터 분석·시각화

| 항목 | 내용 |
|---|---|
| **정의** | 업무 데이터를 표준화·전처리하고 AI·통계 도구를 활용해 분석·해석·시각화하여 업무 의사결정에 활용할 수 있는 역량 |
| **핵심 활동** | 데이터 표준 양식 설계 / 결측·이상치 처리 / 기초·예측 분석 / 대시보드·인포그래픽 작성 / 인사이트 보고 |
| **대상 직무** | 생산관리·품질관리·R&D·기획·마케팅·재무 |
| **AI 도구 예시** | Python(pandas, scikit-learn), Power BI, Tableau, Excel Copilot, ChatGPT Advanced Data Analysis |
| **수준 위치** | Lv2 전환 단계의 핵심 역량 |
| **1차 출처** | WEF NES (Data Skills) + 삼일PwC (품질·설비 데이터) |

### 영역 3. AI 활용 콘텐츠·문서 생성

| 항목 | 내용 |
|---|---|
| **정의** | 보고서·기획서·이메일·마케팅 콘텐츠·교육 자료 등 업무 산출물을 생성형 AI 도구를 활용해 초안 작성·고도화·다듬기 할 수 있는 역량 |
| **핵심 활동** | 보고서·기획서 초안 / 이메일 작성 / 회의록 정리 / 마케팅 카피·SNS 콘텐츠 / 교육·매뉴얼 자료 / 이미지·영상 보조 생성 |
| **대상 직무** | 전 직무 공통 (특히 기획·마케팅·교육·CS·R&D) |
| **AI 도구 예시** | ChatGPT, Claude, Gemini, Microsoft Copilot, Canva AI, Midjourney, Sora |
| **수준 위치** | Lv1~Lv2 전 직무 적용 |
| **1차 출처** | WEF FoJR (GenAI 폭증 수요) + 딜로이트 2026 (생산성 AI) |

### 영역 4. AI 협업 업무 자동화·의사결정 지원

| 항목 | 내용 |
|---|---|
| **정의** | AI 시스템과 협업하여 반복 업무를 자동화하고, AI의 분석·예측·추천 결과를 비판적으로 검토·검증해 업무 의사결정에 활용할 수 있는 역량 |
| **핵심 활동** | 워크플로 자동화 설계 / 이상감지·예측 모델 활용 / AI 추천 결과 검증 / 윤리·법적 리스크 검토 / Human-in-the-loop 운영 |
| **대상 직무** | 생산관리·품질·설비·R&D·관리자급 / 의사결정자 |
| **AI 도구 예시** | Zapier, Make, Power Automate, MS Copilot Studio, IoT 센서+AI, Cognex(검사), AutoML, AI 협업 에이전트 |
| **수준 위치** | Lv2~Lv3 정착 단계의 고도 역량 |
| **1차 출처** | WEF FoJR (Augmentation) + 삼일PwC (예측·자율 최적화) + WEF EF (현장 사례) |

## 3. 영역 간 관계 (계층·연속성)

```
Lv3 정착                    [영역 4] AI 협업 자동화·의사결정 지원
                                    ↑
Lv2 전환     [영역 2] 데이터 분석·시각화     [영역 3] 콘텐츠·문서 생성
                  ↑                                ↑
Lv1 선제대응               [영역 1] AI 활용 정보 탐색·요약
                                    ↑
                          기초 디지털 문해력 (전제)
```

**연속성 원칙**:
- 영역 1은 모든 영역의 입력
- 영역 2·3은 영역 1을 전제로 병렬 발전
- 영역 4는 영역 1·2·3을 통합한 고도화 단계

## 4. v4 초안 5개 영역과의 정합 (변경 이력)

| v4 (4월) | v0.5 (5/29) | 변경 유형 |
|---|---|---|
| 생성형 AI 업무 문서작성 | **영역3** AI 활용 콘텐츠·문서 생성 | 명칭 정렬 (콘텐츠 포함 확장) |
| AI 활용 정보 검색·요약 | **영역1** AI 활용 정보 탐색·요약 | 거의 동일 |
| 업무 데이터 표준화 | (영역2에 통합) | v4 단독 영역 → 영역2의 전제 활동으로 통합 |
| AI 도구 활용 데이터 분석 | **영역2** AI 활용 데이터 분석·시각화 | "시각화" 추가 — 분석 결과 활용까지 포함 |
| AI 기반 업무 자동화 | **영역4** AI 협업 업무 자동화·의사결정 지원 | "협업·의사결정 지원" 추가 — WEF FoJR Augmentation 반영 |

**핵심 변경**: v4의 5개 영역을 v5.0 제안서가 명시한 "4대 영역"으로 통합 (업무 데이터 표준화를 영역2의 전제 활동으로 흡수).
