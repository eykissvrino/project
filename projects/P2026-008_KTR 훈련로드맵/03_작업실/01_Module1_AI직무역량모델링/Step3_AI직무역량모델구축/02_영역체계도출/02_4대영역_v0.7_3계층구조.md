## 2. v0.7 — 4대 영역 × 책무 (책무 1차안)

### 영역 1. AI 활용 정보 탐색·요약 (Lv1, 전 직무 공통)

| 책무 | 정의 | 대상 직무 |
|---|---|---|
| 1.1 산업·시장 정보 수집 | 친환경 바이오화학 산업 동향, 경쟁사·고객·정책 정보 수집·정리 | 기획, R&D, 영업 |
| 1.2 기술·법령·논문 검색 | 신기술 동향, 관련 법령·규제, 학술 자료 발굴 | R&D, ESG, 기획 |
| 1.3 다국어 자료 번역·요약 | 영문·중문·일문 자료 번역, 핵심 요약 | 전 직무 |

### 영역 2. AI 활용 데이터 분석·시각화 (Lv2, 생산·품질·R&D·기획)

| 책무 | 정의 | 대상 직무 |
|---|---|---|
| 2.1 업무 데이터 표준화·전처리 | 흩어진 데이터 표준 양식 설계, 결측·이상치 처리 | 생산·품질·재무 |
| 2.2 데이터 분석·해석 | 기초 통계, 예측 분석, 패턴 발견 | 생산·품질·R&D·마케팅 |
| 2.3 시각화·보고 | 대시보드, 인포그래픽, 인사이트 보고 | 전 직무 (관리자급 중심) |

### 영역 3. AI 활용 콘텐츠·문서 생성 (Lv1~2, 전 직무 공통)

| 책무 | 정의 | 대상 직무 |
|---|---|---|
| 3.1 업무 문서 작성 | 보고서·기획서·이메일·회의록 초안 | 전 직무 |
| 3.2 마케팅·교육 콘텐츠 | 카피·SNS·블로그·교육 매뉴얼·영업 자료 | 마케팅, 교육, 영업 |
| 3.3 이미지·영상 보조 | 제품 이미지, 발표 슬라이드, 교육 영상 보조 | 마케팅, R&D, 교육 |

### 영역 4. AI 협업 업무 자동화·의사결정 지원 (Lv2~3, 관리자급·전략)

| 책무 | 정의 | 대상 직무 |
|---|---|---|
| 4.1 반복 업무 자동화 | 워크플로·문서 처리·데이터 수집 자동화 | 사무·관리 |
| 4.2 예측·이상감지 모델 활용 | 품질 불량 예측, 설비 고장 예측, 이상 패턴 감지 | 생산·품질·설비 |
| 4.3 AI 결과 비판적 검증·의사결정 지원 | AI 추천 결과의 한계·편향 검토, Human-in-the-loop 운영, 윤리·법적 리스크 | 관리자, R&D, ESG |

## 5. 스킬 진술문 시범 작성 (v0.7 — 1차 예시)

### 영역 1 시범 (책무 1.1)
1. 「산업 동향 분석 AI 도구(Perplexity, ChatGPT 등)를 활용해 / 친환경 바이오화학 시장 변화 정보를 / 수집·요약한다」
2. 「웹 스크래핑·뉴스 검색 자동화 도구를 활용해 / 경쟁사·고객사 동향을 / 정기 수집·아카이브한다」
3. 「AI 기반 정책·법령 검색 도구를 활용해 / ESG·환경 규제 변화를 / 모니터링한다」

### 영역 2 시범 (책무 2.2)
1. 「Python 데이터 분석 라이브러리(pandas·scikit-learn)와 ChatGPT를 활용해 / 생산 공정 데이터의 / 패턴을 분석한다」
2. 「Excel Copilot·Power BI를 활용해 / 품질 검사 데이터의 / 기초 통계를 산출하고 해석한다」
3. 「예측 모델 자동 생성 도구(AutoML)를 활용해 / 설비 고장 발생 시점을 / 예측한다」

### 영역 3 시범 (책무 3.1)
1. 「ChatGPT·Claude를 활용해 / 친환경 바이오화학 R&D 보고서 초안을 / 작성·구조화한다」
2. 「MS Copilot을 활용해 / 회의록·요약본을 / 자동 생성하고 액션 아이템을 추출한다」
3. 「프롬프트 설계 기법을 활용해 / 직무 맥락에 맞는 결과를 / 도출한다」

### 영역 4 시범 (책무 4.2)
1. 「IoT·센서 + AI 이상감지 시스템을 활용해 / 생산 설비 이상 징후를 / 조기 감지한다」
2. 「머신비전(Cognex 등)을 활용해 / 제품 외관 불량을 / 자동 분류한다」
3. 「예측 정비(Predictive Maintenance) 모델을 활용해 / 부품 교체 시점을 / 결정한다」

> **위 시범은 v0.7 작업용**. v1.0에서는 5건 본문 발췌 결과와 자문회의 1차 검증을 거쳐 확정.
