# 📥 _INBOX — 이 프로젝트 전용 임시함

이 폴더에 파일을 던져넣으면, AI가 내용을 분석해 **이 프로젝트 안의** 알맞은 폴더와
하위폴더로 분류합니다. 프로젝트는 이미 정해져 있으니(이 위치) 폴더만 판단하면 됩니다.

## 어디로 분류되나
- `00_관리` 일정·회의·브리프·계약·현황
- `01_입력자료` 고객이 준 원본
- `02_지식리서치` 참고·조사·분석
- `03_작업실` 작업 중 초안
- `04_산출물` 고객에게 갈 최종본
- `05_보관` 옛 버전·폐기
(없는 하위폴더는 규칙대로 자동 신설)

## 쓰는 법
1. 파일을 이 폴더에 넣는다.
2. 클로드에게 **"여기 분류해줘"** / **"이 프로젝트 인박스 정리해줘"**.
3. 확신 건은 자동 이동, 애매하면 질문 → 모든 이동은 기록(되돌리기 가능, 삭제 안 함).
